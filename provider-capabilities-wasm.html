Rustic Maps SDK

Provider capabilities on WebAssembly

WebAssembly exposes the browser surface: live provider calls over fetch, a styled vector base painted by the canvas, the offline routing archive, and the navigation driving core. It has no native view and no disk cache. This page lists the registry’s providers, the public JavaScript calls each capability uses, and the code that switches a base map or registers a provider.

What you need

  • A Chromium-based browser with WebGPU, and the WebAssembly package served from the page’s own origin over HTTPS or localhost.
  • A provider credential only for the live provider APIs. Read it at runtime; never place it in the bundle.

There is no reverse-geocoding export, no disk tile cache, and no host-implemented provider registration on this surface. Calls reject with the provider’s verbatim message when no provider is registered or the provider refuses.

Switch the base map

A styled vector base

The registry’s keyless vector base for OpenFreeMap is Bright. Install it on the canvas; every following frame draws the styled base beneath your overlays.

mapView.setVectorTileSource({
  urlTemplate: 'https://tiles.openfreemap.org/planet/latest/{z}/{x}/{y}.pbf',
  sourceName: 'openfreemap',
  attributionText:
    'Map data © OpenStreetMap contributors (ODbL) · style Bright from OpenFreeMap styles, design CC BY 4.0',
  styleId: 'bright-light',
  minimumZoomLevel: 0,
  maximumZoomLevel: 14,
});
const status = mapView.vectorTileSourceStatus();

While a vector source is installed, the canvas hides the raster layer and paints the style’s own background. The status readback reports whether a source is configured, the style id, the source name, the attribution line, the zoom ceiling, and the last frame’s drawn and failed tile counts. A failed count above zero with a lastFailureDetail means the tileset refused some tiles; the base stays installed and the next frame retries.

The install is refused while a frame is resolving. Call it outside renderFrame, or retry after the frame settles. Return to the raster layer with clearVectorTileSource().

mapView.clearVectorTileSource();

The raster fallback

The canvas draws its same-origin recorded tiles first. A registry raster template supplies a live fallback for addresses those tiles do not cover; a registered live provider is consulted before the template.

mapView.setRasterTileSource(
  'https://tile.openstreetmap.org/{z}/{x}/{y}.png',
  19,
);

The template must carry {z}, {x}, and {y}; the maximum zoom level must be between 1 and 24. A blank template clears the fallback.

Register a provider

Provider registration is a free call whose first argument is the provider key from the shared registry. The credential lives in module memory only; it is never persisted or logged.

import init, { MapsSdk, registerProvider } from './web/map_web_bindings.js';

await init();
const mapSdk = await MapsSdk.create();
registerProvider('mapquest', providerCredential);

registerProvider dispatches the key to a provider implementation compiled into the WebAssembly module. A key with no compiled provider is refused with a message naming the key. clearProvider() removes the registration; the page then answers from recorded data and the raster fallback.

A refused credential or a key with no dispatch arm throws with the verbatim detail. Apply the credential through a settings form or a test’s runtime environment; never compile it into the bundle.

What you should see

After the vector install, vectorTileSourceStatus() reports a configured source with the bright-light style id and the OpenFreeMap source name. After registerProvider, the live calls resolve; before it, they reject with the registration refusal. The canvas keeps drawing the keyless base and its recorded tiles in either case.

Constraints

  • The module must be initialized and MapsSdk.create() resolved before a MapView is constructed.
  • The browser surface has no reverse geocoding, no tile cache, and no host-implemented provider registration. A provider that needs those contracts is a compiled provider crate, covered in Add a provider.
  • MapView.setVectorTileSource refuses while a frame is resolving; retry after the frame settles.
  • Tests never reach the network. Recorded tiles and provider responses are served from the page’s own origin.
