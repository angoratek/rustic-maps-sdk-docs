Source
Expand description

The UniFFI binding crate of the SDK: objects, records, callback interfaces and the UDL contract consumed by Kotlin, Swift and uniffi-bindgen-react-native. The WebAssembly target uses a hand-maintained TypeScript surface checked against the same UDL.

The crate exposes the anchored camera::MapCamera and its free projection helpers, the async provider surface over provider::MapSdk, the foreign-callback provider contracts (foreign_providers), the navigation controller (navigation), the map surface view and its platform pointer lowering (surface_view, platform_surface), the simulated-trip seam (simulation) and the device-positioning controller (positioning). The diagnostics surface (diagnostics, provider_diagnostics) reports SDK log events and failed foreign provider calls.

The UDL dictionaries are mirrored by the value structs in records: FFI traits cannot be implemented for foreign-crate types, so binding records convert to and from the geospatial-types and rustic-maps-rendering types through explicit constructors and the projection validation helpers. error::SdkError mirrors the geospatial-types SDKError subset these calls produce.

Every exported async method hands reactor-dependent work (the reqwest provider futures, the surface draw’s tile fetches) to a crate-owned tokio runtime through [runtime::drive], so a foreign executor polls only a runtime-independent handback future.

The engine facades (engines: SearchEngine, RoutingEngine, OfflineManager, Diagnostics) construct typed capability objects over an existing MapSdk and delegate every member to it. The offline routing seam (offline_routing) exposes the contract’s offline_route_from_archive_bytes function: archive bytes in, a route out, over the same rustic-maps-core implementation the WebAssembly export uses.

Every exported entry point of this crate (and every callback invocation inside an exported frame) is panic-contained by the UniFFI 0.31.2 scaffolding itself; crate::panic_boundary documents the containment map, which is why this crate adds no redundant catch_unwind layer of its own, and holds the crate’s unwrap/expect policy for FFI-reachable code.

Modules§

camera
The UniFFI-facing anchored camera, wrapping rustic-maps-rendering’s camera; the validation the core leaves to callers happens on every binding call, so the binding surface can only ever receive validated camera state.
diagnostics
The diagnostics sink: the SdkDiagnosticEventListener foreign-callback contract foreign code implements to receive the SDK’s structured internal log events, plus the ring-buffer tracing subscriber and the sink’s privacy scrubbing behind MapSdk::subscribe_to_diagnostic_events and MapSdk::flush_recent_diagnostic_events.
engines
The engine facades: typed capability objects constructed over an existing MapSdk.
error
The error model of the native binding surface: a fielded mirror of the geospatial-types SDKError variants the contract’s calls can actually produce, carrying their verbatim detail messages across the FFI.
foreign_providers
The foreign-callback provider injection surface: the exported callback contracts that foreign code (Kotlin, Swift) implements to serve a provider contract of the SDK, and the adapters that bridge those implementations onto the native geospatial-traits traits behind the rustic-maps-core ProviderRegistry.
navigation
The navigation wiring surface: the NavigationListener foreign-callback contract foreign code implements to observe the navigation state, the Navigator driving a native rustic-maps-navigation session behind it, and the policy records configuring the controller’s step-advance and deviation strategies.
offline_routing
The offline routing graph seam of the native contract: archive bytes in, a route out, over the same rustic-maps-core engine the wasm surface uses.
panic_boundary
Panic containment at the FFI edges
platform_surface
The platform window-handle lowering onto wgpu’s unsafe surface target: native-only, like the surface renderer it feeds. The per-platform lowering of the exported crate::records::SurfaceHandle into a wgpu::SurfaceTargetUnsafe: the seam rustic-maps-rendering’s surface renderer deliberately leaves open. Each supported platform compiles its own guarded branch (macOS on the host, iOS and Android only under their cross targets); every other target refuses at the boundary instead of guessing which pointer to read.
positioning
The contract’s device-positioning controller.
projection
The free projection helpers of the binding surface, mirroring rustic-maps-web-bindings’ namespace functions one-to-one, plus the input validation they and the camera calls share.
provider
The UniFFI-facing async provider surface: one MapSdk object resolving the implemented geospatial-traits contracts through the rustic-maps-core ProviderRegistry, one exported async method per contract call mirroring the trait surface one-to-one.
provider_catalog
The provider catalog: which provider keys this build carries, the capabilities each serves, and the construction call for each.
provider_diagnostics
The provider-failure diagnostic seam: the bounded per-MapSdk ring ProviderFailureDiagnosticsRing recording every failed foreign-callback provider call, read back through MapSdk::latest_provider_failure_diagnostics.
records
The binding-surface records of the UDL contract (src/rustic_maps.udl).
runtime
The crate-owned async runtime: the executor seam of the exported [Async] surface.
simulation
The simulated-trip contract seam: the immutable RouteSimulator over one planned route.
surface_view
The native surface view over rustic-maps-rendering’s surface renderer. The exported map surface view: the FFI face of the rustic-maps-rendering surface renderer, attaching a platform window surface, driving its lifecycle and drawing camera-tiled frames with the overlay list over them.
