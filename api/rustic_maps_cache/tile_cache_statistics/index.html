Module tile_cache_statistics 

Source
Expand description

Exact tile payload cache hit and miss accounting over one shared store.

The installed raster-tile wrapper and the vector base’s payload cache read the same response store: the settings surface’s tile cache is the one database both bases fetch through. TileCacheStatisticsCounters is the single counter pair every view of that store records into, and CountingCachedResponseStore is the store view that records it — both bases consult lookup_response, so both count through the same seam.

Style resources (the style document, glyph ranges and sprite sheets) also live in the same database but are not tile payloads: the style client keeps the plain store view, so those lookups never pollute the tile counters.
