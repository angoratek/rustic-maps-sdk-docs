Turn-by-turn navigation for a planned route.

The crate is a pure event reducer: reduce_navigation_event maps NavigationEvents onto a NavigationSession without touching the network, the clock or the GPU. Each location fix is judged for deviation (deviation), snapped onto the route geometry (geometry), and evaluated against a pluggable StepAdvanceCondition. When the driver leaves the route, the caller supplies a replacement route through NavigationEvent::RerouteProvided and the reducer swaps it in. NavigationPhase moves through Navigating, OffRoute and Arrived; OffRoute is a pause the driver can recover from by returning to the route.

Supporting modules compose the user-visible output:

  • instruction turns a trip state into plain-data banner and text-to-speech payloads.
  • observer delivers state changes to per-topic subscribers with explicit cancellation.
  • reroute applies a time-and-distance hysteresis before signalling that a recalculation is due.
  • speech decides when a spoken instruction is announced.
  • course_filtering turns a raw fix course into the trip’s reported course.
  • recorder optionally keeps a bounded log of fixes and state changes for diagnostics.
  • route_walk walks a route at a fixed pace for simulated trips.

The reducer is synchronous and deterministic: the same event history always produces the same session state. Time is supplied by the caller in the events, and nothing here spawns a thread or performs I/O.
