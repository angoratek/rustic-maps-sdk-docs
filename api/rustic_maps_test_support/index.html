Fixtures the workspace’s test suites share.

Test targets across the workspace build the same handful of fixtures: a geographic coordinate at a pose, a viewport, the downtown Sacramento anchor and a demo camera. This crate holds each one once, so a change to a fixture is a single edit and every suite keeps agreeing on the values.

The crate is development-only: it declares publish = false, every dependent lists it under [dev-dependencies], and it never enters a published crate’s dependency graph.

Two coordinate constructors exist because the suites depend on both behaviours. coordinate builds the record directly, so a test can hand an out-of-range value to the validator under test; validated_coordinate rejects out-of-range input the way the production constructor does. The binding-surface record has no constructor here on purpose: this crate must not depend on the native binding crate, whose exported symbols cannot be linked twice into one test target. Its contract tests build that record through their own shared test module.

Constants§

SACRAMENTO_CAMERA_ZOOM_LEVEL
Zoom level of the Sacramento demo camera, as a floating-point camera level; the tile address uses the same level as SACRAMENTO_TILE_ZOOM_LEVEL.
SACRAMENTO_LATITUDE_DEGREES
Sacramento’s latitude in decimal degrees: the California State Capitol and Capitol Park in downtown Sacramento, the anchor every demo scene uses.
SACRAMENTO_LONGITUDE_DEGREES
Sacramento’s longitude in decimal degrees, the other half of the demo anchor.
SACRAMENTO_TILE_X
Tile column of the Sacramento anchor at zoom 14.
SACRAMENTO_TILE_Y
Tile row of the Sacramento anchor at zoom 14.
SACRAMENTO_TILE_ZOOM_LEVEL
Zoom level of the Sacramento tile address: the level the demo scenes schedule their committed tiles at.
