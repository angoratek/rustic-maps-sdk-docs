OfflineRoutingNetworkGraph archive format: records, deterministic writer and validating in-memory reader.

The container story lives in the crate root (crate). This module holds the format constants, the packed record types, the builder that emits bytes deterministically, and the reader that validates every load against the typed corruption model (SDKError::OfflineRoutingFailure). The memory-mapped zero-copy reader is deliberately out of scope here: milestone M7 slice 2 adds it beside this in-memory implementation.

§Archive layout (format version 1)

All integers little-endian:

  0  magic "RMOG"                                       4 bytes
  4  format version (u32)                               4 bytes
  8  table-of-contents entry count (u32)                4 bytes
 12  table-of-contents entries (48 bytes each):
       resource name  : 32 ASCII bytes, NUL-padded
       resource offset: u64 (multiple of 8)
       resource length: u64
then the resource payloads, in canonical order, optionally separated by
up to 7 unnamed alignment-padding bytes (written as zero).

Canonical resources and record widths:

resourcerecord widthpayload
nodes8coordinate records
edges20directed edges
lane_guidances8lane guidance
instruction_stringsblobUTF-8 text bytes
instruction_lookup_indices4instruction_strings byte offsets, one per turn restriction (INSTRUCTION_ABSENT_INDEX = no text)
turn_restrictions16restricted turns

The edge encoded_value column packs the GraphHopper-style encoded values: bits 0..3 RoadClass, bits 3..8 speed cells (SPEED_QUANTUM_KILOMETERS_PER_HOUR km/h per cell), bit 8 forward access, bit 9 backward access, bits 10..32 reserved (must be zero).

Structs§

EdgeProperties
Speed, road class and direction-access columns of a directed edge, before packing.
EdgeRecord
A directed edge. Distance and duration are plain full-width columns; class, speed and access ride the packed encoded_value column (the GraphHopper encoded-values pattern, docs/research/modern-sdk-inspiration.md §B.3, keeping the routing hot path branch-free).
LaneGuidanceRecord
Precomputed lane guidance for an edge. The record carries a per-edge lane count only — and that is exactly why the OSMPBF compiler emits none (see compiler.rs): OSM turn:lanes expresses which maneuvers each lane permits (e.g. through|through|right), while the SDK’s step-level LaneGuidance carries permitted_directions per lane. A counts-only record can represent neither, so any production from today’s tags would either drop the turn information or fabricate a “recommended” lane. The resource stays empty (and the format byte-stable) until the lane-geometry slice extends the layout.
NodeRecord
Quantized node position. Coordinates are stored as fixed-point whole-COORDINATE_QUANTUM_PER_DEGREE offsets so every record stays a plain integral column.
OfflineRoutingNetworkGraph
A validated in-memory OfflineRoutingNetworkGraph archive.
OfflineRoutingNetworkGraphBuilder
Assembles all archive resources and encodes them deterministically.
TurnRestrictionRecord
A restricted turn: from one directed edge, through a node, onto another.
