The compiler pipeline: OpenStreetMap PBF extract → deterministic [OfflineRoutingNetworkGraph] archive bytes.

§Determinism contract

Two runs over the same PBF produce byte-identical archives. The ordering rules that make this true:

  • nodes keep their surviving graph nodes in ascending OSM node id order;
  • edges sort by (source_node_index, target_node_index, originating OSM way id);
  • lane guidance records (none emitted — see LaneGuidanceRecord’s documentation for the schema refusal) would sort by edge index;
  • turn restrictions sort by (from_edge_index, via_node_index, to_edge_index), and instruction strings are emitted in that same restriction order;
  • the writer’s canonical resource order and zero-filled alignment gaps are fixed in crate::archive.

§Slices

The pipeline collects nodes, drivable ways and restriction relations in one sequential pass ([profile] applies the routing rules), then resolves graph topology and restrictions in memory. Scale limits are a documented M7 slice-2 seam: everything is held in memory (metro-scale extracts only) and unresolved restrictions are skipped rather than failing the compile.
