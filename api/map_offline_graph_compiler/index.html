Crate map_offline_graph_compiler

Expand description

Offline routing network graph compiler.

This crate compiles OpenStreetMap (PBF) extracts into the binary OfflineRoutingNetworkGraph archive defined by PRD.md §4.6: nodes, directed edges with encoded speed/road-class/access columns, lane guidance, instruction strings with lookup indices, and turn restrictions. It is a maintainer/CI tool, never shipped inside the SDK, and stays native-only: its osmpbf reader is not wasm-viable.

§Crate split (recorded 2026-10-29, milestone M7 slice 5)

The archive format — reader, writer and the native mmap consumption seam — lives in the wasm-viable map-offline-graph-archive crate (see its crate docs for the container-format decision), because the SDK’s OfflineRoutingProvider consumes compiled archives as in-memory bytes on every target. This crate therefore depends on it and re-exports its archive module for produce-side path stability:

  • it holds the container-format decision and the archive layout docs;
  • it carries the native mmap reader (mmap_reader lives there, cfg-gated to non-wasm targets);
  • its validating reader answers both the compiler’s own fixture byte-equality guard and map-core’s in-memory and mapped-file load paths.

The compiled fixture and its guarded regeneration seam live in tests/common here; the format itself is unchanged wherever its modules physically live.
