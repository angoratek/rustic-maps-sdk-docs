Module cached_providers 

Source
Expand description

Cache-then-network wrappers around the provider contracts.

Each wrapper implements a geospatial_traits contract by delegating through map_core::execute_cache_then_network with a fingerprint built from the request arguments. The wrapped provider is only contacted on a cache miss, making network and cache-hit behavior indistinguishable to callers — the trait-agnostic wiring called for by PLAN.md M2.
