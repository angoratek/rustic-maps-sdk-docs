Module sqlite_store 

Source
Expand description

SQLite-backed implementation of map_core::CachedResponseStore.

One shared cache database serves every response category; lookups, entries, and eviction are keyed by request fingerprints prepared by the callers. Writes run through a pool of WAL-mode connections, guarded by BEGIN IMMEDIATE + SAVEPOINT so a failed upsert leaves the database untouched. After every write the store evicts least-recently-used entries until the total payload size fits the resolved CacheQuota budget.
