Expand description

SQLite-backed request/response cache for the Maps SDK (PLAN.md M2):

  • RequestDescriptor fingerprints: SHA-256 over order-independent normalized request parameters, category-tagged (geocoding:<hex>).
  • ResponseCategory: per-category default TTLs with per-call override.
  • SqliteResponseCache: pooled WAL-mode connections, SAVEPOINT-guarded writes, lazy TTL expiry, and least-recently-used eviction under a CacheQuota of absolute bytes and/or a share of free disk space.
  • cached_providers: cache-then-network wrappers around every geospatial_traits provider contract.
  • tile_packs: the PRD FR-F tile-pack manager over the same store — region selection, download, honest per-region on-disk reporting and explicit per-pack eviction, with pack tiles pinned against ordinary LRU eviction while their pack record exists.
