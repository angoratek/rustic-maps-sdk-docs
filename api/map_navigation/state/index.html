The plain-data navigation state record produced by the reducer.

TripNavigationState is the exported half of the navigation model: it holds only serializable data (indices, distances, a snapped coordinate), never the live StepAdvanceCondition or DeviationDetector instance. Both live beside the state in a NavigationSession, mirroring how Ferrostar pairs NavState’s plain trip state with its controller-owned conditions; that keeps this record safe to expose through UniFFI in a later slice.
