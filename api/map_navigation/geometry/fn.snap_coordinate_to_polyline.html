pub fn snap_coordinate_to_polyline(
    coordinate: &GeographicCoordinate,
    shape: &[GeographicCoordinate],
) -> Option<PolylineSnap>
Expand description

Snaps a position fix onto a polyline by projecting it onto every segment and keeping the closest projection.

Returns None when the shape has no coordinates at all. A single-point shape snaps to that point. Projections are clipped to the segment (a position fix beyond a segment end snaps to the endpoint); see the module documentation for the projection model.
