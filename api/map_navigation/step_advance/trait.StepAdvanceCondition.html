Expand description

Decides when the reducer moves from the current step to the next one.

Implementations must be Send and Sync because Arc’d conditions are shared with platform wrappers and worker threads.

fn fresh_instance(&self) -> Arc<dyn StepAdvanceCondition> ⓘ

Returns the same configuration with any internal state reset.

The reducer installs this instance whenever it advances, so internal progress (fix counters, entry/exit flags, and so on) cannot leak from one step into the next; see the module documentation for why the reset prevents rapid double-advance.
