Expand description

Defensive ceiling, in steps, on how many hops a single position fix may advance through in the multi-step advance loop.

The loop’s real terminators are the advance condition itself (a Remain verdict ends the walk) and the trip’s arrival on the final step, so the bound is not what makes the loop safe — it exists to guarantee a bounded response even against a pathological condition that advances on every consult (any real fix is unboundedly faster than such a condition could run out of steps). It is set far above any legitimate fix-to-step skip: the stack-safety fixture in this module replays a 1,000-step route with a single huge jump and stays well inside it, as does any recorded trace at the reference applications’ 50× replay acceleration.
