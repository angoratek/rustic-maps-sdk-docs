Crate map_navigation 

Source
Expand description

Turn-by-turn navigation: a pure-functional state machine (Navigating ⇄ OffRoute → Arrived, rerouting via explicit route-swap events), route-progress snapping, pluggable step-advance conditions (including Or/And combinators), and deviation detection.

A pure event reducer (reducer) maps NavigationEvents onto NavigationSessions: location updates are judged for deviation (deviation), snapped (geometry), and evaluated by the StepAdvanceCondition seam (Ferrostar’s pattern, leaner); a reroute is the caller’s RerouteProvided event replacing the route. Turn-by-turn instruction composition (instruction) turns a trip state into the plain-data payload a UI banner or a text-to-speech engine consumes, and per-topic observers with explicit subscription cancellation (observer) deliver it Mapbox-style. The reroute-recalculation hysteresis (reroute) gates the recalculation signals a fully off-route excursion raises (Ferrostar’s mechanism). Programmatic step advance and the foreign-wiring of the listener surface into the frozen UDL contract remain later slices.

Implemented in milestone M6 (online) per PLAN.md; offline navigation lands in M7.
