) -> Option<f64>
Expand description

Computes the effective course of one processed fix under the trip’s course filtering.

raw_course_heading_degrees is the fix’s own reported course; snapped_bearing_degrees the route line’s bearing at the fix’s snapped position (per [PolylineSnap::bearing_degrees]); previous_course_heading_degrees the effective course currently on the trip’s state, retained when nothing newer can be reported (the snapped-position retention rule). None on either source means “not reported here”.
