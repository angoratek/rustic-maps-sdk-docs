Struct DistanceDeviationDetector 

Source 
pub struct DistanceDeviationDetector {
    pub deviation_threshold_meters: f64,
}
Expand description

Flags a deviation when the raw fix is farther from the remaining route line than the configured threshold, widened by the fix’s reported accuracy.

The shipped default detector; see the module documentation for the widening rule and the deliberate absence of hysteresis.

Fields§

§deviation_threshold_meters: f64

Distance, in meters, from the remaining route line beyond which a fix is judged off route (before any accuracy widening, strictly greater).
