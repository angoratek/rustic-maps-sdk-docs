Expand description

Decides for each position fix whether the trip has left the route.

Implementations must be Send and Sync because Arc’d detectors are shared with platform wrappers and worker threads, exactly like the step-advance conditions.

fn fresh_instance(&self) -> Arc<dyn DeviationDetector> ⓘ

Returns the same configuration with any internal state reset.

The shipped detector is stateless, so this is a re-construction of the configuration, but the contract is uniform so the reducer can reset a future stateful detector when the route context changes (for example on crate::reducer::NavigationEvent::RerouteProvided) without knowing its internals.
