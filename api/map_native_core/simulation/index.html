The simulated-trip contract seam (M27): the immutable RouteSimulator over one planned route.

The traversal mathematics lives in map-navigation’s map_navigation::RouteWalk so the browser demo and every native shell share one implementation; this module only lowers the binding records onto it and maps its refusals onto the contract’s SdkError::InvalidNavigationInput. The SDK carries no pacing policy: the caller constructs the SimulatedTripPace it wants.
