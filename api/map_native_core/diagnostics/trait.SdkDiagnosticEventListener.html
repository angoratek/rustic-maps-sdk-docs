Expand description

The exported SdkDiagnosticEventListener contract: foreign code implements it to receive the SDK’s structured internal log events — either streamed live (through MapSdk::subscribe_to_diagnostic_events, which also lowers the sink’s severity gate) or replayed from the bounded recent-events rings (through MapSdk::flush_recent_diagnostic_events). Callbacks are fire-and-forget: the sink cannot fail on a listener’s failure, and a listener emitting its own events is not recursed into.

Coordinates in event messages are rounded at the sink to DIAGNOSTIC_COORDINATE_DECIMALS decimals; the API key never appears in a message.
