The exported surface view: draws the camera-driven tiled map plus the overlay list onto the attached platform surface.

pub fn attach( &self, surface_handle: SurfaceHandle, width_pixels: u32, height_pixels: u32, ) -> Result<(), SdkError>

Attaches the platform surface (attach’s documented UDL method), building the whole drawing machinery — surface target, renderer, configured extent, tile scheduler — before installing it, so a busy slot races nothing. Attaching an attached view is refused.

pub fn resize( &self, width_pixels: u32, height_pixels: u32, ) -> Result<(), SdkError>

Reconfigures the surface to the new physical-pixel extent (both non-zero). Works while a fetch is in flight — the scheduler is not touched — and surfaces the busy state only against an active render.

Source

pub fn detach(&self)

Detaches (detach’s documented UDL method): releases the surface state until the next attach. Idempotent, safe against a draw still in flight — the draw’s restore honors the detached slot and drops the state without reinstalling it (see [SurfaceSlot::Busy]).

Source

pub fn set_overlays( &self, overlay_descriptors: Vec<MapOverlay>, ) -> Result<(), SdkError>

Replaces the drawn overlay list in one call. Validating the whole list first keeps the previous list in force when any descriptor is invalid — the wasm canvas’ all-or-nothing semantics. This bulk call replaces the whole drawn list, including overlays added through add_overlay, and drops the addressed bookkeeping (the UDL’s documented interaction): identifiers returned before this call no longer address anything.

Source

pub fn add_overlay(&self, overlay: MapOverlay) -> Result<String, SdkError>

Adds one overlay and answers the generated identifier that addresses it. Validation is set_overlays’ all-or-nothing validation for the single descriptor: a refused descriptor throws, adds nothing and consumes no identifier.

Source

pub fn update_overlay( &self, overlay_identifier: String, overlay: MapOverlay, ) -> Result<(), SdkError>

Replaces the overlay the identifier addresses, keeping its draw position. Validating the descriptor before touching the store keeps the previously addressed overlay in force when the descriptor is invalid; an identifier that addresses nothing throws with a precise detail.

Source

pub fn remove_overlay(&self, overlay_identifier: String) -> bool

Removes the overlay the identifier addresses and answers whether that identifier was present. An unknown identifier is not an error.

Source

pub fn clear_overlays(&self)

Clears the whole drawn overlay list — the bulk list and every addressed overlay — so following frames draw the tiles alone until set_overlays or add_overlay supplies new content.

Source

pub fn set_location_indicator( &self, state: LocationIndicatorState, style: LocationIndicatorStyle, ) -> Result<(), SdkError>

Sets the single location layer drawn as the frame’s third pass (set_location_indicator‘s documented UDL method), replacing any earlier state. Validating both records before the store keeps the earlier indicator in force when either is invalid — set_overlays’ all-or-nothing semantics.

Source

pub fn clear_location_indicator(&self)

Clears the location layer; following frames draw tiles and overlays alone until set_location_indicator supplies new state.

Source

pub fn is_frame_settled(&self, camera: Arc<MapCamera>) -> Result<bool, SdkError>

Reads whether the view’s presented state would not change if another frame drew right now (is_frame_settled’s documented UDL method): the camera equals the last drawn camera exactly, the overlay list, location layer and vector base source are unchanged since that draw, and the last frame resolved no pending pixels (raster or vector base). A pure query — it never draws, fetches or mutates state. It answers false while a draw is in flight (the presented state is then changing) and before a frame has ever drawn, and throws when the view is detached.

Source

pub fn set_vector_tile_source( &self, source: UrlTemplateVectorTileSource, ) -> Result<(), SdkError>

Installs a vector base map (set_vector_tile_source’s documented UDL method, M22): the source’s URL template, descriptor and style id build the shared VectorBaseScheduler the draw resolves every frame, and replace any base already installed. The whole source builds before the slot moves, so a refused call (a malformed template, an inverted zoom range or an unknown style id) leaves the previously installed base in force. Installing while a draw is in flight is refused, because the draw owns the scheduler for its duration.

Source

pub fn clear_vector_tile_source(&self) -> Result<(), SdkError>

Removes the vector base map (clear_vector_tile_source’s documented UDL method, M22): following frames draw raster tiles and overlays alone. Like installing, clearing while a draw is in flight is refused.

Source

pub fn vector_tile_source_status(&self) -> VectorTileSourceStatus

Reads the vector base source’s status (vector_tile_source_status’s documented UDL method, M22): the installed source’s style, name, attribution and zoom ceiling plus the last resolved frame’s drawn and failed tile counts. A pure query that never throws; with no source installed it answers an honest not-configured status.

Source

pub async fn draw( &self, camera: Arc<MapCamera>, ) -> Result<FrameStatistics, SdkError>

Draws one frame for the camera (draw‘s documented UDL method): lists the camera’s visible tiles, resolves them straight from the pool’s state (no await on the network), plans the detached warm fetch of the misses — the visible set plus the prefetch planner’s ahead ring — and spawns it fire-and-forget through the crate-owned runtime, then renders tiles, overlays and the location layer, and presents. A never-awaited frame, with pending detail arriving on later frames’ resolves (which is_frame_settled’s pump resumes on). Returns the frame’s tile and overlay statistics so the platform render loop can report exactly what a frame drew (the round-9 contract ask), and is_frame_settled can compare the pending counts. The frame’s work hands to the crate-owned runtime through [drive], together with the taken-out session and the overlay and indicator snapshots, so the poller awaits only a runtime-independent handback and then restores the session as if the frame ran locally; a panicking frame surfaces as the same panic here and leaves the slot busy until the next detach cleans it.
