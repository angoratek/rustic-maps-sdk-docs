map_native_core

Module records 

Source
Expand description

The binding-surface records frozen in the UDL contract (src/map_native_core.udl).

Records are plain value shapes on the FFI, so the mirror structs carry exactly the documented fields; the projection core’s own types (map-rendering TileKey/two-component arrays, geospatial-types coordinates) convert through the explicit constructors here, because FFI traits cannot be implemented for foreign-crate types. The async provider surface (M4 slice 3) adds the mirror enums and records of the geospatial-types provider records under the same names.
