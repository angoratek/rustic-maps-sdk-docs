map_native_core

Module navigation 

Source
Expand description

The navigation wiring surface (M6): the NavigationListener foreign-callback contract foreign code implements to observe the navigation state, the Navigator driving a native map-navigation session behind it, and the policy records configuring the controller’s step-advance and deviation strategies.

The controller owns a NavigationStateBroadcaster and the single active [NavigationSession], and feeds the broadcaster’s dispatch calls from the exported methods, so the per-topic subscription semantics, the delivery order and the outcome codes are exactly the native broadcaster’s (see map-navigation’s observer module documentation).

§What the FFI seam changes about the re-entrancy rules

The broadcaster’s own rules hold unchanged across the seam: the controller’s active-trip lock is taken only to clone state snapshots and is released before the first dispatch, so the lock is never held across a listener callback and a listener may freely call back into the controller — including Navigator::current_trip_state and subscription management. Two properties are worth naming at this seam:

  • A foreign listener calling back into a controller-providing method while a dispatch from that controller is still in flight hits the broadcaster’s single-in-flight guard and its nested dispatch is suppressed exactly as a Rust-side re-entrant dispatch would be; the state change behind the suppressed dispatch has already been applied, only its broadcast is skipped. The synchronous single-threaded callback ordering of the native seam carries over: uniffi runs these sync callbacks on the thread driving the controller call, so no cross-thread queueing is introduced.
  • A panicking (Rust-side) listener propagates out of the dispatch on the native seam unchanged: nothing is caught inside the controller. The panic still cannot unwind into foreign code — it stays inside the exported frame whose scaffolding boundary catches it (see crate::panic_boundary); foreign listeners raising exceptions take the foreign vtable’s own report, contained the same way.

§Scope

Trip progress and instructions are read-only for foreign code; the programmatic step advance is deliberately absent — the reducer has no such event yet, and the Manual step-advance policy consequently cannot be driven across this surface.

Structs§

Navigator
The exported navigation controller: drives the native reducer’s session, broadcasts every state change to the registered foreign listeners, and answers read-only state and instruction queries.
Subscription
Handle coupled to one (topic, listener) subscription of the controller’s broadcaster, or to the four-topic set add_navigation_listener registers. Cancelling is explicit and idempotent; dropping the handle does not unsubscribe.

NavigationListener
State listener contract implemented by foreign code; register its subscriptions on Navigator through the subscribe_to_* methods.
