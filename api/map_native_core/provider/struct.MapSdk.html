Struct MapSdk 

Source 
pub struct MapSdk { /* private fields */ }
Expand description

Async provider entry point of the SDK: resolves every call of the implemented provider contracts through the ProviderRegistry.

The exported methods mirror the provider contracts one-to-one; each validates its inputs (binding coordinates must be canonical degrees) and converts the native result into the binding records in crate::records. Provider registration stays native (this crate’s register_* methods).

The registry lock is taken only to clone a provider slot out of the registry; the guard never spans an await, so every exported future stays Send. Each exported method resolves its provider synchronously and then hands the call’s work to the crate-owned tokio runtime through [drive], whose returned future only awaits a completion channel — the foreign executor polls a runtime-independent handback, because the provider futures need a live reactor no foreign polling thread runs (see the runtime module).

pub fn new() -> Self

Builds the SDK with an unconfigured provider registry; the native integrator registers providers through the register_* methods before the first await call. The first construction also installs the process-wide diagnostics subscriber (round 10, the diagnostics seam); later constructions are idempotent — see crate::diagnostics.

A process is constructed once on every supported platform seam; the diagnostics state is process-global by construction.

pub fn subscribe_to_diagnostic_events( &self, listener: Arc<dyn SdkDiagnosticEventListener>, minimum_severity: SdkLogSeverity, )

Subscribes a listener to the diagnostics live stream (round 10): the listener receives every SDK event that meets its minimum severity as it is recorded, fire-and-forget. A subscription at SdkLogSeverity::Debug or SdkLogSeverity::Trace also lowers the sink’s severity gate, which starts the GPU-hot render path’s fine-grained instrumentation (the gate never raises back). Duplicate registrations deliver duplicate events (the caller’s subscription lifecycle owns the listener).

pub fn flush_recent_diagnostic_events( &self, listener: Arc<dyn SdkDiagnosticEventListener>, minimum_severity: SdkLogSeverity, maximum_count: u32, ) -> u32

Replays the most recent events the diagnostics rings recorded (round 10): at most maximum_count events oldest first, every subsystem’s ring interleaved in recording order, filtered by minimum_severity. The flush is non-destructive — the rings are never emptied, so a later flush can redeliver the same events. Delivered events are fired-and-forget, never awaited.

pub fn latest_provider_failure_diagnostics( &self, ) -> Vec<ProviderFailureDiagnostic>

Provider-failure diagnostic seam (round 12): reads the retained diagnostics of every failed foreign-callback provider call this object has served, oldest first — the failures registered foreign implementations of the [Trait, WithForeign] provider contracts threw, both the typed ones (their own SdkError throws) and the unclassified ones (failures without a mapped error, reported at the throwing call under ProviderRequestRejected). The readback is non-destructive and never mutates the ring; the ring is bounded (retaining the newest ProviderFailureDiagnostic:: PROVIDER_FAILURE_DIAGNOSTIC_RING_CAPACITY capacity). Native-registered providers do not surface here: the seam observes the foreign callback surface alone.

pub fn set_provider_credential( &self, credential: String, ) -> Result<(), SdkError>

Rounds 8 (surface slice): registers the seven native MapQuest provider implementations (geocoding, routing, distance matrix, place search, traffic incidents, traffic flow, raster tiles) constructed from the shared client with the documented MapQuest defaults — the foreign mirror of the native integrator’s register_* calls, so a single UDL call with the consumer key installs the whole provider set. Every construction failure throws with its verbatim detail; re-registration replaces the slots. Elevation stays unregistered — there is no MapQuest elevation provider — so elevation calls keep throwing ProviderNotConfigured.

Source

pub fn set_provider_credential_with_tile_cache( &self, mapquest_api_key: String, tile_cache_database_path: String, tile_cache_absolute_maximum_bytes: u64, ) -> Result<(), SdkError>

Round 9 (offline-maps demo): registers the seven native MapQuest provider implementations from one key exactly as Self::set_provider_credential, wrapping the raster-tile contract in the disk response cache opened (or created) as a SQLite database at tile_cache_database_path under an absolute byte budget of tile_cache_absolute_maximum_bytes. Cached tile responses follow the tiles category’s time-to-live (thirty days by default — the imagery-provider terms ceiling, PRD §6.7 — applied as map_cache::ResponseCategory::RasterTiles’s default); a cache miss goes to the network and back-fills the cache, so pre-warmed tiles keep rendering whenever the network is unavailable — the tile-cache substrate of the offline-maps demo.

The path must be non-empty and the byte budget positive; a cache open or quota failure throws with its verbatim detail. Re-registration replaces the slots (including the cached raster-tile slot).

pub fn register_url_template_raster_tile_source( &self, source: UrlTemplateRasterTileSource, ) -> Result<(), SdkError>

Registers a provider-neutral base map (M9’s native base-map switch): any web-mercator XYZ raster tileset that publishes a {z}/{x}/{y} URL template, served by the SDK itself with no provider crate involved — the foreign mirror of the native integrator’s register_raster_tile_provider call, so an application offers a second base map without a new binding.

The registration replaces the raster-tile slot only — every other provider slot keeps serving — and drops any installed tile cache (the cache’s terms belong to the provider that installed it, so the settings surface afterwards reports the honest TileCache not-configured error instead of another provider’s ceiling). Every declaration is validated before the slot moves, so a refused call leaves the previously served provider in place.

Source

pub fn set_raster_tile_cache_time_to_live( &self, time_to_live_seconds: u64, ) -> Result<(), SdkError>

Tile-cache settings surface (M2): overrides the installed raster-tile cache’s time-to-live, in seconds, re-wrapping the cached provider under the requested value through map_cache::CachedRasterTileProvider::with_time_to_live_seconds. A value above the installed provider’s declared terms ceiling is accepted with the ceiling clamping what the cache stores (PRD §6.7 — the ceiling bounds what the cache may retain, never a preference); Self::raster_tile_cache_terms reports the effective value. A zero value is refused: a zero time-to-live expires every entry on capture, a cache that stores nothing. Requires a tile cache installed through Self::set_provider_credential_with_tile_cache — the byte budget is registration-time (the store’s quota is fixed at open) and retunes only through re-registration.

Source

pub fn raster_tile_cache_terms(&self) -> Result<TileCacheTerms, SdkError>

Tile-cache settings surface (M2): reads the effective raster-tile caching terms so a developer can display them — the value currently in force (the category default, or the last accepted override, clamped when it exceeded the provider’s terms ceiling), the provider’s declared ceiling (None when the provider declares no ceiling; the requested value then applies verbatim), and the category default a freshly registered cache starts at. Requires a tile cache installed through Self::set_provider_credential_with_tile_cache; the readback never mutates the cache.
