Module provider 

Source
Expand description

The UniFFI-facing async provider surface (M4 slice 3): one MapSdk object resolving the implemented geospatial-traits contracts through the map-core ProviderRegistry, one exported async method per contract call mirroring the trait surface one-to-one.

Provider registration has two paths. The native integrator path stays foreign-free: the register_* methods here wrap the registry for providers built in Rust — MapQuest providers constructed from a consumer key exactly like the provider crate’s examples, or mock providers in tests. The foreign integrator path (M4 slice 4) injects implementations of the exported callback contracts through the register_*_from_foreign methods, which wrap them in the crate::foreign_providers adapters before the same registry call. Calls into an unregistered contract throw SdkError::ProviderNotConfigured with the contract name.
