The per-platform lowering of the exported crate::records::MapSurfaceTargetHandle into a wgpu::SurfaceTargetUnsafe: the seam map-rendering’s surface renderer deliberately leaves open. Each supported platform compiles its own guarded branch (macOS on the host, iOS and Android only under their cross targets); every other target refuses at the boundary instead of guessing which pointer to read.

The record’s exactly-one-pointer contract is validated once, portable: a u64 0 is a null pointer the lowering must never dereference, and so is more than one pointer, so nothing invalid reaches the unsafe surface creation. The single pointer is then re-checked for this platform’s field, so a handle built for another platform reads as a clean validation failure rather than a wrong-pointer surface (and with it undefined behavior of the kind wgpu’s unsafe surface contract rules out).
