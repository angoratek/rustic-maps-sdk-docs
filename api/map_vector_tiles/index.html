The Mapbox Vector Tile (MVT) v2.1 decoder (milestone M9, PRD.md §4 FR-D): the protobuf wire-format reader, the layer/feature/attribute model and the geometry command-stream decoder that turns fetched vector tiles into renderer-consumable structures.

The crate is pure byte parsing with zero runtime dependencies beyond thiserror, so it builds on native targets and on wasm32-unknown-unknown alike. These are internal processing types, not FFI records: nothing here appears in the frozen UDL contract, and no VectorTile bytes are trusted — every malformed input surfaces as a typed VectorTileError, never a panic or a guessed decode.

Entry point: decode_vector_tile, taking the unwrapped MVT protobuf payload (the provider seam unwraps any gzip envelope before handing the bytes over). The decoded tile carries VectorTileLayers of VectorTileFeatures whose geometries are the specification’s MoveTo/LineTo/ClosePath command stream resolved to tile-local extent coordinates.
