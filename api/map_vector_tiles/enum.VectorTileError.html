Expand description

A failure the Mapbox Vector Tile v2.1 decoder encountered while turning wire bytes into crate::decoder::VectorTile structures.

Variants§

§

TruncatedBuffer

The byte stream ended before a value this position requires.

Fields

§context: &'static str

Where in the decode the stream ended early.

§

VarintByteCountExceeded

A varint uses more than the 10 bytes a 64-bit value can occupy.

Fields

§maximum_byte_count: u32

The maximum varint byte count (10 for 64-bit values).

§context: &'static str

Where in the decode the varint was read.

§

VarintValueExceeds64Bits

A varint’s value does not fit into 64 bits (the 10th byte’s continuation payload exceeds the remaining addressable bits).

Fields

§context: &'static str

Where in the decode the varint was read.

§

InvalidWireField

A protobuf field key has field number 0 or a wire type the decoder does not recognize (0 varint, 1 64-bit, 2 length-delimited and 5 32-bit are the only valid ones).

Fields

§field_number: u32

The decoded field number.

§wire_type: u64

The decoded wire type.

§context: &'static str

Where in the decode the key was read.

§

UnsupportedWireType

A field the decoder knows about arrived with a wire type it cannot carry; such payloads would be silently misread, so they are refused.

Fields

§field_number: u32

The field number whose wire type is inapplicable.

§wire_type: u64

The inapplicable wire type.

§context: &'static str

Where in the decode the field was read.

§

LengthDelimitedOverrun

A length-delimited field claims more bytes than the buffer holds.

Fields

§claimed_length: u64

The claimed byte length.

§context: &'static str

Where in the decode the field was read.

§

InvalidUtf8

A string field the decoder reads as UTF-8 is not valid UTF-8.

Fields

§context: &'static str

Where in the decode the string was read.

§

UnsupportedLayerVersion

A layer’s version field is missing or names an unsupported MVT major version; the v2.1 specification requires exactly 2.

Fields

§found: u32

The version value the layer carried (an absent field decodes to the protobuf default of 1).

§

MissingLayerName

A layer carries no name field; the specification makes it required.

§

DuplicateLayerName

Two layers in one tile share a name; the specification makes layer names unique within a tile.

Fields

§name: String

The duplicated name.

§

TagElementCountNotEven

A feature’s tags field holds an odd number of integers; tags are key/value index pairs and must come in pairs.

Fields

§found: u64

The odd element count.

§

AttributeIndexOutOfRange

A tag’s key or value index points past its layer’s dictionary.

Fields

§index: u64

The out-of-range dictionary index.

§context: &'static str

Whether the failing index selects a key or a value.

§dictionary_size: u64

The actual dictionary size the index was checked against.

§

AttributeValueVariantMissing

A layer attribute value carries none of the seven value variants; the specification requires exactly one.

§

AttributeValueVariantConflicting

A layer attribute value carries more than one of the seven value variants; the specification requires exactly one.

§

UnknownGeometryType

A feature declares geometry type UNKNOWN (0) or a type value beyond the specification’s enum; no compliant producer emits these.

Fields

§found: u32

The type value the feature declared.

§

UnknownGeometryCommand

A geometry command integer names no command (MoveTo, LineTo, ClosePath).

Fields

§command_id: u64

The unknown command id.

§

GeometryCommandCountOfZero

A geometry command integer carries a count of 0; commands always process at least one occurrence.

Fields

§command_id: u64

The command id carrying the zero count.

§

GeometryCommandCountOutOfRange

A geometry command carries a count beyond the 29-bit range the specification’s packing admits.

Fields

§found: u64

The out-of-range count.

§

ClosePathCommandCountNotOne

A ClosePath command’s count is not 1; the specification requires exactly one occurrence per ring closure.

Fields

§found: u64

The count the command integer declared.

§

GeometryParameterStreamTruncated

The geometry parameter stream ended before the pending command’s declared parameter count was fulfilled.

Fields

§context: &'static str

Which command was waiting for parameters.

§

MultiVertexMoveToOutsidePoints

A MoveTo with a command count greater than 1 appeared inside a geometry kind that requires exactly one vertex per MoveTo.

Fields

§count: u64

The declared count.

§geometry_kind: &'static str

The geometry kind the command appeared in.

§

GeometryCommandNotAllowed

A geometry command appeared whose parameter/semantic shape its geometry kind does not allow (a LineTo or ClosePath in a POINT feature, a ClosePath in a LINESTRING feature).

Fields

§command_id: u64

The disallowed command id.

§geometry_kind: &'static str

The geometry kind the command appeared in.

§

LineToBeforeMoveTo

A LineTo appeared before the stream’s first MoveTo; there is no previous cursor vertex to continue from.

§

ZeroDeltaLineTo

A LineTo carried the (0, 0) delta, which the specification forbids (zero-length segments are not representable).

§

PolygonRingUnclosed

A polygon’s command stream ended with a ring still open (no ClosePath); polygon rings are always explicitly closed.

§

GeometryCoordinateOverflow

Accumulating a geometry coordinate’s delta overflowed the signed 64-bit cursor.

§

PackedFieldUnpacked

A geometry or tags field arrived unpacked; the specification pins both to the packed encoding, and an unpacked stream would otherwise decode to an empty geometry or attribute set silently.

Fields

§field_number: u32

The field number that must travel packed.

§wire_type: u64

The wire type it arrived with.
