Module prefetch 

Source
Expand description

GPU-free predictive prefetch planning: the bounded tile set a caller warms ahead of motion so the pool covers the camera’s next poses (the Mapbox predictive-cache pattern applied to this crate’s budget machinery).

The planner emits an ordered request list — the camera’s visible set at its tile zoom first, then the ring of tiles ahead along the bearing vector (PREFETCH_RING_TILES viewport-heights ahead), then a navigation route corridor’s tiles when navigation feeds one, then one coarser fallback zoom under everything (PREFETCH_FALLBACK_ZOOM_BELOW below the camera’s tile zoom, the MapLibre prefetchZoomDelta-equivalent of 4) — deduplicated against the pool’s contents and an already-warming set, capped at PREFETCH_MAXIMUM_CONCURRENT_FETCHES. The list feeds crate::tile_scheduler::TileScheduler::warm_tiles or its detached crate::tile_scheduler::TileScheduler::plan_warm_tiles twin, whose own per-call budget keeps the concurrent fetches bounded.

Survey calibration (see the round’s research): MapLibre wires its parent-prefetch delta to gesture progress; Mapbox’s predictive route cache precomputes the route corridor within radii. The constants here start at that calibration and are tuned by the profiling pass; the navigation-corridor entries keep exactly the road corridor warm (the offline-maps card’s live tile line displays the effect through TileFrameStatistics).

Structs§

TilePrefetchPlanner
Plans the prefetch request list for one camera pose (see the module documentation for the ring’s shape and calibration). State-free planning: the calibration constants are module level, so the planner carries no fields of its own.

Constants§

PREFETCH_FALLBACK_ZOOM_BELOW
Coarser-zoom offset of the single fallback layer under everything: the MapLibre prefetchZoomDelta default of 4 levels, expressed as the distance below the camera’s tile zoom (a zoom 14 view prefetches its tiles’ zoom 10 ancestors).
PREFETCH_MAXIMUM_CONCURRENT_FETCHES
How many prefetch request tiles the planner emits at most: the cap that keeps prefetch’s concurrent fetches bounded (the caller’s warm task applies its own per-call budget inside this).
PREFETCH_RING_TILES
How far ahead the ring reaches, in viewport-heights along the camera’s bearing vector: the survey’s first calibration of the Mapbox predictive-cache radius.
