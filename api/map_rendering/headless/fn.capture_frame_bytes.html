Expand description

Copies a rendered texture into a staging buffer honoring the 256-byte row alignment ([wgpu::COPY_BYTES_PER_ROW_ALIGNMENT]), maps the buffer, and reads it back as a tightly packed CapturedFrame, stripping the padding the alignment inserts between rows.

§Reusability

Any render-attachment texture (RENDER_ATTACHMENT | COPY_SRC, RGBA8 unorm) of any size is captured. The copy commands are encoded onto the provided encoder, which the caller has not submitted yet and which this function then finishes and submits; mapping completes through device polling — native only (see the module docs).
