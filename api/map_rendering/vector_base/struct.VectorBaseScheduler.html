The shared vector base pipeline: fetches, decodes, styles and caches one vector tileset.

pub fn served_zoom_level(&self, requested_zoom_level: u8) -> u8

The zoom level the tileset actually serves for a requested zoom level: the request clamped into the descriptor’s declared span, so a camera beyond either edge keeps a base map at the nearest served resolution. A descriptor declaring an inverted span clamps to its lower edge rather than panicking (the providers refuse such a declaration at construction; a hand-written implementor might not).

The last resolved frame’s last tile failure detail, if that frame had one. Cleared by a frame whose tiles all resolved.

pub fn set_style( &mut self, style_id: &str, ) -> Result<(), VectorStyleArtifactError>

Replaces the style with the committed artifact a style id names, keeping every decoded tile: the next frame restyles the cached tiles under the new style without fetching them again. An unknown id reports the artifact error and keeps the current style in force.

Source

pub async fn resolve_frame( &mut self, visible_tile_keys: &[TileKey], style_zoom_level: f64, ) -> VectorBaseFrame

Resolves the base map for the given visible tile addresses and camera zoom level: every missing tile is fetched and decoded once, every tile is styled at the camera zoom’s bucket (from the decoded cache when the bucket or the style changed), and the frame’s overlay primitives are returned in tile-address order. A tile that fails to fetch or decode is skipped and counted; the frame never fails as a whole.
