Module vector_style 

Source
Expand description

Minimal vector-tile styling (M9, the fill/line/circle slice): a decoded map_vector_tiles::VectorTile becomes the renderer’s existing overlay primitives — filled polygons for polygon features, polylines for line features, point markers for point features — under a small explicit style.

The style is deliberately data-only: a layer entry names the source layer, the geometry kind it paints, an optional one-attribute text filter and the paint values (RGBA, line width, marker radius). A symbol layer declares the label style a text pass will use — ordered text-field fallbacks, font stack, size stops, text and halo paint, VectorSymbolPlacement, priority and overlap — but paints no overlay primitive itself: the frame-level label pass (crate::labels) reads it and draws its text through the glyph atlas, either anchored at a point or run along a line feature (M9 slices S3 and S4). No expression language yet — that is a later slice. The committed artifact DEFAULT_VECTOR_STYLE_ARTIFACT_JSON carries the default style; default_vector_tile_style parses it and in_code_default_vector_tile_style is the documented fallback when the artifact is missing or malformed.

Polygon features paint every exterior ring with its interior rings subtracted through the overlay’s hole-aware fill (see crate::overlay::FilledPolygonOverlay), and the conversion groups its primitives into one VectorOverlayBatch per style layer, the seam a dedicated vector pipeline would consume later.

Coordinates convert from tile-local extent space (x right, y down, the MVT convention) through the tile’s web-mercator address to geographic degrees, so the overlays project exactly like every other map coordinate.
