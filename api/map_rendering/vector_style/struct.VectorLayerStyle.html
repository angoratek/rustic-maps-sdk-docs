Expand description

One style layer: source layer, painted kind, optional filter and paint, plus the zoom span and width stops the layer is evaluated at.

Fields§

§source_layer: String

The decoded layer name the style paints (water, highways, …).

§geometry_kind: VectorStyleGeometryKind

The geometry kind the style paints.

§filter: Option<VectorAttributeFilter>

An optional one-attribute text filter.

§fill_rgba: [f32; 4]

Fill RGBA (used by VectorStyleGeometryKind::Fill).

§line_rgba: [f32; 4]

Line RGBA (used by VectorStyleGeometryKind::Line).

§line_width_pixels: f64

Line width in screen pixels.

§circle_rgba: [f32; 4]

Marker RGBA (used by VectorStyleGeometryKind::Circle).

§circle_radius_pixels: f64

Marker radius in screen pixels.

§min_zoom_level: f64

The lowest zoom level (inclusive) the layer paints at; below it the layer is invisible, exactly like a MapLibre layer’s minzoom.

§max_zoom_level: f64

The highest zoom level (exclusive) the layer paints at; at or above it the layer is invisible (MapLibre’s maxzoom).

§width_zoom_stops: Vec<VectorWidthZoomStop>

The layer’s width stops, ascending by zoom. Empty keeps line_width_pixels at every zoom.

§text_field_fallbacks: Vec<String>

Ordered attribute keys a symbol layer tries for its label text: the first key the feature carries wins (name:latin, then name, then ref by default).

§font_stack: Vec<String>

The font family stack a symbol layer asks for, most preferred first.

§text_rgba: [f32; 4]

Text RGBA (used by VectorStyleGeometryKind::Symbol).

§text_size_pixels: f64

Text size in screen pixels when the layer carries no size stops.

§text_size_zoom_stops: Vec<VectorTextSizeZoomStop>

The layer’s text-size stops, ascending by zoom. Empty keeps text_size_pixels at every zoom.

§halo_rgba: [f32; 4]

Halo RGBA drawn behind the text (used by VectorStyleGeometryKind::Symbol).

§halo_width_pixels: f64

Halo width in screen pixels; zero paints no halo.

§placement: VectorSymbolPlacement

Where a symbol layer anchors its labels.

§priority: u32

The label’s priority rank: lower ranks are more important and draw first when two labels collide.

§allow_overlap: bool

Whether a symbol layer may draw labels that overlap other labels.

§rank_zoom_stops: Vec<VectorRankZoomStop>

Feature-rank ceiling stops of a symbol layer, ascending by zoom level. Empty means no ceiling: every ranked feature draws at every zoom.

§class_minimum_zooms: Vec<VectorClassMinimumZoom>

Per-class minimum zoom levels of a symbol layer: classes that are not useful at a wide zoom (shop, bus, …) wait until the map is closer. Empty means every class follows min_zoom_level.

pub fn maximum_rank_at_zoom(&self, zoom_level: f64) -> u32

The feature-rank ceiling the layer draws under at zoom_level: the highest-rank feature that still earns a label. The stops step rather than interpolate, because rank is ordinal; below the first stop the first stop’s ceiling applies, and a layer with no stops returns DEFAULT_VECTOR_SYMBOL_MAXIMUM_RANK (no ceiling).

Source

pub fn is_feature_class_visible_at_zoom( &self, feature_class: Option<&str>, zoom_level: f64, ) -> bool

Whether a feature of feature_class (the feature’s class attribute, when it carries one) draws at zoom_level under this layer’s per-class minimum zooms. A feature with no class, or a class no group names, is governed by the layer’s own zoom span instead.

Source

pub fn width_pixels_at_zoom(&self, zoom_level: f64) -> f64

The line width the layer paints at zoom_level: the fixed width when the layer carries no stops, the linearly interpolated stop value between two stops, or the nearest stop’s value outside the stop range.

pub fn text_size_pixels_at_zoom(&self, zoom_level: f64) -> f64
