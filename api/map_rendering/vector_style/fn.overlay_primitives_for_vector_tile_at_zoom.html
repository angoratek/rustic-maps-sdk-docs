Expand description

The same conversion as overlay_primitives_for_vector_tile, with the style’s zoom span and width stops evaluated at an explicit style_zoom_level rather than at the tile’s own zoom level.

The base-map scheduler styles a cached tile at the camera’s fractional zoom level, so a pan across a width stop restyles the already-fetched tile instead of fetching it again; the tile’s address still converts every coordinate, because the geometry belongs to the tile, not to the zoom the paint is evaluated at.
