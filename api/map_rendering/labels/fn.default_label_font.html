The SDK’s default label font: DEFAULT_LATIN_GLYPH_RANGE_PBF_BYTES decoded and packed into one atlas the first time a frame asks for it, then reused. The packed atlas rides in an Arc, so handing the font to LabelLayer::place never re-copies the page, and the renderer’s atlas upload happens once per distinct revision.

The embedded bytes are the committed fixture; should they ever fail to decode or pack (a corrupted build rather than a normal path), the documented in-code fallback is an empty font stack: every label measures no glyph and the pass paints nothing, so a map still draws instead of failing. This mirrors the vector style’s in-code fallback when its committed artifact is unreadable. A caller with another glyph source keeps using LabelLayer::place with its own LabelFont.
