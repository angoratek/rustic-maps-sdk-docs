Module location_indicator 

Source
Expand description

GPU-free location-indicator assembly: the position fix drawn as a screen-facing disc with its optional ground-projected accuracy ring and a course-directed wing, in the same clip-space stream pattern the overlay layer uses (see crate::overlay).

The indicator is the third draw layer of a frame — the explicit draw order is tiles, then overlays, then the indicator (LOCATION_INDICATOR_TOP_LAYER_DRAW_ORDER) — so the fix’s visuals always paint over route lines and polygons without the overlay list growing or reordering. The vertices reuse the crate::overlay::ClipSpaceOverlayVertex type and draw through the existing overlay solid-color pipeline (a shader/layout-identical third pass), alpha-blended over what the first two layers drew.

Layer semantics, recorded for this slice:

  • Screen anchoring. The disc and its wing are screen-space shapes anchored at the fix’s projected position — the fix’s pixel stays fixed under zoom and pan while the layers beneath move, exactly like point markers do (center anchoring, “screen-facing”). At pitch this keeps the dot legible where a ground-projected dot would foreshorten to a sliver, and the wing rotates with the camera’s bearing so a course heading reads as the same compass direction it reads on the ground.
  • The guided-course visual. LocationIndicatorVisualKind::GuidedCourseArrow draws the course wing — a cone of HEADING_WEDGE_HALF_ANGLE_DEGREES half-angle reaching LOCATION_COURSE_WEDGE_REACH_PIXELS up-course from the disc center — underneath the same disc the plain form draws; with the course unknown (None) it degrades to the plain dot. The visual is the survey’s “disc ± course cone” reading, not a separate arrow sprite.
  • Accuracy ring. A ground-projected circle of the fix’s horizontal accuracy — the honest reading of “this fix is this accurate” — drawn through the filled-polygon machinery, so it foreshortens into the ellipse the ground shows at pitch and splits at world-copy boundaries like every other ground shape. A fix more accurate than MINIMUM_ACCURACY_RING_DRAW_METERS draws no ring (a circle inside the disc itself carries no information), and an absurdly coarse fix clamps to MAXIMUM_ACCURACY_RING_DIAMETER_PIXELS on screen instead of flooding the viewport (the alternative — skipping an over-large ring — is documented for the profiling pass to revisit).
  • World copies. The screen-facing shapes anchor once per visible world-copy window like the tile spans’ fragments, so at the zoom < 1 world-copy views the indicator draws in every copy that renders the fix; the ground ring splits across windows in the polygon machinery.
  • Behind the camera. A screen-shape anchor whose homogeneous weight is not positive (the fix behind the camera plane) draws no disc or wing — the screen-space shapes’ documented skip — while the ground-projected ring still projects by genuine corners and leaves near-plane straddling to the GPU’s frustum clip.

DEFAULT_LOCATION_DISC_RADIUS_PIXELS
Default location-disc radius in screen pixels: the survey’s ≈ 11 px between its dot-puck and blue-dot defaults.

Default disc color: the accent blue of the reference app’s design language, opaque.
HEADING_WEDGE_HALF_ANGLE_DEGREES
Half-angle of the course wing’s cone, in degrees: the ≈ 50° total cone of the survey’s course-arrow reads.
LOCATION_ACCURACY_RING_FAN_SIDES
Arc resolution of the accuracy ring’s ground-space circle: 32 straight sides keep the drawn ellipse sub-pixel at the clamped diameter.
LOCATION_COURSE_WEDGE_FAN_SIDES
Arc resolution of the course wing’s cone: smooth at the wing’s small reach.
LOCATION_COURSE_WEDGE_REACH_PIXELS
Course wing reach in screen pixels, measured from the fix’s projected center: the wing extends this far up-course so it reads over and past the dot.
LOCATION_DISC_FAN_SIDES
Circle-fan resolution of the location disc: the survey’s ≥ 24 floor, so the disc reads round at every radius the style admits.
LOCATION_INDICATOR_TOP_LAYER_DRAW_ORDER
Explicit draw order of the location indicator layer: the top layer of a frame’s explicit three-layer order — tiles (0), overlays (1), the indicator (2).
MAXIMUM_ACCURACY_RING_DIAMETER_PIXELS
Screen-diameter cap of the accuracy ring: an absurdly coarse fix clamps its ring to this diameter instead of flooding the viewport.
MINIMUM_ACCURACY_RING_DRAW_METERS
Fixes more accurate than this radius (in meters) draw no accuracy ring: the circle would sit entirely inside the default disc, carrying no information.

Functions§

location_indicator_vertices
Assembles the location-indicator layer of one frame into the flat clip-space triangle list the overlay pipeline draws. A None layer (the cleared state) produces no vertices; a fix whose anchor projects behind the camera produces no disc or wing for any window, while its accuracy ring (a ground-projected polygon) still assembles with genuine corners for the GPU’s frustum clip.
