Module projection 

Source
Expand description

Web-mercator projection: geographic coordinates, normalized world space, and the XYZ tile grid.

Normalized world coordinates span [0, 1] in both axes — x grows eastward from the antimeridian, y grows southward from the north pole — so a single multiplication by zoom_scale_pixels places geometry in screen-scale units. All math stays in f64 because world units reach ~8.6e9 pixels at zoom 24, beyond f32 mantissa precision.

Reverses coordinate_to_normalized_world; longitude wraps on integer multiples of the world width and latitude clamps to the Mercator cutoffs.
