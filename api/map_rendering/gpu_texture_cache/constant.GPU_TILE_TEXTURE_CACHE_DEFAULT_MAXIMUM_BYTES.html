Default GPU byte budget, sized as a heuristic for one complete 16 × 16 tile grid of 256-px RGBA8 tiles — the payload size platform raster tile sources produce today. Budgets size the cache, not the textures: the upload path textures whatever a payload decodes to, so a 512-px payload holds half as many tiles in the same byte budget.
