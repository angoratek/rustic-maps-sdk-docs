Crate map_rendering 

Source
Expand description

wgpu rendering engine: camera model, quadtree raster tile scheduler with parent fallback and a texture pool, overlays, and later a Mapbox Vector Tile pipeline (fill/line/circle/symbol).

Implemented in milestones M3 (raster) and M9 (vector) per PLAN.md. The modules here are the GPU-free core — projection, camera, scheduling, and the quad-assembly half of renderer — so they build and test on every target including wasm; the headless wgpu renderer in headless lands on top of this slice and is native-only (see its module documentation).

Modules§

camera
Camera model: geographic center, zoom, bearing, and pitch, projected into a perspective viewport whose ground magnification matches the zoom scale.
camera_interaction
The gesture-input camera seam: the delta vocabulary a platform’s gesture recognizer speaks to the SDK (docs/ReferenceAppUX.md §5.1’s owner split — the platform owns gesture recognition, the SDK owns camera math).
gpu_texture_cache
Byte-bounded LRU cache of tiles already uploaded to GPU memory.
headless
Headless wgpu rendering of raster tiles plus deterministic frame capture.
labels
The frame-level label pass (M9 slices S3 and S4): symbol-layer text from the decoded vector tiles becomes screen-space glyph quads, anchored at a point for place and POI names and run along a line for road names.
location_indicator
GPU-free location-indicator assembly: the position fix drawn as a screen-facing disc with its optional ground-projected accuracy ring and a course-directed wing, in the same clip-space stream pattern the overlay layer uses (see crate::overlay).
overlay
GPU-free overlay assembly: route polylines, filled polygons, point markers, and traffic-flow lines projected into clip-space solid-color triangle lists drawn over the tile quads.
prefetch
GPU-free predictive prefetch planning: the bounded tile set a caller warms ahead of motion so the pool covers the camera’s next poses (the Mapbox predictive-cache pattern applied to this crate’s budget machinery).
projection
Web-mercator projection: geographic coordinates, normalized world space, and the XYZ tile grid.
renderer
GPU-free frame assembly: prepared tiles mapped to drawable quads.
surface
Surface rendering of raster tiles plus overlays onto a live native window: the same scene composition as the headless renderer, presented through a real wgpu::Surface.
tile_key
Web-mercator tile identity shared by the projection, scheduler, and pool.
tile_scheduler
Frame-driven raster tile scheduling with parent fallback.
tile_texture_pool
Least-recently-used pool of encoded tile payloads awaiting GPU upload.
vector_base
Shared vector-tile base pipeline (M22): one scheduler that fetches a vector tileset through the VectorTileProvider trait, decodes each tile once, styles it, and answers the overlay primitives the frame draws beneath its own overlays.
vector_style
Minimal vector-tile styling (M9, the fill/line/circle slice): a decoded map_vector_tiles::VectorTile becomes the renderer’s existing overlay primitives — filled polygons for polygon features, polylines for line features, point markers for point features — under a small explicit style.
