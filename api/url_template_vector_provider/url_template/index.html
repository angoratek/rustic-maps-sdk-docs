Module url_template 

Source
Expand description

Validation and expansion of the {z}/{x}/{y} URL template a tileset publishes.

The validator is shared by both tile contracts of the URL-template family — the vector source in this crate and the raster source in url-template-raster-provider — so “what a valid tile template is” has exactly one definition.

A template is accepted only when it is an absolute http/https URL carrying the three web-mercator placeholders and no placeholder this source cannot honestly expand. Everything is checked once at construction, so a fetch never builds a broken or partially substituted URL.
