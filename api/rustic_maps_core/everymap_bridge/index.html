Source
Expand description

Adapters presenting an everymap-rs provider through this SDK’s contracts.

everymap-rs owns the provider layer: the transport seam, pacing, retry, observation and the vendor integrations. The SDK’s rendering, cache and application surfaces speak the contracts in geospatial-traits, so a provider instance is wrapped in one of the adapters here before it is registered. The adapters convert records and errors only; they hold no vendor knowledge and name no provider.
