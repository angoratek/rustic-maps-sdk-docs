Expand description

Loads a compiled routing graph from in-memory archive bytes and calculates one route between two coordinates with the default request options (RouteOptions::default: automobile, fastest, metric).

The bytes are validated by the same reader as OfflineGraphSource::Memory. This function is the single implementation behind the corresponding free helper and WebAssembly export, so the native and browser surfaces cannot diverge.

§Parameters

  • archive_bytes — a complete compiled routing graph archive.
  • start, end — the route endpoints.

§Returns

A route between the two points, including geometry and steps.

§Errors

Returns SDKError::OfflineRoutingFailure when the archive is truncated, malformed or of an unsupported version. Returns SDKError::InvalidCoordinateInput when an endpoint is beyond the graph’s snap tolerance, and SDKError::ProviderRequestRejected when the graph cannot connect the two points. No coordinate or connection is guessed.

§Async

The function performs no network access and does not block on I/O beyond validating the supplied bytes.
