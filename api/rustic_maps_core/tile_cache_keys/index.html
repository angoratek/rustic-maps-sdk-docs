Module tile_cache_keys 

Source
Expand description

Stable cache keys for tile payloads.

Raster and vector tile payloads share one cache store, and nothing in a tile address says which provider or source produced the bytes. Every key therefore carries a tile_source_namespace: the provider key for a catalog provider, a stable caller-supplied key for an application provider. The namespace is part of the key, so two sources serving the same address can never read each other’s payloads.

The vector-tile key lives here rather than in the storage crate because the renderer builds the same key before handing a fetch to a store, and the renderer must stay free of a storage backend.
