Expand description

Runs one owned blocking job away from the async reactor.

Implementations must not run work before the returned future is polled; they decide where it ultimately executes.

fn run_blocking( &self, work: Box<dyn FnOnce() -> Box<dyn Any + Send> + Send + 'static>, ) -> Pin<Box<dyn Future<Output = Box<dyn Any + Send>> + Send + 'static>>

Runs work and returns a future that resolves to its output.

The closure and its output are owned ('static) because a threaded implementation hands them to a worker that outlives the caller’s borrow. The erased output is downcast back to its concrete type by run_blocking, which only this module calls.
