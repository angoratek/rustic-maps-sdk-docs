Expand description

Fetches one rendering style resource with the configured credential.

Implementations wrap the client that serves the provider’s own contract calls, so the credential, transport and request policy are the provider layer’s and the SDK holds neither the credential nor a vendor URL shape.

§Parameters
  • url — the absolute resource address without a credential: the client appends the configured credential in the shape its provider uses.
§Returns

The resource bytes as the provider serves them.

§Errors

Returns SDKError::NetworkRequestFailed when the request cannot reach the provider, SDKError::RateLimitExhausted when the provider refuses its rate, and SDKError::ProviderRequestRejected when the provider answers with a refusal.
