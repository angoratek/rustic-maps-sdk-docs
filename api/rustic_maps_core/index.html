Orchestration core of the Maps SDK: the provider registry, the cache-then-network policy and the typed value boundary between providers and the rest of the SDK.

Rendering, navigation and provider crates build on this crate. No concrete provider is wired in directly; applications register providers at startup through ProviderRegistry.
