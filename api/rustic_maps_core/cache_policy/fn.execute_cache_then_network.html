Expand description

Executes the cache-then-network policy.

The store is consulted first. On a hit, the cached value is returned. On a miss, network_fetch is awaited once, the result is stored for time_to_live_seconds, and the fresh value is returned.

§Parameters

  • response_store — the store consulted before and written after the network call.
  • request_fingerprint — the stable key identifying the request.
  • time_to_live_seconds — how long the stored value stays valid.
  • network_fetch — called once, and only on a cache miss.

§Returns

The value and CacheThenNetworkOutcome::CacheHit or CacheThenNetworkOutcome::NetworkFetch, saying where it came from.

§Errors

Returns the store’s [SDKError] when the lookup fails, and the network fetch’s [SDKError] when the fetch fails. A failed cache write never fails the call: the fresh value is still returned and storage degrades to cache-less operation.

§Async

The returned future is safe to poll on any async runtime. The network closure runs after the lookup and before the write.
