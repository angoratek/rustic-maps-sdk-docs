Vendor-neutral provider contracts for the Maps SDK.

The core speaks only to the traits in this crate. A vendor integration (MapQuest, HERE, TomTom, Mapbox, Radar, Google, or an offline engine) implements the relevant traits; no core crate depends on any provider.

Compile-time mock implementations live in mock and are reused by the unit tests of dependent crates.

Modules§

mock
Compile-time mock provider implementations reused by unit tests of dependent crates. Each mock returns canned deterministic records so tests need no HTTP stack and no trait-agnostic harness.
