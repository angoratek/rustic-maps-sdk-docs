Device positioning for the map SDK.

One controller validates the fixes a host’s location source reports, de-duplicates them, smooths their course and tracks staleness, so every consumer — the renderer’s location indicator, the follow camera and the navigation controller — reads one consistent position stream.

Hosts own the operating system’s positioning API and its permission prompt: Android supplies LocationManager (or a fused engine), iOS supplies Core Location, the browser supplies navigator.geolocation, and a desktop application supplies its own source or the simulated source in this crate. The controller never requests a permission and never touches the network.
