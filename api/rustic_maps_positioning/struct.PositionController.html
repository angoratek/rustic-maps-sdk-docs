Struct PositionController

pub struct PositionController { /* private fields */ }
Expand description

Validates, de-duplicates and smooths one host’s position stream.

Feed it every fix and source failure the platform reports, then read the accepted state from Self::state. The controller performs no I/O, never requests a permission, never spawns a thread, and holds no internal locks: call it from the thread that owns it.

pub fn feed_fix(&mut self, fix: PositionFix) -> Result<(), PositioningError>

Accepts one fix from the host’s source.

A fix that repeats the previous coordinate exactly is ignored for the course window: a stationary receiver must not invent a heading. A successful fix clears the last source failure.

§Parameters
  • fix — the source’s position report. The coordinate must be inside its canonical ranges, and every reported scalar must be finite (accuracy and timestamp also non-negative).
§Returns

Ok(()) when the fix was accepted and became the latest state.

§Errors

Returns PositioningError::InvalidCoordinate when the latitude or longitude is outside its range, PositioningError::InvalidAccuracy when the accuracy is negative or not finite, PositioningError::InvalidCourse when the course is not finite, and PositioningError::InvalidTimestamp when the timestamp is negative or not finite. A refused fix leaves the controller unchanged.
