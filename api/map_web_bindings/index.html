WebAssembly bindings for the Rustic Maps SDK core.

Exposes the Rust core (projection, camera, tile scheduling) as a hand-reviewed JavaScript/TypeScript surface for the browser test harness. This crate intentionally carries no UniFFI — the UDL contract stays the single source of truth for native platforms, and this surface mirrors it (parity asserted by tests, per PRD §4.7).

The exported JavaScript surface lives in [exports], which only compiles under wasm32; the shared validation and version plumbing stays here so host tests exercise it without a browser.
