1//! A provider-neutral vector-tile source driven by a `{z}/{x}/{y}` URL
2//! template (FR-D, PLAN.md M9).
3//!
4//! [`UrlTemplateVectorTileProvider`] implements
5//! [`geospatial_traits::VectorTileProvider`] for any web-mercator XYZ
6//! tileset that publishes a URL template — the shape a TileJSON `tiles`
7//! array names — with no vendor-specific code. The template's authority,
8//! path layout, file extension and query string all come from the caller,
9//! so a new tileset is a template plus a
10//! [`geospatial_traits::VectorTileSourceDescriptor`], never a new provider
11//! crate.
12//!
13//! The template must carry the `{z}`, `{x}` and `{y}` placeholders and use
14//! the `http` or `https` scheme; [`UrlTemplate::new`] refuses anything else
15//! at construction. Requests are paced by the shared token bucket and
16//! transient failures are retried in bounds through [`provider_transport`],
17//! so the source behaves like the SDK's concrete providers on every target.
18//! Tiles are returned in their wire encoding; gzip sniffing stays in
19//! [`geospatial_types::VectorTileData`].
