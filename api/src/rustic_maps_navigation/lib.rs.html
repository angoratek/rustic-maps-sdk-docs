1//! Turn-by-turn navigation for a planned route.
2//!
3//! The crate is a pure event reducer: [`reduce_navigation_event`] maps
4//! [`NavigationEvent`]s onto a [`NavigationSession`] without touching the
5//! network, the clock or the GPU. Each location fix is judged for deviation
6//! ([`deviation`]), snapped onto the route geometry ([`geometry`]), and
7//! evaluated against a pluggable [`StepAdvanceCondition`]. When the driver
8//! leaves the route, the caller supplies a replacement route through
9//! [`NavigationEvent::RerouteProvided`] and the reducer swaps it in.
10//! [`NavigationPhase`] moves through `Navigating`,
11//! `OffRoute` and `Arrived`; `OffRoute` is a pause the driver can recover
12//! from by returning to the route.
13//!
14//! Supporting modules compose the user-visible output:
15//!
16//! - [`instruction`] turns a trip state into plain-data banner and
17//!   text-to-speech payloads.
18//! - [`observer`] delivers state changes to per-topic subscribers with
19//!   explicit cancellation.
20//! - [`reroute`] applies a time-and-distance hysteresis before signalling
21//!   that a recalculation is due.
22//! - [`speech`] decides when a spoken instruction is announced.
23//! - [`course_filtering`] turns a raw fix course into the trip's reported
24//!   course.
25//! - [`recorder`] optionally keeps a bounded log of fixes and state changes
26//!   for diagnostics.
27//! - [`route_walk`] walks a route at a fixed pace for simulated trips.
28//!
29//! The reducer is synchronous and deterministic: the same event history
30//! always produces the same session state. Time is supplied by the caller in
31//! the events, and nothing here spawns a thread or performs I/O.
32
33// The reducer and observer code runs inside rustic-maps-native-core's exported FFI
34// frames, so the no-`unwrap`/`expect` policy of the FFI edge applies here
35// too (its `panic_boundary` module documents the scaffolding containment
36// these invariants lean on). The deny is lifted for the test builds (this
37// crate's test modules, compiled with `cfg(test)`), where the assertion
38// shorthands are honest; the deliberately panic-expressing sites that
39// remain (the poisoned-lock guard asserts in the broadcaster and the
40// recorder, and the reducer's current-step invariant) carry their
41// justifications inline.
42#![cfg_attr(not(test), deny(clippy::expect_used, clippy::unwrap_used))]
43
