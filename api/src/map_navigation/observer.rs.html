1//! Mapbox-pattern per-topic observers over the navigation state machine.
2//!
3//! Following the Mapbox Navigation observer split, this module registers
4//! listeners *per topic* behind one
5//! [`NavigationStateChangeListener`] trait, each subscription with an
6//! explicit [`TopicSubscription::cancel`], so a consumer subscribes to only
7//! what it needs and each subscription cancels exactly itself:
8//!
9//! - **instructions** (`dispatch_*` always): the composed
10//!   [`NavigationInstruction`] payload of every dispatched state change,
11//!   produced by [`crate::instruction::compose_navigation_instructions`];
12//! - **deviation status** (on change): [`DeviationStatusChange`] as the
13//!   detector's judgment enters, deepens/updates or clears — the per-fix
14//!   judgment stream, including measurement drift while the phase stays
15//!   `OffRoute`;
16//! - **phase** (on transition): [`NavigationPhaseChange`] — one-shot
17//!   transitions `OffRoute` entered/cleared, `RerouteProvided` applied, and
18//!   `Arrived`.
19//!
20//! # Threading contract
21//!
22//! Dispatch is synchronous and single-threaded by contract: callbacks run on
23//! the caller's thread, in the dispatch's own stack frame. The foreign
24//! callback wiring into the frozen UDL contract is a later slice and will own
25//! platform-side thread hop; this stays a Rust-side seam. Cross-thread calls
26//! are data-race-free (the trait requires [`Send`] + [`Sync`]) and are at
27//! worst [suppressed](NavigationDispatchOutcome::SuppressedReentrant) by the
28//! re-entrancy guard, but the ordering guarantee is stated for
29//! single-threaded use only.
30//!
31//! # Dispatch rules
32//!
33//! - **No lock is held across listener callbacks.** The registry lock is
34//!   taken once to snapshot the (cheaply cloned) listener lists and released
35//!   before the first callback runs, so a listener may freely call back into
36//!   the broadcaster — including [`TopicSubscription::cancel`] — without
37//!   deadlocking (Mapbox's rule in spirit).
38//! - **Delivery order**: within a topic, strict registration order;
39//!   across topics, instructions first, then deviation status, then phase.
40//! - **One dispatch in flight.** The deliberate re-entrancy bound: a
41//!   dispatch that starts while another dispatch is still in flight —
42//!   typically a listener driving the reducer and re-dispatching from its own
43//!   callback — delivers *nothing* and reports
44//!   [`NavigationDispatchOutcome::SuppressedReentrant`]. Nothing is queued
45//!   (no unbounded growth, no re-entrant cascade): the state change behind a
46//!   suppressed dispatch is never lost — it already happened in the reducer —
47//!   but its broadcast is skipped, so a listener that re-dispatches must let
48//!   the outer dispatch finish and dispatch again from the top level. The
49//!   common listener shapes (recording, platform notification) are fully
50//!   synchronous and unaffected.
51//! - **Listener errors cannot poison the reducer.** Listener methods return
52//!   nothing, so there is no error channel by construction; the dispatch
53//!   runs *after* the reducer has already produced its new state and only
54//!   reads the state it is handed. A listener that panics propagates the
55//!   panic to the dispatch caller (this is a synchronous Rust seam, not a
56//!   foreign boundary), and cannot corrupt the trip state or wedge the
57//!   broadcaster: the in-flight guard releases on unwind. Whether to catch
58//!   panics per listener is deferred to the foreign-wiring slice, which owns
59//!   the actual FFI error policy.
60//! - **Snapshot semantics for cancel**: a subscription cancelled during a
61//!   dispatch may still receive that dispatch's callbacks (the snapshot was
62//!   taken before); cancellation is guaranteed for every dispatch started
63//!   after `cancel` returns.
64

74/// One listener's callback surface, split by topic.
75///
76/// The methods have default no-op bodies: implementing only the topics a
77/// consumer needs is trivial. Registered subscriptions select which method a
78/// dispatch may call — subscribing to instructions delivers only
79/// [`Self::on_navigation_instruction`] to that subscription, and so on.
80///
81/// Payloads are flat immutable records with no error channel: the listener
82/// cannot fail into the broadcaster (see the module-head dispatch rules).
83pub trait NavigationStateChangeListener: Send + Sync {
84    /// Receives the composed [`NavigationInstruction`] payload of every
85    /// dispatched state change (the instructions topic).
86    fn on_navigation_instruction(&self, _instruction: &NavigationInstruction) {}
87
88    /// Receives a deviation-status stream update (the deviation topic):
89    /// [`DeviationStatusChange::OffRoute`] on entry and on every recorded
90    /// measurement update while the deviation persists,
91    /// [`DeviationStatusChange::OnRoute`] when it clears.
92    fn on_deviation_status_change(&self, _deviation_status_change: &DeviationStatusChange) {}
93
94    /// Receives one [`NavigationPhaseChange`] per transition (the phase
95    /// topic): `OffRoute` entered or cleared, a reroute applied, arrival.
96    fn on_navigation_phase_change(&self, _navigation_phase_change: &NavigationPhaseChange) {}
97
98    /// Receives one speech-trigger utterance the controller's pacing policy
99    /// judged newsworthy (round 10, the speech topic). Never emitted while no
100    /// listener subscribes to the topic; the composed speech text is carried
101    /// verbatim and the platform owns playback.
102    fn on_speech_utterance(&self, _speech_utterance: &crate::speech::SpeechUtterance) {}
103}

105/// A deviation-topic update: the detector's judgment changed between the
106/// previous and the current trip state.
107#[derive(Debug, Clone, PartialEq)]
108pub enum DeviationStatusChange {
109    /// The trip is judged deviating. Delivered when a deviation first enters
110    /// and again whenever the recorded measurement or grade is updated by a
111    /// further graded fix while any deviation persists. The carried
112    /// [`DeviationInfo`]'s grade distinguishes the freezing fully-off grade
113    /// from a merely wrong-step `OffStepOnRoute` record: the wrong-step grade
114    /// is delivered as a deviation-topic update while the trip phase stays
115    /// `Navigating` — the phase topic stays silent for it.
116    OffRoute(DeviationInfo),
117    /// A previously recorded deviation cleared; the trip is judged on route.
118    OnRoute,
119}
120
121/// A phase-transition event delivered on the phase topic.
122#[derive(Debug, Clone, Copy, PartialEq, Eq)]
123pub enum NavigationPhaseChange {
124    /// The trip entered [`NavigationPhase::OffRoute`] from [`NavigationPhase::Navigating`].
125    OffRouteEntered,
126    /// A graded fix back on the route line lifted the deviation and returned
127    /// the trip to [`NavigationPhase::Navigating`].
128    OffRouteCleared,
129    /// A [`crate::reducer::NavigationEvent::RerouteProvided`] event replaced
130    /// the route (delivered only when the event actually applied — an
131    /// ignored reroute produces no transition).
132    RerouteApplied,
133    /// The final step completed; the trip reached [`NavigationPhase::Arrived`].
134    Arrived,
135}

137/// Outcome of one dispatch call.
138#[derive(Debug, Clone, Copy, PartialEq, Eq)]
139pub enum NavigationDispatchOutcome {
140    /// The dispatch ran and delivered to all subscribed topics in order.
141    Delivered,
142    /// The dispatch was suppressed by the re-entrancy guard because another
143    /// dispatch is still in flight (see the module-head dispatch rules).
144    /// Nothing was delivered; the state change behind this dispatch has
145    /// already been applied by the reducer.
146    SuppressedReentrant,
147}

149/// Per-topic observer registry: registers listeners, cancels subscriptions,
150/// and dispatches state changes.
151///
152/// Cheaply cloneable (an `Arc` of the registry core), so the broadcaster can
153/// be shared with a listener for the re-entrant drive pattern or handed to
154/// another owner without lifetime gymnastics.
155#[derive(Clone, Default)]
156pub struct NavigationStateBroadcaster {
157    core: Arc<BroadcasterCore>,
158}
159
160/// The shared registry core behind [`NavigationStateBroadcaster`].
161struct BroadcasterCore {
162    /// The registry lock. Held only for registration, cancellation and list
163    /// snapshots — never across a listener callback.
164    registry: Mutex<RegistryState>,
165    /// The single-dispatch-in-flight flag backing the re-entrancy guard.
166    dispatch_in_flight: AtomicBool,
167}
168
169impl Default for BroadcasterCore {
170    fn default() -> Self {
171        Self {
172            registry: Mutex::new(RegistryState::default()),
173            dispatch_in_flight: AtomicBool::new(false),
174        }
175    }
176}

178/// The locked registry state: one listener list per topic plus the
179/// registration id counter.
180#[derive(Default)]
181struct RegistryState {
182    instruction_registrations: Vec<ListenerRegistration>,
183    deviation_registrations: Vec<ListenerRegistration>,
184    phase_registrations: Vec<ListenerRegistration>,
185    speech_registrations: Vec<ListenerRegistration>,
186    next_registration_id: u64,
187}

189/// One registered listener in one topic list.
190struct ListenerRegistration {
191    registration_id: u64,
192    listener: Arc<dyn NavigationStateChangeListener>,
193}

195/// Handle coupled to exactly one `(topic, listener)` registration.
196///
197/// Calling [`TopicSubscription::cancel`] removes exactly that registration —
198/// a listener subscribed to several topics (or twice to one) loses only the
199/// subscription the handle names. Cancellation is explicit and idempotent;
200/// dropping the handle does *not* unsubscribe, so a long-lived consumer keeps
201/// delivering until it cancels.
202#[derive(Clone)]
203pub struct TopicSubscription {
204    core: Arc<BroadcasterCore>,
205    registration_id: u64,
206}
207
208impl TopicSubscription {
209    /// Cancels this subscription: the named listener stops receiving the
210    /// subscription's topic from the next dispatch on. Idempotent.
211    pub fn cancel(&self) {
212        let mut registry_state = self.core.registry.lock().expect(
213            "the registry mutex cannot be poisoned: no listener code runs while it is held",
214        );
215        let RegistryState {
216            instruction_registrations,
217            deviation_registrations,
218            phase_registrations,
219            speech_registrations,
220            ..
221        } = &mut *registry_state;
222        // Registration ids are unique across all topics, so filtering every
223        // list removes exactly this subscription and nothing else.
224        instruction_registrations
225            .retain(|registration| registration.registration_id != self.registration_id);
226        deviation_registrations
227            .retain(|registration| registration.registration_id != self.registration_id);
228        phase_registrations
229            .retain(|registration| registration.registration_id != self.registration_id);
230        speech_registrations
231            .retain(|registration| registration.registration_id != self.registration_id);
232    }
233}

326    /// Registers a listener on one topic list and returns its subscription.
327    fn register(
328        &self,
329        listener: Arc<dyn NavigationStateChangeListener>,
330        topic_list: impl FnOnce(&mut RegistryState) -> &mut Vec<ListenerRegistration>,
331    ) -> TopicSubscription {
332        let registration_id = {
333            let mut registry_state = self.core.registry.lock().expect(
334                "the registry mutex cannot be poisoned: no listener code runs while it is held",
335            );
336            let registration_id = registry_state.next_registration_id;
337            registry_state.next_registration_id += 1;
338            topic_list(&mut registry_state).push(ListenerRegistration {
339                registration_id,
340                listener,
341            });
342            registration_id
343        };
344        TopicSubscription {
345            core: Arc::clone(&self.core),
346            registration_id,
347        }
348    }

350    /// Dispatches one speech-trigger utterance to the speech topic, in
351    /// registration order, under the same single-in-flight guard as the
352    /// state-change dispatches.
353    pub fn dispatch_speech_utterance(
354        &self,
355        speech_utterance: &crate::speech::SpeechUtterance,
356    ) -> NavigationDispatchOutcome {
357        let entered_dispatch = self
358            .core
359            .dispatch_in_flight
360            .compare_exchange(false, true, Ordering::SeqCst, Ordering::SeqCst)
361            .is_ok();
362        if !entered_dispatch {
363            return NavigationDispatchOutcome::SuppressedReentrant;
364        }
365        let in_flight_guard = DispatchInFlightGuard {
366            dispatch_in_flight: &self.core.dispatch_in_flight,
367        };
368
369        let speech_listeners = {
370            let registry_state = self.core.registry.lock().expect(
371                "the registry mutex cannot be poisoned: no listener code runs while it is held",
372            );
373            snapshot_listener_list(&registry_state.speech_registrations)
374        };
375
376        for listener in &speech_listeners {
377            listener.on_speech_utterance(speech_utterance);
378        }
379
380        drop(in_flight_guard);
381        NavigationDispatchOutcome::Delivered
382    }
383
384    /// The shared dispatch: delivers the instruction payload, then deviation
385    /// status, then phase transitions — each topic in registration order —
386    /// holding no lock across any callback.
387    fn dispatch_state_change(
388        &self,
389        previous_state: Option<&TripNavigationState>,
390        current_state: &TripNavigationState,
391        is_reroute_event: bool,
392        unit_system: UnitSystem,
393    ) -> NavigationDispatchOutcome {
394        let entered_dispatch = self
395            .core
396            .dispatch_in_flight
397            .compare_exchange(false, true, Ordering::SeqCst, Ordering::SeqCst)
398            .is_ok();
399        if !entered_dispatch {
400            return NavigationDispatchOutcome::SuppressedReentrant;
401        }
402        // The guard releases the in-flight flag on every exit path, including
403        // an unwind out of a panicking listener.
404        let in_flight_guard = DispatchInFlightGuard {
405            dispatch_in_flight: &self.core.dispatch_in_flight,
406        };
407
408        let (instruction_listeners, deviation_listeners, phase_listeners) = {
409            let registry_state = self.core.registry.lock().expect(
410                "the registry mutex cannot be poisoned: no listener code runs while it is held",
411            );
412            (
413                snapshot_listener_list(&registry_state.instruction_registrations),
414                snapshot_listener_list(&registry_state.deviation_registrations),
415                snapshot_listener_list(&registry_state.phase_registrations),
416            )
417        };
418
419        let instruction = compose_navigation_instructions(current_state, unit_system);
420        for listener in &instruction_listeners {
421            listener.on_navigation_instruction(&instruction);
422        }
423
424        if let Some(deviation_status_change) =
425            deviation_status_change_between(previous_state, current_state)
426        {
427            for listener in &deviation_listeners {
428                listener.on_deviation_status_change(&deviation_status_change);
429            }
430        }
431
432        for phase_change in phase_changes_between(previous_state, current_state, is_reroute_event) {
433            for listener in &phase_listeners {
434                listener.on_navigation_phase_change(&phase_change);
435            }
436        }
437
438        drop(in_flight_guard);
439        NavigationDispatchOutcome::Delivered
440    }
441}

443/// Releases the dispatch-in-flight flag when the dispatch leaves scope.
444struct DispatchInFlightGuard<'guard> {
445    dispatch_in_flight: &'guard AtomicBool,
446}
447
448impl Drop for DispatchInFlightGuard<'_> {
449    fn drop(&mut self) {
450        self.dispatch_in_flight.store(false, Ordering::SeqCst);
451    }
452}

454/// Clones the listener handles of one topic list for lock-free delivery.
455fn snapshot_listener_list(
456    registrations: &[ListenerRegistration],
457) -> Vec<Arc<dyn NavigationStateChangeListener>> {
458    registrations
459        .iter()
460        .map(|registration| Arc::clone(&registration.listener))
461        .collect()
462}

464/// Classifies the deviation-topic update between two states: delivered on a
465/// deviation entering, updating its measurement while persisting, or
466/// clearing — and never between identical deviation snapshots.
467fn deviation_status_change_between(
468    previous_state: Option<&TripNavigationState>,
469    current_state: &TripNavigationState,
470) -> Option<DeviationStatusChange> {
471    let previous_state = previous_state?;
472    if previous_state.deviation == current_state.deviation {
473        return None;
474    }
475    Some(match current_state.deviation {
476        Some(deviation_info) => DeviationStatusChange::OffRoute(deviation_info),
477        None => DeviationStatusChange::OnRoute,
478    })
479}

481/// Classifies the phase-topic transitions between two states. A reroute event
482/// contributes `RerouteApplied` only when it actually applied (the states
483/// differ); an ignored reroute on an arrived trip contributes nothing.
484fn phase_changes_between(
485    previous_state: Option<&TripNavigationState>,
486    current_state: &TripNavigationState,
487    is_reroute_event: bool,
488) -> Vec<NavigationPhaseChange> {
489    let mut phase_changes = Vec::new();
490    let Some(previous_state) = previous_state else {
491        // A trip start is not a transition: the fresh state's phase is its
492        // origin, with no previous phase to leave.
493        return phase_changes;
494    };
495    let did_reroute_apply = is_reroute_event && previous_state != current_state;
496    if did_reroute_apply {
497        phase_changes.push(NavigationPhaseChange::RerouteApplied);
498    }
499    match (previous_state.phase, current_state.phase) {
500        (NavigationPhase::Navigating, NavigationPhase::OffRoute) => {
501            phase_changes.push(NavigationPhaseChange::OffRouteEntered);
502        }
503        (NavigationPhase::OffRoute, NavigationPhase::Navigating) => {
504            phase_changes.push(NavigationPhaseChange::OffRouteCleared);
505        }
506        (NavigationPhase::Navigating | NavigationPhase::OffRoute, NavigationPhase::Arrived) => {
507            phase_changes.push(NavigationPhaseChange::Arrived);
508        }
509        _ => {}
510    }
511    phase_changes
512}

1006    #[test]
1007    fn reentrant_dispatch_from_a_listener_is_suppressed_and_bounded() {
1008        /// Drive rounds the listener deliberately performs inside its own
1009        /// callback before falling quiet — the structural ceiling that keeps
1010        /// recursion finite even if the suppression guard regressed.
1011        const REENTRANT_DRIVE_BUDGET: usize = 2;
1012
1013        struct ReentrantDrivingListener {
1014            broadcaster: NavigationStateBroadcaster,
1015            trip_session: Arc<Mutex<Option<NavigationSession>>>,
1016            remaining_drive_budget: AtomicUsize,
1017            observed_outcomes: Mutex<Vec<NavigationDispatchOutcome>>,
1018        }
1019
1020        impl ReentrantDrivingListener {
1021            /// Consumes one drive round from the bounded budget. The
1022            /// budget is test-local single-threaded state (the dispatch
1023            /// contract itself), so a load/store pair suffices.
1024            fn take_drive_round(&self) -> bool {
1025                let remaining = self.remaining_drive_budget.load(Ordering::SeqCst);
1026                if remaining == 0 {
1027                    return false;
1028                }
1029                self.remaining_drive_budget
1030                    .store(remaining - 1, Ordering::SeqCst);
1031                true
1032            }
1033        }
1034
1035        impl NavigationStateChangeListener for ReentrantDrivingListener {
1036            fn on_navigation_instruction(&self, _instruction: &NavigationInstruction) {
1037                if !self.take_drive_round() {
1038                    return;
1039                }
1040                let mut session_guard = self.trip_session.lock().unwrap();
1041                let Some(session) = session_guard.as_ref() else {
1042                    return;
1043                };
1044                let previous_state = session.state.clone();
1045                // The listener drives the reducer (a real event, a moved
1046                // walker fix) and re-dispatches during its own callback.
1047                let walker_offset_meters = previous_state.progress.distance_remaining_meters;
1048                let reduced_session = reduce_navigation_event(
1049                    Some(session.clone()),
1050                    NavigationEvent::LocationUpdated(route_fix(walker_offset_meters / 2.0)),
1051                )
1052                .expect("the driven session must stay alive");
1053                let current_state = reduced_session.state.clone();
1054                *session_guard = Some(reduced_session);
1055                drop(session_guard);
1056                let outcome = self.broadcaster.dispatch_location_update(
1057                    &previous_state,
1058                    &current_state,
1059                    UnitSystem::Metric,
1060                );
1061                self.observed_outcomes.lock().unwrap().push(outcome);
1062            }
1063        }
1064
1065        let broadcaster = NavigationStateBroadcaster::new();
1066        let trip_session = Arc::new(Mutex::new(Some(started_session())));
1067        let listener = Arc::new(ReentrantDrivingListener {
1068            broadcaster: broadcaster.clone(),
1069            trip_session: Arc::clone(&trip_session),
1070            remaining_drive_budget: AtomicUsize::new(REENTRANT_DRIVE_BUDGET),
1071            observed_outcomes: Mutex::new(Vec::new()),
1072        });
1073        let _instructions_subscription =
1074            broadcaster.subscribe_to_navigation_instructions(listener.clone());
1075
1076        // The top-level dispatch runs; its sole instruction callback drives
1077        // one reducer event and attempts a re-dispatch that must be
1078        // suppressed (the outer dispatch is still in flight), so no cascade
1079        // can form and the call returns.
1080        let initial_state = trip_session.lock().unwrap().as_ref().unwrap().state.clone();
1081        assert_eq!(
1082            broadcaster.dispatch_trip_started(&initial_state, UnitSystem::Metric),
1083            NavigationDispatchOutcome::Delivered
1084        );
1085        let first_round_outcomes = listener.observed_outcomes.lock().unwrap().clone();
1086        assert_eq!(
1087            first_round_outcomes,
1088            vec![NavigationDispatchOutcome::SuppressedReentrant],
1089            "the nested dispatch must be suppressed exactly once, not cascade"
1090        );
1091        // The driven state change did land in the session even though its
1092        // broadcast was skipped.
1093        let driven_state = trip_session.lock().unwrap().as_ref().unwrap().state.clone();
1094        assert!(driven_state.snapped_coordinate.is_some());
1095        assert_ne!(driven_state, initial_state);
1096
1097        // After the guard released, a fresh top-level dispatch delivers
1098        // normally again; its listener callback may then drive one more
1099        // bounded round, whose nested dispatch is suppressed in turn. The
1100        // test completing is itself the no-deadlock, no-infinite-recursion
1101        // proof; the outcome log pins the exact shape.
1102        broadcaster.dispatch_trip_started(&driven_state, UnitSystem::Metric);
1103        let outcomes_after_second_dispatch = listener.observed_outcomes.lock().unwrap().clone();
1104        assert_eq!(
1105            outcomes_after_second_dispatch,
1106            vec![
1107                NavigationDispatchOutcome::SuppressedReentrant,
1108                NavigationDispatchOutcome::SuppressedReentrant,
1109            ]
1110        );
1111    }
