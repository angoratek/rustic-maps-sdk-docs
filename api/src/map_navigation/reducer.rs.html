1//! The pure event reducer driving an active trip.
2//!
3//! `reduce_navigation_event` maps one event onto the previous session and
4//! returns the next one; it has no I/O, no clock and no mutable globals, so
5//! every outcome is reproducible from the event history (the seam Ferrostar
6//! builds its whole controller around). The live
7//! [`StepAdvanceCondition`] and
8//! [`DeviationDetector`] instances are threaded through
9//! [`NavigationSession`] — pairing state with its decision objects exactly as
10//! Ferrostar's `NavState` does — because they are swapped for their
11//! [`StepAdvanceCondition::fresh_instance`] (or
12//! [`DeviationDetector::fresh_instance`]) counterparts at reset points, and the
13//! exported [`crate::state::TripNavigationState`] must stay free of trait
14//! objects.
15//!
16//! Semantics in this slice:
17//! - [`NavigationEvent::StartTrip`] flattens the route and reports the declared
18//!   step values as remaining progress until the first fix arrives.
19//! - [`NavigationEvent::LocationUpdated`] is judged for deviation first:
20//!   a fix the detector judges off route *freezes* the session — the snapped
21//!   coordinate and progress stay at the last on-route values, and neither the
22//!   step-advance condition is consulted nor the step advances (deviating
23//!   positions must not drive route progress; the reference freezes the same
24//!   way while deviating). A fix without an accuracy report is not judged at
25//!   all: it can neither raise nor clear a deviation, because one threshold
26//!   rule cannot conservatively decide both directions. A graded fix inside
27//!   the allowance lifts an active deviation and the update then proceeds
28//!   normally (condition consulted, position snapped, progress recomputed).
29//!   At most one advance happens per update, exactly as before.
30//!   [`crate::state::NavigationPhase::OffRoute`] is therefore a pause the user
31//!   may recover from by returning to the route, not a terminal state.
32//! - [`NavigationEvent::RerouteProvided`] rebuilds the session for the same
33//!   trip from a fresh route. The remote-first, offline-fallback policy
34//!   (compute the replacement route remotely, fall back to an offline graph)
35//!   lives at the integrator/event-source layer, which owns the route request;
36//!   the reducer stays policy-free and pure. See the event documentation for
37//!   the route-anchoring contract it implies.
38//! - Updates after the phase is `Arrived` are ignored; reroutes offered to an
39//!   arrived trip are ignored as well.
40//!
41//! Later slices, deliberately deferred: observers and listeners, and
42//! programmatic step advance.
43

54/// Inputs the reducer accepts for one active trip.
55pub enum NavigationEvent {
56    /// Begin navigating the given route with the given advance strategy.
57    ///
58    /// The condition and the deviation detector are supplied per trip (the
59    /// reference's controller receives them the same way) rather than through
60    /// configuration, so changing either policy is an explicit event in the
61    /// history.
62    StartTrip {
63        /// The route to navigate.
64        route: RouteData,
65        /// The strategy deciding when to move between steps.
66        step_advance_condition: Arc<dyn StepAdvanceCondition>,
67        /// The strategy deciding when the trip is judged off route.
68        deviation_detector: Arc<dyn DeviationDetector>,
69    },
70    /// Replace the route of the active trip (a reroute).
71    ///
72    /// This event is the caller's answer to a detected deviation — or a
73    /// proactive route swap. The `remote-first, offline-fallback` policy (ask
74    /// a remote router for a replacement route, fall back to an offline
75    /// graph) decides *where* the replacement comes from and lives at the
76    /// integrator/event-source layer; the reducer only applies it, staying
77    /// pure and policy-free.
78    ///
79    /// # Anchoring contract
80    ///
81    /// [`Self::RerouteProvided`] rebuilds the session exactly as
82    /// [`Self::StartTrip`] does, so the replacement route must be authored to
83    /// *begin at the trip's current snapped coordinate* — which is where a
84    /// reroute router anchors its request anyway. The reducer performs no
85    /// trimming or re-ghosting of the new route's geometry; if the anchoring
86    /// contract is violated, the next graded fix will be judged against the
87    /// remaining route line by the deviation detector (and would flag a
88    /// deviation), so a mis-authored reroute is at worst flagged, never
89    /// silently mis-projected.
90    ///
91    /// The replacement advance condition must be fresh from the caller's side;
92    /// the reducer additionally rebuilds it via
93    /// [`StepAdvanceCondition::fresh_instance`] as a defensive reset so a
94    /// mid-schedule instance carried over from the old route cannot corrupt
95    /// the new step sequence (the double-advance contract).
96    RerouteProvided {
97        /// The replacement route, anchored at the current snapped coordinate.
98        route: RouteData,
99        /// The fresh strategy deciding when to move between steps of the new
100        /// route.
101        step_advance_condition: Arc<dyn StepAdvanceCondition>,
102    },
103    /// A new position fix was received while a trip is active.
104    LocationUpdated(
105        /// The fix to judge, snap and evaluate.
106        NavigationLocationUpdate,
107    ),
108}

110/// An active trip: the plain-data state plus the live decision instances.
111///
112/// This pairing (rather than embedding the conditions in the state) is what
113/// keeps [`TripNavigationState`] serializable end to end.
114#[derive(Clone)]
115pub struct NavigationSession {
116    /// The plain-data record consumers and UI read.
117    pub state: TripNavigationState,
118    /// The condition consulted on the next location update.
119    pub step_advance_condition: Arc<dyn StepAdvanceCondition>,
120    /// The detector consulted on the next location update.
121    pub deviation_detector: Arc<dyn DeviationDetector>,
122}

135/// Reduces one event onto the previous session.
136///
137/// `None` means no trip is active: `LocationUpdated` and `RerouteProvided`
138/// before any `StartTrip` are dropped, and `StartTrip` begins a session.
139/// `LocationUpdated` and `RerouteProvided` on an arrived trip leave the
140/// session untouched.
141pub fn reduce_navigation_event(
142    session: Option<NavigationSession>,
143    event: NavigationEvent,
144) -> Option<NavigationSession> {
145    match event {
146        NavigationEvent::StartTrip {
147            route,
148            step_advance_condition,
149            deviation_detector,
150        } => Some(NavigationSession {
151            state: build_trip_state(route),
152            step_advance_condition,
153            deviation_detector,
154        }),
155        NavigationEvent::RerouteProvided {
156            route,
157            step_advance_condition,
158        } => {
159            let mut session = session?;
160            // An arrived trip ignores reroutes: the destination was reached,
161            // and a replacement route cannot unreach it.
162            if session.state.phase != NavigationPhase::Arrived {
163                session = apply_reroute(session, route, step_advance_condition);
164            }
165            Some(session)
166        }
167        NavigationEvent::LocationUpdated(update) => {
168            let mut session = session?;
169            // An arrived trip keeps its session untouched; navigating and
170            // off-route trips consume fixes (consuming a fix is the only way
171            // an off-route trip recovers).
172            if session.state.phase != NavigationPhase::Arrived {
173                session = process_location_update(session, update);
174            }
175            Some(session)
176        }
177    }
178}

180/// Builds the initial state for a trip, before any location fix.
181///
182/// Shared by [`NavigationEvent::StartTrip`] and
183/// [`NavigationEvent::RerouteProvided`]: both rebuild the trip's route
184/// projection from scratch.
185fn build_trip_state(route: RouteData) -> TripNavigationState {
186    let step_positions = TripNavigationState::build_step_positions(&route);
187    // A route without traversable steps has nothing to navigate; represent
188    // that as an already-arrived trip rather than wedging in `Navigating`.
189    let phase = if step_positions.is_empty() {
190        NavigationPhase::Arrived
191    } else {
192        NavigationPhase::Navigating
193    };
194    let mut state = TripNavigationState {
195        phase,
196        route,
197        step_positions,
198        current_step_position: 0,
199        progress: TripProgress::default(),
200        deviation: None,
201        snapped_coordinate: None,
202    };
203    state.progress = compute_progress(&state);
204    state
205}

207/// Rebuilds the session for the same trip from the replacement route onward.
208fn apply_reroute(
209    mut session: NavigationSession,
210    route: RouteData,
211    step_advance_condition: Arc<dyn StepAdvanceCondition>,
212) -> NavigationSession {
213    session.state = build_trip_state(route);
214    // Defensive reset: the caller may hand back a condition instance that was
215    // mid-schedule on the old route (for example the same `Arc` still held in
216    // its own state); a mid-schedule instance would corrupt the new step
217    // sequence (the double-advance contract).
218    session.step_advance_condition = step_advance_condition.fresh_instance();
219    // The deviation detector's configuration persists across the route swap,
220    // but its instance is rebuilt so a future stateful detector's tracking
221    // restarts with the new route context (same contract as the condition
222    // swap on advance).
223    session.deviation_detector = session.deviation_detector.fresh_instance();
224    session
225}

227/// Applies one fix to a navigating session: judge deviation, consult, then act.
228fn process_location_update(
229    mut session: NavigationSession,
230    update: NavigationLocationUpdate,
231) -> NavigationSession {
232    // Deviation judgment comes first, and only for fixes carrying an accuracy
233    // report: one threshold rule cannot conservatively decide both raising
234    // and clearing a deviation, so an ungraded fix can do neither (it still
235    // snaps and progresses when the trip is not already off route, as it did
236    // before deviation detection landed).
237    let is_fix_accuracy_graded = update.horizontal_accuracy_meters.is_some();
238    if is_fix_accuracy_graded {
239        let remaining_route_line = remaining_route_line(&session.state);
240        let distance_from_route_meters =
241            snap_coordinate_to_polyline(&update.coordinate, &remaining_route_line).map(
242                |remaining_route_line_snap| remaining_route_line_snap.distance_to_polyline_meters,
243            );
244        let detection_inputs = DeviationDetectionInputs {
245            coordinate: &update.coordinate,
246            horizontal_accuracy_meters: update.horizontal_accuracy_meters,
247            distance_from_route_meters,
248        };
249        if let DeviationStatus::OffRoute {
250            deviation_from_route_meters,
251        } = session
252            .deviation_detector
253            .deviation_status(&detection_inputs, &session.state)
254        {
255            // Freeze: the snapped coordinate and progress stay at the last
256            // on-route values, the step does not advance, and the condition
257            // is not consulted (a deviating fix must not drive route
258            // progress). Only the phase and the recorded measurement change.
259            session.state.phase = NavigationPhase::OffRoute;
260            session.state.deviation = Some(DeviationInfo {
261                deviation_from_route_meters,
262            });
263            return session;
264        }
265    }
266    if session.state.phase == NavigationPhase::OffRoute {
267        // Reaching this point on an off-route trip means the fix either lacked
268        // an accuracy report or was judged within the allowance. An ungraded
269        // fix can neither raise nor clear the judgment, so the deviation holds
270        // and the session stays frozen; a graded fix inside the allowance
271        // lifts it, and the update continues with the normal projection below
272        // so progress re-anchors onto the route from the recovering fix.
273        if !is_fix_accuracy_graded {
274            return session;
275        }
276        session.state.phase = NavigationPhase::Navigating;
277        session.state.deviation = None;
278    }
279
280    let decision = {
281        let state = &session.state;
282        // The caller guarantees the phase is `Navigating` with a traversal
283        // built from the route, so the current step always resolves.
284        let current_step = state
285            .current_step()
286            .expect("navigating session must always have a current step");
287        let snap = snap_coordinate_to_polyline(&update.coordinate, &current_step.shape);
288        // Straight-line distance from the raw fix to the maneuver point,
289        // mirroring Ferrostar's eager condition which measures the raw
290        // location, while progress (below) measures the snapped position.
291        let distance_to_end_of_step_meters = current_step.shape.last().map(|terminal_coordinate| {
292            update
293                .coordinate
294                .haversine_distance_meters(terminal_coordinate)
295        });
296        let distance_from_step_meters = snap
297            .as_ref()
298            .map(|snapped| snapped.distance_to_polyline_meters);
299        let inputs = StepAdvanceInputs {
300            coordinate: &update.coordinate,
301            horizontal_accuracy_meters: update.horizontal_accuracy_meters,
302            current_step,
303            next_step: state.step_at(state.current_step_position + 1),
304            snapped_coordinate: snap.as_ref().map(|snapped| &snapped.snapped_coordinate),
305            distance_to_end_of_step_meters,
306            distance_from_step_meters,
307        };
308        session
309            .step_advance_condition
310            .should_advance_step(&inputs, state)
311    };
312
313    if decision == StepAdvanceDecision::Advance {
314        if session.state.is_on_final_step() {
315            session.state.phase = NavigationPhase::Arrived;
316        } else {
317            session.state.current_step_position += 1;
318        }
319        session.step_advance_condition = session.step_advance_condition.fresh_instance();
320    }
321    session.state = apply_location_to_state(session.state, &update);
322    session
323}

325/// The polyline of the route remaining from the current step onward: the
326/// current step's shape plus every following step's shape, in traversal order.
327///
328/// Deviation is measured against this line rather than only the current step
329/// (the reference's route-line semantics): a lagging step — eager advance
330/// semantics, pauses at intersections — is then never mistaken for a
331/// deviation. Consecutive steps may repeat their shared boundary coordinate,
332/// which degenerates to a zero-length segment the snapping projection already
333/// treats as a point.
334fn remaining_route_line(state: &TripNavigationState) -> Vec<GeographicCoordinate> {
335    let mut remaining_route_line = Vec::new();
336    for step_position in state
337        .step_positions
338        .iter()
339        .skip(state.current_step_position)
340    {
341        if let Some(step) = state.step_for_position(step_position) {
342            remaining_route_line.extend_from_slice(&step.shape);
343        }
344    }
345    remaining_route_line
346}

348/// Snaps the fix onto the current step and recomputes progress from it.
349///
350/// When the current step's shape carries no geometry, snapping is impossible;
351/// the previous snapped position is retained so the progress projection
352/// degrades continuously instead of flickering.
353fn apply_location_to_state(
354    mut state: TripNavigationState,
355    update: &NavigationLocationUpdate,
356) -> TripNavigationState {
357    let snapped_coordinate = state
358        .current_step()
359        .and_then(|current_step| {
360            snap_coordinate_to_polyline(&update.coordinate, &current_step.shape)
361        })
362        .map(|snapped| snapped.snapped_coordinate)
363        .or(state.snapped_coordinate);
364    state.snapped_coordinate = snapped_coordinate;
365    state.progress = compute_progress(&state);
366    state
367}

369/// Recomputes [`TripProgress`] for the state's current step.
370///
371/// `distance_to_next_maneuver_meters` measures the snapped position against
372/// the step's terminal coordinate (Ferrostar's approach); without a snap it
373/// falls back to the provider-declared step distance. The remaining total
374/// adds the provider-declared distances and durations of the steps after the
375/// current one, and the current step's remaining duration is scaled linearly
376/// along the step — an approximation, since providers do not distribute speed
377/// uniformly within a step.
378fn compute_progress(state: &TripNavigationState) -> TripProgress {
379    if state.phase == NavigationPhase::Arrived {
380        return TripProgress::default();
381    }
382    let Some(current_step) = state.current_step() else {
383        return TripProgress::default();
384    };
385
386    let distance_to_next_maneuver_meters = match state.snapped_coordinate {
387        Some(snapped_coordinate) => current_step
388            .shape
389            .last()
390            .map(|terminal_coordinate| {
391                snapped_coordinate.haversine_distance_meters(terminal_coordinate)
392            })
393            .unwrap_or(current_step.distance_meters),
394        None => current_step.distance_meters,
395    };
396    let traveled_fraction = if current_step.distance_meters > 0.0 {
397        // Structural fraction of the step left to walk; a snap is inside the
398        // step geometry, and the clamp keeps noisy declared totals honest.
399        (distance_to_next_maneuver_meters / current_step.distance_meters).clamp(0.0, 1.0)
400    } else {
401        // A zero-distance step is instantaneously complete.
402        1.0
403    };
404    let duration_to_next_maneuver_seconds = current_step.duration_seconds * traveled_fraction;
405
406    let distance_remaining_meters = distance_to_next_maneuver_meters
407        + following_declared_distance_meters(state, state.current_step_position);
408    let duration_remaining_seconds = duration_to_next_maneuver_seconds
409        + following_declared_duration_seconds(state, state.current_step_position);
410
411    TripProgress {
412        distance_to_next_maneuver_meters,
413        distance_remaining_meters,
414        duration_remaining_seconds,
415    }
416}

418/// Sums the provider-declared distances of the steps after `from_position`.
419fn following_declared_distance_meters(state: &TripNavigationState, from_position: usize) -> f64 {
420    state
421        .step_positions
422        .iter()
423        .enumerate()
424        .filter(|(position, _)| *position > from_position)
425        .filter_map(|(_, step_position)| state.step_for_position(step_position))
426        .map(|step| step.distance_meters)
427        .sum()
428}

430/// Sums the provider-declared durations of the steps after `from_position`.
431fn following_declared_duration_seconds(state: &TripNavigationState, from_position: usize) -> f64 {
432    state
433        .step_positions
434        .iter()
435        .enumerate()
436        .filter(|(position, _)| *position > from_position)
437        .filter_map(|(_, step_position)| state.step_for_position(step_position))
438        .map(|step| step.duration_seconds)
439        .sum()
440}

539    /// Walks the synthetic route with evenly spaced fixes and returns the
540    /// session after each one, in order.
541    fn walk_route(mut session: NavigationSession) -> Vec<NavigationSession> {
542        let mut update_offsets = Vec::new();
543        let total_updates_for_walker =
544            (TEST_ROUTE_TOTAL_LENGTH_METERS / WALKER_UPDATE_SPACING_METERS) as usize;
545        for update_number in 1..=total_updates_for_walker {
546            update_offsets.push(update_number as f64 * WALKER_UPDATE_SPACING_METERS);
547        }
548        update_offsets.push(TEST_ROUTE_TOTAL_LENGTH_METERS);
549
550        let mut walked_sessions = Vec::new();
551        for update_offset in update_offsets {
552            let update = NavigationLocationUpdate {
553                coordinate: offset_coordinate(update_offset, 0.0),
554                horizontal_accuracy_meters: Some(TEST_ACCURACY_METERS),
555                course_heading_degrees: None,
556                timestamp_seconds: None,
557            };
558            session =
559                reduce_navigation_event(Some(session), NavigationEvent::LocationUpdated(update))
560                    .expect("walked session must stay alive");
561            walked_sessions.push(session.clone());
562        }
563        walked_sessions
564    }

706    #[test]
707    fn walker_fires_maneuvers_in_order_and_arrives() {
708        let session = reduce_navigation_event(
709            None,
710            NavigationEvent::StartTrip {
711                route: straight_three_step_route(),
712                step_advance_condition: Arc::new(
713                    DistanceToEndOfStepCondition::with_ferrostar_defaults(),
714                ),
715                deviation_detector: default_deviation_detector(),
716            },
717        )
718        .unwrap();
719        let walked_sessions = walk_route(session);
720
721        // The walker's first fix sits on step zero; the walk must visit every
722        // step exactly once, in order, and finish arrived.
723        let mut last_seen_position = 0;
724        for walked_session in &walked_sessions {
725            if walked_session.state.phase == NavigationPhase::Arrived {
726                break;
727            }
728            assert!(walked_session.state.current_step_position >= last_seen_position);
729            last_seen_position = walked_session.state.current_step_position;
730        }
731        assert_eq!(last_seen_position, TEST_STEP_COUNT - 1);
732        let final_session = walked_sessions.last().unwrap();
733        assert_eq!(final_session.state.phase, NavigationPhase::Arrived);
734        assert!(
735            final_session.state.progress.distance_remaining_meters < NEAR_ZERO_TOLERANCE_METERS
736        );
737
738        // Within each step the distance to that step's maneuver never grows;
739        // across an advance boundary it legitimately resets to the next
740        // step's full length, so only same-step neighbors are compared.
741        for pair in walked_sessions.windows(2) {
742            let (previous_session, next_session) = (&pair[0], &pair[1]);
743            if previous_session.state.current_step_position
744                == next_session.state.current_step_position
745            {
746                assert!(
747                    next_session.state.progress.distance_to_next_maneuver_meters
748                        <= previous_session
749                            .state
750                            .progress
751                            .distance_to_next_maneuver_meters
752                            + MONOTONICITY_TOLERANCE_METERS,
753                    "distance to the maneuver must not grow within a step: {} -> {}",
754                    previous_session
755                        .state
756                        .progress
757                        .distance_to_next_maneuver_meters,
758                    next_session.state.progress.distance_to_next_maneuver_meters
759                );
760            }
761        }
762        // …while the total remaining distance is monotonic over the whole walk.
763        for pair in walked_sessions.windows(2) {
764            let (previous_session, next_session) = (&pair[0], &pair[1]);
765            assert!(
766                next_session.state.progress.distance_remaining_meters
767                    <= previous_session.state.progress.distance_remaining_meters
768                        + MONOTONICITY_TOLERANCE_METERS,
769                "remaining distance must be non-increasing: {} -> {}",
770                previous_session.state.progress.distance_remaining_meters,
771                next_session.state.progress.distance_remaining_meters
772            );
773        }
774    }

1282        /// Along any increasing walk of the synthetic route, the remaining
1283        /// distance never grows (up to haversine rounding).
1284        #[test]
1285        fn remaining_distance_never_increases_along_a_walk(
1286            walker_fractions in prop::collection::vec(0.0f64..1.0, 16),
1287        ) {
1288            let mut walker_offsets = walker_fractions_to_offsets(&walker_fractions);
1289            walker_offsets.sort_by(|first_offset, second_offset| {
1290                first_offset.partial_cmp(second_offset).unwrap()
1291            });
1292
1293            let session = reduce_navigation_event(
1294                None,
1295                NavigationEvent::StartTrip {
1296                    route: straight_three_step_route(),
1297                    step_advance_condition: Arc::new(
1298                        DistanceToEndOfStepCondition::with_ferrostar_defaults(),
1299                    ),
1300                    deviation_detector: default_deviation_detector(),
1301                },
1302            )
1303            .unwrap();
1304            let mut session = session;
1305            let mut previous_remaining_meters =
1306                session.state.progress.distance_remaining_meters;
1307            for walker_offset in walker_offsets {
1308                session = reduce_navigation_event(
1309                    Some(session),
1310                    NavigationEvent::LocationUpdated(NavigationLocationUpdate {
1311                        coordinate: offset_coordinate(walker_offset, 0.0),
1312                        horizontal_accuracy_meters: Some(TEST_ACCURACY_METERS),
1313                        course_heading_degrees: None,
1314                        timestamp_seconds: None,
1315                    }),
1316                )
1317                .unwrap();
1318                let remaining_meters = session.state.progress.distance_remaining_meters;
1319                prop_assert!(
1320                    remaining_meters <= previous_remaining_meters + MONOTONICITY_TOLERANCE_METERS,
1321                    "remaining distance grew: {previous_remaining_meters} -> {remaining_meters} at offset {walker_offset}"
1322                );
1323                previous_remaining_meters = remaining_meters;
1324            }
1325        }
1326
1327        /// Deviation detection is memoryless in this slice: on a trip whose
1328        /// step never advances (manual advance), each graded fix's off-route
1329        /// flag is exactly that fix's own beyond-allowance verdict — the flag
1330        /// tracks the walker's lateral excursion update by update, and clears
1331        /// as soon as the walker re-enters the widened allowance.
1332        #[test]
1333        fn off_route_flag_tracks_each_fixs_own_verdict(
1334            walker_fractions in prop::collection::vec(0.0f64..1.0, 16),
1335            lateral_fractions in prop::collection::vec(0.0f64..1.0, 16),
1336        ) {
1337            let mut walker_offsets = walker_fractions_to_offsets(&walker_fractions);
1338            walker_offsets.sort_by(|first_offset, second_offset| {
1339                first_offset.partial_cmp(second_offset).unwrap()
1340            });
1341
1342            let mut session = start_manual_trip();
1343            for (walker_offset, lateral_fraction) in walker_offsets.iter().zip(&lateral_fractions) {
1344                let lateral_offset_meters = lateral_fraction * TEST_OFF_ROUTE_EXCURSION_METERS;
1345                session = reduce_navigation_event(
1346                    Some(session),
1347                    NavigationEvent::LocationUpdated(off_route_fix(
1348                        *walker_offset,
1349                        lateral_offset_meters,
1350                    )),
1351                )
1352                .unwrap();
1353                let is_flagged_off_route =
1354                    session.state.phase == NavigationPhase::OffRoute;
1355                let expected_off_route =
1356                    lateral_offset_meters > tester_effective_allowance_meters();
1357                prop_assert!(
1358                    is_flagged_off_route == expected_off_route,
1359                    "at east {walker_offset} with lateral offset {lateral_offset_meters}: \
1360                     the flag must track the fix's own verdict"
1361                );
1362                prop_assert_eq!(session.state.deviation.is_some(), expected_off_route);
1363                if expected_off_route {
1364                    let deviation = session.state.deviation.unwrap();
1365                    prop_assert!(
1366                        (deviation.deviation_from_route_meters - lateral_offset_meters).abs()
1367                            < NEAR_ZERO_TOLERANCE_METERS,
1368                        "the recorded measurement must equal the lateral excursion"
1369                    );
1370                }
1371            }
1372        }
