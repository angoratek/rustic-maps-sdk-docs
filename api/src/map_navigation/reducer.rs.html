1//! The pure event reducer driving an active trip.
2//!
3//! `reduce_navigation_event` maps one event onto the previous session and
4//! returns the next one; it has no I/O, no clock and no mutable globals, so
5//! every outcome is reproducible from the event history (the seam Ferrostar
6//! builds its whole controller around). The live
7//! [`StepAdvanceCondition`] and
8//! [`DeviationDetector`] instances are threaded through
9//! [`NavigationSession`] — pairing state with its decision objects exactly as
10//! Ferrostar's `NavState` does — because they are swapped for their
11//! [`StepAdvanceCondition::fresh_instance`] (or
12//! [`DeviationDetector::fresh_instance`]) counterparts at reset points, and the
13//! exported [`crate::state::TripNavigationState`] must stay free of trait
14//! objects.
15//!
16//! Semantics in this slice:
17//! - [`NavigationEvent::StartTrip`] flattens the route and reports the declared
18//!   step values as remaining progress until the first fix arrives.
19//! - [`NavigationEvent::LocationUpdated`] is judged for deviation first:
20//!   a fix the detector grades *fully* off route *freezes* the session — the
21//!   snapped coordinate and progress stay at the last on-route values, and
22//!   neither the step-advance condition is consulted nor the step advances
23//!   (deviating positions must not drive route progress; the reference freezes
24//!   the same way while deviating). A fix graded *off the current step but on
25//!   the route* ([`DeviationGrade::OffStepOnRoute`], a projection onto a
26//!   future step) never freezes on its own: the grade is recorded in the
27//!   state, the trip stays `Navigating` — no reroute request, instructions
28//!   keep counting down — and the fix is then processed normally (the
29//!   step-advance condition reconciles the step; a delayed condition does so
30//!   within the very fix, via the multi-step advance loop below). A fix
31//!   without an accuracy report is not judged at all: it can neither raise
32//!   nor clear a deviation, because one threshold rule cannot conservatively
33//!   decide both directions. A graded fix inside the allowance lifts an
34//!   active deviation (an `OffRoute` trip recovering from the route line, or
35//!   a lingering wrong-step grade clearing) and the update then proceeds
36//!   normally (condition consulted, position snapped, progress recomputed).
37//!   [`crate::state::NavigationPhase::OffRoute`] is therefore a pause the user
38//!   may recover from by returning to the route, not a terminal state.
39//! - One fix may advance through *several* steps (the reference's
40//!   loop-until-break speed-run semantics, not recursion): after each
41//!   single-hop advance — which swaps in the fresh condition instance exactly
42//!   as the single-advance slice did — the freshly computed inputs decide
43//!   whether the same fix advances the next hop too. The loop is bounded by
44//!   [`MAXIMUM_STEP_ADVANCES_PER_FIX`] and terminates by construction: a hop
45//!   can end the trip only by arriving, and every other break is the
46//!   condition's `Remain`.
47//! - [`NavigationEvent::RerouteProvided`] rebuilds the session for the same
48//!   trip from a fresh route. The remote-first, offline-fallback policy
49//!   (compute the replacement route remotely, fall back to an offline graph)
50//!   lives at the integrator/event-source layer, which owns the route request;
51//!   the reducer stays policy-free and pure. See the event documentation for
52//!   the route-anchoring contract it implies.
53//! - Updates after the phase is `Arrived` are ignored; reroutes offered to an
54//!   arrived trip are ignored as well.
55//!
56//! Later slices, deliberately deferred: observers and listeners, and
57//! programmatic step advance.

71/// Defensive ceiling, in steps, on how many hops a single position fix may
72/// advance through in the multi-step advance loop.
73///
74/// The loop's real terminators are the advance condition itself (a `Remain`
75/// verdict ends the walk) and the trip's arrival on the final step, so the
76/// bound is not what makes the loop safe — it exists to guarantee a bounded
77/// response even against a pathological condition that advances on every
78/// consult (any real fix is unboundedly faster than such a condition could
79/// run out of steps). It is set far above any legitimate fix-to-step skip:
80/// the stack-safety fixture in this module replays a 1,000-step route with a
81/// single huge jump and stays well inside it, as does any recorded trace at
82/// the reference applications' 50× replay acceleration.
83pub const MAXIMUM_STEP_ADVANCES_PER_FIX: usize = 4096;

85/// Inputs the reducer accepts for one active trip.
86pub enum NavigationEvent {
87    /// Begin navigating the given route with the given advance strategy.
88    ///
89    /// The condition and the deviation detector are supplied per trip (the
90    /// reference's controller receives them the same way) rather than through
91    /// configuration, so changing either policy is an explicit event in the
92    /// history.
93    StartTrip {
94        /// The route to navigate.
95        route: RouteData,
96        /// The strategy deciding when to move between steps.
97        step_advance_condition: Arc<dyn StepAdvanceCondition>,
98        /// The strategy deciding when the trip is judged off route.
99        deviation_detector: Arc<dyn DeviationDetector>,
100    },
101    /// Replace the route of the active trip (a reroute).
102    ///
103    /// This event is the caller's answer to a detected deviation — or a
104    /// proactive route swap. The `remote-first, offline-fallback` policy (ask
105    /// a remote router for a replacement route, fall back to an offline
106    /// graph) decides *where* the replacement comes from and lives at the
107    /// integrator/event-source layer; the reducer only applies it, staying
108    /// pure and policy-free.
109    ///
110    /// # Anchoring contract
111    ///
112    /// [`Self::RerouteProvided`] rebuilds the session exactly as
113    /// [`Self::StartTrip`] does, so the replacement route must be authored to
114    /// *begin at the trip's current snapped coordinate* — which is where a
115    /// reroute router anchors its request anyway. The reducer performs no
116    /// trimming or re-ghosting of the new route's geometry; if the anchoring
117    /// contract is violated, the next graded fix will be judged against the
118    /// remaining route line by the deviation detector (and would flag a
119    /// deviation), so a mis-authored reroute is at worst flagged, never
120    /// silently mis-projected.
121    ///
122    /// The replacement advance condition must be fresh from the caller's side;
123    /// the reducer additionally rebuilds it via
124    /// [`StepAdvanceCondition::fresh_instance`] as a defensive reset so a
125    /// mid-schedule instance carried over from the old route cannot corrupt
126    /// the new step sequence (the double-advance contract).
127    RerouteProvided {
128        /// The replacement route, anchored at the current snapped coordinate.
129        route: RouteData,
130        /// The fresh strategy deciding when to move between steps of the new
131        /// route.
132        step_advance_condition: Arc<dyn StepAdvanceCondition>,
133    },
134    /// A new position fix was received while a trip is active.
135    LocationUpdated(
136        /// The fix to judge, snap and evaluate.
137        NavigationLocationUpdate,
138    ),
139}

166/// Reduces one event onto the previous session.
167///
168/// `None` means no trip is active: `LocationUpdated` and `RerouteProvided`
169/// before any `StartTrip` are dropped, and `StartTrip` begins a session.
170/// `LocationUpdated` and `RerouteProvided` on an arrived trip leave the
171/// session untouched.
172pub fn reduce_navigation_event(
173    session: Option<NavigationSession>,
174    event: NavigationEvent,
175) -> Option<NavigationSession> {
176    match event {
177        NavigationEvent::StartTrip {
178            route,
179            step_advance_condition,
180            deviation_detector,
181        } => Some(NavigationSession {
182            state: build_trip_state(route),
183            step_advance_condition,
184            deviation_detector,
185        }),
186        NavigationEvent::RerouteProvided {
187            route,
188            step_advance_condition,
189        } => {
190            let mut session = session?;
191            // An arrived trip ignores reroutes: the destination was reached,
192            // and a replacement route cannot unreach it.
193            if session.state.phase != NavigationPhase::Arrived {
194                session = apply_reroute(session, route, step_advance_condition);
195            }
196            Some(session)
197        }
198        NavigationEvent::LocationUpdated(update) => {
199            let mut session = session?;
200            // An arrived trip keeps its session untouched; navigating and
201            // off-route trips consume fixes (consuming a fix is the only way
202            // an off-route trip recovers).
203            if session.state.phase != NavigationPhase::Arrived {
204                session = process_location_update(session, update);
205            }
206            Some(session)
207        }
208    }
209}

211/// Builds the initial state for a trip, before any location fix.
212///
213/// Shared by [`NavigationEvent::StartTrip`] and
214/// [`NavigationEvent::RerouteProvided`]: both rebuild the trip's route
215/// projection from scratch.
216fn build_trip_state(route: RouteData) -> TripNavigationState {
217    let step_positions = TripNavigationState::build_step_positions(&route);
218    // A route without traversable steps has nothing to navigate; represent
219    // that as an already-arrived trip rather than wedging in `Navigating`.
220    let phase = if step_positions.is_empty() {
221        NavigationPhase::Arrived
222    } else {
223        NavigationPhase::Navigating
224    };
225    let mut state = TripNavigationState {
226        phase,
227        route,
228        step_positions,
229        current_step_position: 0,
230        progress: TripProgress::default(),
231        deviation: None,
232        snapped_coordinate: None,
233    };
234    state.progress = compute_progress(&state);
235    state
236}

238/// Rebuilds the session for the same trip from the replacement route onward.
239fn apply_reroute(
240    mut session: NavigationSession,
241    route: RouteData,
242    step_advance_condition: Arc<dyn StepAdvanceCondition>,
243) -> NavigationSession {
244    session.state = build_trip_state(route);
245    // Defensive reset: the caller may hand back a condition instance that was
246    // mid-schedule on the old route (for example the same `Arc` still held in
247    // its own state); a mid-schedule instance would corrupt the new step
248    // sequence (the double-advance contract).
249    session.step_advance_condition = step_advance_condition.fresh_instance();
250    // The deviation detector's configuration persists across the route swap,
251    // but its instance is rebuilt so a future stateful detector's tracking
252    // restarts with the new route context (same contract as the condition
253    // swap on advance).
254    session.deviation_detector = session.deviation_detector.fresh_instance();
255    session
256}

258/// Applies one fix to a navigating session: judge deviation, consult, then act.
259fn process_location_update(
260    mut session: NavigationSession,
261    update: NavigationLocationUpdate,
262) -> NavigationSession {
263    // Deviation judgment comes first, and only for fixes carrying an accuracy
264    // report: one threshold rule cannot conservatively decide both raising
265    // and clearing a deviation, so an ungraded fix can do neither (it still
266    // snaps and progresses when the trip is not already off route, as it did
267    // before deviation detection landed).
268    let is_fix_accuracy_graded = update.horizontal_accuracy_meters.is_some();
269    if is_fix_accuracy_graded {
270        let remaining_route_line = remaining_route_line(&session.state);
271        let distance_from_route_meters =
272            snap_coordinate_to_polyline(&update.coordinate, &remaining_route_line).map(
273                |remaining_route_line_snap| remaining_route_line_snap.distance_to_polyline_meters,
274            );
275        // The two-grade judgment's second measurement: the current step's own
276        // polyline, where the remaining route line's closest projection may
277        // not sit (a future-step projection is the "on route, wrong step"
278        // grade's shape).
279        let current_step = session.state.current_step();
280        let distance_from_current_step_meters = current_step.and_then(|current_step| {
281            snap_coordinate_to_polyline(&update.coordinate, &current_step.shape)
282                .map(|current_step_snap| current_step_snap.distance_to_polyline_meters)
283        });
284        let detection_inputs = DeviationDetectionInputs {
285            coordinate: &update.coordinate,
286            horizontal_accuracy_meters: update.horizontal_accuracy_meters,
287            distance_from_route_meters,
288            distance_from_current_step_meters,
289        };
290        match session
291            .deviation_detector
292            .deviation_status(&detection_inputs, &session.state)
293        {
294            // Freeze: the snapped coordinate and progress stay at the last
295            // on-route values, the step does not advance, and the condition
296            // is not consulted (a deviating fix must not drive route
297            // progress). Only the phase and the recorded measurement change.
298            DeviationStatus::OffRoute {
299                deviation_from_route_meters,
300            } => {
301                session.state.phase = NavigationPhase::OffRoute;
302                session.state.deviation = Some(DeviationInfo {
303                    grade: DeviationGrade::FullyOffRoute,
304                    deviation_from_route_meters,
305                });
306                return session;
307            }
308            // On route, wrong step: the trip never freezes on this grade —
309            // record it and process the fix normally below (a frozen trip the
310            // grade recovers lifts the freeze here).
311            DeviationStatus::OffStepOnRoute {
312                deviation_from_route_meters,
313            } => {
314                session.state.deviation = Some(DeviationInfo {
315                    grade: DeviationGrade::OffStepOnRoute,
316                    deviation_from_route_meters,
317                });
318                session.state.phase = NavigationPhase::Navigating;
319            }
320            // Fully on route: an active full deviation lifts (recovery), a
321            // lingering wrong-step grade clears.
322            DeviationStatus::OnRoute => {
323                session.state.deviation = None;
324                session.state.phase = NavigationPhase::Navigating;
325            }
326        }
327    } else if session.state.phase == NavigationPhase::OffRoute {
328        // Reaching this point on an off-route trip means an ungraded fix: it
329        // can neither raise nor clear the judgment, so the deviation holds
330        // and the session stays frozen. (A graded fix within the allowance
331        // — or graded onto a future step — has already lifted the freeze
332        // above.)
333        return session;
334    }
335
336    // The multi-step advance loop (the reference's speed-run semantics): the
337    // same fix is re-consulted — with freshly computed inputs — after every
338    // single-hop advance, until the condition says to remain or the trip
339    // arrives. Iterative, never recursive, and bounded by
340    // `MAXIMUM_STEP_ADVANCES_PER_FIX` as a defensive ceiling.
341    let mut applied_advances = 0_usize;
342    loop {
343        let decision = {
344            let state = &session.state;
345            // The caller guarantees the phase is `Navigating` with a traversal
346            // built from the route, so the current step always resolves.
347            let current_step = state
348                .current_step()
349                .expect("navigating session must always have a current step");
350            let snap = snap_coordinate_to_polyline(&update.coordinate, &current_step.shape);
351            // Straight-line distance from the raw fix to the maneuver point,
352            // mirroring Ferrostar's eager condition which measures the raw
353            // location, while progress (below) measures the snapped position.
354            let distance_to_end_of_step_meters =
355                current_step.shape.last().map(|terminal_coordinate| {
356                    update
357                        .coordinate
358                        .haversine_distance_meters(terminal_coordinate)
359                });
360            let distance_from_step_meters = snap
361                .as_ref()
362                .map(|snapped| snapped.distance_to_polyline_meters);
363            let inputs = StepAdvanceInputs {
364                coordinate: &update.coordinate,
365                horizontal_accuracy_meters: update.horizontal_accuracy_meters,
366                current_step,
367                next_step: state.step_at(state.current_step_position + 1),
368                snapped_coordinate: snap.as_ref().map(|snapped| &snapped.snapped_coordinate),
369                distance_to_end_of_step_meters,
370                distance_from_step_meters,
371            };
372            session
373                .step_advance_condition
374                .should_advance_step(&inputs, state)
375        };
376
377        if decision != StepAdvanceDecision::Advance {
378            break;
379        }
380        if session.state.is_on_final_step() {
381            session.state.phase = NavigationPhase::Arrived;
382            break;
383        }
384        session.state.current_step_position += 1;
385        // Each hop swaps in the fresh condition instance exactly as the
386        // single-advance slice did: a stale instance's internal progress can
387        // never leak from one step into the next (the double-advance
388        // contract).
389        session.step_advance_condition = session.step_advance_condition.fresh_instance();
390        applied_advances += 1;
391        if applied_advances >= MAXIMUM_STEP_ADVANCES_PER_FIX {
392            break;
393        }
394    }
395    session.state = apply_location_to_state(session.state, &update);
396    session
397}

399/// The polyline of the route remaining from the current step onward: the
400/// current step's shape plus every following step's shape, in traversal order.
401///
402/// Deviation is measured against this line rather than only the current step
403/// (the reference's route-line semantics): a lagging step — eager advance
404/// semantics, pauses at intersections — is then never mistaken for a
405/// deviation. Consecutive steps may repeat their shared boundary coordinate,
406/// which degenerates to a zero-length segment the snapping projection already
407/// treats as a point.
408fn remaining_route_line(state: &TripNavigationState) -> Vec<GeographicCoordinate> {
409    let mut remaining_route_line = Vec::new();
410    for step_position in state
411        .step_positions
412        .iter()
413        .skip(state.current_step_position)
414    {
415        if let Some(step) = state.step_for_position(step_position) {
416            remaining_route_line.extend_from_slice(&step.shape);
417        }
418    }
419    remaining_route_line
420}

422/// Snaps the fix onto the current step and recomputes progress from it.
423///
424/// When the current step's shape carries no geometry, snapping is impossible;
425/// the previous snapped position is retained so the progress projection
426/// degrades continuously instead of flickering.
427fn apply_location_to_state(
428    mut state: TripNavigationState,
429    update: &NavigationLocationUpdate,
430) -> TripNavigationState {
431    let snapped_coordinate = state
432        .current_step()
433        .and_then(|current_step| {
434            snap_coordinate_to_polyline(&update.coordinate, &current_step.shape)
435        })
436        .map(|snapped| snapped.snapped_coordinate)
437        .or(state.snapped_coordinate);
438    state.snapped_coordinate = snapped_coordinate;
439    state.progress = compute_progress(&state);
440    state
441}

443/// Recomputes [`TripProgress`] for the state's current step.
444///
445/// `distance_to_next_maneuver_meters` measures the snapped position against
446/// the step's terminal coordinate (Ferrostar's approach); without a snap it
447/// falls back to the provider-declared step distance. The remaining total
448/// adds the provider-declared distances and durations of the steps after the
449/// current one, and the current step's remaining duration is scaled linearly
450/// along the step — an approximation, since providers do not distribute speed
451/// uniformly within a step.
452fn compute_progress(state: &TripNavigationState) -> TripProgress {
453    if state.phase == NavigationPhase::Arrived {
454        return TripProgress::default();
455    }
456    let Some(current_step) = state.current_step() else {
457        return TripProgress::default();
458    };
459
460    let distance_to_next_maneuver_meters = match state.snapped_coordinate {
461        Some(snapped_coordinate) => current_step
462            .shape
463            .last()
464            .map(|terminal_coordinate| {
465                snapped_coordinate.haversine_distance_meters(terminal_coordinate)
466            })
467            .unwrap_or(current_step.distance_meters),
468        None => current_step.distance_meters,
469    };
470    let traveled_fraction = if current_step.distance_meters > 0.0 {
471        // Structural fraction of the step left to walk; a snap is inside the
472        // step geometry, and the clamp keeps noisy declared totals honest.
473        (distance_to_next_maneuver_meters / current_step.distance_meters).clamp(0.0, 1.0)
474    } else {
475        // A zero-distance step is instantaneously complete.
476        1.0
477    };
478    let duration_to_next_maneuver_seconds = current_step.duration_seconds * traveled_fraction;
479
480    let distance_remaining_meters = distance_to_next_maneuver_meters
481        + following_declared_distance_meters(state, state.current_step_position);
482    let duration_remaining_seconds = duration_to_next_maneuver_seconds
483        + following_declared_duration_seconds(state, state.current_step_position);
484
485    TripProgress {
486        distance_to_next_maneuver_meters,
487        distance_remaining_meters,
488        duration_remaining_seconds,
489    }
490}

492/// Sums the provider-declared distances of the steps after `from_position`.
493fn following_declared_distance_meters(state: &TripNavigationState, from_position: usize) -> f64 {
494    state
495        .step_positions
496        .iter()
497        .enumerate()
498        .filter(|(position, _)| *position > from_position)
499        .filter_map(|(_, step_position)| state.step_for_position(step_position))
500        .map(|step| step.distance_meters)
501        .sum()
502}

504/// Sums the provider-declared durations of the steps after `from_position`.
505fn following_declared_duration_seconds(state: &TripNavigationState, from_position: usize) -> f64 {
506    state
507        .step_positions
508        .iter()
509        .enumerate()
510        .filter(|(position, _)| *position > from_position)
511        .filter_map(|(_, step_position)| state.step_for_position(step_position))
512        .map(|step| step.duration_seconds)
513        .sum()
514}

646    /// Walks the synthetic route with evenly spaced fixes and returns the
647    /// session after each one, in order.
648    fn walk_route(mut session: NavigationSession) -> Vec<NavigationSession> {
649        let mut update_offsets = Vec::new();
650        let total_updates_for_walker =
651            (TEST_ROUTE_TOTAL_LENGTH_METERS / WALKER_UPDATE_SPACING_METERS) as usize;
652        for update_number in 1..=total_updates_for_walker {
653            update_offsets.push(update_number as f64 * WALKER_UPDATE_SPACING_METERS);
654        }
655        update_offsets.push(TEST_ROUTE_TOTAL_LENGTH_METERS);
656
657        let mut walked_sessions = Vec::new();
658        for update_offset in update_offsets {
659            let update = NavigationLocationUpdate {
660                coordinate: offset_coordinate(update_offset, 0.0),
661                horizontal_accuracy_meters: Some(TEST_ACCURACY_METERS),
662                course_heading_degrees: None,
663                timestamp_seconds: None,
664            };
665            session =
666                reduce_navigation_event(Some(session), NavigationEvent::LocationUpdated(update))
667                    .expect("walked session must stay alive");
668            walked_sessions.push(session.clone());
669        }
670        walked_sessions
671    }

961            if walked_session.state.phase == NavigationPhase::Arrived {

975        // across an advance boundary it legitimately resets to the next

977        for pair in walked_sessions.windows(2) {

981            {

1810        /// Along any increasing walk of the synthetic route, the remaining

1812        #[test]
1813        fn remaining_distance_never_increases_along_a_walk(

1823                NavigationEvent::StartTrip {

1827                    ),
1828                    deviation_detector: default_deviation_detector(),
1829                },
1830            )
1831            .unwrap();
1832            let mut session = session;
1833            let mut previous_remaining_meters =
1834                session.state.progress.distance_remaining_meters;
1835            for walker_offset in walker_offsets {
1836                session = reduce_navigation_event(
1837                    Some(session),
1838                    NavigationEvent::LocationUpdated(NavigationLocationUpdate {
1839                        coordinate: offset_coordinate(walker_offset, 0.0),
1840                        horizontal_accuracy_meters: Some(TEST_ACCURACY_METERS),
1841                        course_heading_degrees: None,
1842                        timestamp_seconds: None,
1843                    }),
1844                )
1845                .unwrap();
1846                let remaining_meters = session.state.progress.distance_remaining_meters;
1847                prop_assert!(
1848                    remaining_meters <= previous_remaining_meters + MONOTONICITY_TOLERANCE_METERS,
1849                    "remaining distance grew: {previous_remaining_meters} -> {remaining_meters} at offset {walker_offset}"
1850                );
1851                previous_remaining_meters = remaining_meters;
1852            }
1853        }
1854
1855        /// Deviation judging is memoryless in this slice: on a trip whose
1856        /// step never advances (manual advance), each graded fix's verdict is
1857        /// exactly that fix's own — the freeze flag tracks the walk's
1858        /// remaining-route measurement update by update, and the deviating
1859        /// state is recorded whenever either grade fires (fully off route:
1860        /// beyond the remaining route line's allowance; on route, wrong step:
1861        /// beyond the current step's allowance while inside the remaining
1862        /// line's), clearing as soon as the walker re-enters both allowances.
1863        #[test]
1864        fn off_route_flag_tracks_each_fixs_own_verdict(
1865            walker_fractions in prop::collection::vec(0.0f64..1.0, 16),
1866            lateral_fractions in prop::collection::vec(0.0f64..1.0, 16),
1867        ) {
1868            let mut walker_offsets = walker_fractions_to_offsets(&walker_fractions);
1869            walker_offsets.sort_by(|first_offset, second_offset| {
1870                first_offset.partial_cmp(second_offset).unwrap()
1871            });
1872
1873            let mut session = start_manual_trip();
1874            for (walker_offset, lateral_fraction) in walker_offsets.iter().zip(&lateral_fractions) {
1875                let lateral_offset_meters = lateral_fraction * TEST_OFF_ROUTE_EXCURSION_METERS;
1876                session = reduce_navigation_event(
1877                    Some(session),
1878                    NavigationEvent::LocationUpdated(off_route_fix(
1879                        *walker_offset,
1880                        lateral_offset_meters,
1881                    )),
1882                )
1883                .unwrap();
1884                // Both grade measurements are exactly these, against the east
1885                // west multi-step line and its first step: the perpendicular
1886                // lateral for the remaining route line, and (past the step's
1887                // terminal) the clamped distance to the terminal for the
1888                // current step.
1889                let distance_from_route_meters = lateral_offset_meters;
1890                let distance_from_current_step_meters = if *walker_offset <= TEST_STEP_LENGTH_METERS
1891                {
1892                    lateral_offset_meters
1893                } else {
1894                    (walker_offset - TEST_STEP_LENGTH_METERS)
1895                        .hypot(lateral_offset_meters)
1896                };
1897                let effective_allowance_meters = tester_effective_allowance_meters();
1898                let is_fully_off_route =
1899                    distance_from_route_meters > effective_allowance_meters;
1900                let is_off_step_on_route = !is_fully_off_route
1901                    && distance_from_current_step_meters > effective_allowance_meters;
1902                prop_assert_eq!(
1903                    session.state.phase == NavigationPhase::OffRoute,
1904                    is_fully_off_route,
1905                    "at east {} with lateral offset {}: \
1906                     the freeze flag must track the fix's own fully-off verdict",
1907                    walker_offset,
1908                    lateral_offset_meters
1909                );
1910                prop_assert_eq!(
1911                    session.state.deviation.is_some(),
1912                    is_fully_off_route || is_off_step_on_route,
1913                    "at east {} with lateral offset {}: \
1914                     a recorded deviation must exist exactly when a grade fires",
1915                    walker_offset,
1916                    lateral_offset_meters
1917                );
1918                if is_fully_off_route || is_off_step_on_route {
1919                    let deviation = session.state.deviation.unwrap();
1920                    prop_assert_eq!(
1921                        deviation.grade,
1922                        if is_fully_off_route {
1923                            DeviationGrade::FullyOffRoute
1924                        } else {
1925                            DeviationGrade::OffStepOnRoute
1926                        }
1927                    );
1928                    prop_assert!(
1929                        (deviation.deviation_from_route_meters - distance_from_route_meters).abs()
1930                            < NEAR_ZERO_TOLERANCE_METERS,
1931                        "the recorded measurement must equal the remaining-route excursion"
1932                    );
1933                }
1934            }
1935        }
