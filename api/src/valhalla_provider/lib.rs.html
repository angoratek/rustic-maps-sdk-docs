1//! Valhalla route calculation for the Maps SDK.
2//!
3//! [Valhalla](https://valhalla.github.io/valhalla/) is a self-hosted,
4//! keyless routing engine. This crate implements
5//! [`geospatial_traits::RoutingProvider`] against its HTTP `/route` endpoint:
6//! ordered waypoints and vendor-neutral [`geospatial_types::route::RouteOptions`]
7//! go in, and a normalized [`geospatial_types::route::RouteData`] with legs,
8//! turn-by-turn steps and the decoded geometry comes out.
9//!
10//! # Configuration
11//!
12//! [`ValhallaProviderConfiguration`] carries the operator's server base URL
13//! and the `User-Agent` the server sees. The default targets the port the
14//! reference Valhalla container publishes, so a locally running server works
15//! without configuration.
16//!
17//! ```no_run
18//! use valhalla_provider::{ValhallaProviderConfiguration, ValhallaRoutingProvider};
19//!
20//! # fn main() -> Result<(), geospatial_types::SDKError> {
21//! let provider = ValhallaRoutingProvider::new(ValhallaProviderConfiguration::default())?;
22//! # let _ = provider;
23//! # Ok(())
24//! # }
25//! ```
26//!
27//! # Request and response
28//!
29//! Requests are JSON POSTs to `{base_url}/route`. Every leg shape is a
30//! precision-6 encoded polyline decoded inside the crate; maneuver `type`
31//! integers map onto [`geospatial_types::route::ManeuverType`] through a
32//! total classification table. All distances are normalized to meters and
33//! durations to seconds.
34//!
35//! # Failure channels
36//!
37//! Transport failures surface as [`geospatial_types::SDKError::NetworkRequestFailed`],
38//! a body that is not a usable Valhalla trip as
39//! [`geospatial_types::SDKError::ResponseParsingFailure`], and a documented
40//! Valhalla `error` refusal as
41//! [`geospatial_types::SDKError::ProviderRequestRejected`] carrying the
42//! provider's message verbatim.
