1//! OSRM implementation of [`geospatial_traits::RoutingProvider`] against the
2//! OSRM HTTP route service (`project-osrm.org/docs/v5.24.0/api/`).
3//!
4//! OSRM is keyless: a deployment is reached by its base URL, so the crate
5//! takes an explicit [`OsrmProviderConfiguration`] whose `base_url` names the
6//! server. When no configuration is supplied the default points at a local
7//! OSRM instance listening on port 5000. Every request goes through the shared
8//! [`provider_transport`] seam ([`client`]) with bounded idempotent-GET
9//! retries, so the same request, parsing and error-mapping code runs natively
10//! and in browsers.
11//!
12//! # Route option mapping
13//!
14//! [`geospatial_traits::RoutingProvider::calculate_route`] maps the SDK
15//! options onto the route service as follows:
16//!
17//! - [`geospatial_types::route::TransportationMode::Automobile`] selects the
18//!   `driving` profile, `Bicycle` the `cycling` profile and `Pedestrian` the
19//!   `walking` profile, in the request path.
20//! - [`geospatial_types::route::AvoidOptions`] fields become `exclude` classes
21//!   (`toll`, `motorway`, `ferry`, `unpaved`).
22//! - `unit_system` does not change the request: the contract is always meters
23//!   and seconds and the service always answers in those units.
24//!
25//! `route_strategy` and `departure_timestamp_seconds` have no route-service
26//! parameter, so they do not affect the request; the deployment's profile
27//! cost model decides the ranking and the service routes for "now".
28//!
29//! # Supported route data
30//!
31//! The provider reads `routes[0]` and decodes the total distance and
32//! duration, the GeoJSON route geometry (from which it derives the bounding
33//! box), and one leg per consecutive waypoint pair. Each leg carries its
34//! steps, and each step is classified through an explicit OSRM
35//! `maneuver.type`/`modifier` table ([`route::map_osrm_maneuver`]). OSRM does
36//! not return human-readable instructions, so the crate authors the display
37//! and speech strings from the maneuver and road name, and it does not map
38//! OSRM lane records, leaving `lane_guidances` empty.
39

41pub mod error_mapping;
42pub mod route;
