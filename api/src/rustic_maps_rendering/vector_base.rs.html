1//! Shared vector-tile base pipeline: one scheduler that fetches a vector
2//! tileset through the [`VectorTileProvider`] trait, decodes each tile once,
3//! styles it, and answers the overlay primitives the frame draws beneath its
4//! own overlays.
5//!
6//! Every target serves its vector base through this one implementation, so the
7//! native surfaces and the browser cannot drift in what a tile paints. The
8//! scheduler owns two caches:
9//!
10//! - **Decoded tiles**, keyed by the tile address: a tile's bytes are fetched
11//!   and decoded once and never again while it stays cached; a style change
12//!   restyles the decoded tile instead of refetching it.
13//! - **Styled geometry**, keyed by the tile address, the style revision and the
14//!   style's zoom bucket: the style's zoom span (`min_zoom`/`max_zoom`) and
15//!   width stops are evaluated at the camera's zoom level, so a camera pan
16//!   across a width stop repaints the tile from the style it already carries —
17//!   no refetch, no decode. The zoom level quantizes to
18//!   [`VECTOR_BASE_STYLE_ZOOM_QUANTIZATION_STEPS_PER_LEVEL`] steps per level so
19//!   a continuous zoom gesture cannot grow the styled cache without bound.
20//!
21//! A tile that fails to fetch or decode does not fail the frame: the scheduler
22//! skips it, keeps painting the tiles that succeeded, and reports the failure
23//! in the frame's counts and its last failure detail. The base map is one layer
24//! of a frame, never the frame's reason to fail.
25//!
26//! # Latency: payload cache, deliberate prefetch, progressive draw
27//!
28//! The camera-facing [`VectorBaseScheduler::cached_frame`] never waits on the
29//! network: it paints the decoded tiles the cache holds, reports the rest as
30//! pending or failed, and lets a detached prefetch fill the gaps. A missing
31//! tile whose ancestor is cached draws that ancestor at the same camera zoom
32//! (the raster path's parent-fallback semantics), so a new area blurs in at
33//! coarse detail instead of flashing holes.
34//!
35//! Fetched wire payloads additionally pass through a
36//! [`rustic_maps_core::CachedResponseStore`] keyed by the tileset's source name
37//! and the tile address. The native surfaces install their disk store (TTL,
38//! LRU and quota), so a region browsed once survives the next session; the
39//! browser installs [`VectorTileMemoryCache`], the same policy in memory where
40//! no SQLite exists.
41//!
42//! [`VectorBaseScheduler::prefetch_missing_tiles`] claims the visible misses;
43//! [`VectorBaseScheduler::prefetch_ring_tiles`] then claims the ring around the
44//! viewport (and the coarse parents that back a fallback) under a small budget.
45//! Both return cancellable detached futures: a dropped future releases its
46//! claims, so a scheduler that is replaced mid-fetch never strands a tile
47//! address as permanently in flight.
48//!
49//! The scheduler is camera-agnostic: the caller lists the visible tile
50//! addresses (through `MapCamera::visible_tile_keys` or the page's own grid)
51//! and names the camera's zoom level; [`VectorBaseScheduler::served_zoom_level`]
52//! clamps that listing to the tileset's declared zoom span.
53//!
54//! Each resolved frame also carries the drawn tiles' label candidates, read
55//! from the active style's symbol layers. [`VectorBaseFrame::label_layer`]
56//! places them at a camera pose through the SDK's embedded default glyph font,
57//! so every platform surface draws the same place names without a
58//! platform-specific asset. A frame without candidates yields `None` and
59//! costs the renderer nothing.

248    /// How many of those tiles failed to fetch or decode this frame.

265    /// Whether this frame drew in motion-graded mode: the camera was moving

268    /// both at the final camera pose and reports `false`.
269    pub motion_graded: bool,
270    /// Whether a tile-level cross-fade still owes frames: the previous level

274    pub zoom_transition_running: bool,
275    /// How many retired-level tiles this frame still drew while the requested
276    /// level fills (at their own address or as an ancestor stand-in). Zero

279    pub retained_tile_count: usize,
280    /// The retired tile zoom level the frame drew, when a transition retains
281    /// one.
282    pub retained_tile_zoom_level: Option<u8>,
283    /// Opacity the retired level is drawn at: one during the hold, ramping to
284    /// zero across the fade.
285    pub retained_opacity: f32,
286    /// The frame's per-source layer accounting, sorted by source id. A source
287    /// matched a layer when the painted tileset carried the `source-layer` the
288    /// layer reads; it drew a layer when that layer painted geometry or placed
289    /// a label.
290    pub source_layer_counts: Vec<VectorSourceLayerCount>,
291    /// The frame's cache-hit, in-flight and first-drawn-tile accounting.
292    pub diagnostics: VectorBaseFrameDiagnostics,
293    /// The revision of the frame's content — its drawn and fallback tiles,
294    /// style revision, style-zoom bucket, sprite atlas and label assembly.
295    /// Two frames with the same revision paint the same overlays and carry
296    /// the same label candidates, so a caller compares this integer instead
297    /// of deep-comparing tens of thousands of overlays (and can share the

299    /// counters are deliberately not part of the revision: they change
300    /// without changing a pixel.

495/// The decoded-tile cache shared between the presenting frame and its detached
496/// prefetch. The frame resolves from whatever the cache already holds, while a
497/// spawned prefetch fetches every missing tile concurrently and inserts it, so
498/// a first frame over unvisited ground never waits on the network. The cache
499/// also remembers in-flight addresses (so a repaint does not start duplicate
500/// fetches) and the last failure per address (so a frame can report it until
501/// the next prefetch retries).
502#[derive(Debug)]
503struct DecodedTileCache {
504    /// Decoded tiles by address (fetched and decoded once).
505    tiles: HashMap<TileKey, Arc<VectorTile>>,
506    /// The cache's insertion order, for eviction.
507    insertion_order: VecDeque<TileKey>,
508    /// Addresses whose fetch is running.
509    in_flight: HashSet<TileKey>,
510    /// The last failure detail per address, cleared by the retry.
511    failure_details: HashMap<TileKey, String>,
512    /// The cache's capacity.
513    maximum_tile_count: usize,
514}
515
516impl DecodedTileCache {
517    fn new(maximum_tile_count: usize) -> Self {
518        Self {
519            tiles: HashMap::new(),
520            insertion_order: VecDeque::new(),
521            in_flight: HashSet::new(),
522            failure_details: HashMap::new(),
523            maximum_tile_count,
524        }
525    }
526
527    fn get(&self, tile_key: &TileKey) -> Option<Arc<VectorTile>> {
528        self.tiles.get(tile_key).cloned()
529    }
530
531    /// Claims the address for a fetch; `false` when it is already cached or a
532    /// fetch is running. Claiming clears any previous failure so the frame
533    /// reports "pending", not a stale refusal, while the retry runs.
534    fn begin_fetch(&mut self, tile_key: TileKey) -> bool {
535        if self.tiles.contains_key(&tile_key) || !self.in_flight.insert(tile_key) {
536            return false;
537        }
538        self.failure_details.remove(&tile_key);
539        true
540    }
541
542    /// Releases an in-flight claim without storing the result, for a ring
543    /// fetch whose tile the camera has already left.
544    fn discard_fetch(&mut self, tile_key: TileKey) {
545        self.in_flight.remove(&tile_key);
546    }
547
548    /// Records one finished fetch: the decoded tile on success, the detail on
549    /// failure, and clears the in-flight mark either way.
550    fn finish_fetch(&mut self, tile_key: TileKey, outcome: Result<Arc<VectorTile>, String>) {
551        self.in_flight.remove(&tile_key);
552        match outcome {
553            Ok(decoded_tile) => {
554                self.failure_details.remove(&tile_key);
555                self.insert_decoded_tile(tile_key, decoded_tile);
556            }
557            Err(failure_detail) => {
558                // The failure map is a diagnostic aid, not a record: it is
559                // capped so a long session over failing ground cannot grow it
560                // without bound.
561                if !self.failure_details.contains_key(&tile_key)
562                    && self.failure_details.len() >= MAXIMUM_RECORDED_FAILURE_DETAILS
563                    && let Some(evicted_key) = self.failure_details.keys().next().copied()
564                {
565                    self.failure_details.remove(&evicted_key);
566                }
567                self.failure_details.insert(tile_key, failure_detail);
568            }
569        }
570    }
571
572    /// Inserts a decoded tile and evicts the oldest decoded tiles beyond the
573    /// cache's capacity. Styled geometry is keyed by the address and a style
574    /// revision, so it stays valid for a re-fetched address and is bounded by
575    /// its own cache; eviction here never touches it.
576    fn insert_decoded_tile(&mut self, tile_key: TileKey, decoded_tile: Arc<VectorTile>) {
577        if self.tiles.insert(tile_key, decoded_tile).is_none() {
578            self.insertion_order.push_back(tile_key);
579        }
580        while self.tiles.len() > self.maximum_tile_count {
581            let Some(evicted_tile_key) = self.insertion_order.pop_front() else {
582                break;
583            };
584            self.tiles.remove(&evicted_tile_key);
585        }
586    }
587}

589/// The in-memory vector-tile payload cache the browser installs where no
590/// SQLite store exists: the same cache-then-network policy as the native disk
591/// store (a fingerprint key, a time-to-live and a bounded capacity), held in
592/// process memory with least-recently-used eviction.
593///
594/// The cache is shared across scheduler installs, so switching a style or
595/// reinstalling the same tileset serves the region from memory instead of
596/// refetching it. It never outlives the page.
597#[derive(Debug)]
598pub struct VectorTileMemoryCache {
599    /// The cached payloads and their access order.
600    state: Mutex<VectorTileMemoryCacheState>,
601    /// The cache's capacity, in tiles.
602    maximum_tile_count: usize,
603}
604
605#[derive(Debug, Default)]
606struct VectorTileMemoryCacheState {
607    /// Cached payloads by request fingerprint.
608    entries: HashMap<String, VectorTileMemoryCacheEntry>,
609    /// Monotonic access stamp, for least-recently-used eviction.
610    access_sequence: u64,
611}
612
613#[derive(Debug)]
614struct VectorTileMemoryCacheEntry {
615    /// The stored wire payload.
616    payload: Arc<VectorTileData>,
617    /// When the entry expires.
618    expires_at: Instant,
619    /// The access stamp of the entry's last read or write.
620    last_accessed: u64,
621}
622
623impl VectorTileMemoryCache {
624    /// Builds an empty payload cache holding at most `maximum_tile_count`
625    /// tiles.
626    pub fn new(maximum_tile_count: usize) -> Self {
627        Self {
628            state: Mutex::new(VectorTileMemoryCacheState::default()),
629            maximum_tile_count,
630        }
631    }
632
633    /// The fingerprints the cache currently holds, for tests and diagnosis.
634    pub fn cached_tile_count(&self) -> usize {
635        self.state
636            .lock()
637            .unwrap_or_else(PoisonError::into_inner)
638            .entries
639            .len()
640    }
641}
642
643impl CachedResponseStore<VectorTileData> for VectorTileMemoryCache {
644    fn lookup_response(
645        &self,
646        request_fingerprint: &str,
647    ) -> Result<Option<Arc<VectorTileData>>, geospatial_types::SDKError> {
648        let mut state = self.state.lock().unwrap_or_else(PoisonError::into_inner);
649        let access_stamp = {
650            state.access_sequence += 1;
651            state.access_sequence
652        };
653        let Some(entry) = state.entries.get_mut(request_fingerprint) else {
654            return Ok(None);
655        };
656        if entry.expires_at <= Instant::now() {
657            state.entries.remove(request_fingerprint);
658            return Ok(None);
659        }
660        entry.last_accessed = access_stamp;
661        Ok(Some(Arc::clone(&entry.payload)))
662    }
663
664    fn store_response(
665        &self,
666        request_fingerprint: &str,
667        response_value: Arc<VectorTileData>,
668        time_to_live_seconds: u64,
669    ) -> Result<(), geospatial_types::SDKError> {
670        let mut state = self.state.lock().unwrap_or_else(PoisonError::into_inner);
671        state.access_sequence += 1;
672        let access_stamp = state.access_sequence;
673        state.entries.insert(
674            request_fingerprint.to_string(),
675            VectorTileMemoryCacheEntry {
676                payload: response_value,
677                expires_at: Instant::now() + Duration::from_secs(time_to_live_seconds),
678                last_accessed: access_stamp,
679            },
680        );
681        while state.entries.len() > self.maximum_tile_count {
682            let Some(least_recently_used_fingerprint) = state
683                .entries
684                .iter()
685                .min_by_key(|(_, entry)| entry.last_accessed)
686                .map(|(fingerprint, _)| fingerprint.clone())
687            else {
688                break;
689            };
690            state.entries.remove(&least_recently_used_fingerprint);
691        }
692        Ok(())
693    }
694}

721/// The guard of a detached prefetch: it clears the in-flight marks of every
722/// claimed tile still undelivered when the future is dropped. Without it, a
723/// cancelled prefetch (the runtime shutting down, or a replaced scheduler)
724/// would report its addresses pending forever and no later plan would retry
725/// them.

983/// The name fragments that identify the tileset a descriptor serves, sorted.
984///
985/// The descriptor's `source_name` is `vendor/tileset` for every catalog
986/// provider (`here/vector`, `mapbox/mapbox.mapbox-streets-v8`), so both the
987/// full name and its tileset half identify the served tileset. The provider's
988/// declared `style_hints` are additional identities: they are its own
989/// statement of the tileset's schema or style family (`omv` and `base` for
990/// HERE's vector tileset), never a guess, and a published style document may
991/// name them in its source address where it names no tileset id.
992fn served_tileset_identities(descriptor: &VectorTileSourceDescriptor) -> Vec<&str> {
993    let mut identities = BTreeSet::new();
994    identities.insert(descriptor.source_name.as_str());
995    if let Some((_, tileset_id)) = descriptor.source_name.rsplit_once('/')
996        && !tileset_id.is_empty()
997    {
998        identities.insert(tileset_id);
999    }
1000    for style_hint in &descriptor.style_hints {
1001        let style_hint = style_hint.trim();
1002        if !style_hint.is_empty() {
1003            identities.insert(style_hint);
1004        }
1005    }
1006    identities.into_iter().collect()
1007}

1009/// Whether one declared source address names the served tileset.
1010///
1011/// The address is compared segment by segment after its scheme and any query
1012/// or fragment, so `mapbox://mapbox.mapbox-streets-v8` and a tile template
1013/// whose path carries the tileset id both match, while an address naming a
1014/// different tileset does not. Nothing is fetched: the provider binding owns
1015/// the fetch address, and the style's `url`/`tiles` is identity documentation.
1016fn declared_address_identifies_tileset(address: &str, served_identities: &[&str]) -> bool {
1017    let address = address.trim();
1018    let after_scheme = address
1019        .split_once("://")
1020        .map_or(address, |(_, remainder)| remainder);
1021    let path = after_scheme
1022        .split_once(['?', '#'])
1023        .map_or(after_scheme, |(path, _)| path);
1024    path.split('/').any(|segment| {
1025        served_identities
1026            .iter()
1027            .any(|identity| segment.eq_ignore_ascii_case(identity))
1028    })
1029}

1031/// Verifies that every vector source the style's layers reference identifies
1032/// the tileset the provider serves.
1033///
1034/// A style may declare several sources, and its layers may reference any of
1035/// them. The vector base fetches exactly one tileset — the provider's — so a
1036/// source whose declared address names a different tileset would paint a
1037/// background and fragments while every layer looked well-formed. The install
1038/// refuses that document instead, naming the declared source(s) and the served
1039/// tileset.
1040///
1041/// A source that declares no `url` and no `tiles` is host-bound: the provider
1042/// binding supplies its fetch, and it always matches. A declared address
1043/// matches when any of its path segments equals the descriptor's
1044/// `source_name`, its tileset half, or one of the provider's declared
1045/// `style_hints`. The hints are provider declarations, not guesses: the
1046/// provider states which schema or style family its tileset serves, so a
1047/// published document that names `base` or `omv` (HERE's vector tileset)
1048/// identifies the served tileset just as a tileset id does. A source of a
1049/// kind the vector base cannot draw (raster, GeoJSON or an opaque type) never
1050/// refuses the install; it is reported as a degraded asset through
1051/// [`VectorBaseStyleFidelity::degraded_asset_names`].
1052///
1053/// # Errors
1054/// [`VectorStyleArtifactError`] naming the declared source(s) and the served
1055/// tileset when a referenced vector source names a different tileset.
1056pub fn verify_declared_vector_sources(
1057    style: &CompiledStyle,
1058    descriptor: &VectorTileSourceDescriptor,
1059) -> Result<(), VectorStyleArtifactError> {
1060    let served_identities = served_tileset_identities(descriptor);
1061    let mut mismatched_declarations = Vec::new();
1062    for source_id in referenced_source_ids(style) {
1063        let Some(CompiledSource::Vector(vector_source)) = style.source(source_id) else {
1064            continue;
1065        };
1066        let declared_addresses = vector_source
1067            .url
1068            .iter()
1069            .chain(vector_source.tiles.iter())
1070            .collect::<Vec<_>>();
1071        if declared_addresses.is_empty() {
1072            continue;
1073        }
1074        let identifies_served_tileset = declared_addresses
1075            .iter()
1076            .any(|address| declared_address_identifies_tileset(address, &served_identities));
1077        if !identifies_served_tileset {
1078            let addresses = declared_addresses
1079                .iter()
1080                .map(|address| format!("{address:?}"))
1081                .collect::<Vec<_>>()
1082                .join(", ");
1083            mismatched_declarations.push(format!("{source_id:?} ({addresses})"));
1084        }
1085    }
1086    if mismatched_declarations.is_empty() {
1087        return Ok(());
1088    }
1089    Err(VectorStyleArtifactError {
1090        detail: format!(
1091            "the style document declares the vector source(s) {} but the served tileset is \
1092             {}; a vector base fetches exactly the tileset its provider serves, so installing \
1093             this document would paint fragments",
1094            mismatched_declarations.join(", "),
1095            descriptor.source_name
1096        ),
1097    })
1098}

1113        if any_icon_layer && !sprite_drawn {
1114            names.push(format!("sprite: {}", sprite.url));
1115        }
1116    }

1122        if any_text_layer && !glyphs_drawn {
1123            names.push(format!("glyphs: {glyphs}"));
1124        }
1125    }

1127        let Some(source) = style.source(source_id) else {
1128            continue;
1129        };
1130        let source_kind = source.kind();
1131        if source_kind != CompiledSourceKind::Vector {

1133                "source {source_id:?} ({}): the vector base cannot draw this source kind",
1134                source_kind.as_str()
1135            ));
1136        }
1137    }

1139    names.dedup();
1140    names.truncate(MAXIMUM_REPORTED_DEGRADED_ASSET_NAMES);

1142}

1163/// The frame's per-source layer accounting.
1164fn source_layer_counts_for_frame(
1165    style: &CompiledStyle,
1166    served_source_layers: &BTreeSet<String>,
1167    contributed_layers: &[bool],
1168) -> Vec<VectorSourceLayerCount> {
1169    let mut counts: BTreeMap<&str, (u32, u32)> = BTreeMap::new();
1170    for (layer_index, layer) in style.layers.iter().enumerate() {
1171        let Some(source_id) = layer.source.as_deref() else {
1172            continue;
1173        };
1174        let counts_for_source = counts.entry(source_id).or_insert((0, 0));
1175        if layer.source_kind != Some(CompiledSourceKind::Vector) {
1176            continue;
1177        }
1178        let matched = match layer.source_layer.as_deref() {
1179            None => true,
1180            Some(source_layer) => served_source_layers.contains(source_layer),
1181        };
1182        if matched {
1183            counts_for_source.0 = counts_for_source.0.saturating_add(1);
1184        }
1185        if contributed_layers
1186            .get(layer_index)
1187            .copied()
1188            .unwrap_or(false)
1189        {
1190            counts_for_source.1 = counts_for_source.1.saturating_add(1);
1191        }
1192    }
1193    counts
1194        .into_iter()
1195        .map(
1196            |(source_id, (matched_layer_count, drawn_layer_count))| VectorSourceLayerCount {
1197                source_id: source_id.to_string(),
1198                matched_layer_count,
1199                drawn_layer_count,
1200            },
1201        )
1202        .collect()
1203}

1551    ///
1552    /// When the incoming style declares a transition (`transition` at the
1553    /// document root or a `*-transition` paint block), the outgoing style is
1554    /// kept and the next timed frame starts blending from it; otherwise the
1555    /// change applies immediately. A transition is driven by the frame clock
1556    /// passed to [`Self::cached_frame_at_time`], never by a timer.
1557    ///
1558    /// # Parameters
1559    /// - `style_id` — the identifier status readbacks report.
1560    /// - `style` — the compiled render plans to install.
1561    pub fn set_compiled_style(&mut self, style_id: impl Into<String>, style: CompiledStyle) {
1562        let transition_lifetime_seconds = style.transition_lifetime_seconds();
1563        let outgoing_style = std::mem::replace(&mut self.style, style);
1564        self.style_id = style_id.into();
1565        self.style_revision += 1;
1566        // A different style never reuses the previous style's geometry.
1567        self.styled_tiles.clear();
1568        self.styled_tile_insertion_order.clear();
1569        // A different style may name a different sprite, so reload it.
1570        self.sprite_atlas = None;

1572        // previous style's font is dropped and the labels draw through the
1573        // embedded range until the host supplies the new style's font.
1574        self.label_font = None;
1575        // A style with no declared timing applies immediately; keeping the
1576        // outgoing plan would only hold values that never blend.
1577        self.previous_style = (transition_lifetime_seconds > 0.0).then_some(outgoing_style);
1578        self.transition_started_at_seconds = None;
1579        // The replacement style declares its own source, so its zoom span and
1580        // attribution apply from the next frame on.
1581        self.bound_base_source = bound_base_vector_source(&self.provider, &self.style);
1582    }

1699    /// Claims the ring around the viewport for a detached prefetch: the eight
1700    /// neighbors of every visible tile at the served zoom, plus each visible
1701    /// tile's coarse parent (the fallback that covers the area while the
1702    /// detailed tile is in flight), under
1703    /// [`Self::with_maximum_prefetch_ring_tile_count`]'s budget.
1704    ///
1705    /// Parents come first because they can cover a missing child immediately;
1706    /// the rest are ordered by distance from the viewport's center, so a
1707    /// budgeted plan grows outward instead of claiming a scattered corner.
1708    /// Nothing already cached, failed or in flight is claimed. `None` when
1709    /// the ring has nothing left to claim, when a visible tile's own fetch is
1710    /// still running (the view comes first), or when the previous plan ran
1711    /// inside the configured interval.
1712    pub fn prefetch_ring_tiles(
1713        &self,
1714        visible_tile_keys: &[TileKey],
1715    ) -> Option<impl std::future::Future<Output = usize> + Send + 'static> {
1716        let visible_tiles_are_fetching = {
1717            let decoded_tiles = self
1718                .decoded_tiles
1719                .lock()
1720                .unwrap_or_else(PoisonError::into_inner);
1721            visible_tile_keys
1722                .iter()
1723                .any(|tile_key| decoded_tiles.in_flight.contains(tile_key))
1724        };
1725        if visible_tiles_are_fetching {
1726            return None;
1727        }
1728        self.remember_visible_tiles(visible_tile_keys);
1729        // Below the low-zoom threshold one screen holds most of the pyramid:
1730        // a ring is a large fraction of the visible set and predicts the next
1731        // camera far worse than at city zoom, so a fit stays visible-only.
1732        let served_zoom_level = visible_tile_keys
1733            .iter()
1734            .map(|tile_key| tile_key.zoom_level)
1735            .max()
1736            .unwrap_or(0);
1737        if served_zoom_level < self.ring_prefetch_minimum_zoom_level {
1738            return None;
1739        }
1740        let candidates = self.ring_prefetch_candidates(visible_tile_keys);
1741        if candidates.is_empty() {
1742            return None;
1743        }
1744        {
1745            let mut last_ring_prefetch_at = self
1746                .last_ring_prefetch_at
1747                .lock()
1748                .unwrap_or_else(PoisonError::into_inner);
1749            let now = Instant::now();
1750            if last_ring_prefetch_at.is_some_and(|last_plan_at| {
1751                now.duration_since(last_plan_at) < self.ring_prefetch_minimum_interval
1752            }) {
1753                return None;
1754            }
1755            *last_ring_prefetch_at = Some(now);
1756        }
1757        self.prefetch_tile_keys(
1758            candidates,
1759            Some(self.maximum_prefetch_ring_tile_count),
1760            true,
1761            None,
1762        )
1763    }

1765    /// The ring plan: coarse parents first, then same-zoom neighbors ordered
1766    /// by distance from the visible set's center. The plan is deduplicated
1767    /// against the visible set; the per-plan budget applies to the tiles the
1768    /// caches cannot already serve, so budgeted plans are not wasted on
1769    /// cached neighbors.
1770    fn ring_prefetch_candidates(&self, visible_tile_keys: &[TileKey]) -> Vec<TileKey> {
1771        let mut visible_tiles = visible_tile_keys.to_vec();
1772        visible_tiles.sort();
1773        visible_tiles.dedup();
1774        if visible_tiles.is_empty() {
1775            return Vec::new();
1776        }
1777        let served_zoom_level = visible_tiles
1778            .iter()
1779            .map(|tile_key| tile_key.zoom_level)
1780            .max()
1781            .unwrap_or(0);
1782        let tiles_per_axis = 1u64
1783            .checked_shl(u32::from(served_zoom_level))
1784            .unwrap_or(u64::MAX);
1785        let visible_tile_set = visible_tiles.iter().copied().collect::<HashSet<_>>();
1786        let center_tile_x = visible_tiles
1787            .iter()
1788            .map(|tile_key| f64::from(tile_key.tile_x))
1789            .sum::<f64>()
1790            / visible_tiles.len() as f64;
1791        let center_tile_y = visible_tiles
1792            .iter()
1793            .map(|tile_key| f64::from(tile_key.tile_y))
1794            .sum::<f64>()
1795            / visible_tiles.len() as f64;
1796        let distance_from_center = |tile_key: &TileKey| {
1797            let horizontal_distance = f64::from(tile_key.tile_x) - center_tile_x;
1798            let vertical_distance = f64::from(tile_key.tile_y) - center_tile_y;
1799            horizontal_distance * horizontal_distance + vertical_distance * vertical_distance
1800        };
1801        let mut parent_tile_keys = visible_tiles
1802            .iter()
1803            .filter_map(|tile_key| tile_key.parent_tile_key())
1804            .filter(|tile_key| !visible_tile_set.contains(tile_key))
1805            .collect::<Vec<_>>();
1806        let mut ring_tile_keys = Vec::new();
1807        for visible_tile in &visible_tiles {
1808            for (horizontal_offset, vertical_offset) in VECTOR_BASE_RING_NEIGHBOR_OFFSETS {
1809                let neighbor_tile_x = i64::from(visible_tile.tile_x) + i64::from(horizontal_offset);
1810                let neighbor_tile_y = i64::from(visible_tile.tile_y) + i64::from(vertical_offset);
1811                if neighbor_tile_x < 0 || neighbor_tile_y < 0 {
1812                    continue;
1813                }
1814                if neighbor_tile_x as u64 >= tiles_per_axis
1815                    || neighbor_tile_y as u64 >= tiles_per_axis
1816                {
1817                    continue;
1818                }
1819                let Ok(neighbor_tile_key) = TileKey::new(
1820                    neighbor_tile_x as u32,
1821                    neighbor_tile_y as u32,
1822                    served_zoom_level,
1823                ) else {
1824                    continue;
1825                };
1826                if !visible_tile_set.contains(&neighbor_tile_key) {
1827                    ring_tile_keys.push(neighbor_tile_key);
1828                }
1829            }
1830        }
1831        parent_tile_keys.sort_by(|first, second| {
1832            distance_from_center(first)
1833                .total_cmp(&distance_from_center(second))
1834                .then_with(|| first.cmp(second))
1835        });
1836        parent_tile_keys.dedup();
1837        ring_tile_keys.sort_by(|first, second| {
1838            distance_from_center(first)
1839                .total_cmp(&distance_from_center(second))
1840                .then_with(|| first.cmp(second))
1841        });
1842        let mut candidates = parent_tile_keys;
1843        candidates.extend(ring_tile_keys);
1844        let mut seen_tile_keys = HashSet::new();
1845        candidates
1846            .into_iter()
1847            .filter(|tile_key| seen_tile_keys.insert(*tile_key))
1848            .collect()
1849    }

1851    /// Claims the cache misses among `candidate_tile_keys`, up to
1852    /// `maximum_claim_count` when one is given, and answers the detached fetch
1853    /// future. Shared by the visible and ring prefetch plans: both
1854    /// deduplicate and claim under one short lock, so neither duplicates
1855    /// another plan's request. The candidate order is the claim priority, and
1856    /// the budget is applied after the cached and in-flight addresses are
1857    /// skipped.
1858    ///
1859    /// Fetches start in bursts of [`Self::with_visible_prefetch_burst_tile_count`]
1860    /// and each completion is written into the shared cache (and handed to
1861    /// `delivery`) immediately, so no `join_all` gates the first arrival. A
1862    /// `drop_stale` plan (the ring) discards a delivery the latest visible set
1863    /// no longer touches instead of inserting a tile the camera has left.
1864    fn prefetch_tile_keys(
1865        &self,
1866        candidate_tile_keys: Vec<TileKey>,
1867        maximum_claim_count: Option<usize>,
1868        drop_stale: bool,
1869        delivery: Option<Arc<dyn Fn(TileKey) + Send + Sync>>,
1870    ) -> Option<impl std::future::Future<Output = usize> + Send + 'static> {
1871        let claimed_tile_keys = {
1872            let mut decoded_tiles = self
1873                .decoded_tiles
1874                .lock()
1875                .unwrap_or_else(PoisonError::into_inner);
1876            let mut seen_tile_keys = HashSet::new();
1877            candidate_tile_keys
1878                .into_iter()
1879                .filter(|tile_key| seen_tile_keys.insert(*tile_key))
1880                .filter(|tile_key| decoded_tiles.begin_fetch(*tile_key))
1881                .take(maximum_claim_count.unwrap_or(usize::MAX))
1882                .collect::<Vec<TileKey>>()
1883        };
1884        if claimed_tile_keys.is_empty() {
1885            return None;
1886        }
1887        let provider = Arc::clone(&self.provider);
1888        let decoded_tiles = Arc::clone(&self.decoded_tiles);
1889        let payload_cache = self.payload_cache.clone();
1890        let payload_cache_source_name = self.provider.source_descriptor().source_name;
1891        let payload_cache_time_to_live_seconds = self.payload_cache_time_to_live_seconds;
1892        let payload_cache_counters = Arc::clone(&self.payload_cache_counters);
1893        let latest_visible_tile_keys = Arc::clone(&self.latest_visible_tile_keys);
1894        let fetch_burst = self.visible_prefetch_burst_tile_count.max(1);
1895        Some(async move {
1896            let mut claim_guard =
1897                PrefetchClaimGuard::new(Arc::clone(&decoded_tiles), claimed_tile_keys.clone());
1898            let make_fetch = |tile_key: TileKey| {
1899                let provider = Arc::clone(&provider);
1900                let payload_cache = payload_cache.clone();
1901                let payload_cache_source_name = payload_cache_source_name.clone();
1902                let payload_cache_counters = Arc::clone(&payload_cache_counters);
1903                async move {
1904                    (
1905                        tile_key,
1906                        Self::fetch_and_decode_vector_tile(
1907                            provider.as_ref(),
1908                            payload_cache.as_deref(),
1909                            &payload_cache_source_name,
1910                            payload_cache_time_to_live_seconds,
1911                            &payload_cache_counters,
1912                            tile_key,
1913                        )
1914                        .await,
1915                    )
1916                }
1917            };
1918            let mut fetches = FuturesUnordered::new();
1919            let mut next_claim_index = 0;
1920            while next_claim_index < claimed_tile_keys.len() && fetches.len() < fetch_burst {
1921                fetches.push(make_fetch(claimed_tile_keys[next_claim_index]));
1922                next_claim_index += 1;
1923            }
1924            let mut delivered_tile_count = 0;
1925            while let Some((tile_key, fetched_tile)) = fetches.next().await {
1926                if next_claim_index < claimed_tile_keys.len() {
1927                    fetches.push(make_fetch(claimed_tile_keys[next_claim_index]));
1928                    next_claim_index += 1;
1929                }
1930                // Stale ring work is dropped, not inserted: the camera has
1931                // panned away and the tile would only occupy the cache.
1932                let is_stale = drop_stale && {
1933                    let latest_visible_tile_keys = latest_visible_tile_keys
1934                        .lock()
1935                        .unwrap_or_else(PoisonError::into_inner);
1936                    !ring_tile_is_relevant(&tile_key, &latest_visible_tile_keys)
1937                };
1938                if is_stale {
1939                    decoded_tiles
1940                        .lock()
1941                        .unwrap_or_else(PoisonError::into_inner)
1942                        .discard_fetch(tile_key);
1943                    claim_guard.mark_finished(tile_key);
1944                    continue;
1945                }
1946                let delivered = fetched_tile.is_ok();
1947                decoded_tiles
1948                    .lock()
1949                    .unwrap_or_else(PoisonError::into_inner)
1950                    .finish_fetch(tile_key, fetched_tile);
1951                claim_guard.mark_finished(tile_key);
1952                if delivered {
1953                    delivered_tile_count += 1;
1954                    if let Some(delivery) = &delivery {
1955                        delivery(tile_key);
1956                    }
1957                }
1958            }
1959            delivered_tile_count
1960        })
1961    }

2143    /// The shared frame-resolution body. `transition` carries the previous
2144    /// style and the elapsed seconds while a change blends; `None` styles
2145    /// from the current style alone and uses the styled-geometry cache.
2146    /// `motion_graded` freezes the style-zoom bucket at the last settled
2147    /// frame's, drops any transition blend and skips label assembly.
2148    /// `tile_zoom_level` is the level this frame's addresses belong to, and
2149    /// `frame_time_seconds` the frame's monotonic clock when it has one.
2150    fn cached_frame_content(
2151        &mut self,
2152        visible_tile_keys: &[TileKey],
2153        style_zoom_level: f64,
2154        transition: Option<&(CompiledStyle, f64)>,
2155        motion_graded: bool,
2156        tile_zoom_level: u8,
2157        frame_time_seconds: Option<f64>,
2158    ) -> Arc<VectorBaseFrame> {
2159        // A level change retires what the last frame drew: capture it before
2160        // this frame's geometry replaces it, so the retired level can stay on
2161        // screen while the new one fills. It is never fetched again.
2162        if self
2163            .zoom_transition
2164            .observed_tile_zoom_level()
2165            .is_some_and(|observed_tile_zoom_level| observed_tile_zoom_level != tile_zoom_level)
2166        {
2167            self.retained_level = self.last_level_frame.take();
2168        }
2169        let mut requested_tile_keys = visible_tile_keys.to_vec();
2170        requested_tile_keys.sort();
2171        requested_tile_keys.dedup();
2172        let requested_style_zoom = quantized_style_zoom(style_zoom_level);
2173        // A graded frame paints from the geometry the last settled frame
2174        // resolved, so a continuous zoom gesture does not restyle every tile
2175        // once per style bucket. A style transition cannot reuse cached
2176        // geometry (its paint changes every frame), so a graded frame paints
2177        // the current style's cache and the blend resumes at the settle.
2178        let quantized_style_zoom = if motion_graded {
2179            // Freeze on the last settled bucket; a gesture that began before
2180            // any frame settled freezes on this frame's own bucket instead,
2181            // so the following graded frames still reuse one style pass.
2182            *self
2183                .settled_style_zoom_bucket
2184                .get_or_insert(requested_style_zoom)
2185        } else {
2186            requested_style_zoom
2187        };
2188        let effective_transition = if motion_graded { None } else { transition };
2189        let evaluated_style_zoom =
2190            quantized_style_zoom as f64 / VECTOR_BASE_STYLE_ZOOM_QUANTIZATION_STEPS_PER_LEVEL;
2191        let sprite_atlas = self.resolved_sprite_atlas();
2192        // Read the cache's verdict for every address under one lock, then
2193        // style from the cloned tiles without holding it.
2194        let (cached_tiles, in_flight_fetch_count) = {
2195            let decoded_tiles = self
2196                .decoded_tiles
2197                .lock()
2198                .unwrap_or_else(PoisonError::into_inner);
2199            let cached_tiles = requested_tile_keys
2200                .iter()

2691    /// The decoded tile for the address, consulted through the payload cache
2692    /// first and fetched from the provider only on a miss. Kept free of the
2693    /// scheduler's caches so the prefetch can fetch every missing tile
2694    /// concurrently and insert the results afterwards.
2695    async fn fetch_and_decode_vector_tile(
2696        provider: &dyn VectorTileProvider,
2697        payload_cache: Option<&dyn CachedResponseStore<VectorTileData>>,
2698        payload_cache_source_name: &str,
2699        payload_cache_time_to_live_seconds: u64,
2700        payload_cache_counters: &VectorBasePayloadCacheCounters,
2701        tile_key: TileKey,
2702    ) -> Result<Arc<VectorTile>, String> {
2703        let payload_cache_fingerprint =
2704            vector_tile_payload_cache_fingerprint(payload_cache_source_name, tile_key);
2705        let decode = |tile_data: &VectorTileData| -> Result<Arc<VectorTile>, String> {
2706            Ok(Arc::new(decode_wire_vector_tile(tile_data).map_err(
2707                |decode_error| {
2708                    format!(
2709                        "the vector base tile {}/{}/{} failed to decode: {decode_error}",
2710                        tile_key.zoom_level, tile_key.tile_x, tile_key.tile_y
2711                    )
2712                },
2713            )?))
2714        };
2715        if let Some(payload_cache) = payload_cache {
2716            match payload_cache.lookup_response(&payload_cache_fingerprint) {
2717                Ok(Some(cached_payload)) => {
2718                    payload_cache_counters
2719                        .hit_count
2720                        .fetch_add(1, Ordering::Relaxed);
2721                    return decode(cached_payload.as_ref());
2722                }
2723                // A miss is a fetch; a store read failure degrades to the
2724                // same path (the cache is an accelerator, never a gate).
2725                Ok(None) | Err(_) => {
2726                    payload_cache_counters
2727                        .miss_count
2728                        .fetch_add(1, Ordering::Relaxed);
2729                }
2730            }
2731        }
2732        let tile_data = provider
2733            .fetch_vector_tile(tile_key.tile_x, tile_key.tile_y, tile_key.zoom_level)
2734            .await
2735            .map_err(|fetch_error| {
2736                format!(
2737                    "the vector base tile {}/{}/{} failed to fetch: {fetch_error}",
2738                    tile_key.zoom_level, tile_key.tile_x, tile_key.tile_y
2739                )
2740            })?;
2741        let decoded_tile = decode(&tile_data)?;
2742        if let Some(payload_cache) = payload_cache {
2743            // Storage is best-effort: a failing store must not lose the
2744            // freshly fetched tile.
2745            let _ = payload_cache.store_response(
2746                &payload_cache_fingerprint,
2747                Arc::new(tile_data),
2748                payload_cache_time_to_live_seconds,
2749            );
2750        }
2751        Ok(decoded_tile)
2752    }
2753
2754    /// Inserts a decoded tile and evicts the oldest decoded tiles beyond the
2755    /// cache's capacity. Styled geometry is keyed by the address and a style
2756    /// revision and is bounded by its own cache, so decoded-tile eviction
2757    /// never touches it.
2758    ///
2759    /// The decoded-tile eviction below drops a tile's styled entries, but a
2760    /// tile stays decoded for many frames while the camera may style it once
2761    /// per zoom bucket; this cache is therefore bounded on its own too.
2762    fn store_styled_tile(
2763        &mut self,
2764        styled_key: StyledTileCacheKey,
2765        styled_contents: StyledTileContents,
2766    ) {
2767        if self
2768            .styled_tiles
2769            .insert(styled_key, styled_contents)
2770            .is_none()
2771        {
2772            self.styled_tile_insertion_order.push_back(styled_key);
2773        }
2774        while self.styled_tiles.len() > self.maximum_cached_styled_tile_count {
2775            let Some(evicted_styled_key) = self.styled_tile_insertion_order.pop_front() else {
2776                break;
2777            };
2778            self.styled_tiles.remove(&evicted_styled_key);
2779        }
2780    }
2781}

2783/// Whether a ring-plan tile still touches the latest visible set: it is a
2784/// visible address, a visible tile's parent (the coarse fallback the plan
2785/// prefetches) or one of the eight same-zoom neighbors of a visible tile. A
2786/// completion that answers `false` is stale — the camera panned away while the
2787/// request was in flight — and is dropped instead of cached.
2788fn ring_tile_is_relevant(tile_key: &TileKey, visible_tile_keys: &[TileKey]) -> bool {
2789    visible_tile_keys.iter().any(|visible_tile_key| {
2790        if visible_tile_key == tile_key
2791            || visible_tile_key.parent_tile_key().as_ref() == Some(tile_key)
2792        {
2793            return true;
2794        }
2795        if visible_tile_key.zoom_level != tile_key.zoom_level {
2796            return false;
2797        }
2798        let horizontal_distance = i64::from(tile_key.tile_x) - i64::from(visible_tile_key.tile_x);
2799        let vertical_distance = i64::from(tile_key.tile_y) - i64::from(visible_tile_key.tile_y);
2800        (-1..=1).contains(&horizontal_distance) && (-1..=1).contains(&vertical_distance)
2801    })
2802}

2804/// Hashes everything a resolved frame's pixels depend on, in paint order: the
2805/// requested addresses, the style revision, the style-zoom bucket, a running
2806/// transition's elapsed time, the sprite atlas revision, the motion-graded and
2807/// label-assembly flags, the tiles drawn at their own address and the coarse
2808/// ancestors painted beneath them. The revision is the caller's cheap
2809/// alternative to deep-comparing a frame's overlay list; equal revisions mean
2810/// equal overlays and equal label candidates.
2811#[allow(clippy::too_many_arguments)]
2812fn frame_content_revision(
2813    style_revision: u64,
2814    quantized_style_zoom: i64,
2815    motion_graded: bool,
2816    transition_elapsed_seconds: Option<f64>,
2817    sprite_revision: u64,
2818    requested_tile_keys: &[TileKey],
2819    drawable_tiles: &[(TileKey, Arc<VectorTile>)],
2820    fallback_ancestors: &[(TileKey, Arc<VectorTile>)],
2821    drawable_tile_keys: &HashSet<TileKey>,
2822    zoom_transition_running: Option<bool>,
2823    retained_level: Option<(u8, f32)>,
2824) -> u64 {
2825    let mut revision = FRAME_CONTENT_REVISION_OFFSET_BASIS;
2826    let mut mix = |value: u64| {
2827        revision ^= value;
2828        revision = revision.wrapping_mul(FRAME_CONTENT_REVISION_PRIME);
2829    };
2830    let mix_tile_key = |mix: &mut dyn FnMut(u64), tile_key: &TileKey| {
2831        mix((u64::from(tile_key.zoom_level) << 48)
2832            ^ (u64::from(tile_key.tile_x) << 24)
2833            ^ u64::from(tile_key.tile_y));
2834    };
2835    mix(style_revision);
2836    mix(quantized_style_zoom as u64);
2837    mix(u64::from(motion_graded));
2838    match transition_elapsed_seconds {
2839        Some(elapsed_seconds) => {
2840            mix(1);
2841            mix(elapsed_seconds.to_bits());
2842        }
2843        None => mix(0),
2844    }
2845    match zoom_transition_running {
2846        Some(is_running) => {
2847            mix(1);
2848            mix(u64::from(is_running));
2849        }
2850        None => mix(0),
2851    }
2852    match retained_level {
2853        Some((retained_tile_zoom_level, retained_opacity)) => {
2854            mix(1);
2855            mix(u64::from(retained_tile_zoom_level));
2856            mix(u64::from(retained_opacity.to_bits()));
2857        }
2858        None => mix(0),
2859    }
2860    mix(sprite_revision);
2861    mix(requested_tile_keys.len() as u64);
2862    for tile_key in requested_tile_keys {
2863        mix_tile_key(&mut mix, tile_key);
2864    }
2865    mix(drawable_tiles.len() as u64);
2866    for (tile_key, _) in drawable_tiles {
2867        mix_tile_key(&mut mix, tile_key);
2868    }
2869    mix(fallback_ancestors.len() as u64);
2870    for (tile_key, _) in fallback_ancestors {
2871        if !drawable_tile_keys.contains(tile_key) {
2872            mix_tile_key(&mut mix, tile_key);
2873        }
2874    }
2875    revision
2876}

2878/// Rebuilds the retired level's geometry from the styled cache at the
2879/// snapshot's style revision and zoom bucket and appends it at `opacity`, in
2880/// global style order. A tile the requested level already paints — at its own
2881/// address or as an ancestor stand-in — is skipped, so a zoom-in never lays
2882/// the same translucent geometry over itself. Returns how many retired tiles
2883/// were appended.
2884fn append_retained_level_overlays(
2885    overlays: &mut Vec<MapOverlay>,
2886    styled_tiles: &HashMap<StyledTileCacheKey, StyledTileContents>,
2887    retained_level: &LevelFrameSnapshot,
2888    opacity: f32,
2889    requested_level_painted_tile_keys: &[TileKey],
2890) -> usize {
2891    let mut retained_layer_batches: Vec<Vec<MapOverlay>> =
2892        vec![Vec::new(); retained_level.layer_count];
2893    let mut retained_tile_count = 0;
2894    for tile_key in &retained_level.tile_keys {
2895        if requested_level_painted_tile_keys.contains(tile_key) {
2896            continue;
2897        }
2898        let styled_key = StyledTileCacheKey {
2899            tile_key: *tile_key,
2900            style_revision: retained_level.style_revision,
2901            quantized_style_zoom: retained_level.quantized_style_zoom,
2902        };
2903        let Some(styled_contents) = styled_tiles.get(&styled_key) else {
2904            continue;
2905        };
2906        retained_tile_count += 1;
2907        for (layer_batch, tile_overlays) in retained_layer_batches
2908            .iter_mut()
2909            .zip(styled_contents.overlays.iter())
2910        {
2911            layer_batch.extend(
2912                tile_overlays
2913                    .iter()
2914                    .map(|overlay| overlay.with_opacity_multiplier(opacity)),
2915            );
2916        }
2917    }
2918    overlays.extend(retained_layer_batches.into_iter().flatten());
2919    retained_tile_count
2920}

2943/// Unwraps the wire envelope and decodes the tile: a gzip-wrapped body is
2944/// decompressed first, so the decoder only ever sees plain MVT protobuf. The
2945/// record is borrowed because the caller keeps the payload for its cache.
2946pub(crate) fn decode_wire_vector_tile(tile_data: &VectorTileData) -> Result<VectorTile, String> {
2947    let plain_tile_bytes = match tile_data.tile_encoding {
2948        VectorTileEncoding::MapboxVectorTile => tile_data.tile_bytes.clone(),
2949        VectorTileEncoding::GzippedMapboxVectorTile => {
2950            let gzip_decoder = GzDecoder::new(tile_data.tile_bytes.as_slice());
2951            let mut unwrapped_bytes = Vec::new();
2952            let mut limited_decoder =
2953                gzip_decoder.take(MAXIMUM_DECOMPRESSED_VECTOR_TILE_BYTES as u64 + 1);
2954            limited_decoder
2955                .read_to_end(&mut unwrapped_bytes)
2956                .map_err(|decompress_error| {
2957                    format!(
2958                        "the gzip-wrapped vector tile payload failed to decompress: \
2959                         {decompress_error}"
2960                    )
2961                })?;
2962            if unwrapped_bytes.len() > MAXIMUM_DECOMPRESSED_VECTOR_TILE_BYTES {
2963                return Err(format!(
2964                    "the gzip-wrapped vector tile payload decompressed beyond the {MAXIMUM_DECOMPRESSED_VECTOR_TILE_BYTES}-byte limit"
2965                ));
2966            }
2967            unwrapped_bytes
2968        }
2969    };
2970    decode_vector_tile(&plain_tile_bytes).map_err(|decode_error| decode_error.to_string())
2971}
