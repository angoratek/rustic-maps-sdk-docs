1//! Offline route calculation over compiled routing graph archives.
2//!
3//! [`ArchiveOfflineRoutingProvider`] implements [`OfflineRoutingProvider`]
4//! over a compiled routing graph archive. It loads the archive from a
5//! memory-mapped file on native targets or from in-memory bytes on every
6//! target, validates it with the archive reader, and builds the adjacency and
7//! turn-restriction indexes once. Route requests are then answered with A*
8//! under a haversine heuristic.
9//!
10//! # Targets
11//!
12//! The whole module compiles on every target; only graph loading differs.
13//!
14//! - [`OfflineGraphSource::Memory`] is available everywhere and is the only
15//!   graph source on WebAssembly.
16//! - [`OfflineGraphSource::FilePath`] memory-maps the archive on native
17//!   targets. On WebAssembly it returns
18//!   [`SDKError::ProviderRequestRejected`] with a message that directs the
19//!   caller to [`OfflineGraphSource::Memory`], because the browser has no
20//!   memory mapping.
21//!
22//! # Routing behavior
23//!
24//! - Only automobile routing is supported. The archive carries an automobile
25//!   profile, so a request for another transportation mode is rejected with
26//!   [`SDKError::ProviderRequestRejected`] rather than answered.
27//! - Costs follow [`RouteOptions::route_strategy`]: `Fastest` minimizes edge
28//!   durations and `Shortest` minimizes edge distances. Edge speeds and road
29//!   classes come from each edge record.
30//! - Steps are derived from graph metadata. Besides road-class and speed
31//!   runs, a step boundary occurs at every junction whose signed bearing
32//!   change leaves the straight band; the step then carries the matching
33//!   [`TurnDirection`]. A road-class or speed change without a turn produces
34//!   a `Continue` step. The archive carries no street names, so instruction
35//!   text stays name-free and faithful to the geometry, for example
36//!   `"Turn right"` or `"U-turn"`. A strongly curved road yields a step at
37//!   each junction.
38//! - Display and speech text on a step names the maneuver at the step's end
39//!   junction, the point a countdown to the next maneuver refers to.
40//!   [`ManeuverType`] stays anchored to the maneuver that opens the step. See
41//!   `end_anchored_instruction_text`.
42//! - Turn restrictions are evaluated against the incoming edge of the
43//!   settled path. The approximation is exact unless a node is reachable
44//!   through several best-cost paths with differently restricted incoming
45//!   edges; in that case it can over-restrict, never under-restrict.
46//!
47//! # Threading and async
48//!
49//! [`OfflineRoutingProvider::load_offline_graph`] validates the archive and
50//! builds the graph indexes, and
51//! [`OfflineRoutingProvider::calculate_offline_route`] snaps the endpoints and
52//! runs A*. Both are CPU-bound and run through the blocking-work seam
53//! ([`crate::blocking_work::BlockingWorkExecutor`]): a target with a blocking
54//! pool runs them on a worker thread, and the browser runs them inline on its
55//! single task queue. No lock is held across an await; the search clones the
56//! loaded graph handle and releases the read lock before running.
57//!
58//! A load validates the new archive completely before replacing the current
59//! graph; a failed load leaves the previous graph loaded. The provider is safe
60//! to share across threads.
61//!
62//! # Search engine and performance measurement
63//!
64//! [`a_star_search`] and [`dijkstra_reference_search`] expose the search
65//! engine directly so performance can be measured over the same loaded graph.
66//! Dijkstra is a reference baseline only: production routing always goes
67//! through A*. Both searches expose [`ComputedRoute::settled_node_count`], a
68//! deterministic expansion metric for comparing them. These items are hidden
69//! from generated documentation and are not part of the supported API.

124// Junction-geometry constants (`offline_routing`'s maneuver derivation).
125//
126// Bearings are measured on the local equirectangular plane around a
127// junction's midpoint, mirroring rustic-maps-navigation's projection geometry and
128// the compiler's mean-Earth radius, so derived turns match the geometry the
129// archive itself encodes.
130/// Mean-Earth radius for the local-plane bearing geometry, meters.
131const EARTH_RADIUS_METERS: f64 = 6_371_000.0;
132/// Segments shorter than this magnitude carry no representable direction;
133/// their junction derives no maneuver rather than a fabricated one.
134const MINIMUM_DIRECTIONAL_SEGMENT_LENGTH_METERS: f64 = 0.01;
135/// Angular domain conversions for bearing arithmetic, in degrees.
136const FULL_CIRCLE_DEGREES: f64 = 360.0;
137/// Half-revolution magnitude, in degrees, of the signed bearing-change range.
138const HALF_TURN_DEGREES: f64 = 180.0;

140// Turn-direction bands over the junction's signed bearing change (degrees).
141//
142// Magnitude bands, chosen so the axis-aligned street grids' ninety-degree
143// corners classify as standard turns and gentle curve junctions stay inside
144// the straight band; each band edge is inclusive on its turn side:
145/// Bearing changes within this absolute magnitude keep the run: the geometry
146/// reads as straight on, so no turn maneuver is derived (a road-class/speed
147/// change in that band still opens a `Continue` step).
148const STRAIGHT_ON_BAND_DEGREES: f64 = 20.0;
149/// Junction turns up to this magnitude are *slight* left/right turns.
150const SLIGHT_TURN_BAND_DEGREES: f64 = 60.0;
151/// Junction turns up to this magnitude are standard left/right turns.
152const STANDARD_TURN_BAND_DEGREES: f64 = 120.0;
153/// Junction turns up to this magnitude are *sharp* left/right turns; beyond
154/// it the geometry reads as a full reversal of direction (a U-turn).
155const SHARP_TURN_BAND_DEGREES: f64 = 160.0;

185/// A validated archive plus the routing indexes built from it at load time.
186///

197    node_coordinates: Vec<GeographicCoordinate>,
198    outgoing_half_edges: Vec<Vec<HalfEdge>>,
199    /// Keyed by `(from edge record index, via node index)`. Multiple rules
200    /// for one key combine: a `no` rule blocks its recorded edge pair, and

202    /// allowed edge records.
203    turn_rules: HashMap<(u32, u32), Vec<TurnRule>>,
204}

206/// Builds a coordinate out of archive node degrees. The archive quantizes
207/// into canonical ranges, so validation can only fail on a compiler bug.
208fn archive_node_coordinate(latitude_degrees: f64, longitude_degrees: f64) -> GeographicCoordinate {
209    GeographicCoordinate::from_degrees(latitude_degrees, longitude_degrees)
210        .expect("archive node coordinates are quantized within the canonical ranges")

213impl LoadedRoutingGraph {
214    /// Turns a validated archive into a router-ready graph, deriving the
215    /// half-edge adjacency and the restriction rules once at load time.
216    ///
217    /// Hidden from generated documentation; public for performance
218    /// measurement code (see the struct documentation).
219    #[doc(hidden)]
220    #[must_use]
221    pub fn new(network_graph: OfflineRoutingNetworkGraph) -> Self {
222        let node_coordinates = network_graph
223            .nodes()
224            .iter()
225            .map(|node_record| {
226                archive_node_coordinate(
227                    node_record.latitude_degrees(),
228                    node_record.longitude_degrees(),
229                )
230            })
231            .collect();
232
233        let mut outgoing_half_edges: Vec<Vec<HalfEdge>> =
234            vec![Vec::new(); network_graph.nodes().len()];
235        let mut turn_rules: HashMap<(u32, u32), Vec<TurnRule>> = HashMap::new();
236
237        for (edge_record_index, edge_record) in network_graph.edges().iter().enumerate() {
238            let road_class = edge_record
239                .road_class()
240                .expect("validated at load: the reader rejects unknown road classes");
241            let half_edge_template = HalfEdge {
242                to_node_index: 0,
243                edge_record_index: edge_record_index as u32,
244                distance_meters: f64::from(edge_record.distance_meters()),
245                duration_seconds: f64::from(edge_record.duration_milliseconds())
246                    / MILLISECONDS_PER_SECOND,
247                road_class,
248                speed_kilometers_per_hour: edge_record.speed_kilometers_per_hour(),
249            };
250            // Emitted record orientation: the compiler stores every
251            // traversable direction as its own (source, target) pair — the
252            // round-trip contract of the committed fixture pins the
253            // against-node-order direction as the stored (later, earlier)
254            // pair — so the traversable direction is exactly the stored one
255            // and the access bits annotate which OSM way node-order
256            // direction the record covers (provenance, not orientation).
257            // (Reading the backward bit as "traverse target→source" instead
258            // would fold every two-way way's two directions onto one arc.)
259            if edge_record.forward_allowed() || edge_record.backward_allowed() {
260                outgoing_half_edges[edge_record.source_node_index() as usize].push(HalfEdge {
261                    to_node_index: edge_record.target_node_index(),
262                    ..half_edge_template
263                });
264            }
265        }
266
267        for turn_restriction in network_graph.turn_restrictions() {
268            turn_rules
269                .entry((
270                    turn_restriction.from_edge_index(),
271                    turn_restriction.via_node_index(),
272                ))
273                .or_default()
274                .push(TurnRule {
275                    restriction_kind: turn_restriction
276                        .restriction_kind()
277                        .expect("validated at load: the reader rejects unknown restriction kinds"),
278                    to_edge_index: turn_restriction.to_edge_index(),
279                });
280        }
281
282        Self {
283            node_coordinates,
284            outgoing_half_edges,
285            turn_rules,
286        }
287    }
288
289    /// Nearest node to the request coordinate within
290    /// [`NODE_SNAP_TOLERANCE_METERS`].
291    fn snap_node_index(&self, request_coordinate: &GeographicCoordinate) -> Result<u32, SDKError> {
292        let (best_node_index, best_distance_meters) = self
293            .node_coordinates
294            .iter()
295            .enumerate()
296            .map(|(node_index, node_coordinate)| {
297                (
298                    node_index,
299                    node_coordinate.haversine_distance_meters(request_coordinate),
300                )
301            })
302            .min_by(|left, right| left.1.total_cmp(&right.1))
303            .expect("the archive always carries at least one node to snap to");
304        if best_distance_meters > NODE_SNAP_TOLERANCE_METERS {
305            return Err(SDKError::InvalidCoordinateInput(format!(
306                "no offline routing graph node within \
307                 {NODE_SNAP_TOLERANCE_METERS} m of the request coordinate"
308            )));
309        }
310        Ok(best_node_index as u32)
311    }
312}

367/// Loads a compiled routing graph from in-memory archive bytes and calculates
368/// one route between two coordinates with the default request options
369/// ([`RouteOptions::default`]: automobile, fastest, metric).
370///
371/// The bytes are validated by the same reader as
372/// [`OfflineGraphSource::Memory`]. This function is the single implementation
373/// behind the corresponding free helper and WebAssembly export, so the native
374/// and browser surfaces cannot diverge.
375///
376/// # Parameters
377/// - `archive_bytes` — a complete compiled routing graph archive.
378/// - `start`, `end` — the route endpoints.
379///
380/// # Returns
381/// A route between the two points, including geometry and steps.
382///
383/// # Errors
384/// Returns [`SDKError::OfflineRoutingFailure`] when the archive is truncated,
385/// malformed or of an unsupported version. Returns
386/// [`SDKError::InvalidCoordinateInput`] when an endpoint is beyond the graph's
387/// snap tolerance, and [`SDKError::ProviderRequestRejected`] when the graph
388/// cannot connect the two points. No coordinate or connection is guessed.
389///
390/// # Async
391/// The function performs no network access and does not block on I/O beyond
392/// validating the supplied bytes.
393pub async fn calculate_offline_route_from_archive_bytes(
394    archive_bytes: &[u8],
395    start: &GeographicCoordinate,
396    end: &GeographicCoordinate,
397) -> Result<RouteData, SDKError> {
398    let offline_provider = ArchiveOfflineRoutingProvider::new();
399    offline_provider
400        .load_offline_graph(OfflineGraphSource::Memory(archive_bytes.to_vec()))
401        .await?;
402    offline_provider
403        .calculate_offline_route(start, end, &RouteOptions::default())
404        .await
405}

418/// The cost weight A* minimizes, derived from
419/// [`RouteOptions::route_strategy`].
420///
421/// Hidden from generated documentation: it is public so performance
422/// measurement code can pass it into both searches (see the struct
423/// documentation of [`LoadedRoutingGraph`]). It is not part of the supported

425#[doc(hidden)]
426#[derive(Debug, Clone, Copy)]
427pub enum TraversalCost {
428    /// Minimize edge durations (the `Fastest` strategy).
429    TimeSeconds,
430    /// Minimize edge distances (the `Shortest` strategy).
431    DistanceMeters,
432}

434impl TraversalCost {
435    fn cost_of(&self, half_edge: &HalfEdge) -> f64 {
436        match self {
437            Self::TimeSeconds => half_edge.duration_seconds,
438            Self::DistanceMeters => half_edge.distance_meters,
439        }
440    }

443/// Binary-heap entry ordered smallest-`priority`-first. Equality and
444/// ordering follow `total_cmp` (total order), so `Eq` is a deliberate, safe
445/// empty implementation.
446#[derive(Debug, PartialEq)]
447struct FrontierEntry {
448    priority: f64,
449    node_index: u32,
450}
451
452impl Eq for FrontierEntry {}
453
454impl Ord for FrontierEntry {
455    fn cmp(&self, other: &Self) -> std::cmp::Ordering {
456        // The heap pops what this ordering calls "greatest", so the priority
457        // comparison is inverted here to pop the smallest priority first.
458        other
459            .priority
460            .total_cmp(&self.priority)
461            .then_with(|| self.node_index.cmp(&other.node_index))
462    }
463}
464
465impl PartialOrd for FrontierEntry {
466    fn partial_cmp(&self, other: &Self) -> Option<std::cmp::Ordering> {
467        Some(self.cmp(other))
468    }
469}

471#[async_trait]
472impl OfflineRoutingProvider for ArchiveOfflineRoutingProvider {
473    async fn load_offline_graph(&self, graph_source: OfflineGraphSource) -> Result<(), SDKError> {
474        // Validation, memory mapping and index construction are CPU-bound and
475        // run through the blocking-work seam; the wasm inline executor runs
476        // them on the browser task queue, the native executor on a worker.
477        let network_graph = run_blocking(self.blocking_work_executor.as_ref(), move || {
478            match graph_source {
479                // Blocking mmap + read-only validation, off the async reactor.
480                #[cfg(not(target_arch = "wasm32"))]
481                OfflineGraphSource::FilePath(archive_path) => {
482                    offline_routing_network_graph_from_mapped_file(Path::new(&archive_path))
483                }
484                // The wasm arm of the compile-time target switch: no `mmap`
485                // exists in the browser, so a file-path load is rejected typed
486                // instead of being attempted (see the module docs).
487                #[cfg(target_arch = "wasm32")]
488                OfflineGraphSource::FilePath(_) => Err(SDKError::ProviderRequestRejected(
489                    wasm_file_path_rejection_message().to_string(),
490                )),
491                OfflineGraphSource::Memory(archive_bytes) => {
492                    OfflineRoutingNetworkGraph::from_bytes(&archive_bytes)
493                }
494            }
495        })
496        .await?;
497
498        // Validate-completely-then-replace: a failed load above leaves the
499        // previously loaded graph untouched. Locks are held for the copy,
500        // never across an await.
501        let mut loaded_graph_guard = self.loaded_graph.write().unwrap_or_else(|poisoned| {
502            // A poisoned lock only means a thread panicked mid-replacement;
503            // the stored graph itself is a plain value and stays usable.
504            poisoned.into_inner()
505        });
506        *loaded_graph_guard = Some(Arc::new(LoadedRoutingGraph::new(network_graph)));
507        Ok(())
508    }
509
510    async fn calculate_offline_route(
511        &self,
512        start: &GeographicCoordinate,
513        end: &GeographicCoordinate,
514        route_options: &RouteOptions,
515    ) -> Result<RouteData, SDKError> {
516        match route_options.transportation_mode {
517            TransportationMode::Automobile => {}
518            other_mode => {
519                return Err(SDKError::ProviderRequestRejected(format!(
520                    "the offline routing graph is an automobile profile; \
521                     requested {other_mode:?}"
522                )));
523            }
524        }
525
526        // Clone the graph handle out of the lock, then release it: the
527        // CPU-bound snap and A* search run through the blocking-work seam
528        // without holding a lock across an await.
529        let loaded_graph = {
530            let loaded_graph_guard = self
531                .loaded_graph
532                .read()
533                .unwrap_or_else(|poisoned| poisoned.into_inner());
534            loaded_graph_guard.as_ref().cloned().ok_or_else(|| {
535                SDKError::ProviderRequestRejected(
536                    "no offline routing graph is loaded; call load_offline_graph first".to_string(),
537                )
538            })?
539        };
540
541        let traversal_cost = match route_options.route_strategy {
542            RouteStrategy::Fastest => TraversalCost::TimeSeconds,
543            RouteStrategy::Shortest => TraversalCost::DistanceMeters,
544        };
545        let start = *start;
546        let end = *end;
547        run_blocking(self.blocking_work_executor.as_ref(), move || {
548            let start_node_index = loaded_graph.snap_node_index(&start)?;
549            let end_node_index = loaded_graph.snap_node_index(&end)?;
550            compute_route(
551                loaded_graph.as_ref(),
552                start_node_index,
553                end_node_index,
554                traversal_cost,
555            )
556        })
557        .await
558    }
559}

585/// Runs A* between the snapped nodes and materializes the result as
586/// [`RouteData`].
587///
588/// # Errors
589/// Returns [`SDKError::ProviderRequestRejected`] when no drivable path exists
590/// between the two nodes.
591fn compute_route(
592    loaded_graph: &LoadedRoutingGraph,
593    start_node_index: u32,
594    end_node_index: u32,
595    traversal_cost: TraversalCost,
596) -> Result<RouteData, SDKError> {
597    let Some(route_chain) = a_star_search(
598        loaded_graph,
599        start_node_index,
600        end_node_index,
601        traversal_cost,
602    ) else {
603        return Err(SDKError::ProviderRequestRejected(
604            "the offline routing graph cannot connect the request points; \
605             no drivable path exists between the snapped nodes"
606                .to_string(),
607        ));
608    };
609    Ok(materialize_route_data(loaded_graph, &route_chain))
610}

612/// The maneuver content of one materialized route step (see the docs of
613/// [`RouteStepSpan`]).
614#[derive(Debug, Clone, Copy, PartialEq)]
615enum StepManeuver {
616    /// The route's opening step.
617    Departure,
618    /// A road-class/speed run change without a derived turn.
619    Continue,
620    /// A junction turn derived from the signed bearing change.
621    Turn(TurnDirection),
622}

624/// One maximal step of the materialized route: a graph-edge span carried as
625/// one `RouteStep`, opened by a maneuver ([`StepManeuver`]) and kept open
626/// while the junctions along it stay inside the straight band on unchanged
627/// road class and speed.
628struct RouteStepSpan {
629    /// Inclusive node-chain index span of the step (the step's shape runs
630    /// from its first node's predecessor edge to the junction node closing
631    /// it — the next step's maneuver point).
632    node_chain_start: usize,
633    node_chain_end: usize,
634    distance_meters: f64,
635    duration_seconds: f64,
636    step_maneuver: StepManeuver,
637}

639/// The junction verdict between two consecutive route edges: the maneuver
640/// [`StepManeuver`] the next step opens with, or `None` when the run
641/// continues (geometry within the straight band on unchanged road class and
642/// speed).
643fn junction_step_entry(
644    node_chain: &[GeographicCoordinate],
645    route_half_edges: &[HalfEdge],
646    edge_position: usize,
647) -> Option<StepManeuver> {
648    let incoming_bearing =
649        segment_bearing_degrees(&node_chain[edge_position - 1], &node_chain[edge_position]);
650    let outgoing_bearing =
651        segment_bearing_degrees(&node_chain[edge_position], &node_chain[edge_position + 1]);
652    let (Some(incoming_bearing_degrees), Some(outgoing_bearing_degrees)) =
653        (incoming_bearing, outgoing_bearing)
654    else {
655        // Unresolvable junction geometry derives no turn maneuver; the
656        // road-class/speed run comparison below still applies.
657        return run_key_change_maneuver(
658            &route_half_edges[edge_position - 1],
659            &route_half_edges[edge_position],
660        );
661    };
662    let signed_bearing_change_degrees =
663        signed_bearing_change_degrees(incoming_bearing_degrees, outgoing_bearing_degrees);
664    if let Some(derived_turn_direction) = derived_turn_direction(signed_bearing_change_degrees) {
665        return Some(StepManeuver::Turn(derived_turn_direction));
666    }
667    run_key_change_maneuver(
668        &route_half_edges[edge_position - 1],
669        &route_half_edges[edge_position],
670    )
671}

673/// The `Continue` maneuver of a road-class or speed change, or `None` when
674/// the two edges share both columns.
675fn run_key_change_maneuver(
676    previous_half_edge: &HalfEdge,
677    half_edge: &HalfEdge,
678) -> Option<StepManeuver> {
679    let same_run_key = previous_half_edge.road_class == half_edge.road_class
680        && previous_half_edge.speed_kilometers_per_hour == half_edge.speed_kilometers_per_hour;
681    if same_run_key {
682        return None;
683    }
684    Some(StepManeuver::Continue)
685}

687/// North-referenced bearing of the segment start→end, in degrees over
688/// `[0, 360)`, measured on the local equirectangular plane around the segment
689/// midpoint.
690///
691/// # Returns
692/// The bearing, or `None` for a segment too short to carry a representable
693/// direction.
694fn segment_bearing_degrees(
695    segment_start: &GeographicCoordinate,
696    segment_end: &GeographicCoordinate,
697) -> Option<f64> {
698    let reference_latitude = (segment_start.latitude + segment_end.latitude) / 2.0;
699    let east_meters = (segment_end.longitude - segment_start.longitude).to_radians()
700        * EARTH_RADIUS_METERS
701        * reference_latitude.to_radians().cos();
702    let north_meters =
703        (segment_end.latitude - segment_start.latitude).to_radians() * EARTH_RADIUS_METERS;
704    let segment_length_meters = east_meters.hypot(north_meters);
705    if segment_length_meters < MINIMUM_DIRECTIONAL_SEGMENT_LENGTH_METERS {
706        return None;
707    }
708    let north_referenced_bearing_degrees = east_meters.atan2(north_meters).to_degrees();
709    Some((north_referenced_bearing_degrees + FULL_CIRCLE_DEGREES).rem_euclid(FULL_CIRCLE_DEGREES))
710}
711
712/// The signed bearing change between two north-referenced bearings, in
713/// degrees over `(-180, 180]`, measuring clockwise (toward east from a
714/// northbound road) as positive: the right-turn side.
715fn signed_bearing_change_degrees(
716    incoming_bearing_degrees: f64,
717    outgoing_bearing_degrees: f64,
718) -> f64 {
719    (outgoing_bearing_degrees - incoming_bearing_degrees + HALF_TURN_DEGREES)
720        .rem_euclid(FULL_CIRCLE_DEGREES)
721        - HALF_TURN_DEGREES
722}

724/// The turn a junction's signed bearing change derives, or `None` while the
725/// change stays inside the straight band (see the band constants above).
726///
727/// [`TurnDirection::Straight`] and [`TurnDirection::LeavingRoad`] are never
728/// derived: the straight band closes on `None`, because the run's `Continue`
729/// semantics cover the straight case, and a road-name departure is not a
730/// bearing fact the archive carries.
731fn derived_turn_direction(signed_bearing_change_degrees: f64) -> Option<TurnDirection> {
732    let turn_magnitude_degrees = signed_bearing_change_degrees.abs();
733    if turn_magnitude_degrees <= STRAIGHT_ON_BAND_DEGREES {
734        return None;
735    }
736    let (right_turn_direction, left_turn_direction) =
737        if turn_magnitude_degrees <= SLIGHT_TURN_BAND_DEGREES {
738            (TurnDirection::SlightRight, TurnDirection::SlightLeft)
739        } else if turn_magnitude_degrees <= STANDARD_TURN_BAND_DEGREES {
740            (TurnDirection::Right, TurnDirection::Left)
741        } else if turn_magnitude_degrees <= SHARP_TURN_BAND_DEGREES {
742            (TurnDirection::SharpRight, TurnDirection::SharpLeft)
743        } else {
744            (TurnDirection::UTurn, TurnDirection::UTurn)
745        };
746    Some(if signed_bearing_change_degrees.is_sign_positive() {
747        right_turn_direction
748    } else {
749        left_turn_direction
750    })
751}

790/// The instruction text surfaced on the step covering the span at
791/// `route_span_index`, given each span's authored text in span order.
792///
793/// # Step text is end-anchored
794///
795/// A span's own opening maneuver is anchored at the junction entering the
796/// span, which matches the head-anchored [`ManeuverType`] and the archive
797/// geometry. A banner, however, counts down to a step's end: the junction
798/// closing the span. While a span is traversed, head-anchoring would keep
799/// narrating the turn already performed and never name the maneuver being
800/// approached. The step's text therefore carries the authored text of the
801/// next span's opening maneuver, the maneuver at the step's end junction.
802///
803/// - The final traversal span has no following junction maneuver, because its
804///   end is the destination itself. It keeps its own authored text, so no
805///   authored text is lost.
806/// - The departure text is never surfaced as a banner while a turn is still
807///   ahead. Only a route with no junction maneuver at all keeps it.
808/// - The arrival is not a span-authored text. It is an appended, zero-cost
809///   terminal step, and its text stays the arrival's own; the final traversal
810///   span does not adopt it.
811fn end_anchored_instruction_text(
812    authored_texts: &[&'static str],
813    route_span_index: usize,
814) -> &'static str {
815    // The `&&'static str` of `get` coerces to the `&'static str` return.
816    authored_texts
817        .get(route_span_index + 1)
818        .unwrap_or(&authored_texts[route_span_index])
819}

821/// A* over the half-edge adjacency with a haversine heuristic.
822///
823/// The heuristic is admissible for both weights: straight-line distance is a
824/// lower bound on distance costs, and, under the packed speed column's
825/// saturation limit, on duration costs. Turn restrictions are evaluated
826/// against the settled path's incoming half-edge (see the module
827/// documentation).
828///
829/// # Parameters
830/// - `loaded_graph` — the indexed graph to search.
831/// - `start_node_index`, `end_node_index` — the endpoint node indexes.
832/// - `traversal_cost` — the cost weight to minimize.
833///
834/// # Returns
835/// The optimal route chain, or `None` when the end node is unreachable.
836///
837/// Hidden from generated documentation: public so performance measurement
838/// code can compare it with [`dijkstra_reference_search`]. It is not part of
839/// the supported API.
840#[doc(hidden)]
841pub fn a_star_search(
842    loaded_graph: &LoadedRoutingGraph,
843    start_node_index: u32,
844    end_node_index: u32,
845    traversal_cost: TraversalCost,
846) -> Option<ComputedRoute> {
847    let end_coordinate = loaded_graph.node_coordinates[end_node_index as usize];
848    frontier_search(
849        loaded_graph,
850        start_node_index,
851        end_node_index,
852        traversal_cost,
853        |node_index| {
854            let straight_line_meters = loaded_graph.node_coordinates[node_index as usize]
855                .haversine_distance_meters(&end_coordinate);
856            match traversal_cost {
857                TraversalCost::DistanceMeters => straight_line_meters,
858                TraversalCost::TimeSeconds => {
859                    straight_line_meters / MAX_GRAPH_SPEED_METERS_PER_SECOND
860                }
861            }
862        },
863    )
864}

889    )

895/// The shared frontier search behind A* and its Dijkstra reference: one
896/// relaxation/settlement/restriction engine, with the heuristic
897/// monomorphized in (zero cost for the reference), so the two algorithms'
898/// comparison isolates exactly the heuristic's pruning.
899fn frontier_search(
900    loaded_graph: &LoadedRoutingGraph,
901    start_node_index: u32,
902    end_node_index: u32,
903    traversal_cost: TraversalCost,
904    heuristic: impl Fn(u32) -> f64,
905) -> Option<ComputedRoute> {
906    let node_count = loaded_graph.node_coordinates.len();
907    let mut distance_from_start = vec![f64::INFINITY; node_count];
908    // Predecessor half-edge as `(source node, outgoing-list position)` —
909    // enough to reconstruct the traversed half-edges backwards.
910    let mut previous_half_edge: Vec<Option<(usize, usize)>> = vec![None; node_count];
911    let mut settled = vec![false; node_count];
912    let mut frontier = std::collections::BinaryHeap::new();
913    // Settled-set size before the terminal settle (the deterministic
914    // expansion metric the benchmark suite compares A* against the Dijkstra
915    // reference with).
916    let mut settled_node_count = 0usize;
917
918    distance_from_start[start_node_index as usize] = 0.0;
919    frontier.push(FrontierEntry {
920        priority: heuristic(start_node_index),
921        node_index: start_node_index,
922    });
923
924    while let Some(FrontierEntry { node_index, .. }) = frontier.pop() {
925        let node_index_as_usize = node_index as usize;
926        if settled[node_index_as_usize] {
927            continue;
928        }
929        settled[node_index_as_usize] = true;
930        settled_node_count += 1;
931        if node_index == end_node_index {
932            break;
933        }
934        for (half_edge_position, half_edge) in loaded_graph.outgoing_half_edges[node_index_as_usize]
935            .iter()
936            .enumerate()
937        {
938            let to_node_index_as_usize = half_edge.to_node_index as usize;
939            if settled[to_node_index_as_usize] {
940                continue;
941            }
942            if turn_is_restricted(
943                loaded_graph,
944                previous_half_edge[node_index_as_usize],
945                node_index_as_usize,
946                half_edge,
947            ) {
948                continue;
949            }
950            let candidate_distance =
951                distance_from_start[node_index_as_usize] + traversal_cost.cost_of(half_edge);
952            if candidate_distance < distance_from_start[to_node_index_as_usize] {
953                distance_from_start[to_node_index_as_usize] = candidate_distance;
954                previous_half_edge[to_node_index_as_usize] =
955                    Some((node_index_as_usize, half_edge_position));
956                frontier.push(FrontierEntry {
957                    priority: candidate_distance + heuristic(half_edge.to_node_index),
958                    node_index: half_edge.to_node_index,
959                });
960            }
961        }
962    }
963
964    if !settled[end_node_index as usize] {
965        return None;
966    }
967
968    let total_cost = distance_from_start[end_node_index as usize];
969    let mut route_half_edges = Vec::new();
970    let mut walk_node_index = end_node_index as usize;
971    while walk_node_index != start_node_index as usize {
972        let (previous_node_index, half_edge_position) = previous_half_edge[walk_node_index]?;
973        let half_edge = loaded_graph.outgoing_half_edges[previous_node_index][half_edge_position];
974        route_half_edges.push(half_edge);
975        walk_node_index = previous_node_index;
976    }
977    route_half_edges.reverse();
978
979    let node_chain_indices = std::iter::once(start_node_index)
980        .chain(
981            route_half_edges
982                .iter()
983                .map(|half_edge| half_edge.to_node_index),
984        )
985        .collect();
986    Some(ComputedRoute {
987        node_chain_indices,
988        route_half_edges,
989        settled_node_count,
990        total_cost,
991    })
992}

994/// Whether the move from `current_node_index` (arrived via the settled
995/// incoming half-edge, or fresh from the start) onto `candidate_half_edge`
996/// is blocked by a turn-rule restriction.
997fn turn_is_restricted(
998    loaded_graph: &LoadedRoutingGraph,
999    incoming_half_edge: Option<(usize, usize)>,
1000    current_node_index: usize,
1001    candidate_half_edge: &HalfEdge,
1002) -> bool {
1003    let Some((previous_node_index, previous_half_edge_position)) = incoming_half_edge else {
1004        return false;
1005    };
1006    let incoming_edge_record_index = loaded_graph.outgoing_half_edges[previous_node_index]
1007        [previous_half_edge_position]
1008        .edge_record_index;
1009    let Some(turn_rules) = loaded_graph.turn_rules.get(&(
1010        incoming_edge_record_index,
1011        u32::try_from(current_node_index).unwrap_or(u32::MAX),
1012    )) else {
1013        return false;
1014    };
1015
1016    let mut forbidden = false;
1017    let mut only_allowed_to_edge_indices: Option<Vec<u32>> = None;
1018    for turn_rule in turn_rules {
1019        match turn_rule.restriction_kind {
1020            RestrictionKind::OnlyStraightOn => only_allowed_to_edge_indices
1021                .get_or_insert_with(Vec::new)
1022                .push(turn_rule.to_edge_index),
1023            _ => forbidden |= turn_rule.to_edge_index == candidate_half_edge.edge_record_index,
1024        }
1025    }
1026    forbidden
1027        || only_allowed_to_edge_indices
1028            .is_some_and(|allowed| !allowed.contains(&candidate_half_edge.edge_record_index))
1029}

1031/// Splits the route's half-edges into maximal steps: a span opens at a
1032/// maneuver ([`StepManeuver`]) — the route's `Departure`, a derived junction
1033/// turn, or a road-class/speed run change — and continues across junctions
1034/// that stay inside the straight band on unchanged road class and speed.
1035fn group_steps(
1036    node_chain: &[GeographicCoordinate],
1037    route_half_edges: &[HalfEdge],
1038) -> Vec<RouteStepSpan> {
1039    let mut step_spans: Vec<RouteStepSpan> = Vec::new();
1040    for (edge_position, half_edge) in route_half_edges.iter().enumerate() {
1041        let step_maneuver = if edge_position == 0 {
1042            StepManeuver::Departure
1043        } else {
1044            match junction_step_entry(node_chain, route_half_edges, edge_position) {
1045                Some(new_step_maneuver) => new_step_maneuver,
1046                None => {
1047                    // The run continues: extend the step already in
1048                    // progress (the first edge always opened one).
1049                    let continuing_step = step_spans
1050                        .last_mut()
1051                        .expect("a continuing step always follows its opened first edge");
1052                    continuing_step.node_chain_end = edge_position + 1;
1053                    continuing_step.distance_meters += half_edge.distance_meters;
1054                    continuing_step.duration_seconds += half_edge.duration_seconds;
1055                    continue;
1056                }
1057            }
1058        };
1059        step_spans.push(RouteStepSpan {
1060            node_chain_start: edge_position,
1061            node_chain_end: edge_position + 1,
1062            distance_meters: half_edge.distance_meters,
1063            duration_seconds: half_edge.duration_seconds,
1064            step_maneuver,
1065        });
1066    }
1067    step_spans
1068}

1070/// Builds the [`RouteData`] for a route chain.
1071///
1072/// The result has one step per junction-justified maneuver or road-class or
1073/// speed run change; it opens with a `Departure` step and ends with a
1074/// terminal, zero-cost `Arrival` step. Distances and durations come strictly
1075/// from the edge records. Step texts are end-anchored (see
1076/// [`end_anchored_instruction_text`]), while [`ManeuverType`] stays
1077/// head-anchored on each span's own opening maneuver.
1078fn materialize_route_data(
1079    loaded_graph: &LoadedRoutingGraph,
1080    route_chain: &ComputedRoute,
1081) -> RouteData {
1082    let node_chain: Vec<GeographicCoordinate> = route_chain
1083        .node_chain_indices
1084        .iter()
1085        .map(|&node_index| loaded_graph.node_coordinates[node_index as usize])
1086        .collect();
1087
1088    let mut steps: Vec<RouteStep> = Vec::new();
1089    if route_chain.route_half_edges.is_empty() {
1090        // A start-equals-end route: both maneuvers at the same point, zero
1091        // cost.
1092        steps.push(RouteStep {
1093            distance_meters: 0.0,
1094            duration_seconds: 0.0,
1095            maneuver_type: ManeuverType::Departure,
1096            instruction_display_text: DEPARTURE_INSTRUCTION_TEXT.to_string(),
1097            instruction_speech_text: DEPARTURE_INSTRUCTION_TEXT.to_string(),
1098            shape: node_chain.clone(),
1099            lane_guidances: Vec::new(),
1100        });
1101    }
1102    let route_step_spans = group_steps(&node_chain, &route_chain.route_half_edges);
1103    // Each span's authored (head-anchored maneuver) text, in span order —
1104    // the pool the end-anchored shift below draws from.
1105    let authored_instruction_texts: Vec<&'static str> = route_step_spans
1106        .iter()
1107        .map(|route_step_span| step_maneuver_instruction_text(route_step_span.step_maneuver))
1108        .collect();
1109    for (route_span_index, route_step_span) in route_step_spans.iter().enumerate() {
1110        let maneuver_type = match route_step_span.step_maneuver {
1111            StepManeuver::Departure => ManeuverType::Departure,
1112            StepManeuver::Continue => ManeuverType::Continue,
1113            StepManeuver::Turn(turn_direction) => ManeuverType::Turn(turn_direction),
1114        };
1115        let instruction_text =
1116            end_anchored_instruction_text(&authored_instruction_texts, route_span_index);
1117        steps.push(RouteStep {
1118            distance_meters: route_step_span.distance_meters,
1119            duration_seconds: route_step_span.duration_seconds,
1120            maneuver_type,
1121            instruction_display_text: instruction_text.to_string(),
1122            instruction_speech_text: instruction_text.to_string(),
1123            shape: node_chain[route_step_span.node_chain_start..=route_step_span.node_chain_end]
1124                .to_vec(),
1125            // The archive's lane-guidance resource is present-but-minimal
1126            // (the compiler emits no records in this slice); no lane
1127            // guidance is fabricated.
1128            lane_guidances: Vec::new(),
1129        });
1130    }
1131    let end_coordinate = *node_chain
1132        .last()
1133        .expect("the route node chain always carries at least the snapped start node");
1134    steps.push(RouteStep {
1135        distance_meters: 0.0,
1136        duration_seconds: 0.0,
1137        maneuver_type: ManeuverType::Arrival,
1138        instruction_display_text: ARRIVAL_INSTRUCTION_TEXT.to_string(),
1139        instruction_speech_text: ARRIVAL_INSTRUCTION_TEXT.to_string(),
1140        shape: vec![end_coordinate],
1141        lane_guidances: Vec::new(),
1142    });
1143
1144    let total_distance_meters: f64 = route_chain
1145        .route_half_edges
1146        .iter()
1147        .map(|half_edge| half_edge.distance_meters)
1148        .sum();
1149    let total_duration_seconds: f64 = route_chain
1150        .route_half_edges
1151        .iter()
1152        .map(|half_edge| half_edge.duration_seconds)
1153        .sum();
1154
1155    RouteData {
1156        distance_meters: total_distance_meters,
1157        duration_seconds: total_duration_seconds,
1158        bounding_box: bounding_box_over(&node_chain),
1159        legs: vec![RouteLeg {
1160            distance_meters: total_distance_meters,
1161            duration_seconds: total_duration_seconds,
1162            steps,
1163        }],
1164    }
1165}

1167/// The geographic bounds of the route's node chain. Coordinates are exact
1168/// (quantized) degrees, so the corner construction cannot fail.
1169fn bounding_box_over(node_chain: &[GeographicCoordinate]) -> BoundingBox {
1170    let (minimum_latitude, maximum_latitude) = node_chain
1171        .iter()
1172        .map(|coordinate| coordinate.latitude)
1173        .fold(
1174            (f64::INFINITY, f64::NEG_INFINITY),
1175            |(minimum, maximum), latitude| (minimum.min(latitude), maximum.max(latitude)),
1176        );
1177    let (minimum_longitude, maximum_longitude) = node_chain
1178        .iter()
1179        .map(|coordinate| coordinate.longitude)
1180        .fold(
1181            (f64::INFINITY, f64::NEG_INFINITY),
1182            |(minimum, maximum), longitude| (minimum.min(longitude), maximum.max(longitude)),
1183        );
1184    BoundingBox::from_corners(
1185        archive_node_coordinate(minimum_latitude, minimum_longitude),
1186        archive_node_coordinate(maximum_latitude, maximum_longitude),
1187    )
1188    .expect("route node coordinates are within the canonical ranges")
1189}
