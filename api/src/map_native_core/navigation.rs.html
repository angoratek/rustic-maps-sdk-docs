1//! The navigation wiring surface (M6): the `NavigationListener`
2//! foreign-callback contract foreign code implements to observe the
3//! navigation state, the [`Navigator`] driving a native
4//! `map-navigation` session behind it, and the policy records configuring
5//! the controller's step-advance and deviation strategies.
6//!
7//! The controller owns a [`NavigationStateBroadcaster`] and the single active
8//! [`NavigationSession`], and feeds the broadcaster's dispatch calls from the
9//! exported methods, so the per-topic subscription semantics, the delivery
10//! order and the outcome codes are exactly the native broadcaster's (see
11//! `map-navigation`'s `observer` module documentation).
12//!
13//! # What the FFI seam changes about the re-entrancy rules
14//!
15//! The broadcaster's own rules hold unchanged across the seam: the
16//! controller's active-trip lock is taken only to clone state snapshots and
17//! is released before the first dispatch, so the lock is never held across a
18//! listener callback and a listener may freely call back into the controller
19//! — including
20//! [`Navigator::current_trip_state`] and subscription
21//! management. Two properties are worth naming at this seam:
22//!
23//! - A foreign listener calling back into a controller-providing method while
24//!   a dispatch from that controller is still in flight hits the
25//!   broadcaster's single-in-flight guard and its nested dispatch is
26//!   suppressed exactly as a Rust-side re-entrant dispatch would be; the
27//!   state change behind the suppressed dispatch has already been applied,
28//!   only its broadcast is skipped. The synchronous single-threaded callback
29//!   ordering of the native seam carries over: uniffi runs these sync
30//!   callbacks on the thread driving the controller call, so no cross-thread
31//!   queueing is introduced.
32//! - A panicking (Rust-side) listener propagates out of the dispatch on the
33//!   native seam unchanged: nothing is caught inside the controller. The
34//!   panic still cannot unwind into foreign code — it stays inside the
35//!   exported frame whose scaffolding boundary catches it (see
36//!   [`crate::panic_boundary`]); foreign listeners raising exceptions take
37//!   the foreign vtable's own report, contained the same way.
38//!
39//! # Scope
40//!
41//! Trip progress and instructions are read-only for foreign code; the
42//! programmatic step advance is deliberately absent — the reducer has no such
43//! event yet, and the `Manual` step-advance policy consequently cannot be
44//! driven across this surface.
45

65/// State listener contract implemented by foreign code; register its
66/// subscriptions on [`Navigator`] through the
67/// `subscribe_to_*` methods.
68///
69/// The callbacks exchange the binding records of the navigation state and
70/// have no error channel: a listener cannot fail into the broadcaster (the
71/// native dispatch rules). Each method of one registered subscription is
72/// called only for the topics the subscription was created for.
73pub trait NavigationListener: Send + Sync {
74    /// Receives the composed instruction payload of every dispatched state
75    /// change (the instructions topic).
76    fn on_navigation_instruction(&self, instruction: NavigationInstruction);
77
78    /// Receives a deviation-status stream update (the deviation topic):
79    /// off-route on entry and on every recorded measurement update while the
80    /// deviation persists, on-route when it clears.
81    fn on_deviation_status_change(&self, deviation_status_change: DeviationStatusChange);
82
83    /// Receives one phase transition per dispatched trip-state transition
84    /// (the phase topic).
85    fn on_navigation_phase_change(&self, navigation_phase_change: NavigationPhaseChange);
86
87    /// Receives one speech-trigger line the controller's pacing policy judged
88    /// newsworthy (round 10, the speech topic). Subscribers of the
89    /// `subscribe_to_speech_instructions` topic receive exactly these
90    /// deliveries; the composed speech text is carried verbatim and the
91    /// platform owns playback.
92    fn on_speech_instruction(&self, speech_instruction: SpeechInstruction);
93
94    /// Internally required by the uniffi foreign-handle machinery (the
95    /// foreign-handle probe of the uniffi 0.32 trait-object lowering);
96    /// Rust-side implementations keep the default, which reports a
97    /// Rust-implemented object.
98    #[doc(hidden)]
99    fn uniffi_foreign_handle(&self) -> Option<::uniffi::Handle> {
100        Option::None
101    }
102}

155/// Handle coupled to one `(topic, listener)` subscription of the
156/// controller's broadcaster, or to the four-topic set
157/// `add_navigation_listener` registers. Cancelling is explicit and
158/// idempotent; dropping the handle does not unsubscribe.
159pub struct Subscription {
160    /// The native handles this binding owns: exactly one for a single-topic
161    /// subscription, all four topics for a composite listener subscription.
162    subscriptions: Vec<TopicSubscription>,
163}
164
165impl Subscription {
166    /// Wraps one native subscription handle.
167    pub(crate) fn new(subscription: TopicSubscription) -> Self {
168        Self {
169            subscriptions: vec![subscription],
170        }
171    }
172
173    /// Wraps the four native handles of a composite listener subscription.
174    pub(crate) fn composite(subscriptions: Vec<TopicSubscription>) -> Self {
175        Self { subscriptions }
176    }
177
178    /// Cancels every subscription this handle owns: the listener stops
179    /// receiving the subscription's topic(s) from the next dispatch on.
180    /// Idempotent.
181    pub fn cancel(&self) {
182        for subscription in &self.subscriptions {
183            subscription.cancel();
184        }
185    }
186}

195/// The exported navigation controller: drives the native reducer's session,
196/// broadcasts every state change to the registered foreign listeners, and
197/// answers read-only state and instruction queries.
198///
199/// The active-trip lock is never held across a broadcaster dispatch (see the
200/// module-head notes on the re-entrancy rules across the seam).
201pub struct Navigator {
202    active_trip: Mutex<Option<ActiveTrip>>,
203    broadcaster: NavigationStateBroadcaster,
204    /// The controller's speech-trigger policy memory: one planner for the
205    /// controller's whole lifetime, so every emitted utterance id stays
206    /// unique across trips and reroutes. Its band memory resets with each
207    /// trip (`reset`); the composition counter deliberately does not. The
208    /// lock is held only over the evaluation itself — never across a
209    /// broadcaster dispatch or a listener callback.
210    speech_planner: Mutex<SpeechInstructionPlanner>,
211    /// The controller's reroute-recalculation hysteresis gate (round 11,
212    /// Ferrostar B3's mechanism): the request-in-flight, cooldown and
213    /// movement thresholds every reroute-request signal must pass, held as a
214    /// wall-clock controller fact — never reducer state. The lock is held
215    /// only over the single gate read or write, never nested with the
216    /// active-trip lock and never across a broadcaster dispatch or a
217    /// listener callback.
218    reroute_gate: Mutex<RerouteRecalculationGate>,
219}
220
221impl Navigator {
222    /// Builds the controller with no active trip, no subscriptions and the
223    /// default reroute-recalculation policy.

225        Self {

227            broadcaster: NavigationStateBroadcaster::new(),
228            speech_planner: Mutex::new(SpeechInstructionPlanner::new()),
229            reroute_gate: Mutex::new(RerouteRecalculationGate::new()),

231    }
232}

287    /// Subscribes one listener to all four navigation topics — instructions,
288    /// deviation status, phase changes and speech instructions — and answers
289    /// the composite subscription that cancels all four. The listener is
290    /// wrapped once and registered on each topic list, so every topic
291    /// dispatches to the same foreign object on its own method; the
292    /// composite `cancel()` removes every registration (idempotent, like a
293    /// single-topic subscription).
294    pub fn add_navigation_listener(
295        &self,
296        listener: Arc<dyn NavigationListener>,
297    ) -> Arc<Subscription> {
298        let native_listener: Arc<dyn map_navigation::NavigationStateChangeListener> =
299            Arc::new(ForeignNavigationStateListener::new(listener));
300        let subscriptions = vec![
301            self.broadcaster
302                .subscribe_to_navigation_instructions(Arc::clone(&native_listener)),
303            self.broadcaster
304                .subscribe_to_deviation_status(Arc::clone(&native_listener)),
305            self.broadcaster
306                .subscribe_to_phase_changes(Arc::clone(&native_listener)),
307            self.broadcaster
308                .subscribe_to_speech_utterances(native_listener),
309        ];
310        Arc::new(Subscription::composite(subscriptions))
311    }

313    /// Evaluates the active trip's speech-trigger policy over one dispatch's
314    /// state transition and delivers the utterances to the speech topic. A
315    /// suppressed state-change dispatch skips the evaluation — the policy
316    /// memory keeps its state, so the next delivered dispatch sees the
317    /// transition whole. The planner lock is held only over the evaluation
318    /// itself, never across a dispatch or listener callback.
319    fn dispatch_speech_policies(
320        &self,
321        previous_state: &map_navigation::TripNavigationState,
322        current_state: &map_navigation::TripNavigationState,
323        unit_system: UnitSystem,
324        dispatch_outcome: NavigationDispatchOutcome,
325    ) {
326        if dispatch_outcome != NavigationDispatchOutcome::Delivered {
327            return;
328        }
329        let mut speech_planner = crate::panic_boundary::state_lock_guard(
330            &self.speech_planner,
331            "the navigation controller's speech planner",
332        );
333        let utterances = speech_planner.evaluate_state_transition(
334            Some(previous_state),
335            current_state,
336            unit_system,
337            Instant::now(),
338        );
339        drop(speech_planner);
340        for utterance in &utterances {
341            self.broadcaster.dispatch_speech_utterance(utterance);
342        }
343    }

345    /// Evaluates the reroute-recalculation gates over one reroute-request
346    /// signal at the wall clock: `true` when every gate passed and a
347    /// calculation is now in flight (readable as the trip state's
348    /// `is_calculating_new_route`); `false` when the signal was refused
349    /// (a calculation in flight, inside the cooldown window, or inside the
350    /// movement threshold — check the trip state for which fact applies).
351    /// A signal without an open, still-navigable trip (no trip, or the trip
352    /// has arrived) is refused before the gates are consulted.
353    ///
354    /// The trip's eligibility is read under a short active-trip lock
355    /// released before the gate lock; neither is held across a dispatch or a
356    /// listener callback. A passing caller owes a settle: the eventual
357    /// `apply_reroute` (applied or ignored) or
358    /// [`Navigator::cancel_reroute_calculation`].
359    pub fn begin_reroute_calculation(&self) -> bool {
360        let trip_is_navigable = {
361            let active_trip = crate::panic_boundary::state_lock_guard(
362                &self.active_trip,
363                "the navigation controller's active trip",
364            );
365            active_trip.as_ref().is_some_and(|trip| {
366                trip.session.state.phase != map_navigation::NavigationPhase::Arrived
367            })
368        };
369        if !trip_is_navigable {
370            return false;
371        }
372        crate::panic_boundary::state_lock_guard(
373            &self.reroute_gate,
374            "the navigation controller's reroute gate",
375        )
376        .begin_calculation(Instant::now())
377    }
378
379    /// Settles an in-flight reroute calculation without applying a route
380    /// (the integrator abandoned the request): the request-in-flight gate
381    /// reopens. The cooldown keeps running from the calculation's beginning
382    /// and the movement reference stays where it was. Idempotent; without an
383    /// active trip the gate is still settled (the gate is controller
384    /// configuration and memory, not trip state).
385    pub fn cancel_reroute_calculation(&self) {
386        crate::panic_boundary::state_lock_guard(
387            &self.reroute_gate,
388            "the navigation controller's reroute gate",
389        )
390        .settle_calculation();
391    }

393    /// Swaps the reroute-recalculation hysteresis policy in force, keeping
394    /// the gate's memory as it stands. Both thresholds must be finite and
395    /// non-negative (`InvalidNavigationInput` otherwise, and the policy in
396    /// force is then untouched).
397    pub fn configure_reroute_policy(&self, reroute_policy: ReroutePolicy) -> Result<(), SdkError> {
398        validated_policy_threshold(
399            reroute_policy.recalculation_cooldown_seconds,

401        )?;
402        validated_policy_threshold(
403            reroute_policy.recalculation_movement_meters,
404            "reroute recalculation movement threshold meters",
405        )?;
406        crate::panic_boundary::state_lock_guard(
407            &self.reroute_gate,
408            "the navigation controller's reroute gate",
409        )
410        .set_policy(map_navigation::ReroutePolicy {
411            recalculation_cooldown_seconds: reroute_policy.recalculation_cooldown_seconds,
412            recalculation_movement_meters: reroute_policy.recalculation_movement_meters,

415    }

434    /// Begins navigating `route` with the given policies, replacing any
435    /// active trip. The initial instruction payload is dispatched; no
436    /// deviation or phase transitions exist yet.
437    ///
438    /// A route without traversable steps represents an already-arrived trip
439    /// (the reducer's own semantics), not a rejection.
440    pub fn start_navigation(
441        &self,
442        route: Route,
443        unit_system: crate::records::UnitSystem,
444        step_advance_policy: StepAdvancePolicy,
445        deviation_policy: DeviationPolicy,
446    ) -> Result<(), SdkError> {
447        let step_advance_condition = build_step_advance_condition(&step_advance_policy)?;
448        let deviation_detector = build_deviation_detector(&deviation_policy)?;
449        let native_route = route.into_native_route_data()?;
450        let native_unit_system = unit_system.to_native_unit_system();
451        let session = crate::panic_boundary::required_invariant(
452            reduce_navigation_event(
453                // A fresh trip replaces any active session outright (the
454                // reducer reads no previous session for a StartTrip event).
455                None,
456                map_navigation::NavigationEvent::StartTrip {
457                    route: native_route,
458                    step_advance_condition,
459                    deviation_detector,
460                    // The arrival-aware advance condition (Ferrostar's B5
461                    // semantics) is not yet an FFI-configurable policy: the
462                    // frozen UDL contract carries no parameter for it, and
463                    // `None` keeps the trip's ordinary condition end-to-end.
464                    arrival_step_advance_condition: None,
465                    // Raw course reporting preserves today's behavior; the
466                    // SnapToRoute policy (Ferrostar's B7) is internal-only
467                    // until its FFI surface is an agreed addition.
468                    course_filtering: map_navigation::CourseFiltering::Raw,
469                },
470            ),
471            "a StartTrip event always produces a session",
472        );
473        let dispatched_state = session.state.clone();
474        *crate::panic_boundary::state_lock_guard(
475            &self.active_trip,
476            "the navigation controller's active trip",
477        ) = Some(ActiveTrip {
478            session,
479            unit_system: native_unit_system,
480        });
481        // The speech policy restarts with the trip: nothing is announced at
482        // trip start (the initial instruction payload is the dispatched
483        // instructions topic's own line, and the platforms speak it). The
484        // planner's band memory resets, while its utterance counter survives
485        // so ids are never reused across trips. The reroute gate forgets its
486        // trip memory (nothing in flight, no cooldown, no fix reference)
487        // while the configured policy persists.
488        crate::panic_boundary::state_lock_guard(
489            &self.speech_planner,
490            "the navigation controller's speech planner",
491        )
492        .reset();
493        crate::panic_boundary::state_lock_guard(
494            &self.reroute_gate,
495            "the navigation controller's reroute gate",
496        )
497        .reset();
498        self.broadcaster
499            .dispatch_trip_started(&dispatched_state, native_unit_system);
500        Ok(())
501    }

503    /// Ends the active trip and clears the trip state: `current_trip_state`
504    /// and `current_instructions` answer `None` afterwards, and location
505    /// updates, reroutes, reroute-request signals and speech evaluations are
506    /// dropped until `start_navigation` begins a new trip. The speech-trigger
507    /// band memory and the reroute-recalculation gate are reset with the
508    /// trip — the utterance identifier counter is deliberately not reset, so
509    /// identifiers stay monotonic across a stop, and the configured reroute
510    /// policy persists. Listener subscriptions are controller configuration,
511    /// not trip state: they are untouched and serve the next trip. Stopping
512    /// without an active trip is a no-op.
513    ///
514    /// No event is dispatched for the stop: the native reducer has no stop
515    /// transition, and the frozen phase channel has no stop variant, so
516    /// inventing one here would be a semantics the reducer does not own.
517    pub fn stop_navigation(&self) {
518        // The three locks are taken sequentially and never nested: the trip
519        // is cleared first, then the two pieces of controller memory are
520        // reset.
521        *crate::panic_boundary::state_lock_guard(
522            &self.active_trip,
523            "the navigation controller's active trip",
524        ) = None;
525        crate::panic_boundary::state_lock_guard(
526            &self.speech_planner,
527            "the navigation controller's speech planner",
528        )
529        .reset();
530        crate::panic_boundary::state_lock_guard(
531            &self.reroute_gate,
532            "the navigation controller's reroute gate",
533        )
534        .reset();
535    }

537    /// Delivers one position fix to the active trip; without one the fix is
538    /// dropped (the reducer's own semantics for event-before-trip).
539    /// The fix is judged for deviation, snapped and evaluated by the active
540    /// step-advance condition exactly as the native reducer documents, and
541    /// the resulting transition is broadcast. A broadcast suppressed by the
542    /// broadcaster's re-entrancy guard is not reported here; the state change
543    /// behind it has already been applied.
544    pub fn update_location(&self, location_update: NavigationLocationUpdate) {
545        let native_update = location_update.into_native_location_update();
546        // The reroute movement gate measures raw fixes, so every consumed fix
547        // feeds it (its own short lock, taken and released before the
548        // active-trip lock — the two are never held together).
549        crate::panic_boundary::state_lock_guard(
550            &self.reroute_gate,
551            "the navigation controller's reroute gate",
552        )
553        .record_fix(native_update.coordinate);
554        let (previous_state, current_state, unit_system) = {
555            // The lock guards only the session swap; it is released before the
556            // dispatch below, so a listener may call back into the controller.
557            let mut active_trip = crate::panic_boundary::state_lock_guard(
558                &self.active_trip,
559                "the navigation controller's active trip",
560            );
561            let Some(trip) = active_trip.as_mut() else {
562                return;
563            };
564            let previous_state = trip.session.state.clone();
565            let session = crate::panic_boundary::required_invariant(
566                reduce_navigation_event(
567                    Some(trip.session.clone()),
568                    map_navigation::NavigationEvent::LocationUpdated(native_update),
569                ),
570                "an active trip's location update always produces a session",
571            );
572            trip.session = session;
573            (previous_state, trip.session.state.clone(), trip.unit_system)
574        };
575        let dispatch_outcome =
576            self.broadcaster
577                .dispatch_location_update(&previous_state, &current_state, unit_system);
578        self.dispatch_speech_policies(
579            &previous_state,
580            &current_state,
581            unit_system,
582            dispatch_outcome,
583        );
584    }

586    /// Replaces the route of the active trip (a reroute). The replacement
587    /// route must be anchored at the trip's current snapped coordinate (the
588    /// reducer's anchoring contract; no trimming happens here). The step
589    /// advance strategy for the new route is configured by
590    /// `step_advance_policy`; the active deviation policy persists.
591    ///
592    /// A reroute offered to an arrived trip is ignored by the reducer and
593    /// produces no phase transition; without an active trip the event is
594    /// dropped.
595    pub fn apply_reroute(
596        &self,
597        route: Route,
598        step_advance_policy: StepAdvancePolicy,
599    ) -> Result<(), SdkError> {
600        let step_advance_condition = build_step_advance_condition(&step_advance_policy)?;
601        let native_route = route.into_native_route_data()?;
602        let (previous_state, current_state, unit_system, reroute_applied) = {
603            let mut active_trip = crate::panic_boundary::state_lock_guard(
604                &self.active_trip,
605                "the navigation controller's active trip",
606            );
607            let Some(trip) = active_trip.as_mut() else {
608                return Ok(());
609            };
610            let previous_state = trip.session.state.clone();
611            let session = crate::panic_boundary::required_invariant(
612                reduce_navigation_event(
613                    Some(trip.session.clone()),
614                    map_navigation::NavigationEvent::RerouteProvided {
615                        route: native_route,
616                        step_advance_condition,
617                    },
618                ),
619                "an active trip's reroute always produces a session",
620            );
621            let reroute_applied = previous_state != session.state;
622            trip.session = session;
623            (
624                previous_state,
625                trip.session.state.clone(),
626                trip.unit_system,
627                reroute_applied,
628            )
629        };
630        let _ =
631            self.broadcaster
632                .dispatch_reroute_applied(&previous_state, &current_state, unit_system);
633        // The in-flight calculation is settled whichever way the reducer
634        // disposed of the route (applied or ignored): the integrator acted
635        // on its request, so the request-in-flight gate reopens. The
636        // cooldown and movement memory stay anchored at the calculation's
637        // beginning.
638        crate::panic_boundary::state_lock_guard(
639            &self.reroute_gate,
640            "the navigation controller's reroute gate",
641        )
642        .settle_calculation();
643        if reroute_applied {
644            // The route (and its step ladder) is new: the speech band memory
645            // restarts, while the utterance counter survives so ids are
646            // never reused.
647            crate::panic_boundary::state_lock_guard(
648                &self.speech_planner,
649                "the navigation controller's speech planner",
650            )
651            .reset();
652        }
653        Ok(())
654    }
655
656    /// The plain state of the active trip, or `None` without one. The
657    /// `is_calculating_new_route` fact is the controller's own reroute gate
658    /// readback (a wall-clock controller fact the pure trip state cannot
659    /// carry); the two reads are short, sequential and never nested.
660    pub fn current_trip_state(&self) -> Option<crate::records::TripNavigationState> {
661        let is_calculating_new_route = crate::panic_boundary::state_lock_guard(
662            &self.reroute_gate,
663            "the navigation controller's reroute gate",
664        )
665        .is_calculating_new_route();
666        let mut trip_state = crate::panic_boundary::state_lock_guard(
667            &self.active_trip,
668            "the navigation controller's active trip",
669        )
670        .as_ref()
671        .map(|trip| {
672            crate::records::TripNavigationState::from_native_trip_navigation_state(
673                &trip.session.state,
674            )
675        })?;
676        trip_state.is_calculating_new_route = is_calculating_new_route;
677        Some(trip_state)
678    }
679
680    /// The composed turn-by-turn instruction payload of the current trip
681    /// state, or `None` without an active trip. Emission is pure in the
682    /// native core, so repeated reads of an unchanged state return the same
683    /// payload.
684    pub fn current_instructions(&self) -> Option<NavigationInstruction> {
685        let active_trip = crate::panic_boundary::state_lock_guard(
686            &self.active_trip,
687            "the navigation controller's active trip",
688        );
689        let trip = active_trip.as_ref()?;
690        Some(NavigationInstruction::from_native_navigation_instruction(
691            &compose_navigation_instructions(&trip.session.state, trip.unit_system),
692        ))
693    }
694}

696/// Builds the native step-advance condition behind a policy record, refusing
697/// non-finite or negative threshold values.
698pub(crate) fn build_step_advance_condition(
699    step_advance_policy: &StepAdvancePolicy,
700) -> Result<Arc<dyn StepAdvanceCondition>, SdkError> {
701    match step_advance_policy.policy_kind {
702        StepAdvancePolicyKind::Manual => Ok(Arc::new(ManualStepAdvanceCondition)),
703        StepAdvancePolicyKind::DistanceToEndOfStep => Ok(Arc::new(DistanceToEndOfStepCondition {
704            advance_threshold_meters: validated_policy_threshold(
705                step_advance_policy.advance_threshold_meters,
706                "step-advance distance threshold",
707            )?,
708            minimum_horizontal_accuracy_meters: validated_policy_threshold(
709                step_advance_policy.minimum_horizontal_accuracy_meters,
710                "step-advance minimum horizontal accuracy",
711            )?,
712        })),
713        StepAdvancePolicyKind::DistanceFromStep => Ok(Arc::new(DistanceFromStepCondition {
714            advance_threshold_meters: validated_policy_threshold(
715                step_advance_policy.advance_threshold_meters,
716                "step-advance distance threshold",
717            )?,
718            minimum_horizontal_accuracy_meters: validated_policy_threshold(
719                step_advance_policy.minimum_horizontal_accuracy_meters,
720                "step-advance minimum horizontal accuracy",
721            )?,
722        })),
723    }
724}
725
726/// Builds the native deviation detector behind a policy record, refusing a
727/// non-finite or negative threshold.
728pub(crate) fn build_deviation_detector(
729    deviation_policy: &DeviationPolicy,
730) -> Result<Arc<dyn DeviationDetector>, SdkError> {
731    match deviation_policy.policy_kind {
732        DeviationPolicyKind::DistanceThreshold => Ok(Arc::new(DistanceDeviationDetector {
733            deviation_threshold_meters: validated_policy_threshold(
734                deviation_policy.deviation_threshold_meters,
735                "deviation distance threshold",
736            )?,
737        })),
738    }
739}
740
741/// Validates one policy threshold: policies are configured by foreign code,
742/// where a NaN or negative threshold would silently disable or permanently
743/// flag the strategy, so the controller boundary refuses them instead.
744fn validated_policy_threshold(
745    policy_threshold_meters: f64,
746    threshold_description: &str,
747) -> Result<f64, SdkError> {
748    if !policy_threshold_meters.is_finite() || policy_threshold_meters.is_sign_negative() {
749        return Err(SdkError::InvalidNavigationInput {
750            detail: format!("{threshold_description} must be finite and non-negative"),
751        });
752    }
753    Ok(policy_threshold_meters)
754}
