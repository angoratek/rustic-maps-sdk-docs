1//! The only UniFFI binding crate: objects, records, callback interfaces and
2//! the UDL source of truth consumed by Kotlin, Swift, and
3//! `uniffi-bindgen-react-native`; the wasm target uses the hand-checked TS
4//! surface verified against the same UDL.
5//!
6//! Milestone M4, slice 1 (2026-10-27) freezes the camera/projection contract
7//! in `src/map_native_core.udl` and implements it here by delegating to
8//! `map-rendering`: the anchored [`camera::MapCamera`] (screen <-> ground
9//! projection, visible tile listing, tile zoom selection), the free
10//! [`projection`] helpers, and [`get_sdk_compiled_version`]. The UDL
11//! dictionaries are mirrored by the value structs in [`records`]; FFI traits
12//! cannot be implemented for foreign-crate types, so binding records convert
13//! to and from the `geospatial-types` and `map-rendering` types through the
14//! explicit record constructors and the `projection` validation helpers.
15//! [`error::SdkError`] mirrors the `geospatial-types` `SDKError` subset these
16//! calls produce. Extended in M4 slice 2 (2026-10-27) with the fit-bounds
17//! constructor (`camera::MapCamera::fit_bounds`, the `EdgeInsets`
18//! record). Extended in M4 slice 3 (2026-10-27) with the async provider
19//! surface: [`provider::MapSdk`] resolves the implemented
20//! `geospatial-traits` contracts through the `map-core` `ProviderRegistry`
21//! with one exported `[Async]` method per call, the provider records and
22//! enums mirror `geospatial-types`, and `error::SdkError` grows the provider
23//! failure variants. Extended in M4 slice 4 (2026-10-27) with the
24//! foreign-callback provider injection ([`foreign_providers`]): the
25//! `[Trait, WithForeign]` contracts `GeocodingProvider` and
26//! `RasterTileProvider` that foreign code implements, the
27//! `MapSdk::register_*_from_foreign` methods wrapping them in the
28//! `foreign_providers` adapters onto the native `geospatial-traits` traits,
29//! and the error round-trip `From<SdkError> for SDKError`. Extended in M6
30//! (2026-10-27) with the navigation wiring ([`navigation`]): the
31//! `[Trait, WithForeign]` listener `NavigationListener` foreign
32//! code implements against the `map-navigation` broadcaster behind the
33//! [`navigation::Navigator`] (trip start with
34//! policy records standing in for the native decision objects, location
35//! updates, reroutes, and the read-only state and instruction payloads), the
36//! `Subscription` cancel handle, and the mirror records of the
37//! `map-navigation` policy records standing in for the native decision
38//! objects, location updates, reroutes, and the read-only state and
39//! instruction payloads), the `Subscription` cancel handle,
40//! and the mirror records of the `map-navigation` state. Extended in round 8
41//! (2026-10-27) with the native surface wiring ([`surface_view`], the
42//! `MapView` object over [`map_rendering::SurfaceTileRenderer`] —
43//! lifecycle, overlay list and the per-frame async draw — with the
44//! [`platform_surface`] lowering of the platform pointer into a `wgpu`
45//! surface, the overlay and handle record mirrors, the two render failure
46//! variants of `SdkError`, and the `set_provider_credential` call
47//! installing the MapQuest providers with an API key) and the
48//! [`runtime`] executor seam: every exported async method hands its
49//! reactor-dependent work (the `reqwest` provider futures, the surface
50//! draw's tile fetches) to a crate-owned tokio runtime through
51//! [`runtime::drive`], so the foreign executor polls only a
52//! runtime-independent handback future. Extended in round 12 (2026-10-29)
53//! with the addition-only provider-failure diagnostic seam
54//! ([`provider_diagnostics`]): every failed foreign-callback provider call
55//! records a [`records::ProviderFailureDiagnostic`]
56//! (classification from [`records::ProviderFailureClassification`], verbatim
57//! failure text) on the owning `MapSdk`'s bounded ring, read back through
58//! `MapSdk::latest_provider_failure_diagnostics`. Extended in the M17
59//! contract slice (2026-10-30) with the engine facades ([`engines`]:
60//! `SearchEngine`, `RoutingEngine`, `OfflineManager`, `Diagnostics`, each
61//! constructed over an existing `MapSdk` and delegating verbatim), the
62//! id-addressed overlay members on [`surface_view::MapView`]
63//! (`add_overlay`/`update_overlay`/`remove_overlay`, beside the documented
64//! bulk `set_overlays`), and the `Navigator` listener/stop verbs
65//! (`add_navigation_listener`'s four-topic composite subscription and
66//! `stop_navigation`). Remaining for
67//! later slices: the remaining provider contracts as foreign callbacks, and
68//! the RN generation pipeline.
69//!
70//! Every exported entry point of this crate (and every callback invocation
71//! inside an exported frame) is panic-contained by the uniffi 0.32.2
72//! scaffolding itself; [`crate::panic_boundary`] documents that verified
73//! containment map, which is why this crate adds no redundant
74//! `catch_unwind` layer of its own — and holds the crate's `unwrap`/
75//! `expect` policy for the FFI-reachable code.
76
77// The scaffolding generated from the UDL builds its namespace metadata in
78// large const arrays (uniffi 0.32's codegen pattern); the attribute cannot
79// scope into the machine-generated macro expansion, so the lint is allowed
80// crate-wide.
81#![allow(clippy::large_const_arrays)]
82// No `unwrap`/`expect` in FFI-reachable code: the deny is lifted for the
83// test builds (the crate's own unit-test modules and the integration-test
84// crates, which rustc also compiles with `cfg(test)`), where the
85// conventional assertion shorthands are honest. The production denials are
86// upheld by the invariants documented in [`crate::panic_boundary`], whose
87// helpers hold the crate's only justifications for the remaining,
88// deliberately panic-expressing sites.
89#![cfg_attr(not(test), deny(clippy::expect_used, clippy::unwrap_used))]
