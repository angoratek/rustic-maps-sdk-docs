1//! Pure behavior math and the flow-state reducer shared by the reference
2//! applications.
3//!
4//! The crate is deliberately small and self-contained: it holds no SDK handle,
5//! no clock, no input/output, no logger and no platform dependency. Every
6//! public item exchanges primitives and crate-local enums only, so the same
7//! source compiles for native targets and for WebAssembly.
8//!
9//! The crate answers the one question the four reference applications must
10//! answer identically (see `docs/design/ReferenceApplicationBehavior.md`):
11//! given the current flow state and an event, what should the user see next?
12//! The follow-camera state machine, the circular course median, the easing
13//! primitives, the scale-bar ladder and the recorded-trace cursor sit beside
14//! that reducer so each platform calls shared math instead of keeping a
15//! mirror. Views, gestures, timers, credentials, speech engines and lifecycle
16//! stay in the platform shells.
17
