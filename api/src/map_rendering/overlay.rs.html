1//! GPU-free overlay assembly: route polylines, filled polygons, point
2//! markers, and traffic-flow lines projected into clip-space solid-color
3//! triangle lists drawn over the tile quads.
4//!
5//! Overlays are the second draw layer of a captured frame: the same camera
6//! pose and viewport that assemble the tile quads
7//! ([`crate::renderer::Renderer::frame_quads`]) also project overlay shapes
8//! into clip-space triangles via [`overlay_triangle_vertices`], which the
9//! headless renderer draws through a separate solid-color pipeline in the
10//! same render pass after the tiles (see the crate-level seam notes in the
11//! browser-loop documentation: the wasm canvas mirrors the vertex contract
12//! verbatim, so the assembly here is deliberately `wgpu`-free and emits one
13//! flat, non-indexed triangle list).
14//!
15//! Design decisions recorded for this slice:
16//!
17//! * **World copies / antimeridian.** Overlay geometry wraps around the
18//!   camera exactly like tile spans do (see
19//!   [`crate::renderer::FrameProjection`]): the first vertex of a shape sits
20//!   in the camera's world copy via the shortest wrapped delta, every
21//!   following vertex unwraps continuously from it, and each resulting
22//!   segment or triangle is split against the camera-centered world-copy
23//!   windows ([`WORLD_COPY_WINDOW_OFFSETS`], reusing the tile spans' window
24//!   half-width). A shape wider than the covered window range clips to
25//!   nothing beyond it; a single unwrapping step never spans more than half a
26//!   world, so three windows cover every reachable fragment.
27//! * **Frustum clipping.** Assembly relies on the GPU's clip-space frustum
28//!   clip, the same mechanism the tile pipeline relies on for near-plane
29//!   straddling spans; no extra CPU cull runs. Screen-space-thickened shapes
30//!   (route lines, markers, traffic) additionally drop the segments and
31//!   markers with a vertex at or behind the camera because the screen-space
32//!   width offset needs a positive homogeneous weight; filled polygons emit
33//!   genuine clip-space corners and keep near-plane straddling triangles for
34//!   the GPU to clip exactly.
35//! * **Line joins.** A polyline draws as butt-capped segment quads plus one
36//!   screen-space square (the line's width) per interior vertex, oriented
37//!   along the bend's bisector. The square fills the wedge the butt caps
38//!   leave outside a bend, which otherwise reads as a gap between styled road
39//!   segments; it never grows a miter spike at sharp angles. Endpoints keep
40//!   their butt caps (a per-feature end has no neighbouring segment to join),
41//!   and sharp joins can still show a sliver where the wedge exceeds the
42//!   square — a full round-join fan is the documented later refinement.
43//! * **Polygon holes.** A filled polygon carries one outer ring and any number
44//!   of hole rings. Holes join the outer boundary through the standard
45//!   bridge-splicing step before ear clipping ([`FilledPolygonOverlay`]
46//!   documents the algorithm), so the emitted triangle stream covers exactly
47//!   the ring set's even-odd interior: the overlay pipeline paints a flat
48//!   triangle list with alpha blending and has no stencil test, so a hole must
49//!   leave its region out of that list rather than erase it after the fact.
50//! * **Markers.** A marker is a regular-octagon triangle fan centered on the
51//!   projected anchor point (center anchoring, not bottom pinning): the
52//!   projected coordinate is the fan's center, so a marker's center sits
53//!   exactly at its geographic position. Sprites and label callouts are
54//!   explicitly not this slice.
55//! * **Pins.** A pin is a teardrop anchored the other way: its tip sits on the
56//!   projected coordinate and the circular head above it carries a hollow
57//!   center. The teardrop is star-shaped around the head center, so the
58//!   outline is one radial function of the angle and the hollow center is the
59//!   annulus between that outline and an inner circle — again a plain triangle
60//!   list, no erase pass.

228/// A filled polygon: one outer ring plus any hole rings, bridge-joined and
229/// ear-clip triangulated in one pass and painted solid
230/// [`FilledPolygonOverlay::rgba_color`] (through the overlay pipeline's alpha
231/// blending, so translucent fills keep the base tiles readable).
232///
233/// Holes stay unfilled by construction: the assembly emits a flat,
234/// non-overlapping triangle list whose triangles cover only the outer ring's
235/// interior outside every hole. The overlay pipeline has no stencil test and
236/// no erase operation, so subtracting the holes from the emitted triangle
237/// stream is the only representation its solid-color fragment stage supports.
238/// The bridge splice (`ear_clip_triangulation_with_holes`) joins each hole
239/// to the outer boundary through a zero-width slit; the slit's duplicated
240/// vertices are collinear, never paint a fragment of their own, and keep the
241/// combined boundary a single simple ring the ear clipper can walk.
242#[derive(Debug, Clone, PartialEq)]
243pub struct FilledPolygonOverlay {
244    /// Outer ring in traversal order, without a repeated closing vertex (a
245    /// repeated one is tolerated and dropped). Self-intersecting or
246    /// near-collinear rings are degenerate and may fill nothing.
247    pub ring_coordinates: Vec<GeographicCoordinate>,
248    /// Hole rings subtracted from the fill, each in traversal order and
249    /// without a repeated closing vertex. The rings' winding is normalized
250    /// before triangulation, so decoded order does not matter. A hole that
251    /// falls outside the outer ring is not contained by it and may paint
252    /// outside the fill; producers emit contained holes.
253    pub hole_ring_coordinates: Vec<Vec<GeographicCoordinate>>,
254    /// Fill color; see [`DEFAULT_FILLED_POLYGON_RGBA`] for the default.
255    pub rgba_color: [f32; 4],
256}

421/// Assembles every overlay of a frame into one flat clip-space triangle list
422/// drawn over the tile quads in the same captured frame.
423///
424/// The shapes project through the same camera pose as the tile quads, wrap
425/// around the camera's world copy like the tile spans do (see the module
426/// notes), and leave frustum clipping to the GPU's clip-space clip. An empty
427/// `overlays` slice produces no vertices, and a shape whose geometry turns
428/// out degenerate (behind the camera for screen-thickened shapes, or
429/// numerically unusable anywhere) skips only that shape's own triangles.
430pub fn overlay_triangle_vertices(
431    camera: &MapCamera,
432    viewport: &ViewportPixels,
433    field_of_view_degrees: f64,
434    overlays: &[MapOverlay],
435) -> Vec<ClipSpaceOverlayVertex> {
436    let frame_projection =
437        OverlayFrameProjection::for_frame(camera, viewport, field_of_view_degrees);
438    let mut vertices = Vec::new();
439    for overlay in overlays {
440        match overlay {
441            MapOverlay::RoutePolyline(route_polyline) => {
442                thickened_polyline_triangles(
443                    &frame_projection,
444                    viewport,
445                    &route_polyline.coordinates,
446                    route_polyline.rgba_color,
447                    route_polyline.width_pixels,
448                    &mut vertices,
449                );
450            }
451            MapOverlay::FilledPolygon(filled_polygon) => {
452                filled_polygon_triangles(
453                    &frame_projection,
454                    &filled_polygon.ring_coordinates,
455                    &filled_polygon.hole_ring_coordinates,
456                    filled_polygon.rgba_color,
457                    &mut vertices,
458                );
459            }
460            MapOverlay::PointMarkers(point_markers) => {
461                for position in &point_markers.positions {
462                    point_marker_triangles(
463                        &frame_projection,
464                        viewport,
465                        position,
466                        point_markers.rgba_color,
467                        point_markers.radius_pixels,
468                        &mut vertices,
469                    );
470                }
471            }
472            MapOverlay::PointPins(point_pins) => {
473                for position in &point_pins.positions {
474                    point_pin_triangles(
475                        &frame_projection,
476                        viewport,
477                        position,
478                        point_pins.rgba_color,
479                        point_pins.radius_pixels,
480                        &mut vertices,
481                    );
482                }
483            }
484            MapOverlay::TrafficFlow(traffic_flow) => {
485                for traffic_flow_data in &traffic_flow.flows {
486                    thickened_polyline_triangles(
487                        &frame_projection,
488                        viewport,
489                        &traffic_flow_data.shape_coordinates,
490                        traffic_congestion_rgba(traffic_flow_data.congestion_level),
491                        traffic_flow.width_pixels,
492                        &mut vertices,
493                    );
494                }
495            }
496        }
497    }
498    vertices
499}

501/// Wraps a shape's coordinates into one continuous normalized-world chain:
502/// the first vertex is placed at `reference_x + shortest wrapped delta` from
503/// `reference_x`, and every following vertex unwraps from its predecessor by
504/// the shortest wrapped delta, so chains crossing the antimeridian continue
505/// past the copy seam instead of tearing back across the viewport (the same
506/// wrap-as-one-unit rule the tile spans follow).
507///
508/// The camera-anchored overlay assembly passes the camera's normalized-world x
509/// as the reference; the cached world-space tessellation passes a
510/// content-defined origin so the result is independent of the camera pose.
511fn unwrapped_normalized_chain(
512    reference_x: f64,
513    coordinates: &[GeographicCoordinate],
514) -> Vec<[f64; 2]> {
515    let mut points = Vec::with_capacity(coordinates.len());
516    let mut previous_x: Option<f64> = None;
517    for coordinate in coordinates {
518        let normalized_world = coordinate_to_normalized_world(coordinate);
519        let wrapped_x = match previous_x {
520            None => reference_x + normalized_shortest_delta(reference_x, normalized_world[0]),
521            Some(previous_x_value) => {
522                previous_x_value + normalized_shortest_delta(previous_x_value, normalized_world[0])
523            }
524        };
525        points.push([wrapped_x, normalized_world[1]]);
526        previous_x = Some(wrapped_x);
527    }
528    points
529}

552            zoom_scale_pixels: zoom_scale_pixels(camera.zoom_level),
553            center_normalized_x: coordinate_to_normalized_world(&camera.center)[0],
554        }
555    }

557    /// The wrapped normalized-world x of a raw normalized-world x: the
558    /// position in `(-0.5, 0.5]` around the camera's world copy, shared with
559    /// the tile spans' wrapping rule.
560    pub(crate) fn wrapped_x(&self, normalized_x: f64) -> f64 {
561        self.center_normalized_x + normalized_shortest_delta(self.center_normalized_x, normalized_x)
562    }

564    /// Wraps a shape's coordinates into one continuous normalized-world chain:
565    /// the first vertex sits in the camera's world copy and every following
566    /// vertex unwraps from its predecessor by the shortest wrapped delta, so
567    /// chains crossing the antimeridian continue past the copy seam instead
568    /// of tearing back across the viewport (the same wrap-as-one-unit rule
569    /// the tile spans follow).
570    fn wrapped_continuous_chain(&self, coordinates: &[GeographicCoordinate]) -> Vec<[f64; 2]> {
571        self.wrapped_continuous_chain_near(self.center_normalized_x, coordinates)
572    }
573
574    /// [`Self::wrapped_continuous_chain`] anchored on a caller-supplied
575    /// normalized-world x rather than the camera center. A hole ring uses its
576    /// outer ring's first wrapped vertex, so both rings land in the same world
577    /// copy even when the polygon straddles the antimeridian and the camera
578    /// center alone would resolve the hole to the neighboring copy.
579    fn wrapped_continuous_chain_near(
580        &self,
581        reference_x: f64,
582        coordinates: &[GeographicCoordinate],
583    ) -> Vec<[f64; 2]> {
584        unwrapped_normalized_chain(reference_x, coordinates)
585    }

587    /// The camera-space clip position of a ground point of one world-copy
588    /// window. Camera world space is y-north pixel space (see
589    /// `MapCamera::ground_position_vector`); the window's copy offset is
590    /// subtracted from the wrapped x so the fragment continues the camera's
591    /// own copy past the window edge, exactly as the tile fragments do.
592    pub(crate) fn ground_clip_position(&self, window_offset: f64, x: f64, y: f64) -> DVec4 {
593        let x_pixels = (x - window_offset) * self.zoom_scale_pixels;
594        let y_pixels = -y * self.zoom_scale_pixels;
595        self.view_projection_matrix * DVec4::new(x_pixels, y_pixels, 0.0, 1.0)
596    }
597
598    /// The wrapped normalized-world x-range one world-copy window spans:
599    /// `[window_start_x, window_end_x)` around the camera's world copy,
600    /// shared by the segment fragments' split rule and the location
601    /// indicator's per-window anchor containment.
602    pub(crate) fn window_x_range(&self, window_offset: f64) -> [f64; 2] {
603        let window_start_x =
604            self.center_normalized_x - CAMERA_WORLD_WINDOW_HALF_WIDTH + window_offset;
605        [
606            window_start_x,
607            window_start_x + 2.0 * CAMERA_WORLD_WINDOW_HALF_WIDTH,
608        ]
609    }
610}

612/// Divides a clip position to viewport pixel coordinates (origin top-left, y
613/// down), matching [`MapCamera::project_to_screen`]. Sound only for a
614/// positive homogeneous weight; callers check that first where screen-space
615/// math follows.
616pub(crate) fn clip_position_to_screen_pixels(
617    clip_position: DVec4,
618    viewport: &ViewportPixels,
619) -> [f64; 2] {
620    let normalized_device_x = clip_position.x / clip_position.w;
621    let normalized_device_y = clip_position.y / clip_position.w;
622    [
623        (normalized_device_x + 1.0) * 0.5 * viewport.width_pixels,
624        (1.0 - (normalized_device_y + 1.0) * 0.5) * viewport.height_pixels,
625    ]
626}

628/// Re-expands a screen-pixel offset of one clip-space reference point into a
629/// clip position carrying the reference's depth and homogeneous weight. The
630/// screen offset is applied in normalized-device space around the reference's
631/// divided position, so per-vertex interpolation across a thickened quad ends
632/// at exactly the offset screen corners; the quad's interior follows the
633/// same perspective weighting as the underlying ground line.
634pub(crate) fn screen_pixels_to_clip_position(
635    screen_pixels: [f64; 2],
636    reference_clip_position: DVec4,
637    viewport: &ViewportPixels,
638) -> [f64; 4] {
639    let normalized_device_x = 2.0 * screen_pixels[0] / viewport.width_pixels - 1.0;
640    let normalized_device_y = 1.0 - 2.0 * screen_pixels[1] / viewport.height_pixels;
641    [
642        normalized_device_x * reference_clip_position.w,
643        normalized_device_y * reference_clip_position.w,
644        reference_clip_position.z,
645        reference_clip_position.w,
646    ]
647}

649/// Pushes one solid-color triangle, skipping it entirely when any corner is
650/// non-finite: an f32-overflowing corner would poison the whole draw with
651/// undefined geometry, while skipping keeps the rest of the overlay healthy.
652pub(crate) fn push_triangle(
653    vertices: &mut Vec<ClipSpaceOverlayVertex>,
654    corners: &[[f64; 4]; 3],
655    rgba_color: [f32; 4],
656) {
657    if corners
658        .iter()
659        .any(|corner| corner.iter().any(|component| !component.is_finite()))
660    {
661        return;
662    }
663    for corner in corners {
664        vertices.push(ClipSpaceOverlayVertex {
665            clip_position: [
666                corner[0] as f32,
667                corner[1] as f32,
668                corner[2] as f32,
669                corner[3] as f32,
670            ],
671            rgba_color,
672        });
673    }

748/// A camera-independent tessellation of the overlay list in normalized world
749/// space, ready to be uploaded once and drawn every frame with
750/// [`WorldSpaceOverlayFrameUniforms`].
751///
752/// The layer is cached across frames while the overlay content is unchanged:
753/// panning, rotation and zoom change only the frame uniform (the view
754/// projection, viewport extent and the origin's world-copy placement), never
755/// this geometry. Screen-space line widths, joins, marker radii and pin
756/// outlines are authored as per-vertex pixel parameters and expanded in the
757/// vertex shader, so they still follow the CPU assembly's screen-pixel math
758/// exactly while the tessellation stays camera-free.
759///
760/// World-copy handling moves to the frame path too: the shader recenters each
761/// vertex by the drawn instance's copy offset and discards fragments outside
762/// the camera's own world-copy window, reproducing the CPU assembly's window
763/// split and antimeridian wrap without re-tessellating.
764#[derive(Debug, Clone, PartialEq)]
765pub struct WorldSpaceOverlayGeometry {
766    /// Normalized-world origin every stored position is relative to.
767    origin_normalized_world: [f64; 2],
768    /// Flat, non-indexed triangle list.
769    vertices: Vec<WorldSpaceOverlayVertex>,
770}
771
772impl WorldSpaceOverlayGeometry {
773    /// Tessellates every overlay into one flat world-space triangle list.
774    /// The origin is the first coordinate of the first overlay that carries
775    /// one (zero for an empty list), so the cached geometry is independent of
776    /// the camera pose.
777    pub fn tessellate(overlays: &[MapOverlay]) -> Self {
778        let origin_normalized_world =
779            first_overlay_normalized_world(overlays).unwrap_or([0.0, 0.0]);
780        let mut tessellation = WorldSpaceTessellation {
781            origin_normalized_world,
782            vertices: Vec::new(),
783        };
784        for overlay in overlays {
785            match overlay {
786                MapOverlay::RoutePolyline(route_polyline) => tessellation.push_polyline(
787                    &route_polyline.coordinates,
788                    route_polyline.rgba_color,
789                    route_polyline.width_pixels,
790                ),
791                MapOverlay::FilledPolygon(filled_polygon) => tessellation.push_filled_polygon(
792                    &filled_polygon.ring_coordinates,
793                    &filled_polygon.hole_ring_coordinates,
794                    filled_polygon.rgba_color,
795                ),
796                MapOverlay::PointMarkers(point_markers) => tessellation.push_point_markers(
797                    &point_markers.positions,
798                    point_markers.rgba_color,
799                    point_markers.radius_pixels,
800                ),
801                MapOverlay::PointPins(point_pins) => tessellation.push_point_pins(
802                    &point_pins.positions,
803                    point_pins.rgba_color,
804                    point_pins.radius_pixels,
805                ),
806                MapOverlay::TrafficFlow(traffic_flow) => {
807                    for flow in &traffic_flow.flows {
808                        tessellation.push_polyline(
809                            &flow.shape_coordinates,
810                            traffic_congestion_rgba(flow.congestion_level),
811                            traffic_flow.width_pixels,
812                        );
813                    }
814                }
815            }
816        }
817        Self {
818            origin_normalized_world,
819            vertices: tessellation.vertices,
820        }
821    }
822
823    /// The normalized-world origin stored positions are relative to.
824    pub fn origin_normalized_world(&self) -> [f64; 2] {
825        self.origin_normalized_world
826    }
827
828    /// The flat, non-indexed world-space triangle list.
829    pub fn vertices(&self) -> &[WorldSpaceOverlayVertex] {
830        &self.vertices
831    }
832
833    /// Number of vertices in the triangle list.
834    pub fn vertex_count(&self) -> usize {
835        self.vertices.len()
836    }
837
838    /// Number of triangles the list draws.
839    pub fn triangle_count(&self) -> usize {
840        self.vertices.len() / OVERLAY_TRIANGLE_VERTEX_COUNT
841    }
842
843    /// Whether the layer draws nothing.
844    pub fn is_empty(&self) -> bool {
845        self.vertices.is_empty()
846    }

849/// Per-frame uniform of the world-space overlay shader: everything that
850/// changes when the camera moves, while [`WorldSpaceOverlayGeometry`] stays
851/// cached.
852///
853/// The layout is the WGSL `FrameUniforms` struct: the camera anchor's clip
854/// position, the view-projection's linear part (translation removed) scaled by
855/// the zoom's world-pixel scale, the layer origin relative to the camera, the
856/// viewport size, and the world-copy offsets the draw's instances index.
857#[derive(Debug, Clone, Copy, PartialEq)]
858pub struct WorldSpaceOverlayFrameUniforms {
859    /// Clip position of the camera's own normalized-world center (its anchor
860    /// ground point), computed in `f64` on the CPU.
861    pub anchor_clip_position: [f32; 4],
862    /// Linear part of the view-projection (translation column zeroed) with its
863    /// x and y columns scaled by [`crate::projection::zoom_scale_pixels`];
864    /// column-major, matching WGSL's `mat4x4<f32>`.
865    pub relative_view_projection: [[f32; 4]; 4],
866    /// The layer origin's nearest world copy relative to the camera in x, and
867    /// the camera-to-origin y delta, both normalized world units. The shader
868    /// subtracts each vertex's stored offset from this to recover the
869    /// camera-relative ground position.
870    pub origin_relative_normalized: [f32; 2],
871    /// Viewport extent in physical pixels.
872    pub viewport_size_pixels: [f32; 2],
873    /// The world-copy offsets the draw's instances select, packed two `vec4`s
874    /// deep (`[c0, c1, c2, c3]`, `[c4, 0, 0, 0]`).
875    pub world_copy_offsets: [[f32; 4]; 2],
876}
877
878impl WorldSpaceOverlayFrameUniforms {
879    /// Builds the frame uniform for a camera pose and a cached layer origin.
880    ///
881    /// The anchor clip position and the relative matrix are computed in `f64`
882    /// and only the final `f32` uniform crosses to the GPU; the shader then
883    /// adds a small camera-relative offset to that anchor, so the projection
884    /// keeps its precision even when the zoom-scaled world coordinates are
885    /// large (the same camera-relative trick the tile quads achieve by
886    /// projecting on the CPU).
887    pub fn for_frame(
888        camera: &MapCamera,
889        viewport: &ViewportPixels,
890        field_of_view_degrees: f64,
891        origin_normalized_world: [f64; 2],
892    ) -> Self {
893        let view_projection = camera.view_projection_matrix(viewport, field_of_view_degrees);
894        let zoom_scale = zoom_scale_pixels(camera.zoom_level);
895        let center_normalized_world = coordinate_to_normalized_world(&camera.center);
896        let anchor_world = DVec4::new(
897            center_normalized_world[0] * zoom_scale,
898            -center_normalized_world[1] * zoom_scale,
899            0.0,
900            1.0,
901        );
902        let anchor_clip = view_projection * anchor_world;
903
904        // The mapping from camera-relative normalized-world offsets to clip
905        // offsets: the view-projection's linear columns, with x and y scaled
906        // by the zoom's pixels-per-world-unit. The z and translation columns
907        // never contribute (all ground points sit on z = 0).
908        let mut relative_view_projection = DMat4::ZERO;
909        relative_view_projection.x_axis = view_projection.x_axis * zoom_scale;
910        relative_view_projection.y_axis = view_projection.y_axis * zoom_scale;
911
912        let origin_relative_normalized = [
913            normalized_shortest_delta(center_normalized_world[0], origin_normalized_world[0]),
914            center_normalized_world[1] - origin_normalized_world[1],
915        ];
916
917        Self {
918            anchor_clip_position: [
919                anchor_clip.x as f32,
920                anchor_clip.y as f32,
921                anchor_clip.z as f32,
922                anchor_clip.w as f32,
923            ],
924            relative_view_projection: [
925                relative_view_projection
926                    .x_axis
927                    .to_array()
928                    .map(|component| component as f32),
929                relative_view_projection
930                    .y_axis
931                    .to_array()
932                    .map(|component| component as f32),
933                relative_view_projection
934                    .z_axis
935                    .to_array()
936                    .map(|component| component as f32),
937                relative_view_projection
938                    .w_axis
939                    .to_array()
940                    .map(|component| component as f32),
941            ],
942            origin_relative_normalized: [
943                origin_relative_normalized[0] as f32,
944                origin_relative_normalized[1] as f32,
945            ],
946            viewport_size_pixels: [viewport.width_pixels as f32, viewport.height_pixels as f32],
947            world_copy_offsets: [
948                [
949                    WORLD_SPACE_OVERLAY_WORLD_COPY_OFFSETS[0],
950                    WORLD_SPACE_OVERLAY_WORLD_COPY_OFFSETS[1],
951                    WORLD_SPACE_OVERLAY_WORLD_COPY_OFFSETS[2],
952                    WORLD_SPACE_OVERLAY_WORLD_COPY_OFFSETS[3],
953                ],
954                [WORLD_SPACE_OVERLAY_WORLD_COPY_OFFSETS[4], 0.0, 0.0, 0.0],
955            ],
956        }
957    }
958}

960/// The first coordinate any overlay carries, in normalized world space: the
961/// content-defined origin that keeps cached geometry camera-independent. The
962/// scan follows the overlay list order, so the origin itself is deterministic.
963fn first_overlay_normalized_world(overlays: &[MapOverlay]) -> Option<[f64; 2]> {
964    for overlay in overlays {
965        let first_coordinate = match overlay {
966            MapOverlay::RoutePolyline(route_polyline) => route_polyline.coordinates.first(),
967            MapOverlay::FilledPolygon(filled_polygon) => filled_polygon.ring_coordinates.first(),
968            MapOverlay::PointMarkers(point_markers) => point_markers.positions.first(),
969            MapOverlay::PointPins(point_pins) => point_pins.positions.first(),
970            MapOverlay::TrafficFlow(traffic_flow) => traffic_flow
971                .flows
972                .iter()
973                .find_map(|flow| flow.shape_coordinates.first()),
974        };
975        if let Some(coordinate) = first_coordinate {
976            return Some(coordinate_to_normalized_world(coordinate));
977        }
978    }
979    None

982/// Mutable assembly state for [`WorldSpaceOverlayGeometry::tessellate`]:
983/// converts each shape's coordinates into origin-relative normalized-world
984/// positions and emits the shader's vertex vocabulary.
985struct WorldSpaceTessellation {
986    origin_normalized_world: [f64; 2],
987    vertices: Vec<WorldSpaceOverlayVertex>,
988}
989
990impl WorldSpaceTessellation {
991    /// Wraps a shape's coordinates into a continuous normalized-world chain
992    /// whose first vertex sits within half a world of the layer origin, then
993    /// stores every point as an offset from that origin.
994    fn anchored_chain(&self, coordinates: &[GeographicCoordinate]) -> Vec<[f64; 2]> {
995        let mut chain = unwrapped_normalized_chain(self.origin_normalized_world[0], coordinates);
996        self.relativize(&mut chain);
997        chain
998    }
999
1000    /// [`Self::anchored_chain`] anchored near a caller-supplied stored x, so a
1001    /// polygon's hole rings land in the same world copy as its outer ring.
1002    fn anchored_chain_near(
1003        &self,
1004        reference_x: f64,
1005        coordinates: &[GeographicCoordinate],
1006    ) -> Vec<[f64; 2]> {
1007        let mut chain =
1008            unwrapped_normalized_chain(self.origin_normalized_world[0] + reference_x, coordinates);
1009        self.relativize(&mut chain);
1010        chain
1011    }
1012
1013    /// One anchored position, the chain rule for a single-coordinate shape.
1014    fn anchored_position(&self, coordinate: &GeographicCoordinate) -> [f64; 2] {
1015        let normalized_world = coordinate_to_normalized_world(coordinate);
1016        let anchored_x = self.origin_normalized_world[0]
1017            + normalized_shortest_delta(self.origin_normalized_world[0], normalized_world[0]);
1018        [
1019            anchored_x - self.origin_normalized_world[0],
1020            normalized_world[1] - self.origin_normalized_world[1],
1021        ]
1022    }
1023
1024    fn relativize(&self, chain: &mut [[f64; 2]]) {
1025        for point in chain {
1026            point[0] -= self.origin_normalized_world[0];
1027            point[1] -= self.origin_normalized_world[1];
1028        }
1029    }
1030
1031    fn push_vertex(
1032        &mut self,
1033        world_position: [f64; 2],
1034        reference_position: [f64; 2],
1035        next_position: [f64; 2],
1036        shape_kind: u32,
1037        shape_parameters: [f64; 2],
1038        rgba_color: [f32; 4],
1039    ) {
1040        self.vertices.push(WorldSpaceOverlayVertex {
1041            world_position: [world_position[0] as f32, world_position[1] as f32],
1042            reference_position: [reference_position[0] as f32, reference_position[1] as f32],
1043            next_position: [next_position[0] as f32, next_position[1] as f32],
1044            shape_kind,
1045            shape_parameters: [shape_parameters[0] as f32, shape_parameters[1] as f32],
1046            rgba_color,
1047        });
1048    }
1049
1050    /// Emits a thick polyline exactly like the CPU assembly: one quad per
1051    /// segment (two triangles, split `0,1,2 / 2,1,3`) followed by one square
1052    /// join per interior vertex. The width and join direction stay as
1053    /// screen-pixel parameters; the shader resolves them per frame.
1054    fn push_polyline(
1055        &mut self,
1056        coordinates: &[GeographicCoordinate],
1057        rgba_color: [f32; 4],
1058        width_pixels: f64,
1059    ) {
1060        let points = self.anchored_chain(coordinates);
1061        let half_width_pixels = width_pixels * 0.5;
1062        for segment in points.windows(2) {
1063            let start = segment[0];
1064            let end = segment[1];
1065            if start == end {
1066                // A duplicated coordinate thickens to an empty quad on the
1067                // CPU; skipping it keeps the triangle tally identical.
1068                continue;
1069            }
1070            // Quad corners: start-offset, start-opposite, end-offset,
1071            // end-opposite. The direction sign makes the shader's segment
1072            // direction always run start to end from either endpoint.
1073            let corners = [
1074                (start, end, 1.0, half_width_pixels),
1075                (start, end, 1.0, -half_width_pixels),
1076                (end, start, -1.0, half_width_pixels),
1077                (end, start, -1.0, -half_width_pixels),
1078            ];
1079            for triangle in [[0_usize, 1, 2], [2, 1, 3]] {
1080                for corner_index in triangle {
1081                    let (world_position, other_endpoint, direction_sign, side_offset) =
1082                        corners[corner_index];
1083                    self.push_vertex(
1084                        world_position,
1085                        other_endpoint,
1086                        [0.0; 2],
1087                        WORLD_SPACE_OVERLAY_SHAPE_SEGMENT,
1088                        [direction_sign, side_offset],
1089                        rgba_color,
1090                    );
1091                }
1092            }
1093        }
1094        for bend_index in 1..points.len().saturating_sub(1) {
1095            let previous = points[bend_index - 1];

1193    /// Emits tip-anchored teardrop pins as the annulus between the hollow head
1194    /// circle and the star-shaped teardrop boundary, exactly the CPU
1195    /// assembly's triangle order. Every vertex keeps the tip's world position
1196    /// and its screen-pixel offset from it.
1197    fn push_point_pins(
1198        &mut self,
1199        positions: &[GeographicCoordinate],
1200        rgba_color: [f32; 4],
1201        radius_pixels: f64,
1202    ) {
1203        if !radius_pixels.is_finite() || radius_pixels <= 0.0 {
1204            return;
1205        }
1206        let pin_height_pixels = radius_pixels * POINT_PIN_HEIGHT_RADIUS_FACTOR;
1207        let hollow_radius_pixels = radius_pixels * POINT_PIN_HOLLOW_RADIUS_RATIO;
1208        let tangent_half_angle = (radius_pixels / pin_height_pixels).acos();
1209        let tip_direction_angle = std::f64::consts::FRAC_PI_2;
1210        let right_tangent_angle = tip_direction_angle - tangent_half_angle;
1211        let left_tangent_angle = tip_direction_angle + tangent_half_angle;
1212        let outline_radius_pixels = |angle: f64| {
1213            if angle > right_tangent_angle && angle < left_tangent_angle {
1214                let edge_angle = if angle <= tip_direction_angle {
1215                    right_tangent_angle
1216                } else {
1217                    left_tangent_angle
1218                };
1219                radius_pixels / (angle - edge_angle).cos()
1220            } else {
1221                radius_pixels
1222            }
1223        };
1224        // Every pin corner sits relative to the *tip's* projected position:
1225        // the head center is above it, and the rings radiate from the head
1226        // center. Screen y grows downward, so the head is at -pin_height.
1227        let screen_offset = |outline_radius: f64, angle: f64| {
1228            [
1229                outline_radius * angle.cos(),
1230                outline_radius * angle.sin() - pin_height_pixels,
1231            ]
1232        };
1233        for position in positions {
1234            let anchor = self.anchored_position(position);
1235            for side_index in 0..POINT_PIN_RING_SIDES {
1236                let start_angle = side_index as f64 * TAU / POINT_PIN_RING_SIDES as f64;
1237                let end_angle = (side_index + 1) as f64 * TAU / POINT_PIN_RING_SIDES as f64;
1238                let inner_start = screen_offset(hollow_radius_pixels, start_angle);
1239                let inner_end = screen_offset(hollow_radius_pixels, end_angle);
1240                let outer_start = screen_offset(outline_radius_pixels(start_angle), start_angle);
1241                let outer_end = screen_offset(outline_radius_pixels(end_angle), end_angle);
1242                for triangle in [
1243                    [inner_start, inner_end, outer_end],
1244                    [inner_start, outer_end, outer_start],
1245                ] {
1246                    for offset in triangle {
1247                        self.push_vertex(
1248                            anchor,
1249                            [0.0; 2],
1250                            [0.0; 2],
1251                            WORLD_SPACE_OVERLAY_SHAPE_ANCHORED,
1252                            offset,
1253                            rgba_color,
1254                        );
1255                    }
1256                }
1257            }
1258        }
1259    }

1263/// with its continuous normalized-world endpoints and the window's copy
1264/// offset for [`OverlayFrameProjection::ground_clip_position`].
1265#[derive(Debug, Clone, Copy, PartialEq)]

1267    /// Continuous normalized-world start point of the fragment.
1268    start: [f64; 2],
1269    /// Continuous normalized-world end point of the fragment.
1270    end: [f64; 2],
1271    /// Whole-world copy offset of the window the fragment lies in.
1272    window_offset: f64,
1273}

1275/// Splits a shape segment against the camera-centered world-copy windows.
1276///
1277/// Each window keeps the segment's intersection with its x-range, matching
1278/// [`CAMERA_WORLD_WINDOW_HALF_WIDTH`] around the camera per offset. A
1279/// vertical segment (zero x-span) joins the one window containing its x,
1280/// half-open on the east so a boundary-exact segment cannot draw twice; a
1281/// segment touching a window only at its edge produces no fragment, mirroring
1282/// the tile spans' empty-fragment rule.
1283fn segment_window_fragments(
1284    frame_projection: &OverlayFrameProjection,
1285    segment_start: [f64; 2],
1286    segment_end: [f64; 2],
1287) -> Vec<SegmentWindowFragment> {
1288    let span_x = segment_end[0] - segment_start[0];
1289    let mut fragments = Vec::new();
1290    for window_offset in WORLD_COPY_WINDOW_OFFSETS {
1291        let window_offset_f64 = f64::from(window_offset);
1292        let [window_start_x, window_end_x] = frame_projection.window_x_range(window_offset_f64);
1293        let (start_fraction, end_fraction) = if span_x == 0.0 {
1294            let zero_span_inside_window =
1295                segment_start[0] >= window_start_x && segment_start[0] < window_end_x;
1296            if !zero_span_inside_window {
1297                continue;
1298            }
1299            (0.0, 1.0)
1300        } else {
1301            let clamped_start_fraction =
1302                ((window_start_x - segment_start[0]) / span_x).clamp(0.0, 1.0);
1303            let clamped_end_fraction = ((window_end_x - segment_start[0]) / span_x).clamp(0.0, 1.0);
1304            if clamped_start_fraction == clamped_end_fraction {
1305                continue;
1306            }
1307            (clamped_start_fraction, clamped_end_fraction)
1308        };
1309        let fragment_start = [
1310            segment_start[0] + span_x * start_fraction,
1311            segment_start[1] + (segment_end[1] - segment_start[1]) * start_fraction,
1312        ];
1313        let fragment_end = [
1314            segment_start[0] + span_x * end_fraction,
1315            segment_start[1] + (segment_end[1] - segment_start[1]) * end_fraction,
1316        ];
1317        fragments.push(SegmentWindowFragment {
1318            start: fragment_start,
1319            end: fragment_end,
1320            window_offset: window_offset_f64,
1321        });
1322    }
1323    fragments
1324}

1326/// Assembles a thick polyline: consecutive coordinate pairs thicken to
1327/// per-segment screen-space quads split against the world-copy windows, and
1328/// every interior vertex fills its joint with a screen-space square of the
1329/// line's width.
1330///
1331/// The join fill is what keeps a multi-segment line continuous: butt-capped
1332/// quads meet at the shared vertex but leave a wedge on a bend's outer side,
1333/// which reads as a gap between segments — the most visible case is a styled
1334/// road network, whose per-way geometry bends at nearly every vertex.
1335/// Endpoints keep their butt caps (a per-feature end has no neighbouring
1336/// segment to join), and the square join never grows a miter spike at sharp
1337/// angles the way a mitered join would.
1338fn thickened_polyline_triangles(
1339    frame_projection: &OverlayFrameProjection,
1340    viewport: &ViewportPixels,
1341    coordinates: &[GeographicCoordinate],
1342    rgba_color: [f32; 4],
1343    width_pixels: f64,
1344    vertices: &mut Vec<ClipSpaceOverlayVertex>,
1345) {
1346    let wrapped_points = frame_projection.wrapped_continuous_chain(coordinates);
1347    for segment_index in 1..wrapped_points.len() {
1348        for fragment in segment_window_fragments(
1349            frame_projection,
1350            wrapped_points[segment_index - 1],
1351            wrapped_points[segment_index],
1352        ) {
1353            thickened_segment_triangles(
1354                frame_projection,
1355                viewport,
1356                &fragment,
1357                rgba_color,
1358                width_pixels,
1359                vertices,
1360            );
1361        }
1362    }
1363    for vertex_index in 1..wrapped_points.len().saturating_sub(1) {
1364        polyline_join_triangles(
1365            frame_projection,
1366            viewport,
1367            PolylineBend {
1368                previous: wrapped_points[vertex_index - 1],
1369                vertex: wrapped_points[vertex_index],
1370                next: wrapped_points[vertex_index + 1],
1371            },
1372            rgba_color,
1373            width_pixels,
1374            vertices,
1375        );
1376    }
1377}

1387/// Fills one interior polyline vertex's joint with a screen-space square of
1388/// the line's own width, oriented along the bend's bisector. The square
1389/// covers the wedge the two butt-capped segment quads leave outside a bend;
1390/// see [`thickened_polyline_triangles`] for why the join exists.
1391fn polyline_join_triangles(
1392    frame_projection: &OverlayFrameProjection,
1393    viewport: &ViewportPixels,
1394    bend: PolylineBend,
1395    rgba_color: [f32; 4],
1396    width_pixels: f64,
1397    vertices: &mut Vec<ClipSpaceOverlayVertex>,
1398) {
1399    // One join lives in the world-copy window that contains it; a vertex on a
1400    // window's east half-open edge belongs to the following copy, matching
1401    // the segment split's rule.
1402    let window_offset = WORLD_COPY_WINDOW_OFFSETS.iter().copied().find(|offset| {
1403        let [window_start_x, window_end_x] = frame_projection.window_x_range(f64::from(*offset));
1404        bend.vertex[0] >= window_start_x && bend.vertex[0] < window_end_x
1405    });
1406    let Some(window_offset) = window_offset else {
1407        return;
1408    };
1409    let window_offset_f64 = f64::from(window_offset);
1410    let project = |point: [f64; 2]| {
1411        frame_projection.ground_clip_position(window_offset_f64, point[0], point[1])
1412    };
1413    let previous_clip_position = project(bend.previous);
1414    let vertex_clip_position = project(bend.vertex);
1415    let next_clip_position = project(bend.next);
1416    if previous_clip_position.w <= 0.0
1417        || vertex_clip_position.w <= 0.0
1418        || next_clip_position.w <= 0.0
1419    {
1420        return;
1421    }
1422    let previous_screen = clip_position_to_screen_pixels(previous_clip_position, viewport);
1423    let vertex_screen = clip_position_to_screen_pixels(vertex_clip_position, viewport);
1424    let next_screen = clip_position_to_screen_pixels(next_clip_position, viewport);
1425    let incoming = [
1426        vertex_screen[0] - previous_screen[0],
1427        vertex_screen[1] - previous_screen[1],
1428    ];
1429    let outgoing = [
1430        next_screen[0] - vertex_screen[0],
1431        next_screen[1] - vertex_screen[1],
1432    ];
1433    let incoming_length = incoming[0].hypot(incoming[1]);
1434    let outgoing_length = outgoing[0].hypot(outgoing[1]);
1435    if incoming_length < MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS
1436        || outgoing_length < MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS
1437    {
1438        return;
1439    }
1440    let incoming_unit = [incoming[0] / incoming_length, incoming[1] / incoming_length];
1441    let outgoing_unit = [outgoing[0] / outgoing_length, outgoing[1] / outgoing_length];
1442    let half_width_pixels = width_pixels * 0.5;
1443    // The bisector of the two segment directions is the direction the wedge
1444    // opens along. A reversal (sum near zero) has no bisector: the incoming
1445    // perpendicular is its 90-degree stand-in.
1446    let sum = [
1447        incoming_unit[0] + outgoing_unit[0],
1448        incoming_unit[1] + outgoing_unit[1],
1449    ];
1450    let sum_length = sum[0].hypot(sum[1]);
1451    let bisector_unit = if sum_length < MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS {
1452        [-incoming_unit[1], incoming_unit[0]]
1453    } else {
1454        [sum[0] / sum_length, sum[1] / sum_length]
1455    };
1456    let perpendicular_unit = [-bisector_unit[1], bisector_unit[0]];
1457    let corner_screens = [
1458        [
1459            vertex_screen[0] + (bisector_unit[0] + perpendicular_unit[0]) * half_width_pixels,
1460            vertex_screen[1] + (bisector_unit[1] + perpendicular_unit[1]) * half_width_pixels,
1461        ],
1462        [
1463            vertex_screen[0] + (-bisector_unit[0] + perpendicular_unit[0]) * half_width_pixels,
1464            vertex_screen[1] + (-bisector_unit[1] + perpendicular_unit[1]) * half_width_pixels,
1465        ],
1466        [
1467            vertex_screen[0] + (-bisector_unit[0] - perpendicular_unit[0]) * half_width_pixels,
1468            vertex_screen[1] + (-bisector_unit[1] - perpendicular_unit[1]) * half_width_pixels,
1469        ],
1470        [
1471            vertex_screen[0] + (bisector_unit[0] - perpendicular_unit[0]) * half_width_pixels,
1472            vertex_screen[1] + (bisector_unit[1] - perpendicular_unit[1]) * half_width_pixels,
1473        ],
1474    ];
1475    let corner_clip_positions = corner_screens.map(|corner_screen_pixels| {
1476        screen_pixels_to_clip_position(corner_screen_pixels, vertex_clip_position, viewport)
1477    });
1478    push_triangle(
1479        vertices,
1480        &[
1481            corner_clip_positions[0],
1482            corner_clip_positions[1],
1483            corner_clip_positions[2],
1484        ],
1485        rgba_color,
1486    );
1487    push_triangle(
1488        vertices,
1489        &[
1490            corner_clip_positions[0],
1491            corner_clip_positions[2],
1492            corner_clip_positions[3],
1493        ],
1494        rgba_color,
1495    );
1496}

1498/// Assembles one thickened segment fragment as a screen-space quad: the
1499/// perpendicular offset of half the line width, applied in screen pixels
1500/// around each endpoint's divided position, so a line keeps its pixel width
1501/// regardless of zoom and pitch.
1502///
1503/// A fragment with a vertex at or behind the camera draws nothing — the
1504/// screen-space offset needs a positive homogeneous weight — which is the
1505/// documented limitation next to the filled polygons' GPU-clipped near-plane
1506/// straddling (see the module notes).
1507fn thickened_segment_triangles(
1508    frame_projection: &OverlayFrameProjection,
1509    viewport: &ViewportPixels,
1510    fragment: &SegmentWindowFragment,
1511    rgba_color: [f32; 4],
1512    width_pixels: f64,
1513    vertices: &mut Vec<ClipSpaceOverlayVertex>,
1514) {
1515    let start_clip_position = frame_projection.ground_clip_position(
1516        fragment.window_offset,
1517        fragment.start[0],
1518        fragment.start[1],
1519    );
1520    let end_clip_position = frame_projection.ground_clip_position(
1521        fragment.window_offset,
1522        fragment.end[0],
1523        fragment.end[1],
1524    );
1525    if start_clip_position.w <= 0.0 || end_clip_position.w <= 0.0 {
1526        return;
1527    }
1528    let start_screen = clip_position_to_screen_pixels(start_clip_position, viewport);
1529    let end_screen = clip_position_to_screen_pixels(end_clip_position, viewport);
1530    let direction = [
1531        end_screen[0] - start_screen[0],
1532        end_screen[1] - start_screen[1],
1533    ];
1534    let screen_length = direction[0].hypot(direction[1]);
1535    if screen_length < MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS {
1536        return;
1537    }
1538    let perpendicular_unit = [-direction[1] / screen_length, direction[0] / screen_length];
1539    let half_width_pixels = width_pixels * 0.5;
1540    let start_offset = [
1541        start_screen[0] + perpendicular_unit[0] * half_width_pixels,
1542        start_screen[1] + perpendicular_unit[1] * half_width_pixels,
1543    ];
1544    let start_opposite = [
1545        start_screen[0] - perpendicular_unit[0] * half_width_pixels,
1546        start_screen[1] - perpendicular_unit[1] * half_width_pixels,
1547    ];
1548    let end_offset = [
1549        end_screen[0] + perpendicular_unit[0] * half_width_pixels,
1550        end_screen[1] + perpendicular_unit[1] * half_width_pixels,
1551    ];
1552    let end_opposite = [
1553        end_screen[0] - perpendicular_unit[0] * half_width_pixels,
1554        end_screen[1] - perpendicular_unit[1] * half_width_pixels,
1555    ];
1556    // Corner order mirrors the tile quads: start-offset, start-opposite,
1557    // end-offset, end-opposite, split by the quads' `0,1,2 / 2,1,3` triangle
1558    // pattern, each corner re-expanded around its own endpoint's depth.
1559    let corner_clip_positions = [
1560        (start_offset, start_clip_position),
1561        (start_opposite, start_clip_position),
1562        (end_offset, end_clip_position),
1563        (end_opposite, end_clip_position),
1564    ]
1565    .map(|(corner_screen_pixels, reference_clip_position)| {
1566        screen_pixels_to_clip_position(corner_screen_pixels, reference_clip_position, viewport)
1567    });
1568    push_triangle(
1569        vertices,
1570        &[
1571            corner_clip_positions[0],
1572            corner_clip_positions[1],
1573            corner_clip_positions[2],
1574        ],
1575        rgba_color,
1576    );
1577    push_triangle(
1578        vertices,
1579        &[
1580            corner_clip_positions[2],
1581            corner_clip_positions[1],
1582            corner_clip_positions[3],
1583        ],
1584        rgba_color,
1585    );
1586}

1638/// Assembles one point pin: a teardrop outline anchored with its tip on the
1639/// projected coordinate and a hollow circular center in the head, emitted as
1640/// the annulus between the two outlines.
1641///
1642/// The teardrop is star-shaped around the head center — every ray from the
1643/// center crosses the outline exactly once — so both boundaries are radial
1644/// functions of the same angle and pair up into quads without a bridge. Inside
1645/// the tangent sector the outline is the straight edge running to the tip
1646/// (radius `R / cos(angle - tangentAngle)`); outside it is the head circle
1647/// itself. The hole therefore needs no erase pass, which this pipeline cannot
1648/// perform (see the module notes on holes).
1649fn point_pin_triangles(
1650    frame_projection: &OverlayFrameProjection,
1651    viewport: &ViewportPixels,
1652    position: &GeographicCoordinate,
1653    rgba_color: [f32; 4],
1654    radius_pixels: f64,
1655    vertices: &mut Vec<ClipSpaceOverlayVertex>,
1656) {
1657    let normalized_world = coordinate_to_normalized_world(position);
1658    let tip_clip_position = frame_projection.ground_clip_position(
1659        0.0,
1660        frame_projection.wrapped_x(normalized_world[0]),
1661        normalized_world[1],
1662    );
1663    if tip_clip_position.w <= 0.0 || !radius_pixels.is_finite() || radius_pixels <= 0.0 {
1664        return;
1665    }
1666    let tip_screen = clip_position_to_screen_pixels(tip_clip_position, viewport);
1667    let pin_height_pixels = radius_pixels * POINT_PIN_HEIGHT_RADIUS_FACTOR;
1668    let head_center_screen = [tip_screen[0], tip_screen[1] - pin_height_pixels];
1669    let hollow_radius_pixels = radius_pixels * POINT_PIN_HOLLOW_RADIUS_RATIO;
1670    // The head's tangent points sit this far around the head from the tip
1671    // direction (screen angles grow from +x towards +y, i.e. clockwise in the
1672    // displayed image, so the tip direction is a quarter turn).
1673    let tangent_half_angle = (radius_pixels / pin_height_pixels).acos();
1674    let tip_direction_angle = std::f64::consts::FRAC_PI_2;
1675    let right_tangent_angle = tip_direction_angle - tangent_half_angle;
1676    let left_tangent_angle = tip_direction_angle + tangent_half_angle;
1677    let outline_radius_pixels = |angle: f64| {
1678        if angle > right_tangent_angle && angle < left_tangent_angle {
1679            let edge_angle = if angle <= tip_direction_angle {
1680                right_tangent_angle
1681            } else {
1682                left_tangent_angle
1683            };
1684            radius_pixels / (angle - edge_angle).cos()
1685        } else {
1686            radius_pixels
1687        }
1688    };
1689    // Both outlines share the tip's clip-space reference, so the whole pin
1690    // stays screen-facing at the anchor's depth like a marker fan does.
1691    let corner_clip_position = |radius: f64, angle: f64| {
1692        screen_pixels_to_clip_position(
1693            [
1694                head_center_screen[0] + radius * angle.cos(),
1695                head_center_screen[1] + radius * angle.sin(),
1696            ],
1697            tip_clip_position,
1698            viewport,
1699        )
1700    };
1701    for side_index in 0..POINT_PIN_RING_SIDES {
1702        let start_angle = side_index as f64 * TAU / POINT_PIN_RING_SIDES as f64;
1703        let end_angle = (side_index + 1) as f64 * TAU / POINT_PIN_RING_SIDES as f64;
1704        let inner_start = corner_clip_position(hollow_radius_pixels, start_angle);
1705        let inner_end = corner_clip_position(hollow_radius_pixels, end_angle);
1706        let outer_start = corner_clip_position(outline_radius_pixels(start_angle), start_angle);
1707        let outer_end = corner_clip_position(outline_radius_pixels(end_angle), end_angle);
1708        push_triangle(vertices, &[inner_start, inner_end, outer_end], rgba_color);
1709        push_triangle(vertices, &[inner_start, outer_end, outer_start], rgba_color);
1710    }
1711}

1713/// Assembles a filled polygon: the ring set (outer boundary plus holes)
1714/// triangulates in continuous normalized-world space, every triangle splits
1715/// against the world-copy windows (convex clipping keeps the pieces convex),
1716/// and each clipped piece fans into triangles projected by their genuine
1717/// clip-space corners. Hole rings anchor to the outer ring's world copy (see
1718/// [`OverlayFrameProjection::wrapped_continuous_chain_near`]) so a polygon
1719/// straddling the antimeridian keeps its holes with its exterior. Shared
1720/// (crate-visible) with the location-indicator layer, whose ground-projected
1721/// accuracy ring reuses the exact fill machinery (without holes).
1722pub(crate) fn filled_polygon_triangles(
1723    frame_projection: &OverlayFrameProjection,
1724    ring_coordinates: &[GeographicCoordinate],
1725    hole_ring_coordinates: &[Vec<GeographicCoordinate>],
1726    rgba_color: [f32; 4],
1727    vertices: &mut Vec<ClipSpaceOverlayVertex>,
1728) {
1729    let wrapped_ring = frame_projection.wrapped_continuous_chain(ring_coordinates);
1730    let Some(reference_x) = wrapped_ring.first().map(|vertex| vertex[0]) else {
1731        return;
1732    };
1733    let wrapped_holes: Vec<Vec<[f64; 2]>> = hole_ring_coordinates
1734        .iter()
1735        .map(|hole_ring| frame_projection.wrapped_continuous_chain_near(reference_x, hole_ring))
1736        .collect();
1737    let triangle_minimum_x =
1738        |triangle: &[[f64; 2]; 3]| triangle[0][0].min(triangle[1][0]).min(triangle[2][0]);
1739    let triangle_maximum_x =
1740        |triangle: &[[f64; 2]; 3]| triangle[0][0].max(triangle[1][0]).max(triangle[2][0]);
1741    for triangle in ear_clip_triangulation_with_holes(&wrapped_ring, &wrapped_holes) {
1742        let (triangle_minimum_x, triangle_maximum_x) =
1743            (triangle_minimum_x(&triangle), triangle_maximum_x(&triangle));
1744        for window_offset in WORLD_COPY_WINDOW_OFFSETS {
1745            let window_offset_f64 = f64::from(window_offset);
1746            let [window_start_x, window_end_x] = frame_projection.window_x_range(window_offset_f64);
1747            // A triangle lying entirely outside one of the window's two
1748            // half-planes clips down to the boundary line itself — fewer than
1749            // three corners, and the fan below would draw nothing. Rejecting
1750            // it by its x-extent is exact and saves the whole clip.
1751            if triangle_maximum_x <= window_start_x || triangle_minimum_x >= window_end_x {
1752                continue;
1753            }
1754            // A triangle wholly inside both half-planes passes through the
1755            // clip unchanged — the overwhelmingly common case, since the
1756            // windows are a third of the world apart — so it projects its own
1757            // three corners and skips two Sutherland–Hodgman passes.
1758            let clipped_ring =
1759                if triangle_minimum_x >= window_start_x && triangle_maximum_x <= window_end_x {
1760                    WindowClippedTriangle {
1761                        corners: [triangle[0], triangle[1], triangle[2], [0.0; 2], [0.0; 2]],
1762                        corner_count: 3,
1763                    }
1764                } else {
1765                    clip_triangle_to_x_range(&triangle, window_start_x, window_end_x)
1766                };
1767            if clipped_ring.corner_count < 3 {
1768                continue;
1769            }
1770            // Clipped corners project by their genuine clip-space positions,
1771            // so a triangle straddling the near plane stays for the GPU to
1772            // clip exactly (see the module notes); only an f32-overflowing
1773            // corner drops via `push_triangle`.
1774            for fan_index in 1..clipped_ring.corner_count - 1 {
1775                let corner_clip_positions = [
1776                    clipped_ring.corners[0],
1777                    clipped_ring.corners[fan_index],
1778                    clipped_ring.corners[fan_index + 1],
1779                ]
1780                .map(|corner| {
1781                    let corner_clip_position = frame_projection.ground_clip_position(
1782                        window_offset_f64,
1783                        corner[0],
1784                        corner[1],
1785                    );
1786                    [
1787                        corner_clip_position.x,
1788                        corner_clip_position.y,
1789                        corner_clip_position.z,
1790                        corner_clip_position.w,
1791                    ]
1792                });
1793                push_triangle(vertices, &corner_clip_positions, rgba_color);
1794            }
1795        }
1796    }
1797}

1799/// A triangle clipped against one world-copy window: a convex ring of at most
1800/// [`MAXIMUM_WINDOW_CLIPPED_CORNERS`] corners.
1801///
1802/// The corners live in a fixed array because this runs once per triangle per
1803/// window on every frame — hundreds of thousands of times during a pan — and
1804/// the heap allocation a `Vec` would make per call is a measurable share of
1805/// the frame (PLAN.md, M23). The arithmetic is the same Sutherland–Hodgman the
1806/// allocation-based clipper uses, in the same order, so the drawn vertices are
1807/// unchanged.
1808struct WindowClippedTriangle {
1809    corners: [[f64; 2]; MAXIMUM_WINDOW_CLIPPED_CORNERS],
1810    corner_count: usize,
1811}

1813/// Clips one triangle to `window_start_x <= x < window_end_x` without
1814/// allocating: one Sutherland–Hodgman pass per half-plane over fixed buffers.
1815fn clip_triangle_to_x_range(
1816    triangle: &[[f64; 2]; 3],
1817    window_start_x: f64,
1818    window_end_x: f64,
1819) -> WindowClippedTriangle {
1820    let mut first_clip = [[0.0_f64; 2]; MAXIMUM_WINDOW_CLIPPED_CORNERS];
1821    let first_clip_count =
1822        clip_ring_to_x_half_plane(triangle, true, window_start_x, &mut first_clip);
1823    let mut second_clip = [[0.0_f64; 2]; MAXIMUM_WINDOW_CLIPPED_CORNERS];
1824    let second_clip_count = clip_ring_to_x_half_plane(
1825        &first_clip[..first_clip_count],
1826        false,
1827        window_end_x,
1828        &mut second_clip,
1829    );
1830    WindowClippedTriangle {
1831        corners: second_clip,
1832        corner_count: second_clip_count,
1833    }
1834}

1836/// One Sutherland–Hodgman pass of a convex ring against a vertical half-plane
1837/// (`keep_greater` selects `x >= boundary_x`), writing into a fixed buffer.
1838/// [`clip_polygon_to_x_half_plane`] is the allocating form with the same
1839/// arithmetic; this one is the frame-path copy.
1840fn clip_ring_to_x_half_plane(
1841    polygon: &[[f64; 2]],
1842    keep_greater: bool,
1843    boundary_x: f64,
1844    clipped_polygon: &mut [[f64; 2]; MAXIMUM_WINDOW_CLIPPED_CORNERS],
1845) -> usize {
1846    let mut clipped_corner_count = 0;
1847    for edge_index in 0..polygon.len() {
1848        let edge_start = polygon[edge_index];
1849        let edge_end = polygon[(edge_index + 1) % polygon.len()];
1850        let start_inside = if keep_greater {
1851            edge_start[0] >= boundary_x
1852        } else {
1853            edge_start[0] <= boundary_x
1854        };
1855        let end_inside = if keep_greater {
1856            edge_end[0] >= boundary_x
1857        } else {
1858            edge_end[0] <= boundary_x
1859        };
1860        if start_inside && clipped_corner_count < MAXIMUM_WINDOW_CLIPPED_CORNERS {
1861            clipped_polygon[clipped_corner_count] = edge_start;
1862            clipped_corner_count += 1;
1863        }
1864        if start_inside != end_inside {
1865            let crossing_fraction = (boundary_x - edge_start[0]) / (edge_end[0] - edge_start[0]);
1866            // A crossing at the edge's own endpoint is a vertex on the
1867            // boundary; it already landed through the inside-start pushes of
1868            // the neighboring edges, and pushing it again would degenerate
1869            // the clipped ring into a zero-area fan triangle.
1870            if crossing_fraction > 0.0
1871                && crossing_fraction < 1.0
1872                && clipped_corner_count < MAXIMUM_WINDOW_CLIPPED_CORNERS
1873            {
1874                clipped_polygon[clipped_corner_count] = [
1875                    boundary_x,
1876                    edge_start[1] + (edge_end[1] - edge_start[1]) * crossing_fraction,
1877                ];
1878                clipped_corner_count += 1;
1879            }
1880        }
1881    }
1882    clipped_corner_count
1883}

1885/// Doubled signed area of a ring (the fan-formula sum, without the constant
1886/// factor): positive for one winding, negative for the other, zero for a
1887/// collinear ring.
1888fn ring_doubled_signed_area(ring: &[[f64; 2]]) -> f64 {
1889    ring.iter()
1890        .enumerate()
1891        .map(|(index, vertex)| {
1892            let next = ring[(index + 1) % ring.len()];
1893            vertex[0] * next[1] - next[0] * vertex[1]
1894        })
1895        .sum()
1896}

1898/// Twice the signed area of one triangle (a × b cross-product form): positive
1899/// for counterclockwise winding, negative for clockwise.
1900fn triangle_doubled_signed_area(
1901    first_vertex: [f64; 2],
1902    second_vertex: [f64; 2],
1903    third_vertex: [f64; 2],
1904) -> f64 {
1905    (second_vertex[0] - first_vertex[0]) * (third_vertex[1] - first_vertex[1])
1906        - (second_vertex[1] - first_vertex[1]) * (third_vertex[0] - first_vertex[0])
1907}

1909/// Whether a point lies inside a triangle or on its boundary, by winding-sign
1910/// tests against the triangle's (consistently wound) edges.
1911fn point_lies_within_triangle(
1912    point: [f64; 2],
1913    first_vertex: [f64; 2],
1914    second_vertex: [f64; 2],
1915    third_vertex: [f64; 2],
1916) -> bool {
1917    triangle_doubled_signed_area(point, first_vertex, second_vertex)
1918        >= -EAR_CLIPPING_BOUNDARY_TOLERANCE
1919        && triangle_doubled_signed_area(point, second_vertex, third_vertex)
1920            >= -EAR_CLIPPING_BOUNDARY_TOLERANCE
1921        && triangle_doubled_signed_area(point, third_vertex, first_vertex)
1922            >= -EAR_CLIPPING_BOUNDARY_TOLERANCE
1923}

1925/// Triangulates a simple polygon ring by ear clipping, over the ring's own
1926/// vertices in O(n²) — no external geometry dependency, consistent with the
1927/// crate owning its minimal math.
1928///
1929/// The ring normalizes to one winding (positive doubled signed area) first,
1930/// so input order does not matter. Degenerate rings (fewer than three
1931/// vertices, near-zero area, or a remainder with no clipgable ear — fully
1932/// collinear chains) contribute fewer triangles or none; a numerically stuck
1933/// remainder stops the loop instead of spinning, matching the documented
1934/// "degenerate rings may fill nothing" contract.
1935fn ear_clip_triangulation(ring: &[[f64; 2]]) -> Vec<[[f64; 2]; 3]> {
1936    let mut normalized_ring = ring.to_vec();
1937    if normalized_ring.len() >= 2 && normalized_ring.first() == normalized_ring.last() {
1938        normalized_ring.pop();
1939    }
1940    if normalized_ring.len() < 3 {
1941        return Vec::new();
1942    }
1943    let doubled_signed_area = ring_doubled_signed_area(&normalized_ring);
1944    if doubled_signed_area.abs() < POLYGON_AREA_DEGENERACY_TOLERANCE {
1945        return Vec::new();
1946    }
1947    if doubled_signed_area < 0.0 {
1948        normalized_ring.reverse();
1949    }
1950    let mut remaining_indices: Vec<usize> = (0..normalized_ring.len()).collect();
1951    let mut triangles = Vec::with_capacity(normalized_ring.len() - 2);
1952    while remaining_indices.len() > 3 {
1953        let ear_position = (0..remaining_indices.len())
1954            .find(|&position| is_ring_ear(&normalized_ring, &remaining_indices, position));
1955        let Some(ear_position) = ear_position else {
1956            break;
1957        };
1958        let corner_indices = ear_corner_indices(&remaining_indices, ear_position);
1959        triangles.push([
1960            normalized_ring[corner_indices[0]],
1961            normalized_ring[corner_indices[1]],
1962            normalized_ring[corner_indices[2]],
1963        ]);
1964        remaining_indices.remove(ear_position);
1965    }
1966    if remaining_indices.len() == 3 {
1967        triangles.push([
1968            normalized_ring[remaining_indices[0]],
1969            normalized_ring[remaining_indices[1]],
1970            normalized_ring[remaining_indices[2]],
1971        ]);
1972    }
1973    triangles
1974}

1976/// Triangulates a ring set with holes: the outer boundary plus every hole,
1977/// bridge-joined into one simple ring and ear-clip triangulated in one pass.
1978///
1979/// The hole handling follows the standard bridge-splicing construction (the
1980/// `earcut` algorithm's `eliminateHoles` step) with the crate's own vector
1981/// math: each hole joins the boundary through a zero-width slit, so the
1982/// emitted triangles cover the ring set's interior minus the holes and never
1983/// the holes themselves. Winding normalizes first (outer positive, holes
1984/// negative), so the decoded ring order does not matter.
1985///
1986/// A degenerate outer ring fills nothing, and a hole ring that cannot be
1987/// bridged (fewer than three vertices, zero area, or no visible bridge) is
1988/// skipped rather than approximated; a numerically stuck ear-clipping
1989/// remainder stops early and leaves that remainder unfilled, matching the
1990/// documented "degenerate rings may fill nothing" contract.
1991fn ear_clip_triangulation_with_holes(
1992    outer_ring: &[[f64; 2]],
1993    hole_rings: &[Vec<[f64; 2]>],
1994) -> Vec<[[f64; 2]; 3]> {
1995    if hole_rings.is_empty() {
1996        return ear_clip_triangulation(outer_ring);
1997    }
1998    let normalized_outer = normalized_ring(outer_ring, true);
1999    if normalized_outer.len() < 3 {
2000        return Vec::new();
2001    }
2002    let mut nodes = Vec::new();
2003    let Some(ring_head) = ring_nodes(&normalized_outer, &mut nodes) else {
2004        return Vec::new();
2005    };
2006    let mut holes: Vec<Vec<[f64; 2]>> = hole_rings
2007        .iter()
2008        .map(|hole_ring| normalized_ring(hole_ring, false))
2009        .filter(|hole_ring| hole_ring.len() >= 3)
2010        .collect();
2011    // Left-to-right hole order, matching the bridge search's proven order:
2012    // each hole's westward ray then meets only edges already part of the
2013    // combined boundary.
2014    holes.sort_by(|left, right| {
2015        ring_leftmost_point(left)[0]
2016            .partial_cmp(&ring_leftmost_point(right)[0])
2017            .unwrap_or(std::cmp::Ordering::Equal)
2018    });
2019    for hole_ring in &holes {
2020        let Some(hole_head) = ring_nodes(hole_ring, &mut nodes) else {
2021            continue;
2022        };
2023        // The bridge search validates a bridge from the hole's leftmost
2024        // vertex; the splice must start the hole at that same vertex, or the
2025        // cycle would gain an unvalidated edge across the hole.
2026        let hole_leftmost = hole_leftmost_node(hole_head, &nodes);
2027        let Some(bridge_index) = find_hole_bridge(hole_leftmost, ring_head, &nodes) else {
2028            continue;
2029        };
2030        splice_hole_ring(bridge_index, hole_leftmost, &mut nodes);
2031    }
2032    ear_clip_nodes(&mut nodes, ring_head)
2033}

2035/// One node of the mutable circular ring list the hole-aware triangulator
2036/// clips ears from. Nodes are never freed: removal relinks the neighbors and
2037/// leaves the node unreachable, so arena indices stay valid across removals.
2038struct EarClipNode {
2039    /// The node's position in normalized-world space.
2040    vertex: [f64; 2],
2041    /// Arena index of the previous ring node.
2042    previous_index: usize,
2043    /// Arena index of the next ring node.
2044    next_index: usize,
2045}

2047/// Builds a circular node ring from a ring's vertices, dropping the repeated
2048/// closing vertex and consecutive duplicates. Returns the first node's arena
2049/// index, or `None` when fewer than three distinct vertices remain.
2050fn ring_nodes(points: &[[f64; 2]], nodes: &mut Vec<EarClipNode>) -> Option<usize> {
2051    let mut cleaned: Vec<[f64; 2]> = Vec::with_capacity(points.len());
2052    for &point in points {
2053        if cleaned.last() != Some(&point) {
2054            cleaned.push(point);
2055        }
2056    }
2057    if cleaned.len() >= 2 && cleaned.first() == cleaned.last() {
2058        cleaned.pop();
2059    }
2060    if cleaned.len() < 3 {
2061        return None;
2062    }
2063    let first_index = nodes.len();
2064    for &vertex in &cleaned {
2065        nodes.push(EarClipNode {
2066            vertex,
2067            previous_index: 0,
2068            next_index: 0,
2069        });
2070    }
2071    let vertex_count = cleaned.len();
2072    for position in 0..vertex_count {
2073        let node_index = first_index + position;
2074        nodes[node_index].previous_index =
2075            first_index + (position + vertex_count - 1) % vertex_count;
2076        nodes[node_index].next_index = first_index + (position + 1) % vertex_count;
2077    }
2078    Some(first_index)
2079}

2081/// Normalizes a ring to one winding: drops the repeated closing vertex and
2082/// consecutive duplicates, reverses the ring when its signed area has the
2083/// wrong sign, and returns an empty ring for fewer than three vertices or
2084/// near-zero area.
2085fn normalized_ring(ring: &[[f64; 2]], positive_winding: bool) -> Vec<[f64; 2]> {
2086    let mut normalized: Vec<[f64; 2]> = Vec::with_capacity(ring.len());
2087    for &point in ring {
2088        if normalized.last() != Some(&point) {
2089            normalized.push(point);
2090        }
2091    }
2092    if normalized.len() >= 2 && normalized.first() == normalized.last() {
2093        normalized.pop();
2094    }
2095    if normalized.len() < 3 {
2096        return Vec::new();
2097    }
2098    let doubled_signed_area = ring_doubled_signed_area(&normalized);
2099    if doubled_signed_area.abs() < POLYGON_AREA_DEGENERACY_TOLERANCE {
2100        return Vec::new();
2101    }
2102    if (doubled_signed_area > 0.0) != positive_winding {
2103        normalized.reverse();
2104    }
2105    normalized
2106}

2108/// The ring vertex with the smallest x (the bridge search's ray origin side).
2109fn ring_leftmost_point(ring: &[[f64; 2]]) -> [f64; 2] {
2110    ring.iter()
2111        .copied()
2112        .fold([f64::INFINITY, f64::INFINITY], |leftmost, point| {
2113            if point[0] < leftmost[0] {
2114                point
2115            } else {
2116                leftmost
2117            }
2118        })
2119}

2121/// Splices a hole ring into the outer ring at a bridge vertex: the outer
2122/// boundary turns into the hole, walks the hole ring, crosses back over the
2123/// zero-width bridge, and continues with the outer ring. `hole_head` must be
2124/// a node of the hole ring; the hole enters the cycle after `bridge_index`.
2125/// Returns the hole-head copy, the second cycle's head when the same wiring
2126/// splits a self-touching ring at a diagonal.
2127fn splice_hole_ring(bridge_index: usize, hole_head: usize, nodes: &mut Vec<EarClipNode>) -> usize {
2128    let bridge_copy_index = nodes.len();
2129    nodes.push(EarClipNode {
2130        vertex: nodes[bridge_index].vertex,
2131        previous_index: 0,
2132        next_index: 0,
2133    });
2134    let hole_head_copy_index = nodes.len();
2135    nodes.push(EarClipNode {
2136        vertex: nodes[hole_head].vertex,
2137        previous_index: 0,
2138        next_index: 0,
2139    });
2140    let bridge_next_index = nodes[bridge_index].next_index;
2141    let hole_last_index = nodes[hole_head].previous_index;
2142    // bridge -> hole head ... hole last -> hole head copy -> bridge copy ->
2143    // (original bridge next), the standard splitPolygon wiring.
2144    nodes[bridge_index].next_index = hole_head;
2145    nodes[hole_head].previous_index = bridge_index;
2146    nodes[hole_last_index].next_index = hole_head_copy_index;
2147    nodes[hole_head_copy_index].previous_index = hole_last_index;
2148    nodes[hole_head_copy_index].next_index = bridge_copy_index;
2149    nodes[bridge_copy_index].previous_index = hole_head_copy_index;
2150    nodes[bridge_copy_index].next_index = bridge_next_index;
2151    nodes[bridge_next_index].previous_index = bridge_copy_index;
2152    hole_head_copy_index
2153}

2155/// The hole ring vertex with the smallest x: the bridge search's ray origin
2156/// and the vertex the splice must enter the hole through.

2169/// The outer ring node a hole ring should bridge to, or `None` when the hole
2170/// does not overlap the ring at all.
2171///
2172/// This is the `earcut` hole-bridge search: cast a ray westward from the
2173/// hole's leftmost vertex, take the nearest boundary edge it crosses, then
2174/// refine over the vertices of that crossing's wedge to the one with the
2175/// minimum angle that is locally inside the boundary. The refinement is what
2176/// keeps the bridge segment from crossing the ring on concave boundaries.
2177fn find_hole_bridge(
2178    hole_leftmost: usize,
2179    ring_head: usize,
2180    nodes: &[EarClipNode],
2181) -> Option<usize> {
2182    let [hole_x, hole_y] = nodes[hole_leftmost].vertex;
2183
2184    // First pass: the nearest boundary edge to the west of the hole's
2185    // leftmost vertex. The candidate is that edge's endpoint with the lesser
2186    // x, the side the hole approaches from.
2187    let mut nearest_crossing_x = f64::NEG_INFINITY;
2188    let mut bridge_index: Option<usize> = None;
2189    let mut ring_node = ring_head;
2190    loop {
2191        let ring_next = nodes[ring_node].next_index;
2192        let ring_vertex = nodes[ring_node].vertex;
2193        let ring_next_vertex = nodes[ring_next].vertex;
2194        if hole_y <= ring_vertex[1]
2195            && hole_y >= ring_next_vertex[1]
2196            && ring_next_vertex[1] != ring_vertex[1]
2197        {
2198            let crossing_x = ring_vertex[0]
2199                + (hole_y - ring_vertex[1]) * (ring_next_vertex[0] - ring_vertex[0])
2200                    / (ring_next_vertex[1] - ring_vertex[1]);
2201            if crossing_x <= hole_x && crossing_x > nearest_crossing_x {
2202                nearest_crossing_x = crossing_x;
2203                bridge_index = Some(if ring_vertex[0] < ring_next_vertex[0] {
2204                    ring_node
2205                } else {
2206                    ring_next
2207                });
2208                if crossing_x == hole_x {
2209                    return bridge_index;
2210                }
2211            }
2212        }
2213        ring_node = ring_next;
2214        if ring_node == ring_head {
2215            break;
2216        }
2217    }
2218    let initial_bridge_index = bridge_index?;
2219    let initial_bridge_vertex = nodes[initial_bridge_index].vertex;
2220    let stop_index = initial_bridge_index;
2221    let mut minimum_tangent = f64::INFINITY;
2222    let mut ring_node = initial_bridge_index;
2223    loop {
2224        let ring_vertex = nodes[ring_node].vertex;
2225        if hole_x >= ring_vertex[0]
2226            && ring_vertex[0] >= initial_bridge_vertex[0]
2227            && hole_x != ring_vertex[0]
2228            && point_lies_within_earcut_triangle(
2229                [
2230                    if hole_y < initial_bridge_vertex[1] {
2231                        hole_x
2232                    } else {
2233                        nearest_crossing_x
2234                    },
2235                    hole_y,
2236                ],
2237                initial_bridge_vertex,
2238                [
2239                    if hole_y < initial_bridge_vertex[1] {
2240                        nearest_crossing_x
2241                    } else {
2242                        hole_x
2243                    },
2244                    hole_y,
2245                ],
2246                ring_vertex,
2247            )
2248        {
2249            let tangent = (hole_y - ring_vertex[1]).abs() / (hole_x - ring_vertex[0]);
2250            if node_locally_inside(nodes, ring_node, [hole_x, hole_y]) && tangent < minimum_tangent
2251            {
2252                minimum_tangent = tangent;
2253                bridge_index = Some(ring_node);
2254            }
2255        }
2256        ring_node = nodes[ring_node].next_index;
2257        if ring_node == stop_index {
2258            break;
2259        }
2260    }
2261    bridge_index
2262}

2264/// Earcut's point-in-triangle test, written in the winding convention the
2265/// bridge search assumes (outer rings positive).
2266fn point_lies_within_earcut_triangle(
2267    point: [f64; 2],
2268    first: [f64; 2],
2269    second: [f64; 2],
2270    third: [f64; 2],
2271) -> bool {
2272    (third[0] - point[0]) * (first[1] - point[1]) >= (first[0] - point[0]) * (third[1] - point[1])
2273        && (first[0] - point[0]) * (second[1] - point[1])
2274            >= (second[0] - point[0]) * (first[1] - point[1])
2275        && (second[0] - point[0]) * (third[1] - point[1])
2276            >= (third[0] - point[0]) * (second[1] - point[1])
2277}

2279/// Whether the boundary is locally inside at a ring node for a candidate
2280/// bridge endpoint point: for a convex vertex the point must sit between the
2281/// node's two boundary edges, for a reflex vertex outside both.
2282fn node_locally_inside(nodes: &[EarClipNode], node_index: usize, point: [f64; 2]) -> bool {
2283    let previous_vertex = nodes[nodes[node_index].previous_index].vertex;
2284    let vertex = nodes[node_index].vertex;
2285    let next_vertex = nodes[nodes[node_index].next_index].vertex;
2286    if triangle_doubled_signed_area(previous_vertex, vertex, next_vertex) > 0.0 {
2287        triangle_doubled_signed_area(vertex, point, next_vertex) <= 0.0
2288            && triangle_doubled_signed_area(vertex, previous_vertex, point) <= 0.0
2289    } else {
2290        triangle_doubled_signed_area(vertex, point, previous_vertex) > 0.0
2291            || triangle_doubled_signed_area(vertex, next_vertex, point) > 0.0
2292    }
2293}

2300/// Whether the node at `ear_index` is a valid ear: convex, and with no
2301/// reflex boundary vertex inside or on its triangle. Duplicate bridge
2302/// vertices are collinear slits, so the reflex-only containment filter keeps
2303/// them from blocking every ear next to a splice.
2304fn is_ear_node(nodes: &[EarClipNode], ear_index: usize) -> bool {
2305    let previous_index = nodes[ear_index].previous_index;
2306    let next_index = nodes[ear_index].next_index;
2307    let previous_vertex = nodes[previous_index].vertex;
2308    let vertex = nodes[ear_index].vertex;
2309    let next_vertex = nodes[next_index].vertex;
2310    if triangle_doubled_signed_area(previous_vertex, vertex, next_vertex) <= 0.0 {
2311        return false;
2312    }
2313    let minimum_x = previous_vertex[0].min(vertex[0]).min(next_vertex[0]);
2314    let maximum_x = previous_vertex[0].max(vertex[0]).max(next_vertex[0]);
2315    let minimum_y = previous_vertex[1].min(vertex[1]).min(next_vertex[1]);
2316    let maximum_y = previous_vertex[1].max(vertex[1]).max(next_vertex[1]);
2317    let mut point_index = nodes[next_index].next_index;
2318    while point_index != previous_index {
2319        let point = nodes[point_index].vertex;
2320        if point[0] >= minimum_x
2321            && point[0] <= maximum_x
2322            && point[1] >= minimum_y
2323            && point[1] <= maximum_y
2324            && point_lies_within_earcut_triangle(point, previous_vertex, vertex, next_vertex)
2325        {
2326            let point_previous_vertex = nodes[nodes[point_index].previous_index].vertex;
2327            let point_next_vertex = nodes[nodes[point_index].next_index].vertex;
2328            if triangle_doubled_signed_area(point_previous_vertex, point, point_next_vertex) <= 0.0
2329            {
2330                return false;
2331            }
2332        }
2333        point_index = nodes[point_index].next_index;
2334    }
2335    true
2336}

2339fn remove_ear_node(nodes: &mut [EarClipNode], node_index: usize) {

2341    let next_index = nodes[node_index].next_index;
2342    nodes[previous_index].next_index = next_index;
2343    nodes[next_index].previous_index = previous_index;

2346/// Ear-clip loops over the assembled node ring, emitting each ear's triangle
2347/// and relinking around it. The traversal advances past the removed ear like
2348/// `earcut`, so well-formed rings stay near linear. Stalls recover in the
2349/// `earcut` order: first drop duplicate and collinear nodes, then cure local
2350/// self-intersections, then split the ring at a valid diagonal and clip both
2351/// halves. A ring that still has no ear stops instead of spinning, leaving
2352/// that remainder unfilled.
2353fn ear_clip_nodes(nodes: &mut Vec<EarClipNode>, ring_head: usize) -> Vec<[[f64; 2]; 3]> {
2354    let mut triangles = Vec::new();
2355    let mut ear_index = ring_head;
2356    let mut stop_index = ring_head;
2357    let mut filtered_once = false;
2358    let mut cured_once = false;
2359    while nodes[ear_index].previous_index != nodes[ear_index].next_index {
2360        let previous_index = nodes[ear_index].previous_index;
2361        let next_index = nodes[ear_index].next_index;
2362        if is_ear_node(nodes, ear_index) {
2363            triangles.push([
2364                nodes[previous_index].vertex,
2365                nodes[ear_index].vertex,
2366                nodes[next_index].vertex,
2367            ]);
2368            remove_ear_node(nodes, ear_index);
2369            ear_index = nodes[next_index].next_index;
2370            stop_index = ear_index;
2371            continue;
2372        }
2373        ear_index = next_index;
2374        if ear_index == stop_index {
2375            if !filtered_once {
2376                filtered_once = true;
2377                if let Some(filtered_head) = filter_ring_nodes(nodes, ear_index) {
2378                    ear_index = filtered_head;
2379                    stop_index = filtered_head;
2380                    continue;
2381                }
2382            }
2383            if !cured_once {
2384                cured_once = true;
2385                let cured_head = cure_local_intersections(nodes, ear_index, &mut triangles);
2386                ear_index = cured_head;
2387                stop_index = cured_head;
2388                continue;
2389            }
2390            if let Some((first_head, second_head)) = split_ring_at_valid_diagonal(nodes, ear_index)
2391            {
2392                triangles.extend(ear_clip_nodes(nodes, first_head));
2393                triangles.extend(ear_clip_nodes(nodes, second_head));
2394                return triangles;
2395            }
2396            break;
2397        }
2398    }
2399    triangles
2400}

2402/// The ear clipper's last resort (`earcut`'s `splitEarcut`): find any pair of
2403/// non-adjacent ring nodes joined by a valid diagonal, split the ring there
2404/// into two smaller cycles, and return both cycle heads. Splitting strictly
2405/// shrinks each piece, so the recursive call always terminates.
2406fn split_ring_at_valid_diagonal(
2407    nodes: &mut Vec<EarClipNode>,
2408    start: usize,
2409) -> Option<(usize, usize)> {
2410    let mut first = start;
2411    loop {
2412        let mut second = nodes[nodes[first].next_index].next_index;
2413        while second != nodes[first].previous_index {
2414            if is_valid_diagonal(nodes, first, second) {
2415                let second_head = splice_hole_ring(first, second, nodes);
2416                return Some((first, second_head));
2417            }
2418            second = nodes[second].next_index;
2419        }
2420        first = nodes[first].next_index;
2421        if first == start {
2422            break;
2423        }
2424    }
2425    None
2426}

2428/// Whether the diagonal between two ring nodes is safe to split at: the nodes
2429/// are non-adjacent, both ends are locally inside, the diagonal's midpoint is
2430/// inside the ring, it crosses no boundary edge, and it does not create
2431/// opposite-facing sectors (`earcut`'s `isValidDiagonal`).
2432fn is_valid_diagonal(nodes: &[EarClipNode], first: usize, second: usize) -> bool {
2433    let first_previous = nodes[first].previous_index;
2434    let first_next = nodes[first].next_index;
2435    let second_previous = nodes[second].previous_index;
2436    let second_next = nodes[second].next_index;
2437    first_next != second
2438        && first_previous != second
2439        && !diagonal_intersects_ring(nodes, first, second)
2440        && node_locally_inside_node(nodes, first, second)
2441        && node_locally_inside_node(nodes, second, first)
2442        && diagonal_middle_inside(nodes, first, second)
2443        && (triangle_doubled_signed_area(
2444            nodes[first_previous].vertex,
2445            nodes[first].vertex,
2446            nodes[second_previous].vertex,
2447        ) != 0.0
2448            || triangle_doubled_signed_area(
2449                nodes[first].vertex,
2450                nodes[second_previous].vertex,
2451                nodes[second].vertex,
2452            ) != 0.0
2453            || (nodes[first].vertex == nodes[second].vertex
2454                && triangle_doubled_signed_area(
2455                    nodes[first_previous].vertex,
2456                    nodes[first].vertex,
2457                    nodes[first_next].vertex,

2459                && triangle_doubled_signed_area(

2493/// Whether a candidate split diagonal's midpoint lies inside the ring
2494/// (even-odd ray cast; `earcut`'s `middleInside`).
2495fn diagonal_middle_inside(nodes: &[EarClipNode], first: usize, second: usize) -> bool {
2496    let midpoint = [
2497        (nodes[first].vertex[0] + nodes[second].vertex[0]) * 0.5,
2498        (nodes[first].vertex[1] + nodes[second].vertex[1]) * 0.5,
2499    ];
2500    let mut inside = false;
2501    let mut node = first;
2502    loop {
2503        let next = nodes[node].next_index;
2504        let current_vertex = nodes[node].vertex;
2505        let next_vertex = nodes[next].vertex;
2506        if (current_vertex[1] > midpoint[1]) != (next_vertex[1] > midpoint[1])
2507            && next_vertex[1] != current_vertex[1]
2508        {
2509            let boundary_x = (next_vertex[0] - current_vertex[0])
2510                * (midpoint[1] - current_vertex[1])
2511                / (next_vertex[1] - current_vertex[1])
2512                + current_vertex[0];
2513            if midpoint[0] < boundary_x {
2514                inside = !inside;
2515            }
2516        }
2517        node = next;
2518        if node == first {
2519            break;
2520        }
2521    }

2525/// The ear clipper's stall recovery: removes ring nodes that duplicate their
2526/// next node or are collinear with both neighbors, so the retried scan walks
2527/// a simpler boundary. Returns the head to resume from, or `None` when
2528/// nothing was removable.
2529fn filter_ring_nodes(nodes: &mut [EarClipNode], ring_head: usize) -> Option<usize> {
2530    let mut removed_any = false;
2531    let mut head = ring_head;
2532    loop {
2533        // Snapshot the current cycle so removal never invalidates the walk.
2534        let mut cycle_nodes = Vec::new();
2535        let mut node = head;
2536        loop {
2537            cycle_nodes.push(node);
2538            node = nodes[node].next_index;
2539            if node == head {
2540                break;
2541            }
2542        }
2543        if cycle_nodes.len() <= 3 {
2544            break;
2545        }
2546        let mut removable_node = None;
2547        for &candidate in &cycle_nodes {
2548            let previous_vertex = nodes[nodes[candidate].previous_index].vertex;
2549            let vertex = nodes[candidate].vertex;
2550            let next_vertex = nodes[nodes[candidate].next_index].vertex;
2551            let is_duplicate = vertex == next_vertex;
2552            let longer_edge_squared = (vertex[0] - previous_vertex[0])
2553                .hypot(vertex[1] - previous_vertex[1])
2554                .max((next_vertex[0] - vertex[0]).hypot(next_vertex[1] - vertex[1]))
2555                .powi(2);
2556            let is_collinear = triangle_doubled_signed_area(previous_vertex, vertex, next_vertex)
2557                .abs()
2558                <= EAR_CLIPPING_COLLINEAR_RELATIVE_TOLERANCE * longer_edge_squared;
2559            if is_duplicate || is_collinear {
2560                removable_node = Some(candidate);
2561                break;
2562            }
2563        }
2564        let Some(candidate) = removable_node else {
2565            break;
2566        };
2567        remove_ear_node(nodes, candidate);
2568        removed_any = true;
2569        if candidate == head {
2570            head = nodes[candidate].next_index;
2571        }
2572    }
2573    removed_any.then_some(head)
2574}

2576/// The ear clipper's second stall recovery (`earcut`'s
2577/// `cureLocalIntersections`): when two adjacent boundary edges cross, the
2578/// small triangle they form is emitted directly and the two crossing nodes
2579/// are removed, untangling a locally self-intersecting boundary (common in
2580/// real tile data where a hole touches its exterior at a vertex). Returns the
2581/// head to resume clipping from, after a final collinearity filter.
2582fn cure_local_intersections(
2583    nodes: &mut [EarClipNode],
2584    start: usize,
2585    triangles: &mut Vec<[[f64; 2]; 3]>,
2586) -> usize {
2587    let mut node = start;
2588    let mut head = start;
2589    loop {
2590        let previous_index = nodes[node].previous_index;
2591        let next_index = nodes[node].next_index;
2592        let after_next_index = nodes[next_index].next_index;
2593        if nodes[previous_index].vertex != nodes[after_next_index].vertex
2594            && segments_intersect(
2595                nodes[previous_index].vertex,
2596                nodes[node].vertex,
2597                nodes[next_index].vertex,
2598                nodes[after_next_index].vertex,
2599            )
2600            && node_locally_inside_node(nodes, previous_index, after_next_index)
2601            && node_locally_inside_node(nodes, after_next_index, previous_index)
2602        {
2603            triangles.push([
2604                nodes[previous_index].vertex,
2605                nodes[node].vertex,
2606                nodes[next_index].vertex,
2607            ]);
2608            remove_ear_node(nodes, node);
2609            remove_ear_node(nodes, next_index);
2610            node = after_next_index;
2611            head = after_next_index;
2612        }
2613        node = nodes[node].next_index;
2614        if node == head {
2615            break;
2616        }
2617    }
2618    filter_ring_nodes(nodes, node).unwrap_or(node)
2619}

2642/// Whether two closed segments intersect, including touching and collinear
2643/// overlaps (the `earcut` `intersects` test the local-intersection cure
2644/// relies on).
2645fn segments_intersect(
2646    first_start: [f64; 2],
2647    first_end: [f64; 2],
2648    second_start: [f64; 2],
2649    second_end: [f64; 2],
2650) -> bool {
2651    let first_orientation = sign_of(triangle_doubled_signed_area(
2652        first_start,
2653        first_end,
2654        second_start,
2655    ));
2656    let second_orientation = sign_of(triangle_doubled_signed_area(
2657        first_start,
2658        first_end,
2659        second_end,
2660    ));
2661    let third_orientation = sign_of(triangle_doubled_signed_area(
2662        second_start,
2663        second_end,
2664        first_start,
2665    ));
2666    let fourth_orientation = sign_of(triangle_doubled_signed_area(
2667        second_start,
2668        second_end,
2669        first_end,
2670    ));
2671    if first_orientation != second_orientation && third_orientation != fourth_orientation {
2672        return true;
2673    }
2674    (first_orientation == 0 && point_lies_on_segment(second_start, first_start, first_end))
2675        || (second_orientation == 0 && point_lies_on_segment(second_end, first_start, first_end))
2676        || (third_orientation == 0 && point_lies_on_segment(first_start, second_start, second_end))
2677        || (fourth_orientation == 0 && point_lies_on_segment(first_end, second_start, second_end))
2678}

3079    /// Whether a screen-space triangle contains a point (boundary inclusive).
3080    fn screen_triangle_contains_point(triangle: [[f64; 2]; 3], point: [f64; 2]) -> bool {
3081        let edge_side = |start: [f64; 2], end: [f64; 2]| {
3082            (end[0] - start[0]) * (point[1] - start[1])
3083                - (end[1] - start[1]) * (point[0] - start[0])
3084        };
3085        let sides = [
3086            edge_side(triangle[0], triangle[1]),
3087            edge_side(triangle[1], triangle[2]),
3088            edge_side(triangle[2], triangle[0]),
3089        ];
3090        !(sides.iter().any(|side| *side < 0.0) && sides.iter().any(|side| *side > 0.0))
3091    }

3395    /// Point-in-triangle test on the display's pixel axes; orientation does
3396    /// not matter because the barycentric signs are compared as a set.
3397    fn screen_point_in_triangle(screen_point: [f64; 2], corners: [[f64; 2]; 3]) -> bool {
3398        let edge_signs: Vec<f64> = (0..3)
3399            .map(|edge_index| {
3400                let start = corners[edge_index];
3401                let end = corners[(edge_index + 1) % 3];
3402                (end[0] - start[0]) * (screen_point[1] - start[1])
3403                    - (end[1] - start[1]) * (screen_point[0] - start[0])
3404            })
3405            .collect();
3406        let has_negative = edge_signs
3407            .iter()
3408            .any(|sign| *sign < -SCREEN_PIXEL_TOLERANCE);
3409        let has_positive = edge_signs.iter().any(|sign| *sign > SCREEN_PIXEL_TOLERANCE);
3410        !(has_negative && has_positive)
3411    }

3428    /// Screen-pixel tolerance of the world-space parity assertions: the frame
3429    /// uniform crosses to the GPU as `f32`, while the CPU assembly keeps
3430    /// `f64` through its projection, so a sub-hundredth of a pixel is expected
3431    /// and a whole pixel would be a real drift.
3432    const WORLD_SPACE_SCREEN_TOLERANCE_PIXELS: f64 = 0.05;
3433
3434    /// Reimplements the world-space overlay vertex shader in `f64` for the
3435    /// parity tests: the same mode dispatch and world-copy window discard,
3436    /// evaluated against the same frame uniform the GPU receives. Returns the
3437    /// final screen position, or `None` when the vertex's world copy is not
3438    /// the camera's own (the shader's fragment discard).
3439    fn world_space_vertex_screen(
3440        uniforms: &WorldSpaceOverlayFrameUniforms,
3441        vertex: &WorldSpaceOverlayVertex,
3442        copy_offset: f64,
3443    ) -> Option<[f64; 2]> {
3444        let origin_relative = [
3445            f64::from(uniforms.origin_relative_normalized[0]),
3446            f64::from(uniforms.origin_relative_normalized[1]),
3447        ];
3448        let window_relative_x =
3449            origin_relative[0] + f64::from(vertex.world_position[0]) - copy_offset;
3450        if !(-0.5..0.5).contains(&window_relative_x) {
3451            return None;
3452        }
3453        let world_to_clip = |position: [f32; 2]| {
3454            let relative = [
3455                origin_relative[0] + f64::from(position[0]) - copy_offset,
3456                origin_relative[1] - f64::from(position[1]),
3457            ];
3458            let mut clip_position = [0.0_f64; 4];
3459            for (row, component) in clip_position.iter_mut().enumerate() {
3460                *component = f64::from(uniforms.anchor_clip_position[row])
3461                    + f64::from(uniforms.relative_view_projection[0][row]) * relative[0]
3462                    + f64::from(uniforms.relative_view_projection[1][row]) * relative[1];
3463            }
3464            clip_position
3465        };
3466        let clip_to_screen = |clip_position: [f64; 4]| {
3467            let normalized_device = [
3468                clip_position[0] / clip_position[3],
3469                clip_position[1] / clip_position[3],
3470            ];
3471            [
3472                (normalized_device[0] + 1.0) * 0.5 * f64::from(uniforms.viewport_size_pixels[0]),
3473                (1.0 - (normalized_device[1] + 1.0) * 0.5)
3474                    * f64::from(uniforms.viewport_size_pixels[1]),
3475            ]
3476        };
3477        match vertex.shape_kind {
3478            0 => Some(clip_to_screen(world_to_clip(vertex.world_position))),
3479            1 => {
3480                let anchor_clip_position = world_to_clip(vertex.world_position);
3481                if anchor_clip_position[3] <= 0.0 {
3482                    return None;
3483                }
3484                let anchor_screen = clip_to_screen(anchor_clip_position);
3485                Some([
3486                    anchor_screen[0] + f64::from(vertex.shape_parameters[0]),
3487                    anchor_screen[1] + f64::from(vertex.shape_parameters[1]),
3488                ])
3489            }
3490            2 => {
3491                let self_clip_position = world_to_clip(vertex.world_position);
3492                let other_clip_position = world_to_clip(vertex.reference_position);
3493                if self_clip_position[3] <= 0.0 || other_clip_position[3] <= 0.0 {
3494                    return None;
3495                }
3496                let self_screen = clip_to_screen(self_clip_position);
3497                let other_screen = clip_to_screen(other_clip_position);
3498                let direction = [
3499                    (other_screen[0] - self_screen[0]) * f64::from(vertex.shape_parameters[0]),
3500                    (other_screen[1] - self_screen[1]) * f64::from(vertex.shape_parameters[0]),
3501                ];
3502                let direction_length = direction[0].hypot(direction[1]);
3503                if direction_length < super::MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS {
3504                    return None;
3505                }
3506                let perpendicular = [
3507                    -direction[1] / direction_length,
3508                    direction[0] / direction_length,
3509                ];
3510                Some([
3511                    self_screen[0] + perpendicular[0] * f64::from(vertex.shape_parameters[1]),
3512                    self_screen[1] + perpendicular[1] * f64::from(vertex.shape_parameters[1]),
3513                ])
3514            }
3515            3 => {
3516                let previous_clip_position = world_to_clip(vertex.reference_position);
3517                let vertex_clip_position = world_to_clip(vertex.world_position);
3518                let next_clip_position = world_to_clip(vertex.next_position);
3519                if previous_clip_position[3] <= 0.0
3520                    || vertex_clip_position[3] <= 0.0
3521                    || next_clip_position[3] <= 0.0
3522                {
3523                    return None;
3524                }
3525                let previous_screen = clip_to_screen(previous_clip_position);
3526                let vertex_screen = clip_to_screen(vertex_clip_position);
3527                let next_screen = clip_to_screen(next_clip_position);
3528                let incoming = [
3529                    vertex_screen[0] - previous_screen[0],
3530                    vertex_screen[1] - previous_screen[1],
3531                ];
3532                let outgoing = [
3533                    next_screen[0] - vertex_screen[0],
3534                    next_screen[1] - vertex_screen[1],
3535                ];
3536                let incoming_length = incoming[0].hypot(incoming[1]);
3537                let outgoing_length = outgoing[0].hypot(outgoing[1]);
3538                if incoming_length < super::MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS
3539                    || outgoing_length < super::MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS
3540                {
3541                    return None;
3542                }
3543                let incoming_unit = [incoming[0] / incoming_length, incoming[1] / incoming_length];
3544                let outgoing_unit = [outgoing[0] / outgoing_length, outgoing[1] / outgoing_length];
3545                let direction_sum = [
3546                    incoming_unit[0] + outgoing_unit[0],
3547                    incoming_unit[1] + outgoing_unit[1],
3548                ];
3549                let direction_sum_length = direction_sum[0].hypot(direction_sum[1]);
3550                let bisector =
3551                    if direction_sum_length < super::MINIMUM_VISIBLE_SEGMENT_LENGTH_PIXELS {
3552                        [-incoming_unit[1], incoming_unit[0]]
3553                    } else {
3554                        [
3555                            direction_sum[0] / direction_sum_length,
3556                            direction_sum[1] / direction_sum_length,
3557                        ]
3558                    };
3559                let perpendicular = [-bisector[1], bisector[0]];
3560                Some([
3561                    vertex_screen[0]
3562                        + bisector[0] * f64::from(vertex.shape_parameters[0])
3563                        + perpendicular[0] * f64::from(vertex.shape_parameters[1]),
3564                    vertex_screen[1]
3565                        + bisector[1] * f64::from(vertex.shape_parameters[0])
3566                        + perpendicular[1] * f64::from(vertex.shape_parameters[1]),
3567                ])
3568            }
3569            _ => None,
3570        }
3571    }
