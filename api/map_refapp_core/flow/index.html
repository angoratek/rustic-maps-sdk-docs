Module flow 

Source
Expand description

The reference-application flow vocabulary and reducer.

The reducer is a total pure function:

use map_refapp_core::{FlowEvent, FlowState, advance_flow};
let transition = advance_flow(FlowState::HomePeek, FlowEvent::StartTrip);
assert_eq!(transition.state, FlowState::Navigating);

It answers one question: given the flow state and an event, what should the user see next? It does not own the SDK handle, the route record, the camera pose, the credential store, the speech engine or the view lifecycle. Every event from every state returns either a new state or an explicit unchanged transition, whose FlowTransition::unchanged flag is true.

Settings and diagnostics are overlays, not flow positions. Their events leave the flow state untouched and report the overlay outcome, because opening either surface never moves the visitor within the plan or navigation flow. FlowState::ProviderSettings and FlowState::Diagnostics therefore stay in the vocabulary for a platform’s own overlay model, but advance_flow never returns them.
