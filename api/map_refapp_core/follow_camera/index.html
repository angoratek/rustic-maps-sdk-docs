Expand description

The navigation follow-camera state machine.

While a guided trip runs the camera holds a fixed deep zoom, centres on the guided fix and eases its bearing toward a median-smoothed course-over-ground. A user gesture breaks follow immediately; a later fix re-targets the state but does not snap the visitor’s panned view back. The my-location control re-engages explicitly. The pre-trip camera is captured at trip start and restored at trip end.
