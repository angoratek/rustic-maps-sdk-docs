Module location_animation 

Source
Expand description

The location puck’s interpolation between fixes.

A shell hands the renderer one fix at a time; drawn as-is, the position disc hops the distance between fixes and the accuracy ring jumps with it. This module eases the drawn pose from the previous fix to the new one over the fix interval, retargets when a fix lands mid-flight, and takes the shorter arc for the course, so the puck glides instead of hopping.

The animator holds no clock: the caller passes the time in, exactly like the easing primitives beside it, so a test drives it deterministically and every platform’s frame pump reads the same math.
