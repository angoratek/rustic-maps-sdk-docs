Pure behavior math and the flow-state reducer shared by the reference applications.

The crate is deliberately small and self-contained: it holds no SDK handle, no clock, no input/output, no logger and no platform dependency. Every public item exchanges primitives and crate-local enums only, so the same source compiles for native targets and for WebAssembly.

The crate answers the one question the four reference applications must answer identically (see docs/design/ReferenceApplicationBehavior.md): given the current flow state and an event, what should the user see next? The follow-camera state machine, the circular course median, the easing primitives, the scale-bar ladder and the recorded-trace cursor sit beside that reducer so each platform calls shared math instead of keeping a mirror. Views, gestures, timers, credentials, speech engines and lifecycle stay in the platform shells.
