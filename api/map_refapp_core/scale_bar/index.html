Module scale_bar 

Source
Expand description

The scale bar’s clean-distance ladder.

From the camera’s ground-meters-per-screen-pixel answer the bar selects the largest ladder distance whose physical width does not exceed the token maximum, provided that width also reaches the token minimum. The ladder is the conventional 1-2-3-5-10 sequence per decade.
