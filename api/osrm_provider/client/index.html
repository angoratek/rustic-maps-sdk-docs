osrm_provider

Module client 

Source
Expand description

Configuration and the HTTP facade shared by OSRM endpoint implementations.

Unlike a credentialed commercial platform, OSRM is addressed by its deployment URL and needs no key, so this client carries no credential injection and no rate limiter: it holds one base URL and one user agent, performs idempotent GETs through provider_transport, and hands each response to crate::error_mapping::interpret_json_response.
