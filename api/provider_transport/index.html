The provider HTTP transport seam (round 19, M13): one request/response vocabulary and one HttpTransport contract that provider crates use on every target. Native targets get the reqwest implementation; the browser gets a fetch implementation, so the same provider request, parsing and error-mapping code runs in both places.

The seam deliberately exchanges plain owned bytes and strings — no provider crate ever names a platform HTTP type.
