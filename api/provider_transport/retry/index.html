Module retry 

Source
Expand description

One bounded-retry helper for idempotent GETs, shared by every provider crate.

Providers keep their own status-to-SDKError mapping (the statuses are vendor vocabulary); this module supplies the retry loop, the transient classification and the back-off schedule. Only idempotent GETs may use it — a POST may already have been processed when a retry fires.
