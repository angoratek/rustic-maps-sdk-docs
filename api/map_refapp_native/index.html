Refapp-only UniFFI bindings over the shared reference-application math.

The Kotlin and Swift reference applications call the same follow-camera, course-median, easing, scale-bar and trace-cursor values instead of keeping per-platform mirrors. Every member delegates to [map_refapp_core]; this crate only lowers the shared types across the UniFFI boundary.

The crate is deliberately outside every published package: it is not a dependency of rustic-maps-native-core, and scripts/build-android.sh and scripts/build-ios.sh assert that the AAR and the XCFramework file sets do not carry it.

§Re-entrancy and threading

The UniFFI scaffolding calls every interface method through &self, while the shared state transitions need &mut self. Each wrapper therefore holds its delegate behind a mutex and releases the lock before returning, so a call can never hold two wrappers’ locks at once. The methods are synchronous and never await while a lock is held.
