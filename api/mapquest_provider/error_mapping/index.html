Module error_mapping

Expand description

Mapping between MapQuest service signals and the SDK error model.

Two distinct failure channels exist for MapQuest web services and both are handled here:

  1. Transport-level failures carried in the HTTP status (for example HTTP 401 for a rejected API key).
  2. Application-level failures where the platform replies with HTTP 200 but info.statuscode is non-zero together with human-readable info.messages (verified against the live Directions API, which returns this shape for invalid coordinates).
