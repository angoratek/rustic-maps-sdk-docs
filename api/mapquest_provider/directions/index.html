map_turn_type_to_maneuver_type
Maps the documented Directions API turnType enumeration (developer.mapquest.com/documentation/directions/route/) onto ManeuverType. -1 (documented arrival marker) maps to ManeuverType::Arrival.
parse_matrix_payload
Parses the route matrix reply: distance and time are flat row-major arrays over the concatenated origin+destination location list, distances in the requested unit. Unroutable cells arrive as null and are skipped.
parse_route_payload
Parses a documented route payload into a RouteData, converting the unit-dependent distances into meters and splitting the shared shape by shape.maneuverIndexes.
