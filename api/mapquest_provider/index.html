Crate mapquest_provider 

Source
Expand description

MapQuest implementations of every contract in geospatial_traits supported by the documented MapQuest platform (developer.mapquest.com/documentation/):

  • Directions API v2: route + route matrix (directions)
  • Geocoding API v1: address + reverse (geocoding)
  • Search Ahead API v3: prediction (search)
  • Traffic API v2: incidents (traffic) + JSON flow (traffic_flow)
  • Tiles API: raster tiles (tiles)

The Elevation API is retired (absent from the current documentation), so geospatial_traits::ElevationProvider has no MapQuest implementation and its registry slot stays unconfigured; see PLAN.md M1.

All calls share one rate-limited HTTP client (client) with key injection, bounded idempotent-GET retries and the info.statuscode -> [SDKError] mapping (error_mapping).
