Photon implementation of geospatial_traits::SearchPlaceProvider and geospatial_traits::GeocodingProvider.

Photon is an open geocoder that answers forward queries, completion candidates and reverse lookups without a credential. It is reached by its deployment URL: the public instance by default, or any self-hosted one through PhotonProviderConfiguration. Every request goes through the shared provider_transport seam (client) with bounded idempotent-GET retries, so the same request, parsing and error-mapping code runs natively and in browsers.

§Result mapping

Photon answers with a GeoJSON FeatureCollection. Each feature’s point becomes a geospatial_types::PlaceResult:

  • the display line is the feature’s name when Photon published one, otherwise the address components (housenumber street, postcode city, state, country) joined with commas;
  • the feature’s type (house, street, locality, district, city, county, state, country, postcode) maps onto the SDK’s geospatial_types::place::GeocodeQuality scale, with anything else reported as a point.

Autocomplete asks for five candidates (the reference applications’ row count) and a settled search for ten. A search boundary becomes Photon’s bbox filter.
