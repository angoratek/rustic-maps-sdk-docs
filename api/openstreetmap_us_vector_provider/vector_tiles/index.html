Constants§

OSMUS_SOURDOUGH_ATTRIBUTION_TEXT
Human-readable attribution line the usage policy requires wherever the imagery is shown. The policy’s example reads Tiles by OSM US © OpenStreetMap and the displayed parts must link to https://tiles.openstreetmap.us and https://www.openstreetmap.org/copyright respectively; rendering surfaces translate this line into their own linked markup.
OSMUS_TILESERVICE_BASE_URL
Public base URL of the OpenStreetMap US tileservice.
OSMUS_TILESERVICE_USAGE_POLICY_URL
Usage-policy document every integrator must comply with.
OSMUS_USER_AGENT_TEXT_PREFIX
Prefix of the identifying User-Agent the usage policy requires. The configuration appends an integrator-provided contact; spoofing the client identity is explicitly forbidden.
OSMUS_VECTOR_TILESETS_PAGE_URL
Vector tileset listing page the tilesets are documented on.
OSMUS_VECTOR_TILE_CACHE_CEILING_SECONDS
The imagery-caching ceiling this provider installs: 30 calendar days, the common maximum under imagery-provider terms (PRD §6.7, owner ruling 2026-10-28) and the same ceiling the MapQuest raster path inherits. The usage policy separately requires honoring Cache-Control response headers; a live probe (2026-10-29) observed Cache-Control: public, max-age=86400 — an 86400-second per-response tightening is a refinement the decoder slice may take, while this 30-day value remains the SDK’s terms ceiling, enforced by this crate’s lockstep test against map_cache::ResponseCategory::VectorTiles.
SOURDOUGH_MAXIMUM_ZOOM_LEVEL
Zoom ceiling from the Sourdough TileJSON maxzoom (fetched 2026-10-29).
SOURDOUGH_MINIMUM_ZOOM_LEVEL
Zoom floor from the Sourdough TileJSON minzoom (fetched 2026-10-29).
SOURDOUGH_SCHEMA_DOCUMENTATION_URL
Sourdough schema documentation (the schema mirrors OSM tagging).
SOURDOUGH_TILEJSON_URL
TileJSON address of the Sourdough tileset this provider serves.
SOURDOUGH_TILESET_SOURCE_NAME

SOURDOUGH_TILE_FILE_EXTENSION

SOURDOUGH_TILE_PATH_ROOT

SOURDOUGH_URL_TEMPLATE
Sourdough tile URL template, verbatim from the TileJSON tiles array (fetched 2026-10-29).
