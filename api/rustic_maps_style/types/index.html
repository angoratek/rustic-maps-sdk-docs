Source
Expand description

The value model the expression engine evaluates and the property abstraction a style layer stores.

Value mirrors the JSON value types an expression can produce, plus a resolved Color. Property is either a constant of the property’s type or an expression that produces one; a constant never enters the evaluator, so a style layer’s paint constants stay as cheap to read as the renderer’s existing paint fields.
