Compilation of a parsed style document into render plans.

compile_style_document walks a MapStyleDocument once and produces a CompiledStyle: the document order is fixed, every layer’s zoom span is resolved to a pair of numbers, each layer’s paint and layout properties are carried as Property values (a constant or an expression), and the filter stays an [Expression] tree. Nothing is re-parsed per feature or per frame: a caller evaluates the plan with CompiledLayer::resolved_paint, [CompiledLayer::resolved_filter] and CompiledLayer::resolved_symbol_layout at the frame’s zoom and the feature’s properties.

§Ordering

CompiledLayer::order_index is the layer’s position among the compiled render layers, zero based and stable for a given document. A renderer uses it as the global paint order key: every tile’s layer 0 paints before every tile’s layer 1, so one tile’s fill can never overpaint another tile’s earlier line.

§Background

A background layer is the canvas clear colour, not a spatial layer, so the compiler folds it into CompiledStyle::background and does not give it an order index. The last background layer in document order wins, matching the painter’s model where a later background paints over an earlier one.

§Degradation

A property that fails at evaluation time resolves to its documented default from crate::defaults; a layer type this crate does not render compiles to CompiledLayerKind::Other with CompiledPaint::None rather than failing the whole document. CompiledStyle::unsupported carries the document’s diagnostics so a caller can report exactly what was skipped.
