The source layer name the layer reads.

§minimum_zoom: f64

The lowest zoom (inclusive) the layer draws at.

§maximum_zoom: f64

The zoom (exclusive) the layer stops drawing at.

§order_index: usize

The global paint order key: every layer with a lower index paints before every layer with a higher one, across all tiles.

§filter: Option<Expression>

The layer’s filter, evaluated per feature with the frame zoom in the context (zoom-gated filters such as per-class minimum zooms are data expressions whose step input is ["zoom"]).

§paint: CompiledPaint

The kind-specific paint plan.

§layout: CompiledLayout

The layer’s layout plan.

§declares_line_presentation: bool

Whether the document’s layer declares any line presentation property (line-cap, line-join, line-dasharray, line-offset, line-gap-width or line-blur).

A renderer uses this to choose between the default stroke and the styled one: a layer that declares nothing keeps the renderer’s default geometry, an explicit declaration is honoured exactly.

§declares_circle_pitch: bool

Whether the document’s layer declares a circle pitch property (circle-pitch-scale or circle-pitch-alignment).

A renderer that has no ground-plane geometry for an omitted property can use this to keep its own documented default for a layer that asks for nothing, while honouring an explicit request.

§declares_text_max_angle: bool

Whether the document’s layer declares text-max-angle.

A renderer whose default run tolerance differs from the specification’s can keep its own default for a layer that asks for nothing while honouring an explicit request.

§declares_symbol_spacing: bool

Whether the document’s layer declares symbol-spacing.

A renderer whose default repeat distance differs from the specification’s (a single-tile frame names a road more often) can use this to keep its own default for a layer that asks for nothing.

pub fn matches_filter(&self, context: &EvaluationContext<'_>) -> bool

Whether a feature passes the layer’s filter.

A missing filter admits every feature. A filter that evaluates to a non-boolean value or fails at runtime rejects the feature rather than painting something the style did not ask for.

pub fn resolved_symbol_layout( &self, context: &EvaluationContext<'_>, ) -> ResolvedSymbolLayout

The layer’s symbol layout resolved against one feature.

The text field is evaluated against the feature; the size and placement values are camera properties and may vary with context.zoom. A layer that omits the text field resolves to the empty string, which the label pass treats as “no label”.
