Module document 

Source
Expand description

The version-8 MapLibre style document model.

A document holds the root properties, the source declarations and the ordered layer list. Layers carry a typed layout and paint struct whose fields are Property values: a constant, or an expression resolved per feature at the frame zoom.

The parser deliberately degrades instead of rejecting an entire document for one property it does not apply. Unknown and unimplemented properties are collected in MapStyleDocument::unsupported with their layer or source id, so a caller can report exactly what was skipped and a single unsupported property can never blank the base map. Structural problems — a missing id, an invalid filter, a malformed expression — are errors.
