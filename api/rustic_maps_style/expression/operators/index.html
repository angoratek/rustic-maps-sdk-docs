Module operators

Expand description

Value coercion, comparison and collection helpers shared by the expression evaluator and the filter normaliser.

Coercion follows the specification rather than Rust’s PartialEq: numbers compare numerically, strings lexically, and a mixed number/string comparison is false unless a conversion operator produced one of the values.
