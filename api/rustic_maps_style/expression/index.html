Module expression 

Source
Expand description

The typed expression tree, its parser and its static analysis.

The parser accepts the specification’s array form and, through the legacy-function normaliser, the deprecated {stops, type, base, property, default} object form. Both normalize into the same tree, so evaluation has one path.

Parsing validates the rules that do not depend on runtime data: operator arity, numeric and strictly ascending interpolation stops, and the rule that ["zoom"] may only be the direct input of a top-level step or interpolate. Expression::analysis classifies an expression as constant, camera-driven, data-driven or both, so a caller can reject a data-driven property where the specification forbids one before it is ever evaluated.
