Expand description

Interpolation curves for the interpolate expression.

Inputs are the numeric stop positions; outputs are numbers or colours. The exponential curve is the specification’s (base^(z - z0) - 1) / (base^(z1 - z0) - 1); a base of exactly one is linear. The cubic-bezier curve solves its x component for the normalized position and evaluates its y component, so a style can bend the response between two stops without changing the stop values.
