Struct ProviderRegistry 

Source 
pub struct ProviderRegistry { /* private fields */ }
Expand description

Registry of provider implementations keyed by contract, not by vendor.

Slots default to unconfigured; feature crates resolve with [ProviderRegistry::require_*] and surface [SDKError::ProviderNotConfigured] when the integrator skipped a provider.
