Struct OfflineFallbackRoutingProvider 

Source 
pub struct OfflineFallbackRoutingProvider { /* private fields */ }
Expand description

Wraps a primary routing provider with an offline retry: on a primary failure for a multi-waypoint request, each consecutive waypoint pair is calculated over the loaded offline graph and the per-pair answers are joined into one route (one leg per pair, summed distance and duration, the union bounding box).

Behavioral guarantees:

  • a successful primary response is returned untouched, and the offline provider is never consulted;
  • a request with fewer than [MINIMUM_ROUTE_WAYPOINT_COUNT] waypoints has no offline point-to-point equivalent, so the request is rejected without any fallback attempt;
  • if the offline retry fails too, the offline failure is logged and returned — it describes what actually failed last, and the caller has already seen the primary failure surface the same way.
