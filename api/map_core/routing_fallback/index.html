Module routing_fallback 

Source
Expand description

Route-calculation fallback seam: a [RoutingProvider] wrapper that retries a failed primary (online) request over a configured [OfflineRoutingProvider], joining the per-leg answers into one RouteData.

Policy placement follows the navigation reducer’s contract: route requests live at the integrator/event-source layer, so the fallback is a plain provider implementation registered into the registry’s routing slot (ProviderRegistry::register_routing_provider) — navigation and the FFI layer see an ordinary [RoutingProvider] and need no new contract surface.

Structs§

OfflineFallbackRoutingProvider
Wraps a primary routing provider with an offline retry: on a primary failure for a multi-waypoint request, each consecutive waypoint pair is calculated over the loaded offline graph and the per-pair answers are joined into one route (one leg per pair, summed distance and duration, the union bounding box).
