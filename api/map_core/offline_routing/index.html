The consumption path of compiled OfflineRoutingNetworkGraph archives: the in-repo OfflineRoutingProvider implementation.

The provider loads a compiled archive (memory-mapped file on native or in-memory bytes — both validated by the same typed reader in map-offline-graph-compiler::archive), keeps the validated graph plus a prebuilt half-edge adjacency and the turn-restriction rules, and answers route calculations over it with A* under a haversine heuristic (the M7 engine of PRD.md §4.6).

This module is compiled only for native targets: the browser path still consumes the archive from in-memory bytes and is the remaining M7 wasm-slice work, so the whole implementation is cfg-gated out of the wasm32 build (the compiler crate is outside the wasm closure).

§Honest scope of this slice

  • Routing covers automobile travel only: the archive profile is the minimal drivable-ways profile, so a RouteOptions request for another mode is rejected instead of being answered dishonestly.
  • The cost weight follows RouteOptions::route_strategy (Fastest = graph edge durations, Shortest = graph edge distances); edge speeds and the packed road classes come out of each edge record.
  • Route steps are graph-metadata maneuvers: besides the road-class/ speed runs, a step boundary occurs at every junction whose derived turn — the signed bearing change between the two route edges measured on their real geometry — leaves the straight band, and the step then carries a Turn maneuver from the SDK’s shared TurnDirection vocabulary (the same enum the reducer, instruction emitter and FFI labels speak; no competing classification is invented here). The archive carries no street names, so step texts stay name-free and true to the geometry ("Turn right", "U-turn"); a class/speed change without a turn stays a Continue step. The per-turn-restriction instruction strings remain restriction records — they describe forbidden turns, which a route by construction never traverses — and are not step content. Derived from adjacent graph-edge bearings, a strongly curved way yields a step per junction: the honest answer of the minimal schema (the accepted PRD §4.6 richness trade-off); no maneuver is invented beyond the bearing the graph itself records.
  • The turn-restriction approximation follows the classic caveat of a node-keyed A*: a restriction applies against the settled path’s incoming edge, which is exact unless a node can be reached on several best-cost paths through differently-restricted incoming edges (over-restrictive rather than understating).

§Runtime rules

load_offline_graph performs its mmap/read/validate work synchronously inside the async method — short-lived, with no await points, so no lock or I/O ever crosses an await. calculate_offline_route is pure computation over the loaded graph. A load fully validates the new source and only then replaces an already-loaded graph; a failed load leaves the previous graph loaded.
