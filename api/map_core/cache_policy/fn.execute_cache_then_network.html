Expand description

Executes the cache-then-network policy:

  1. Try response_store for request_fingerprint.
  2. On a hit, return it with CacheThenNetworkOutcome::CacheHit.
  3. On a miss, await network_fetch, store with time_to_live_seconds, and return the fresh value with CacheThenNetworkOutcome::NetworkFetch.

A cache write failure never fails the call — the fresh value is returned; storage failures degrade to cache-less operation.
