Module offline_routing_benchmark 

Source
Expand description

Deterministic synthetic graphs for measuring the offline routing engine.

The generators write archive bytes with the same deterministic builder the graph compiler uses, read them back through the same validating reader and index them with [LoadedRoutingGraph::new]. Measurements therefore run over the production graph structures, on reproducible inputs, with no network access.

Cost columns are chosen so both strategies’ heuristics stay admissible: every distance is at least the endpoints’ straight-line distance, and every duration is distance / speed at a speed below the packed column’s saturation limit.

These functions support performance measurement only. Production routing always goes through [crate::offline_routing::a_star_search].
