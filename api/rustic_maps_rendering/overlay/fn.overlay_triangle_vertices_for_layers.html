Expand description

Assembles several ordered overlay layers into one flat clip-space triangle list, scaling every overlay’s declared point/CSS screen sizes by device_pixel_ratio while the shape is emitted rather than cloning a pre-scaled copy of the list.

The layers draw in order: a style-derived vector base list first, then the caller’s own overlays over it — the composition a frame with an installed vector base draws. A layer may be empty, and an empty layer list produces no vertices. The geometry, wrapping, clipping and skip rules are exactly overlay_triangle_vertices’s, whose single-list form is this function with one layer at UNSCALED_DEVICE_PIXEL_RATIO.

§Parameters

  • camera — the pose the overlay shapes are projected through.
  • viewport — the viewport the frame targets, in physical pixels.
  • field_of_view_degrees — vertical field of view of the projection.
  • overlay_layers — the ordered overlay lists to assemble.
  • device_pixel_ratio — the drawing buffer’s device pixels per point/CSS pixel; route and traffic line widths, marker and pin radii and a styled stroke’s offset, gap and blur multiply by it.

§Returns

One flat, non-indexed clip-space triangle list for the whole frame.
