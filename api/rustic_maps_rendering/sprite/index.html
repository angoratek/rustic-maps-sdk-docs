Module sprite 

Source
Expand description

The sprite atlas: a style’s sprite index document and its sheet decoded into one texture the icon pass samples.

A MapLibre style names a sprite base URL. The host resolves that URL through an injected SpriteSource and hands back a SpriteAtlas; the renderer never fetches, so a test binds the URL to committed fixtures and a product keeps the fetch in its own transport. The index follows the published sprite-index format: an object keyed by icon name whose members are the icon’s rectangle in the sheet (x, y, width, height) and the pixel ratio it was authored at.

A malformed index, a missing icon and an icon rectangle outside the sheet all degrade to “no icon” rather than failing a frame: an icon that cannot be sampled is not painted, and the rest of the map (and the layer’s text) still draws.
