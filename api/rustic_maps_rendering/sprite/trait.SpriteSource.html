Expand description

A host-supplied sprite loader: the style’s sprite URL in, the decoded atlas out.

Injection keeps the renderer free of URLs and credentials: a test binds the URL to committed fixtures, an application to its own transport and cache.

§Errors

A URL the source does not serve and a malformed index or sheet report SpriteAtlasError; the frame then draws no icons.
