pub fn with_payload_cache( self, payload_cache: Arc<dyn CachedResponseStore<VectorTileData>>, time_to_live_seconds: u64, ) -> Self

Routes every fetched vector-tile payload through a response store before decoding it, and stores each fresh payload for time_to_live_seconds. A lookup hit skips the network entirely, so a region browsed once is served from the store on a later scheduler.

The store is keyed by the tileset’s declared source name and the tile address; a failing store degrades to network-only operation rather than failing a frame.

§Parameters
  • payload_cache — the store the fetches consult and back-fill.
  • time_to_live_seconds — how long a stored payload stays valid.

pub fn set_compiled_style( &mut self, style_id: impl Into<String>, style: CompiledStyle, )

Replaces the style with an already-compiled plan, keeping every decoded tile. This is the seam a host uses for a style document it parsed itself, and the one Self::set_style calls.

When the incoming style declares a transition (transition at the document root or a *-transition paint block), the outgoing style is kept and the next timed frame starts blending from it; otherwise the change applies immediately. A transition is driven by the frame clock passed to Self::cached_frame_at_time, never by a timer.

§Parameters

  • style — the compiled render plans to install.

pub async fn resolve_frame( &mut self, visible_tile_keys: &[TileKey], style_zoom_level: f64, ) -> VectorBaseFrame

Resolves the base map for the given visible tile addresses and camera zoom level: every missing tile is fetched and decoded once — the misses are fetched concurrently, so the frame waits for the slowest request rather than the sum of all of them — every tile is styled at the camera zoom’s bucket (from the decoded cache when the bucket or the style changed), and the frame’s overlay primitives are returned in tile-address order. A tile that fails to fetch or decode is skipped, counted, and covered by its nearest cached ancestor when one exists; the frame never fails as a whole.

This is the blocking reference path (tests and captures that want a settled frame). A presenting surface instead resolves with Self::cached_frame and lets the returned detached prefetches fill the cache.

Self::resolve_frame with the frame’s monotonic clock, in seconds, so a style change blends over its declared transition instead of applying immediately.

pub fn prefetch_missing_tiles( &self, visible_tile_keys: &[TileKey], ) -> Option<impl Future<Output = usize> + Send + 'static>

Claims every visible tile the cache does not hold and answers the prefetch to spawn detached: it fetches (through the payload cache) the claimed tiles concurrently, decodes them and writes the results into the shared cache, returning how many tiles it delivered. None when every visible tile is cached or already being fetched, so a repaint never starts a duplicate request. The caller presents a Self::cached_frame immediately and lets this run.

The future is cancellable by dropping it: its claims are released, so no address stays in flight forever.

Source

pub fn prefetch_ring_tiles( &self, visible_tile_keys: &[TileKey], ) -> Option<impl Future<Output = usize> + Send + 'static>

Claims the ring around the viewport for a detached prefetch: the eight neighbors of every visible tile at the served zoom, plus each visible tile’s coarse parent (the fallback that covers the area while the detailed tile is in flight), under Self::with_maximum_prefetch_ring_tile_count’s budget.

Parents come first because they can cover a missing child immediately; the rest are ordered by distance from the viewport’s center, so a budgeted plan grows outward instead of claiming a scattered corner. Nothing already cached, failed or in flight is claimed. None when the ring has nothing left to claim, when a visible tile’s own fetch is still running (the view comes first), or when the previous plan ran inside the configured interval.

Source

pub fn cached_frame( &mut self, visible_tile_keys: &[TileKey], style_zoom_level: f64, ) -> VectorBaseFrame

Resolves one frame from the decoded cache alone — never the network: every cached tile is styled at the camera zoom’s bucket (from the styled cache when the bucket or the style is unchanged) and its labels read, an address whose prefetch is running counts as pending, and a recorded failure counts as failed with its detail. A missing address whose ancestor is cached draws that ancestor’s geometry once for the whole area it covers (the raster path’s parent fallback), so the frame paints coarse detail instead of a hole.

This is what a surface draws while a detached Self::prefetch_missing_tiles fills the cache, so a first frame over unvisited ground presents the style’s background or the cached coarse detail instead of blocking on every tile’s latency.

Source

pub fn cached_frame_at_time( &mut self, visible_tile_keys: &[TileKey], style_zoom_level: f64, frame_time_seconds: f64, ) -> VectorBaseFrame

Self::cached_frame with the frame’s monotonic clock, in seconds, so a style change blends from the previous style over its declared transition. The first timed frame after a change starts the clock; the same frame clock keeps the blend advancing until the transition’s lifetime elapses, after which the previous style is dropped.

§Parameters
  • visible_tile_keys — the camera’s visible tile addresses.
  • style_zoom_level — the camera’s fractional zoom for paint evaluation.
  • frame_time_seconds — a monotonic clock reading. A non-finite value applies the change immediately rather than freezing a blend.
Source

pub fn cached_frame_at_time_in_motion( &mut self, visible_tile_keys: &[TileKey], style_zoom_level: f64, frame_time_seconds: f64, motion_graded: bool, ) -> VectorBaseFrame

Self::cached_frame_at_time with the frame graded by camera motion.

While motion_graded is true the camera is mid-gesture (a pan, zoom or rotate by input), so the frame is assembled entirely from what the caches already hold: decoded tiles, styled geometry at the last settled style-zoom bucket, and no label candidates. Styling a tile the camera has newly revealed still happens once, because there is no earlier geometry to reuse; what is skipped is the repeated assembly — the per-bucket restyle a continuous zoom would otherwise pay every frame and the per-tile label extraction plus placement the settled frame resolves. A style transition does not blend on a graded frame for the same reason; it resumes (or completes) at the settle.

The next call with motion_graded false is the settle: it resolves at the camera’s own style bucket and carries the frame’s labels, exactly as a direct Self::cached_frame_at_time at that pose would.

§Parameters
  • visible_tile_keys — the camera’s visible tile addresses.
  • style_zoom_level — the camera’s fractional zoom for paint evaluation.
  • frame_time_seconds — a monotonic clock reading.
  • motion_graded — true while a camera gesture is active.
