Expand description

The signed-distance threshold that draws a glyph’s outline shifted outward by halo_width_pixels, clamped to the field’s border.

halo_width / fontScale is the halo in atlas pixels, and one atlas pixel is 1 / 8 field unit, so the threshold moves down by that amount. The halo quad itself is not inflated: the fragment stage’s lower threshold is what spreads the edge.
