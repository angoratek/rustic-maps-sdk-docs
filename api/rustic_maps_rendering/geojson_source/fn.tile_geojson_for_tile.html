Expand description

Tiles one GeoJSON value for one tile address.

§Parameters

  • json_value — a FeatureCollection, a single Feature or a bare geometry.
  • tile_key — the web-mercator address the geometry is clipped to.
  • options — extent, buffer, simplification and layer naming.

§Errors

A value that is not a GeoJSON object, a missing or unsupported geometry type, or a malformed coordinate reports GeoJsonTilingError. A feature with no geometry is skipped, not an error.
