Module geojson_source 

Source
Expand description

Deterministic GeoJSON tiling at the source boundary.

A GeoJSON source is consumed through this module so downstream buckets, overlays and symbol placement see the same VectorTile feature model a vector source produces. The tiler projects each GeoJSON position through web mercator into tile-local extent coordinates, clips it to the tile rectangle, optionally simplifies it and quantizes it to the integer extent.

§Tiling policy

  • Projection: longitude and latitude convert to normalized world coordinates, then to the tile’s local grid of DEFAULT_TILE_EXTENT units.
  • Clipping: points outside the tile (plus the configured buffer) are dropped; line segments are clipped to the rectangle; polygon rings are clipped with the Sutherland–Hodgman algorithm and re-oriented so an exterior ring winds positively and a hole negatively in the tile’s (x right, y down) grid.
  • Simplification: the Douglas–Peucker algorithm runs on the tile-local float geometry with the configured tolerance. The default tolerance is zero, so quantization to the integer extent is the only loss.
  • Quantization: every surviving coordinate rounds to the nearest integer extent unit, consecutive duplicates collapse, rings with fewer than three distinct vertices drop and line pieces with fewer than two drop.
  • Determinism: features keep their input order, attributes sort by key, polygon rings keep their source order with each exterior followed by its holes, and a generated feature id is a fixed FNV-1a hash of the feature’s canonical JSON. The same collection and the same tile address therefore always produce a byte-identical tile.

The module is pure CPU and JSON: it never fetches, reads a clock or uses a hash map whose iteration order could leak into the output.

Constants§

DEFAULT_GEOJSON_BUFFER_PIXELS
The default clipping buffer, in extent units. A style’s source buffer overrides it; zero keeps a feature in exactly one tile and makes the tile set a partition of the input.
DEFAULT_GEOJSON_SIMPLIFICATION_TOLERANCE
The default Douglas–Peucker tolerance, in extent units. Zero disables simplification.
DEFAULT_GEOJSON_TILING_EXTENT
The default tile edge, in extent units.
GEOJSON_MAXIMUM_MERCATOR_LATITUDE_DEGREES
The latitude beyond which web mercator is not finite.
GEOJSON_TILE_LAYER_NAME
The name of the implicit tile layer a GeoJSON source produces. A GeoJSON style layer reads it without a source-layer.
