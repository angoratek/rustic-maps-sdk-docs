Expand description

The number of tile fetches one warm pass or blocking frame keeps in flight.

A viewport holds a dozen or more tiles, so a serial pass spends most of its time waiting on one round trip at a time and the map fills in visibly tile by tile. Eight concurrent fetches fill a normal viewport within one provider round trip while staying inside what a public tile service and a browser’s per-host connection pool comfortably serve; the provider’s token bucket is sized to match (DEFAULT_TOKEN_BUCKET_CAPACITY_TOKENS and DEFAULT_REFILL_TOKENS_PER_SECOND in the URL-template providers).
