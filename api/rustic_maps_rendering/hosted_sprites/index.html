Module hosted_sprites 

Source
Expand description

Sprite sheets for a hosted vector style, fetched through the provider’s authenticated style-resource client.

A style document published by a tileset’s provider names its sprite by a base address; the sprite protocol resolves the index document at <base>.json and the sheet at <base>.png. Both are served only to a request carrying the provider’s credential, so the fetches go through StyleResourceClient and the credential never reaches this crate. The base resolves against the style document’s own address, exactly as a glyph template does, and the resolved address must land on the document’s origin or on a host the provider declared: any other host is refused before a request is made, because a style document must not be able to aim the provider credential at a host the provider did not declare.

The sheet is decoded here because the renderer’s SpriteSource is synchronous: both install paths prefetch once and hand the decoded atlas to the scheduler. The PNG decoder builds on every target, so the native surface and the browser canvas resolve a style’s sprite the same way.
