Expand description

Fetches and decodes the sprite sheet a hosted style names.

§Parameters

  • style_resources — the provider’s authenticated style-resource client.
  • style_document_url — the style document’s address, whose origin and directory bound both sprite requests.
  • sprite_url — the document’s sprite value, the base address the protocol resolves the index and the sheet from, either absolute or relative to the document’s own address.
  • declared_hosts — the hosts the provider declared for its published style resources; the base may live on any of them as well as on the document’s own origin.

§Returns

The decoded atlas, ready for the scheduler’s per-URL sprite cache.

§Errors

Returns SDKError::ResponseParsingFailure when the base address does not resolve to an absolute http/https URL, or when the index or sheet cannot be fetched or decoded; SDKError::ProviderRequestRejected when the resolved base names a host that is neither the document’s origin nor one the provider declared.
