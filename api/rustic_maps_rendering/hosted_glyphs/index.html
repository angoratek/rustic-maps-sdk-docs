Module hosted_glyphs 

Source
Expand description

Glyph ranges for a hosted vector style, fetched through the provider’s authenticated style-resource client.

A style document published by a tileset’s provider names its glyph endpoint as a template (…/{fontstack}/{range}.pbf). The ranges are only served to a request carrying the provider’s credential, so the fetch goes through StyleResourceClient and the credential never reaches this crate. The template resolves against the style document’s own address, and the result must land on the document’s origin or on a host the provider declared: any other host is refused before a request is made, because a style document must not be able to aim the provider credential at a host the provider did not declare.

Decoded ranges are retained in a GlyphRangeCache keyed by the provider’s namespace, the font stack and the range, so two providers serving the same font-stack name never share a range and a repeated frame costs no request.
