Crate rustic_maps_rendering 

Source
Expand description

GPU map rendering: camera model, raster tile scheduling with parent fallback and a texture pool, vector-tile styling (fill, line, circle and symbol layers), overlays, and location indicators.

The crate separates scene composition from GPU execution. Projection, camera math, tile scheduling, overlay and label assembly, and the quad assembly in renderer are free of wgpu types, so they build and run on every target, including WebAssembly. The native headless and surface renderers consume that composition and submit it to a wgpu device. On WebAssembly the host page drives WebGPU and consumes the same vertex and style contracts through the wasm bindings.

labels
The frame-level label pass: symbol-layer text from decoded vector tiles becomes screen-space glyph quads, anchored at a point for place and POI names and run along a line for road names.
location_indicator
GPU-free location-indicator assembly: the position fix drawn as a screen-facing two-mode puck over its optional ground-projected accuracy ring, in the same clip-space stream pattern the overlay layer uses (see crate::overlay).
overlay
GPU-free overlay assembly: route polylines, filled polygons, point markers, and traffic-flow lines projected into clip-space solid-color triangle lists drawn over the tile quads.
prefetch
GPU-free predictive prefetch planning: the bounded tile set a caller warms ahead of motion so the pool covers the camera’s next poses.
projection
Web-mercator projection: geographic coordinates, normalized world space, and the XYZ tile grid.
renderer
GPU-free frame assembly: prepared tiles mapped to drawable quads.
source_binding
The provider seam between a style document’s abstract sources and the tiles a provider fetches.
sprite
The sprite atlas: a style’s sprite index document and its sheet decoded into one texture the icon pass samples.
surface
Surface rendering of raster tiles plus overlays onto a live native window: the same scene composition as the headless renderer, presented through a real wgpu::Surface.
tile_key
Web-mercator tile identity shared by the projection, scheduler, and pool.
tile_scheduler
Frame-driven raster tile scheduling with parent fallback.
tile_texture_pool
Least-recently-used pool of encoded tile payloads awaiting GPU upload.
vector_base
Shared vector-tile base pipeline: one scheduler that fetches a vector tileset through the VectorTileProvider trait, decodes each tile once, styles it, and answers the overlay primitives the frame draws beneath its own overlays.
vector_style
Vector-tile styling: a decoded rustic_maps_vector_tiles::VectorTile becomes the renderer’s overlay primitives under a compiled style plan.
zoom_transition
Cross-fade between adjoining tile zoom levels.
