Vector-tile styling: a decoded rustic_maps_vector_tiles::VectorTile becomes the renderer’s overlay primitives under a compiled style plan.

The style document and its expressions live in rustic-maps-style; this module is the renderer’s consumer. vector_tile_style_from_id parses a committed version-8 style document and compiles it once into a CompiledStyle. Each frame then resolves the compiled plan at the camera’s fractional zoom, so paint expressions change continuously with the camera without re-parsing the document.

Polygon features paint every exterior ring with its interior rings subtracted through the overlay’s hole-aware fill (see crate::overlay::FilledPolygonOverlay); line features become styled polylines and point features become screen-facing markers. Primitives are grouped into one VectorOverlayBatch per style layer and one bucket per layer in vector_tile_overlay_layers_at_zoom, so a frame can paint every tile’s layer 0 before any tile’s layer 1: global style order across the visible tile set.

Coordinates convert from tile-local extent space (x right, y down, the MVT convention) through the tile’s web-mercator address to geographic degrees, so the overlays project exactly like every other map coordinate.

Symbol layers paint no overlay primitive: their labels are data for the frame-level label pass (crate::labels), which reads the same compiled plan, filter and layout.
