# rustic-maps-sdk-docs

Public documentation site for the **Rustic Maps SDK** — a native map SDK in Rust
with UniFFI bindings for Android, iOS and React Native, and a first-class
WebAssembly target.

## What lives here

- `main` — the rebuildable site sources (`site/book.toml`, `site/book-src/`),
  produced and maintained in the SDK's private source repository.
- `gh-pages` — the rendered site, **never hand-edited**: every render is
  generated by the private repository's build pipeline (mdBook + rustdoc + the
  frozen UniFFI contract) from one named source commit and pushed as a whole
  tree. Each render carries `provenance.txt` with the source commit and the
  gate assertion.

The rendered site is served at
`https://angoratek.github.io/rustic-maps-sdk-docs/` once the first render is
published.

Sections are exposed only when the pipeline that produces them is green; the
site is built by a fail-closed pre-publish scrub (no secrets, no private
paths, no key-shaped literals).
